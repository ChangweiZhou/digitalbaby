# MiniFly V199 — Round 8 Reproduction

Thirty jobs produced 48 scored rows across Python hash seeds 0, 1 and 2. The original hash seed was unavailable.

The probability-space predictor scored 2.491–2.494 bits/byte under the original online protocol and 2.640–2.646 with weights frozen on the scored segment. Markov-3 scored 2.674. The original predictor protocol updates on each scored byte after predicting it.

With the trained query template, two-hop accuracy was 93.8–97.7% under the original scoring and 93.8–96.1% when the first hop had to generate the exact intermediate key and its own period. The unseen remember template scored 35.9–55.5% under the original rule and 0–0.8% under the strict rule. The tell-me template scored zero in both cases. The original loop strips the last generated byte even when that byte is not a period. The composition loop is engineered.

## Reproduction

Install NumPy and run `ROUND8_ALICE=/path/to/pg11.txt OPENBLAS_NUM_THREADS=1 python -B reproduce.py`. Use the Project Gutenberg eBook 11 plain-text file and verify its SHA-256 against PLAN.json. The recovered source and original two-hop log are included, so the original session export is unnecessary for reruns.
