# VALUE-INTERACT — 三循环准备结果

**资格：通过，正式科学实验未启动。** 目标仍是用更少样本与计算获得并保留未见四则题的完整自主字节输出能力。当前采用的核心没有改动。

## 三次循环

| 循环 | 审核与实际试跑 | 修订与结果 |
| --- | --- | --- |
| 1 | 全14组参数的有限差分；8项功能测试；四配置各1024条固定记录的共享单支路测试 | 抓到并修复加性梯度数组别名。四配置均完整输出 A、BC、-7、12、49 和自身EOS。 |
| 2 | 28项单元/篡改测试；五配置完整技术世界，每个W/N_ALL/SHUFFLE | 加入优化器与辅助路径逐事件审计、探针工作状态恢复。5任务全部接受。 |
| 3 | 最终34项测试；修订后的独立技术世界；两个脱离进程的工作进程；暂停/恢复、分析、报告、打包 | 消除共享诊断的哈希访问；补齐预测值、辅助损失与前缀覆盖收据；立即拒绝非有限状态。5任务全部接受；暂停前2任务收据未重复或改动。 |

失败记录和早期实现保留在各循环目录。最终源锁匹配的任务是5个、15条相关历史、7680次记录应用。各次准备版本合计16个完整技术任务；均不计入正式统计。固定已教输出夹具也不是四则泛化证据。

## 固定比较与限制

- 配置：BYTE-ADD / VALUE-ADD / BYTE-PROD / VALUE-PROD / LEGACY-B。
- 未改变家族留出、负数、新答案字符串、预算点或完整回答+EOS评分。
- 实际答案的数值只在观察EOS时提供辅助损失。推理仅使用模型自己的预测值；SHUFFLE使用实际打乱后的答案，N_ALL禁写包括优化器二阶矩与step。
- 82项预声明比較保留；因素CPU比较使用四配置共同区间，旧基线比较使用两配置共同区间。正式区间需要48个完整配对世界；缺失不可改用较小样本集。零方差使用有界区间。
- 加性/乘积和数值辅助的因素可分别比较；共同的直连、独立分支训练、周期先验与优化器只能作为整体工程方案评价。
- 公开的十进制周期先验和观察答案词法解析仍是工程先验；本轮不是原生Full151验证，也不验证混合表达式或任意精度。
- 字节接口接收任意0–255 payload，独立EOS；窗口4096事件，输出上限16字节。非整数答案仍能训练字节头，只关闭数值辅助。

## 待授权的正式运行

48个新世界 × 5配置 = 240任务，720条相关历史，368640次记录应用。数值辅助预期98304次。两个工作进程、单线程BLAS；8小时停止接纳，10小时硬边界，不自动重跑或恢复失败。

完整技术任务测量的线性估计为 **39.2分钟**；规划范围约 **39–59分钟**，不保证实际墙钟。来源和逐配置CPU/RSS见[RUNTIME_ESTIMATE.json](RUNTIME_ESTIMATE.json)。
