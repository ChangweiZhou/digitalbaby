# VALUE-INTERACT：数值辅助约束 × 可学习特征交互

2026-10-12，设计 V1。状态：**设计已交付，尚未实现，尚未完成三循环，未授权启动科学运行。** 配置、训练预算、评分、比较项和准备边界见同目录 `DESIGN.json`；静态审查见 `DESIGN_REVIEW.md`。

目标固定：同一个有限状态核心，用更少的外部训练示例和计算，获得对未见四则题的完整回答能力，并在随后学习其他运算后保留它。保持任意字节接入、模型自己的多字节输出和 EOS。四则混合表达式仍是后续步骤；本轮不改成噪声优化、记忆扩容、NLP或Q&A。

## 1. 本轮问题和可检验假说

ADAPT-2 完成 48 世界、240 任务、720 条相关历史，审核接受，判定 `NO_CONFIRMED_REPLACEMENT`。表示可学比匹配冻结版本有小幅样本曲线增益，但未形成可靠四则泛化；新适配器的已教题获取和跨运算保持也弱于原基线。

复核支持以下边界：题面最长 5 字节，共同特征可以看到前 8 字节；没有证据说明缺少递归或长程输入是主要原因。原成功加法核心学习连续数值并采用顺序数字读出，当前模型改为字节类别学习，不能继承旧加法成绩。跨四运算统计，18.4% 的未见加法题、69.3% 的未见乘法题要求生成训练中未出现过的完整答案。它们是保留的挑战，不作为排除项。

本轮假说是：**稳定感知直连、与精确记忆分开训练的共享支路、学习型数值读出底物，可以形成一个更合理的共同比较起点；在此起点上，数值辅助约束和可学习特征乘积分别可能提高未见题样本效率。** 这些均是待检验假说，不是已定位的充分原因，也不保证当前预算能学会四则。

两因素完整交叉：辅助数值目标有/无；相同参数数量的特征组合采用加和/乘积。另保留原基线。新共同底物的收益由对原基线的比较衡量；因素比较不能把共同底物的收益归到某个开关。

数值辅助目标只在实际答案及 EOS 已观察之后，由收到的答案字节派生。它提供**工程化数值先验和另一种训练损失**；相同外部字节不代表相同归纳偏置。辅助因素的收益指这一整体训练改动，不能进一步宣称已排除正则化或梯度分配作用。

共同读出还明确采用十进制周期特征，作用于模型自己预测的连续数值；全部四配置获得相同特征。它是共同底物的格式先验，不是第三个随机挑选的候选，不单独获得因果功劳。它不执行除法取位、取整、取模、字符串格式化或正确答案查询；257 类读出权重从观察字节学习。

不增加算术题面解析器，不传入运算ID、操作数、真实结果、期望长度或候选答案。模型没有加、减、乘、除的预写计算函数。所有输入载荷仍可为 0..255。输出始终来自可塑字节头；任何数值正确但字节错误的响应仍计错。

M001/M007 递归版本继续保留在账本中，本轮不测试，也不据本轮结果排除。生物局部性不是本轮通过条件；不得把手写 NumPy 反传称作无反向传播的局部学习。

## 4. 保留任务、样本和泛化难度

原样复用 ADAPT-2 家族生成规则，仅换新世界种子。a、b 为 0..7。SUM 和 PRODUCT 各有 36 个无序种子家族，其中 24 教学、12 留出；留出从 2≤a≤b≤7 的 21 个非平凡家族抽取。每个家族的交换式及逆式一起教学或一起留出。

| 家族 | 教学或留出的整个集合 |
| --- | --- |
| SUM(a,b)，s=a+b | a+b=s、b+a=s、s−a=b、s−b=a、a−s=−b、b−s=−a，去重 |
| PRODUCT(a,b)，p=a*b | a*b=p、b*a=p；a>0 时 p/a=b，b>0 时 p/b=a，去重 |

答案是规范十进制整数串：加法到 14，乘法到 49，减法含负数，除法为精确整数逆式。每个配置每条历史最多 128 条记录/运算，共 512 条。预算点每运算 4/8/16/32/64/128，即全历史累计 16/32/64/128/256/512 条。

每个预算增量按原平衡轮换顺序依次学习四个运算块。题池打乱整轮循环，与模型表现无关。所有配置接收相同记录；不得多给候选独特题、同家族逆式或格式热身。

不增加预训练、数字输出暖身、噪声、回放、进化搜索或额外优化循环。保留原字符覆盖检查；完整答案未在训练中出现不是缺陷，也不据此重抽世界。每个前缀分别报告独特题、重复题、已覆盖家族、输入字符、输出字符、完整输出串。

每块及每预算点结束只读评分。最后推进模拟 86400 秒再评分；本设计权重不随时间衰减，这一步为公开的无操作，不称为巩固。保持的实际压力来自后续其他运算的写入。

## 5. 通用接口、共同特征和观察时序

沿用独立 BEGIN/REPLY/EOS 控制；全部 256 字节为载荷，包括 LF、NUL、空格、`=` 和无效 UTF-8。上下文上限 4096 事件；生成最多 16 个载荷字节，未选择 EOS 则明确 `TRUNCATED`。本科学题面≤5字节，这不声明获得长表达式能力。

共享即时输入 h 为原 `LegacyCore._features()` 的 96 维固定特征：前八字节位置的 8 维随机嵌入、对应 ASCII 数字值/9、回复偏移、前一个回复字节嵌入和其余窗口的顺序摘要。数字感知先验所有配置相同，不隐藏。

问题输入 h0 取同一特征构造的 prompt-only 版本，回复偏移和前一个回复字节分量置零。它不得包含实际或生成答案；按当前有效窗口重算，不能用永久缓存保留退出窗口的问题字节。工作元数据不含评估器标签。科学短题中 h0 在回复期间不变。

每个真实回复字节及真实 EOS 都先用旧状态预测，再从观察产生损失和更新，最后推进工作状态。生成只推进临时上下文，不运行观察更新、数值辅助更新或优化统计。真实教学回复前缀只能作为已到来的过去字节参与下一字节训练，不能把完整未来答案提前交给核心。

## 6. 固定结构和精确训练规则

以下是 V1 固定工程配方；尚未宣称最优或已通过技术资格。共同共享宽度 64，交互秩 16，字节头隐藏宽度 64。连续数值头和周期读出存在于所有四配置，即使辅助约束关闭。

```text
x = sqrt(96) h0
p = tanh(B x + bB)                      B:16×96
r = tanh(C x + bC)                      C:16×96
s = (p+r)/sqrt(2)                      ADD
  或 p⊙r                              PROD
sbar = s/sqrt(mean(s²)+1e-6)
f = tanh(A x + E sbar + b)              A:64×96，E:64×16
v = 16 (wᵀ f + bv)                     w:64；模型预测值，允许为非整数

phi(v) = [v/16, sqrt(v²+1e-8)/16,
          sin(2πv/10), cos(2πv/10),
          sin(2πv/100), cos(2πv/100)]
d = concat(h, f/sqrt(64), phi(v)/sqrt(6))  d:166
t = tanh(D d + bD)                     D:64×166
z_shared = Rᵀ h + Vᵀ t + c            R:96×257，V:64×257
z_total = z_shared + 0.25 z_memory
P_total = softmax(z_total)             256载荷类别+EOS
```

周期 10/100 是公开十进制格式先验，尺度 16 是固定数值学习单位。模型输入不给真实 v；上述 v 仅由当前问题和学习参数产生。输入任意非算术字节也执行相同前向，不启用一个知道当前任务的分派器。保留直连 Rᵀh，使字节位置和 EOS 信息不必全部穿过变化的内部表示。

精确记忆复用 `ByteCore` 的 4096×257 float32 数组、16 接触、完整有序窗口地址、读取 z_memory=ΣW_i。它独立拟合实际观察字节：

```text
P_memory = softmax(z_memory)
W_i += (4/16) [onehot(event)−P_memory]   对16个接触
```

共享支路也独立从每个实际回复事件学习，不因精确记忆已经答对而失去训练信号：

```text
L_byte = −log softmax(z_shared)[event]
L_value = 0.5 [(v−y)/16]²              仅真实EOS、有效观察整数、VALUE配置
L = L_byte + L_value                   其他情况 L=L_byte
```

两支路的预测都必须在观察事件加入上下文之前产生。EOS 时 L_byte 和 L_value 的所有方向从同一个更新前参数状态计算，然后一次更新共享参数。数值目标 y 不进入字节头的前向，也不以 y 替换 v。记忆梯度使用独立记忆概率，不存相对于共享支路的残差。固定 0.25 混合不按题类、熟悉度或真实标签改变；共享预测仍可能干扰整个系统的已教题表现，这属于实验结果。

共享全部参数采用同一个有偏差校正的指数二阶矩归一化更新。令 g 为 L 对全部共享参数的联合梯度，先令 g←g·min(1,1/||g||₂)，零梯度不除零；然后：

```text
step += 1
M = 0.99 M + 0.01 g²
Mhat = M/(1−0.99^step)
theta -= 0.001 g/(sqrt(Mhat)+1e-8)
```

每个观察字节/EOS 恰好一次共享优化步骤，不做隐含多次拟合。辅助损失增加该次反传内容，不增加外部记录或优化步骤数。M、step 是持久学习状态，纳入禁写与恢复审核。禁写事件不衰减 M、不推进 step。固定学习率是新工程配方，不能引用旧 .6/.025 的不同损失版本为其数值依据；正式数据后不调参。

出生：固定字节嵌入沿用共同子流；A/B/C/E/D 独立高斯子流，标准差为输入维度平方根的倒数；内部偏置、w/bv、R/V/c、W、M、step 初始零。对应数组四配置数值一致、对象独立。内部学习参数 62,466 个 float64；M 同尺寸。加和和乘积配置参数数相同、实际计算和梯度不同，按真实成本计费。

不使用固定取整或数值→字符串输出函数。即使 v=正确整数，字节头输出错或没有 EOS 仍错。记录 v 仅作解释，不能替代正式正确率。

## 7. 数值辅助目标的产生和边界

核心仅对实际观察的回复维护一个有界临时整数词法状态。接受规范 `0`、无前导零的正整数、或 `-` 后接非零首位的负整数；禁止 `+`、`-0`、空串、空白、嵌入控制字节和其他二进制。数值幅度超过 1,000,000 时关闭该记录的辅助损失。**这些字节及更长回复仍正常接入和进行字节学习，不能被辅助解析器拒绝。** 词法状态用有界计数和溢出标记，不保存历史答案表。

只有真实观察 EOS 才把完整、有效回复解释为 y；此前字符不触发辅助更新。状态从实际收到的回复建立，推理生成的字节和 EOS 不属于该观察状态，也不能触发它。非整数观察仍训练普通字节通路。

SHUFFLE 的 y 必须来自它实际收到的错配答案串，不能从原正确答案取值。N_ALL 可临时接收同一串，但不得更新数值权重、二阶矩、学习计数或影响未来输出的统计。审核日志记录目标来源、就绪时刻、可学许可和辅助有效性。

## 8. 因果历史、暴露和反模型

每个世界配置运行三条出生相同、可变对象独立的历史：W 正确观察学习；N_ALL 同字节、同边界、同时间但所有持久学习禁写；SHUFFLE 在每运算预算增量内固定排列整个答案串，保持字符、长度、答案频率及数值频率。

W/N_ALL 禁写差异覆盖精确记忆、所有共享连接、数值头、字节头、M/step及任何可塑辅助统计；不能只关闭某一个分支。排列固定点如实保留。所有探针只读，首次未见题回答先于任何该题反馈。

暴露审核覆盖整个交换/逆式家族，不仅字符串去重。报告精确表、交换/逆式事实表、常见答案、仅左/右操作数快捷模型在同实际前缀上的得分。未知项弃答，不能从测试标签填表。评估器算术函数是可解性见证，禁止核心导入或调用。

现有已教记忆和旧专用加法提供局部阳性证据，但不存在已确认能通过整个新四则任务的低样本通用核心；报告不能把 E1 阳性或数学可解性见证称为学习型 E3 阳性。负面结果只能否定本配方在所测预算中的增量，不宣布四则不可学习或机制家族死亡。

最高证据为此有限四则范围的 E3，含其他运算写入后的保持。已教为 E1；没有呈现改变 E2、混合表达式、无教学信号自主学习或E4结论。

## 9. 固定测量目标和统计清单

每个预算点，四块全部学习完成后的未见题完整回答+EOS正确率为 A_o(n)；四运算等权宏平均为 A(n)。主样本指标保持原 log₂ 面积：

```text
J_samples = [A(4)/2 + A(8) + A(16) + A(32) + A(64) + A(128)/2]/5
```

逐运算同式。已教准确率、块刚结束的未见准确率、块后同运算损失、预测数值误差、首字节/整数格式/EOS错误、完整答案是否见过均报告，但不替换主终点，不筛掉新答案、进位或负数。

J_cpu 使用实际训练 CPU 的公共 log 区间积分，每个世界分别建立区间。候选对 LEGACY-B 的比较使用该对配置在4样本CPU的较大值到128样本CPU的较小值。**因素和交互的全部CPU比较使用四个新配置共同的同一个区间**：下端为四者4样本CPU最大值，上端为四者128样本CPU最小值。不能把不同配对区间上的两个差再相减冒充CPU交互。区间无交集标 `UNAVAILABLE`，不能看准确率后选区间。不用不同公共区间上的绝对面积给多个配置排序。

在每个有效 [L,U] 上，对六个点之间的准确率沿log(CPU)线性插值，再计算 `J_cpu = ∫_L^U A(c) dlog(c) / log(U/L)`，因此每个配置的J_cpu在[0,1]。L≤0或U≤L均不可用，不加人为CPU平移常数。

CPU 包含记忆更新、直接字节读出、共享前向、数值词法、周期函数、全部反传和二阶矩；记录损失、梯度范数、裁剪事件和优化步数。另计只读评估、状态复制、审核、序列化、打包和全任务墙钟。外部记录、独特题、回复字节、EOS及派生数值目标数分别报告；辅助目标不是新的外部样本，也不算免费计算。模拟休息无生物巩固结论。

统计单位是 48 个配对世界。一个世界内题目、检查点、运算及三历史都相关。固定共 **82 项**两侧 Bonferroni 家族95%配对世界区间：

| 比较 | 数量 |
| --- | ---: |
| 四新配置各对 LEGACY-B 的宏 J_samples、J_cpu | 8 |
| 四个条件因素差及一个交互，各对 J_samples、J_cpu | 10 |
| 四新配置×四运算，最终 W−N_ALL、W−SHUFFLE | 32 |
| 四新配置各对 LEGACY-B 的逐运算 J_samples | 16 |
| 四新配置各对 LEGACY-B 的最终未见准确率 | 16 |
| 合计 | **82** |

条件因素差：VALUE-ADD−BYTE-ADD、VALUE-PROD−BYTE-PROD、BYTE-PROD−BYTE-ADD、VALUE-PROD−VALUE-ADD。交互：(VALUE-PROD−BYTE-PROD)−(VALUE-ADD−BYTE-ADD)。不能由“一组显著、另一组不显著”代替交互比较。

有限且世界差标准差>0时使用配对 t 区间，尾部概率 0.05/(2×82)。零方差不伪造总体等价：普通成对差在[-1,1]，使用半径 `sqrt(2·ln(2×82/0.05)/48)` 的有界 Hoeffding 区间；两个差再相减的交互在[-2,2]，半径是上述值的两倍。区间分别与对应界相交。J_cpu经长度归一化后采用相同规则。CPU不可用或非有限项单列，不缩小82家族。保留全部世界差和未校正描述性区间。

正式比较需要48世界的完整对应数据。某CPU比较有世界缺失有效公共区间时，整项正式结论为 `UNAVAILABLE`；可以报告有效世界的描述性结果，但不删除缺失世界后冒充原48世界确认，也不据该子集采用核心。

没有80%/90%绝对准确率门槛，也没有临时 −5pp 无损豁免。增量边界为零；微小统计增量仍须按其绝对能力报告，不叫掌握四则。

## 10. 结果判定、建议采用及停止规则

机制结果：相应因素 J_samples 的校正下界>0，支持该工程因素提高样本效率；J_cpu 独立判断。交互只有自己的区间支持才成立。共同 BYTE-ADD 对 LEGACY-B 的改进不能细分归因为直连、解耦训练、周期特征或优化器中的某一项。

有限能力：某运算最终 W−N_ALL 和 W−SHUFFLE 两个下界都>0，支持它在该范围内的 E3；四个运算均成立才报告四则范围的保留泛化。不能把未学会导致无遗忘当持久能力。

整体工程配方建议采用，需同时满足：

1. 相对 LEGACY-B 的宏 J_samples 和 J_cpu 下界均>0。
2. 四运算最终两个因果比较均成立。
3. 四运算 J_samples 及最终未见准确率相对 LEGACY-B 的下界均≥0。
4. 最终已教题逐题、逐世界的正确集合覆盖 LEGACY-B 的正确集合，即没有在其答对的已教题上新失误。该项为保守的**观察性保护检查**，不是总体零损害等价证明；单列更强或更弱的已教能力。

如有多个配置通过，按预声明的最终四运算宏准确率较高、再 W 训练CPU中位数较低、再总持久数组字节较少、再名称排序选择；完整报告所有通过者。这不是根据不同 CPU 积分区间排序。建议采用是此范围工程推荐，不自动修改用户已采用核心。

只改善部分运算、只省样本但多用计算、或尚未保留的结果按真实范围报告。`NO_CONFIRMED_REPLACEMENT`、`PARTIAL_MECHANISM_GAIN`、`COMPUTE_UNRESOLVED` 都是有效结束；不自动加宽、扩样、改辅助权重、移除困难题、替换输出头或再开补丁轮。任何下一轮需解释本轮实际缺口并重新获得授权。
