## What stays and what the result changes

Keep observed-vector initialization and inactive capacity, normalized M3 profiles and validation-only class selection, actual-density causal frame calibration, raw-bit access and finite generic relative registers. The executed repairs removed observed M2 aliases. Do not spend another round merely forcing a semantic class partition or higher component score.

Keep the completed R2 states/results as the comparison. Exact taught acquisition is still an important unresolved part of this dose/encoder combination. A failed own-output answer is not explained by held-out difficulty alone. A one-event directional response is not dose qualification. A native-allocation arm that also fails cannot justify blaming the strict gate alone.

The current D0 also spends thousands of correct-answer observations while native writes are disabled. This is representation formation, not end-to-end arithmetic pretraining. A later joint-warmup arm could let actual expected bytes teach the operative native path as learned address gates become usable, with small increasing coefficients and a matched delayed-write control. That is a separate generic developmental intervention, not a claim that R2 already performed it. Any moving-address effects must be measured and every observation still charged.

## Next bounded diagnostic before another large experiment

1. **Measure the real input-to-value influence matrix.** On the same allowed OLD prompts, save each *prefeedback* frame and its active support. On private zero-value states, apply one declared small signed native event at frame j and read every frame i. Measure the per-channel influence matrix, diagonal versus cross-input response, numerical rank/effective condition and saturation. Compare this with the already measured actual active overlap. Use both signs, passive controls and the same physiological reference. These are technical native perturbation events, counted separately; no new answer lookup or arithmetic feature enters the learner. A useful diagonal must be measured rather than inferred from 65,536 cells or stable input codes.
2. **Instrument the existing complete learning path.** Before each write, retain native/reference margins, target-sign agreement and applied residual per compartment. Before record completion, count mixed signs, repeat/spacing suppression, pre-event eligible q and actual slow allocation. Log format-common versus input-varying target statistics only in the evaluator; these labels never feed the model. Record per-phase CPU and explicitly include private evaluation copies/sweeps. This requires a new prospective source lock; it is not a reanalysis that invents missing R2 counters.
3. **Choose a single justified intervention prospectively.** If influence is nearly shared across different prompts, test one generic KC connectivity/competition change against the retained repaired encoder, with matched N, information and actual CPU. Do not add operand slots, digit values, carries or arithmetic relations. If influence is selective but too weak, qualify a gradual feedback schedule using actual native margin/dynamic-range measurements on training-only frames; lock it before any held score, preserve the cap and include it as a separate arm. A stronger arbitrary learning-rate grid is not the default answer. If one taught item can be acquired but interleaved items interfere, a generic blocked-to-interleaved **data order** comparison may isolate that issue while retaining the same facts, totals and held endpoint. Do not combine all these changes into an uninterpretable new kernel.

A future engineering run should retain the R-W/A-W/no-OLD-write/shuffled controls where needed for attribution, the same addition range, global held exclusion before every listening stage, own-prefix EOS scoring, OLD/rest/NEW/rest chronology, and D0/repetition/CPU charging. Use taught acquisition to localize the failure, never to replace the unseen-addition endpoint.
