## Changes made to the attachment's suggested sequence

1. Return the new tests to the same bounded addition data. The completed text result motivates a hypothesis; it does not authorize a new NLP campaign or supply an arithmetic result.
2. Factor permutation and the actual historical decay constants. Keep read-time normalization and control timing fixed, avoiding a hidden amplitude or timing change.
3. Treat probe accessibility as conditional on a finite decoder and optimizer. A decoding gap alone cannot prove information was destroyed. Add exact conflicting-target collision checks.
4. Match full versus full and C16 versus C16 when comparing online/batch updates. Native uses a different reachable state/update family even at the same output codebook; its gap is not automatically a pure local-rule gap.
5. Keep external linear fits as evaluator instruments, with no native write/read path and no E3 candidate role. They do not become an ELM kernel or an external answer module. Native-only answer evidence remains the endpoint.
6. Use zero explicit bias in the primary matched readout/native comparisons. This is an experimental control, not a claim that bias is intrinsically defective. Diagnose the existing q path separately, without changing trained weights.
7. Use old checkpoints for C before considering new Q0 training. An evaluation ablation and a full training intervention answer different questions. No Q0 trajectories are launched by this design.
8. Remove the failed-reference veto on native measurement. Report each native group's acquisition and retention even when a diagnostic solver or checkpoint lane is unavailable.

## Claims kept separate

No part of this design asserts that FE0 solves addition, that R1 gives an absolute representability ceiling, that q has been proven to cause EOS collapse, or that local rules as a family failed. V150, V151 and V152 were different systems/tasks/interventions and do not form a single controlled causal chain.

No new mechanism is selected from the 254-entry register. Oja, biased sampling, KC clocks and broader feedback changes remain deferred pending a measured need. The existing register and its scope-specific exclusions are unchanged.
