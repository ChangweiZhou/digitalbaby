# 有限加法观察支持方向恢复实验设计

2026年10月11日，设计稿V1。目标是用更少带噪或缺失答案的外部样本，提高自身输出对未教过加法组合的正确率，并保留旧知识。本稿细化一个U034移植版本；它不是已通过资格化的实验，也不授权运行。当前开发核心仍是用户采用的COV-SUPPORT，确认锚点是COV-R。

## 版本依据与选择范围

完整机制与版本资料已发布到GitHub提交`1e4709c`，见[版本复核](../PROJECT_DOCUMENTS/MECHANISM_SCREEN_20261007/VERSION_REGISTER_20261011/REVIEW.md)和[当前候选](../PROJECT_DOCUMENTS/MECHANISM_SCREEN_20261007/CURRENT_TEST_SHORTLIST_20261011.md)。249是程序和版本记录数，不是独立候选或存活数。

本次检验的假说是：有限、受观察支持的方向恢复，可能改善完整相关更新对后续少样本组合的学习。现有数据没有证明P收缩是当前瓶颈；P是算法状态，不是已校准的噪声后验。V23全局bayes_reopening弱于其stable版本，V31有限horizon MESU的总体结论未决，这些不构成本版本有效的证据。

选择先操作化本版本，是因为可以保持一次外部观察对应一次权重更新，并给恢复次数和恢复总量明确上限。没有证据表明它比U047信息互补回放更有希望。U047仍需与已经测试的残差优先REPLAY-P、均匀REPLAY-U及COV-REPLAY区分；本稿不加入回放、换边、第二输出器或联合机制。

## 五个固定配置

| 配置 | 操作 | 角色 |
| --- | --- | --- |
| COV-R | 已确认的完整相关鲁棒更新 | 科学锚点 |
| COV-SUPPORT | 用户采用的观察支持写门 | 当前开发基线 |
| SUPPORT-DIR | SUPPORT加观察支持方向恢复 | 唯一可选择候选 |
| SUPPORT-RAND | 同样资格、时刻和总量，随机方向恢复 | 方向内容对照 |
| SUPPORT-ISO | 同样资格、时刻和总量，均匀分配到31维 | 全局恢复对照 |

RAND和ISO不能因结果较好临时晋级。诊断结果用于解释方向选择，而不产生第二个可选择候选。所有候选和对照使用相同输入、先验、输出、出生w/P及因果权限。

## 保持现有任务与信息边界

沿用[U042最终设计](../addition_observation_support_v1_design_20261011/EXPERIMENT.md)的任务生成、反馈分布、共享前缀、检查点及曝光审计，不修改旧实验。15个字节身份、左/右角色和常数构成31维特征，每个题面激活三个坐标；w出生为0，P为10I。核心只能收到题面、时钟、实际到来的答案及因果写入权限，不能获得隐藏数值映射、真值、噪声类别或未教题名单。

字节符号代表未知0至4，输出0至8。工程先验包括加性角色读出与有序数字输出；这是有限任务内的E3检验，不是无先验发现算术。STANDARD反馈正确/错误/缺失为80/10/10，BLURRY为60/20/20。当前答案到来之前必须先输出。实际错误答案也是观察，不能使用环境真值过滤。

OLD和NEW符号映射独立。所有评分未教组合的两种方向在全生命周期均无答案暴露；查询不会进入支持表或恢复窗口。主NEW样本20/40/80是OLD320之后的新增外部样本，对应出生后340/360/400条，不能写成从出生只看20条。

## 恢复触发只取决于实际观察

保留SUPPORT原规则：最多32个有序题面键，每键最近8个允许观察答案；当前答案进入支持表之前，至少两票且严格多数才成立。当前答案与过去多数冲突时，原写门因子为1/4，否则为1。当前答案更新后仍进入表，不因冲突删除。

三个恢复配置增加一个最多8项的窗口B。只有实际答案存在、允许写入、过去严格多数成立、当前答案等于这个过去多数时，才向B加入当前的三个特征索引和实际答案，并增加资格计数c。这里只判断观察一致性，不声称知道答案正确。

当c是8的倍数、B含至少两个不同的实际有序题面键，且生命周期已触发次数小于64时，本事件触发恢复。窗口保持最近8项，不因触发清空。三个恢复配置的资格判断、c、B和触发计数与权重无关：在相同分支的相同观察历史上必须逐记录相同。没有满足资格的8项就不恢复，不为20样本处另设冷启动救援。

此操作对候选草案作了一项明确收敛：**恢复时刻由观察支持决定，预测残差只决定恢复方向**。不用各配置自己的预测误差决定是否触发，从而保证方向对照不同时改变恢复次数。它测试的是支持条件下的经验方向恢复，不能解释成已确证的冲突检测器。

正式TRIANGLE_TAIL每10条轮次的10个有序题面各出现一次；NEW最初20条不可能具有两次同键过去观察。因此三个恢复配置在NEW最初20条不触发恢复；缺失和错误可能进一步推迟。A20差异可能来自OLD留下的状态，不能归因于NEW20已经发生恢复。DEV图的重复槽位结构不同，触发时刻须分开报告。

## 恢复方向与总量

在当前允许答案已经到来、但本次w/P更新和支持表插入尚未执行时，B已经加入当前合格观察。用本事件之前的w计算每个缓存观察的残差，并构造方向：

```
g = sum_i clip(y_i - dot(w, x_i), -1, 1) * x_i
z = g / norm(g)                       if norm(g) > 1e-12
z = x_current / sqrt(3)               otherwise
delta = 0.25
```

窗口只保留真正到来的答案，不把多数当清洁目标。计算g是有限方向统计，不对缓存记录再次更新w/P，不增加外部样本数。零残差回退是固定规则；若频繁使用，须报告候选实际主要恢复当前题面方向，不能称多观察方向起作用。

触发时执行：DIR的`P <- P + delta*z*z^T`；RAND用独立学习RNG生成31个±1并除以sqrt(31)，执行同一秩一恢复；ISO执行`P <- P + delta*I/31`。RAND符号与数据和标签独立。三个恢复配置另用独立辅助`random.Random`，种子固定为`int.from_bytes(sha256(b"U034-DIRECTION-V1:" + str(world_id).encode("ascii")).digest()[:8], "big")`，Python版本与运行环境一同锁定。每次触发依次执行31次`getrandbits(1)`，0映射为−1、1映射为+1。DIR/ISO推进同样抽样但不用它们选方向。该RNG不替换原SUPPORT RNG，克隆/恢复包括其完整状态，禁写与查询不推进它。世界编号只作与映射无关的出生随机种子。

每次恢复增加的trace均为0.25，最多64次，出生后累计最多16。三个恢复配置在相同分支上触发次数、每次trace剂量及累计剂量严格一致；方向和其对后续w/P的影响可以不同。ISO并非谱形状完全匹配的对照，RAND才是秩一形状对照。

所有恢复项均为半正定，原相关更新也保持半正定。理想算术下，P最大特征值不超过出生10加累计恢复trace16，即26；不要求每个对角都低于出生值，也不做结果依赖的重置。数值资格化须验证有限性、对称性和PSD容差；不允许通过静默修正负特征值隐藏实现错误。

单条最长实验路径只有OLD320加NEW80，不超过400条记录；最多50次八资格触发，因此64次生命周期上限不会在本任务中人为耗尽后续NEW的恢复预算。共享前缀分叉各自继承计数，不能按全任务2560条或按阶段清零。

剂量0.25、窗口8、步距8、次数64和零残差阈值均是固定工程设计值，并非已验证最优值。不在DEV后换剂量、增加次数或扩容窗口。若技术成本不达标，在读取DEV前公开修订并保留旧稿；科学负面结果不触发参数救援。

## 一次观察的一次权重更新

恢复完成后，以已经输出的预反馈v计算`r=y-v`，沿用SUPPORT的s和原残差鲁棒因子：

```
gamma_R = 1 if abs(r) <= 1 else 1 / abs(r)
gamma = s * gamma_R
q = P * x
d = 1 + gamma * dot(x, q)
w <- clip(w + gamma * r * q / d, -4*kappa, 4*kappa)
P <- P - gamma * q*q^T / d
P <- (P + P^T) / 2
```

恢复不重新输出当前答案，也不倒改已缓存的v。四个SUPPORT配置随后按原顺序更新原支持缓存/H；三个恢复配置的额外窗口已在恢复前完成本次合格插入。允许反馈数与权重更新次数不因方向恢复增加。

缺失、禁写、查询和休息不改变w、P、支持缓存/H、B、c、恢复计数或学习RNG。克隆、擦除、冷恢复必须包含所有这些状态。N_OLD/N_NEW及打乱分支分别只使用本分支真正允许的观察；不能从W拷贝多数、B、方向或恢复时间表。跨配置相同观察的资格时间匹配，不能变成跨因果历史共享辅助状态。

## 主终点与采用规则

保持主终点：opaque BLURRY、OLD320之后，延迟未教NEW题自身输出的`J=.25*A20+.50*A40+.25*A80`。训练CPU、有效载荷和估算内存移动分别报告，不把额外恢复当免费操作，不以已教题回忆替代J。

候选采用须同时满足：相对COV-SUPPORT及COV-R的平均J均至少提高5个百分点，两项预声明配对Student单侧95%下界均大于0；相对两基线的OLD曲线和OLD末值各不下降超过3个百分点，OLD末值至少85%；STANDARD与普通数字的OLD曲线和NEW J各不下降超过3个百分点。两项基线增益须同时成立，是同一采用主张的合取门，不以任选更弱基线取胜。

沿用前轮NEW的W−N_NEW、W−SHUFFLED_NEW，以及OLD积分的W−N_OLD、W−SHUFFLED_OLD下界均大于0的因果门；均值超过预声明最佳未学习捷径至少5个百分点。零差或常数差采用前轮保守有界下界，不用零宽区间捷径。资源限额：生产训练CPU不超过SUPPORT的1.5倍、有效载荷不超过2倍、worker RSS不超过512MiB；同时报告相对COV-R成本。

DIR−RAND及DIR−ISO为预声明诊断，不作可选择效能检验。若DIR通过能力门而不优于它们，只能说该恢复配方带来有限任务内改善，不能声称观察方向优于一般恢复。若任何对照更好，不把它改名为胜者进入确认。

## 固定样本规模与运行预算

DEV沿用12个全新opaque世界，PATH_LOOP/STAR_LOOP与STANDARD/BLURRY四层各3个，五配置60个完整任务、153600条外部记录。只有DIR可晋级：BLURRY J对两基线均至少+3个百分点、NEW两种因果均值为正、现有保持/保护及资源门通过。

一次条件确认使用128个全新TRIANGLE_TAIL世界：64 opaque BLURRY主组、32 opaque STANDARD、32普通数字且两噪声各16。五配置共640任务、1638400条外部记录。最大程序规模700任务、1792000条外部记录；每任务2560条记录、23条有共享前缀的相关状态轨迹，最多16100条轨迹，不称独立生命。未晋级则仅完成DEV，不必跑满。

使用同世界同字节流配对。技术世界不进入DEV/确认；种子清单与源锁在最后资格化后、正式读取前生成并冻结。确认几何只允许无学习曝光/可解性检查，不提前测新图能力。

先按技术完整任务测端到端时间，包括独立审核、IO、分析和打包。初始两后台worker，caffeinate跟随supervisor，8小时保守准入、10小时硬上限、整任务边界暂停；可能需要多个明确授权的会话，不承诺一次窗口完成全部条件确认。不自动续跑，不在见结果后缩n或删对照。预算过大须在DEV前修订，不能把运行成本推迟到结果出来再处理。

## 三次资格化循环的设计范围

本稿没有执行这些循环。后续三次循环在同一实现内完成，不另开科学定位实验：

1. 独立标量恢复/更新参考；s=1及无触发时原基线一致；恢复trace相同和累计上限、零残差回退、PSD/有限性、支持当前答案不能支持自己、资格窗口/次数边界、两方向键独立。用公开合成序列验证规则，不统计效能。
2. 全部因果权限、克隆/擦除/冷恢复、漏禁写和辅助状态泄漏篡改拒绝；独立重建五配置输入、三恢复配置B/c/触发时刻/RNG次数；禁止用候选自己的门函数作唯一审核。检查缺失后不跨事件补写，以及两个基线无新增学习状态。
3. 预留技术世界完整任务与双worker运行，实测生产和审核成本；监督器原子提交、并发读取、脱离终端、caffeinate、安全暂停、负面不晋级、确认准入、最终审核和打包。监控只读紧凑计数，分析不反复解压全部收据。

每次保存设计、审查、试跑和修订记录。正式运行前锁定方程、随机种子规则、控制、终点、门槛、样本和运行预算；技术资格失败不是科学负面，负面科学也不是程序故障。

## 曝光审计与反模型

每世界报告精确键表、规范化键表、观察答案众数/均值、固定ASCII/序号算术、单操作数拟合、出生状态、完整学习状态擦除及正常因果历史。未教键回退按前轮预声明策略，不杜撰统一机会率。简单但由训练学到的加性规则是合法E3解释；实验不声称超出本任务的推理。

方向窗口只能含当前分支实际允许观察的教学键。查询不读答案缓存输出，方向恢复只影响P，答案由w读出。学到的表现不得归为未经改变的Full151原生能力。

失败、未晋级或确认未决均保留用户开发默认COV-SUPPORT及科学锚点COV-R。该结果只筛掉本方向、剂量和触发配方，不否定整个U034、不自动转入U047，也不授权下一轮。当前授权范围为上传清单和细化设计。
