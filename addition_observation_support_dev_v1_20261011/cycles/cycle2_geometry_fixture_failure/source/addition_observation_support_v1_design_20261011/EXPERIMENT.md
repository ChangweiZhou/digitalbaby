# 有限加法观察支持写入门实验设计

2026年10月11日。设计版本V1，尚未实现、资格化或冻结，未运行新轨迹。本次只细化U042，保留现有COV-R工作核心和历史实验结论。

## 目标与证据范围

在相同带噪训练样本和计算预算内，提高模型自身对未教过加法组合的正确率，并保留旧知识。主证据为有限任务内的E3。每个符号代表未知的0至4取值，答案为0至8；工程先验仍包括角色与身份特征、加性读出和有序数字输出。本实验不声称从任意假设空间发现加法，不扩展任务或精度。

[上一轮结果](../addition_feedback_efficiency_dev_v1_20261011/results/REPORT.md)中，额外当前样本更新相对COV-R的主增益为1.07个百分点，未过升级门槛；均匀历史回放没有显示主指标改善。这里检验一个不同假说：用过去实际观察答案的支持来降低部分冲突反馈的写入强度。噪声是候选解释，不是已被单独定位的原因。

## 固定三配置

| 配置 | 操作 | 用途 |
|---|---|---|
| COV-R | 已采用的全协方差、固定残差阈值更新 | 匹配参考 |
| COV-SUPPORT | 有界历史支持决定当前写入因子 | 唯一可推进的候选 |
| COV-RATE | 相同支持统计；按过去门控频率随机降低当前写入 | 区分内容相关选择与一般降低写入的诊断对照 |

只有一个候选，不扫窗口、阈值或衰减因子，不加入回放、额外更新、拓扑、第二核心或新编码器。COV-RATE是诊断同行，不因结果好而临时变成第二个确认候选。

## 固定输入与输出

沿用[前轮接口和方程](../addition_feedback_efficiency_v1_design_20261011/EXPERIMENT.md)：31维特征，15个左身份、15个右身份和常数，三项激活；w出生为0，P出生为10I。输入为`a+b=`及可缺失的实际答案字节；在答案到来前由w输出最近的0至8数字，精确平局取较小数字。答案查询只调用权重读出，不访问支持缓存。

三个配置获得相同字节、时钟和因果写入权限。不向核心传入真值、噪声类型、阶段、语义取值或未教题名单。固定角色和加性先验继续披露；本轮没有增加交换律共享：支持键为实际有序字节对，`A+B`与`B+A`分别统计。

## 支持规则

COV-SUPPORT和COV-RATE都维护最多32个键。每个键存最近8个允许写入且实际到来的答案；9个计数由该环形窗口确定。新键按首次插入的FIFO顺序置换，访问已有键不改变键的置换顺序。记录缺失或禁写时，不创建或移动键、不加入答案。休息和查询不更新缓存，不按OLD或NEW标签清空缓存。

在当前答案y进入缓存前，从过去窗口计算票数c。若总数n≥2，且某个m满足c[m]≥2及2c[m]>n，令E=1；否则E=0。严格多数至多一个，不使用平局字节顺序挑选“正确答案”。

令D=1当且仅当E=1且y≠m。COV-SUPPORT的写入因子s在D=1时为1/4，其余为1。更新后把本次实际y加入缓存，包括被降低强度的y。窗口不会删除与当前多数冲突的观察，因此没有通过筛掉证据永久锁死多数的规则；但仍可能强化偶然错误多数，纠正速度不受保证。

次数2、窗口8、键数32、因子1/4固定。它们是可检验的工程配方，不是从旧正式世界拟合出的最优值。

## 随机写入对照

两个非参考配置都另存最近32次E=1事件的D，称为H，并使用同样出生的独立于环境的学习RNG。每次允许且存在的目标，均取一次随机数u；COV-SUPPORT记录但不使用u选择s。

COV-RATE只根据当前过去支持是否达到E，以及本事件之前的H选择s：E=0或H为空时s=1；否则p=mean(H)，当u<p时s=1/4，其余为1。不得用当前D选择随机写入强度。当前事件更新结束后，如果E=1，两个配置均将当前D加入H，保留最后32项，再加入当前答案。两者的缓存、H和RNG在同一观察历史上应完全相同，其权重/P可以不同。

这保持冷启动资格相同，并让随机门跟随过去的选择频率；它不使用未来记录、真值或候选权重。**它不是逐事件或逐世界精确匹配的写入对照。**有限窗口、时间变化和随机性会造成门控率差异；权重不同也会令基础残差gamma不同。分别报告s及最终gamma，不称为严格等写入预算消融。候选相对参考的能力提升是唯一正式效能检验；是否来自内容相关筛选，只能结合这个有上述限制的诊断解释。

## 更新方程与状态权限

缓存预反馈值v=xᵀw。答案到来且允许写入时，r=y−v，gamma_R=1若|r|≤1，否则1/|r|。取gamma=s×gamma_R，q=Px，u_P=xᵀq，d=1+gamma×u_P：

```
w <- clip(w + gamma * r * q / d, -4*kappa, 4*kappa)
P <- P - gamma * q*q^T / d
P <- (P + P^T) / 2
kappa = 15 / sqrt(45)
```

同一gamma作用于w和P，不在降低权重更新时仍按完整证据收缩P，不增加第二次更新，不做隐藏的P重置或特征修复。s=1的更新须与冻结COV-R达到已声明的数值一致性。

缺失与禁写必须保持w、P、缓存、H、学习RNG和学习计数不变；感知解析器和时钟可按同一字节流正常前进。N_OLD/N_NEW不能只关闭w。克隆、恢复和擦除包括全部辅助状态，所有可变状态独立。审计计数与生产学习状态分别定义。

## 预先声明的表现预测

正式TRIANGLE_TAIL中，10个有序上下文各出现一次于每个10记录epoch。NEW字节与OLD不同，故前20条NEW记录中，每次查询支持最多只有一次先前观察；本配方的NEW软门必为s=1。最早在第21条记录才可能出现降低强度，缺失答案还可能推迟它。

因此本配方直接改善NEW反馈利用的机会主要在40和80样本处。20样本结果若不同，可能源于先前OLD门控改变了初始w/P；不能称为前20条NEW反馈已经被筛噪。DEV有重复的对角槽位，最早启用位置可能更早，不能把这一优势外推到正式图。独立审计必须验证正式历史的前20条NEW记录没有支持门触发，不新增轨迹。

有限重复条件下，本配方可能太迟，或以错误多数压低正确观察而更差。接受这两类负面结果，不把门槛降到一票、不共享反向键、不增加训练量来救当前配方。OLD和NEW的支持建立速度、触发时刻和实际写入分配均从已有收据报告。

## 任务与样本预算

沿用前轮任务：5个符号随机对应0至4，5个语义组合教学，另外10个组合在整个历史中两种方向都不教学。OLD使用A至E，NEW使用F至J且取值映射独立；普通数字保护组的OLD使用0至4。STANDARD为80/10/10，BLURRY为60/20/20的正确/错误/缺失反馈；错误答案在8个错误数字中均匀取一个。核心不知道分类。

三条OLD历史W、N_OLD、SHUFFLED_OLD各320条，保存10/20/40/80/160/320的共享前缀检查点。每个检查点分叉，休息一个模型日、接受相同80条NEW、再休息一个模型日；NEW20/40/80分别读出延迟未教题和已教题。W的OLD320另分叉N_NEW与SHUFFLED_NEW。分叉不得重执行前缀或改变父状态。

OLD/NEW禁写控制包括缓存和随机门状态。打乱控制的缓存仅接收该分支真正到来的打乱答案，不保留正常答案副本。

每个完整世界配置任务仍为2560条外部记录、23条相关状态轨迹。每条记录含噪声或缺失也计入训练量；共享前缀、探针和轨迹不冒充独立样本。主NEW曲线明确对应出生后340/360/400条总外部记录，不称为出生后仅20条的学习。

## 主终点与升级条件

主终点不改：OLD320之后的延迟未教NEW题自身输出正确率，J=0.25 A20+0.50 A40+0.25 A80。主组为opaque BLURRY，统计单位为配对世界。STANDARD、已教题、门控“精确率”和总回忆率不能替代它。

正式采用需要COV-SUPPORT相对同世界COV-R的平均J提升至少5个百分点，单侧95%配对Student下界>0；NEW的W−N_NEW及W−SHUFFLED_NEW、OLD积分保持的W−N_OLD及W−SHUFFLED_OLD下界均>0。常数差异沿用前轮保守有界下界，禁止零宽区间捷径。

保持及成本保护沿用前轮：主组OLD曲线与末值各不下降超过3个百分点，OLD末值至少85%；STANDARD和普通数字的OLD曲线与NEW J各不下降超过3个百分点；生产训练CPU不超过参考1.5倍，可变有效载荷不超过2倍，单worker RSS不超过512MiB。原始主J还应超过声明的最佳未学习捷径至少5个百分点。

COV-RATE的配对结果、门控率差异和成本为诊断，不作为第二个确认检验。如果它也有相近收益，报告“不能把收益专门归因于上下文一致性”，不能声称本实验已排除一般低写入强度解释。候选仍须凭上述固定能力/保持/预算规则获得采用；诊断不事后改写规则。

## DEV与一次确认

DEV为12个新opaque世界，PATH_LOOP/STAR_LOOP与STANDARD/BLURRY四层各3个，固定三配置，共36任务、92160记录。技术资格化数据不进入DEV。只有COV-SUPPORT可推进：BLURRY平均J增益至少3个百分点、可用的OLD/STD保护及资源规则通过，NEW两种因果平均效应均为正。普通数字保护只在技术接口资格化和正式普通组分别检查，DEV不声称包含其效能检验。

未推进则完成NO_ADVANCE_RETAIN_COV_R并打包。推进后冻结选择、实际代码和一次确认：128个全新TRIANGLE_TAIL世界，64 opaque BLURRY主组、32 opaque STANDARD、32普通数字保护且两种噪声各16；三个配置共384任务、983040记录。确认种子与私有映射在选择锁定后生成，不为新图提前看学习表现。

最大程序规模为420任务、1075200记录、9660条相关状态轨迹；确认条件不满足时并非必须跑满。失败或未达升级门槛均保留COV-R，停止这个具体配方，不追加世界或转入参数救援。不得把全部U042/U045/U047家族写成被证伪。

## 曝光审计与反模型

全生命周期检查未教组合两种方向均无答案暴露；支持表只能出现实际教过的有序键。查询不加入表、不检索多数答案来输出、不更新H/RNG/P/w。响应发生在反馈前，不提供未教题反馈。

同世界报告原始键及规范化键表、答案众数/均值、ASCII或固定序号加法、单操作数拟合、出生状态和完整学习状态擦除；未知键采用声明的回退策略，不能杜撰统一机会水平。清洁加性拟合为环境侧可解性见证，不参与核心输出。简单但实际学到的加性规则允许作为本任务E3解释。

## 三次设计审核试跑修订

以下为后续实施资格化计划，本设计交付不等于已经完成：

1. 独立标量方程验证s作用于w/P、正定与有限性、s=1基线一致；支持边界、当前答案不能支持自己、两方向不合并、错误多数后观察仍进入窗口、缺失/禁写惰性和第33键置换。固定公开合成序列覆盖早期错误多数与窗口修订，仅验证规则，不成为新效能基准。
2. 独立重建每条支持决定与随机门；验证随机因子仅依赖过去H、E和独立随机数；全部因果分支及克隆/冷恢复/擦除；篡改答案、权限、缓存、H、RNG及P会被拒绝。不能通过调用候选自己的门函数来做独立审计。
3. 只在预留技术世界运行三配置完整任务，测实际CPU、状态及审核/IO成本；验证缓存命中、早期触发预测和共同输入。测试双worker脱离终端、caffeinate、安全暂停、并发状态读取、选择/负面完成、审核和打包全路径。正式图仅做无学习的几何/曝光检查。

每次修订保留前版和问题记录。科学源文件与实际审核源均在最后资格化后锁定。运行故障不通过删配置完成资格化。样本规模在读取DEV前确定；预计超时须先公开修订，不在看到结果后缩n。
