# Byte→Full151 桥接阶段：退出审查与下一阶段边界

**裁定：有限工程桥接已经完成；不再把新的“整合验证”列为进入下一阶段的默认前置实验。** 本文是对已完成实验的只读审查，不修改任何冻结代码、源锁或收据，也不启动新轨迹。此前建议“还需一次整合确认才能开始机制阶段”把期望项事后升级为硬门槛，应撤回。

## 先固定三个不同的主张

| 主张 | 证据 | 当前状态 |
|---|---|---|
| **有限工程桥接**：逐字节到来的输入形成 Full151 地址；原生记忆在教学后保存已教关联，模型先于答案字节自行输出答案；后续新教学后仍保持 | [桥接确认](FULL151_VISIBLE_CONTEXT_BRIDGE_20260927/REPORT.md) 与 [同结构持久性确认](FULL151_VISIBLE_CONTEXT_PERSISTENCE_20260927/REPORT.md) | **已完成，E1/E2 范围** |
| **有限 E3 测量标尺**：旧学习对从未教学的关系配对，在延迟与干扰后改善模型发出的二选一输出 | [Step 10](FULL151_E3_OUTPUT_STEP10_INTERNAL_CHOICE_20260927/REPORT.md) 与 [四可见字节题面资格确认](BYTE_FULL151_E3_ASSAY_QUALIFICATION_20260928/results/REPORT.md)；阳性为 FE0 | **已具备标尺，但属于另一种任务/输出结构** |
| **同一具体系统兼有上述已教记忆、保持和 E3 迁移** | 现有实验没有以相同输入路由、存储拓扑、教学及输出规则在一个具体系统中同时证明 | **未证明；只阻止该更强主张，不推翻已完成的有限桥接** |

本审查采用已经执行的 [桥接设计](FULL151_VISIBLE_CONTEXT_BRIDGE_20260927/DESIGN.md) 所冻结的 **E1/E2 工程交付定义**，而不擅自把后来的“一点泛化”期望解释为该设计的 E3 硬门槛；这不等于用户已批准放弃同一系统 E3 目标。项目 [目标契约](MINIFLY_OBJECTIVE_CONTRACT.md) 要求在宣称“可复用的持久学习核心”之前取得 E3，但也明确承认 E1/E2 是合法组件证据。**可以结束当前定义的组件桥接阶段，不能据此宣称最终核心已经实现。**

## 已完成的主张到底有多窄

- 在 32 个新世界、16 道任意标签题上，CONTENT 路由的原题、未教空格呈现和固定 `Q` 前缀呈现各 512/512；关闭原生 Full151 写入时各为 25%。模型在 `=` 后、答案字节到来前从四个答案通道自行发出一个字节。该编码器固定且不含答案标签；每个通道是一份原生 Full151 记忆。空格与 `Q` 变体映射到**同一个有效四字节键**，因此是窄 E2，不是未教关系迁移。
- 同一 CONTENT＋四输出架构在 64 个新世界中先学旧 16 键、再学四批共 16 个新键；最后一次模拟 24 小时休息后，旧题为 1016/1024＝99.22%。相对不写新内容的分支，写入导致 −0.78 个百分点的可测小损失，95% 世界级区间 [−1.30,−0.26]；不能称为“零遗忘”。
- 新 E3 资格实验在 64 个独立世界中得到 FE0 未教配对最终 W−N +17.2 点 [95% 区间 +9.8,+24.6]；CONTENT 同任务为 −1.0 点 [−8.2,+6.1]。这套 E3 是**单个二元 valence 存储＋环境给出的两个选项＋固定 L/R 比较器**，而已教字节输出是四份答案存储＋`=` 后 argmax。未教配对不能靠已教精确键背诵，但学得一位符号类别规则即可解决，因此只属狭窄关系家族。两套成绩不能相加后称为一只已验证的飞脑。

## 已知边界，不是下一轮桥接阻断项

| 条件 | 实际影响 | 处理 |
|---|---|---|
| CONTENT 只取本行最近四个非空格字节，换行清空；不足四字节退回 FE0 | 长题同后四字节可碰撞；改变一个有效字节通常产生无关地址；短题使用不同路由 | 在产品/实验声明中限制适用域。扩大键长或格式是**新能力**，不是推翻当前 E1 桥接 |
| 答案字节作为外部教学信号，测试时有 `=` 提示 | 尚未证明无教师学习、何时自主作答或自由生成 | 留在以后里程碑，不暗中变成桥接验收项 |
| 仅四个答案字节、32 个键和特定虚拟时钟 | 不能外推至 10/256 个输出、80 键、真实日历时间或自然文本 | 超域主张须另立目标；不为进入机制研究而先补全 |
| E3 由环境提供两个选项，FE0 与 CONTENT 分别训练 | 有有限迁移标尺，但没有同一四输出系统的 E3 证据 | 下一阶段候选的归因必须在**同一试验内**给未改基线与候选相同路由、教学、输出与世界；不得拼接两套实验的优点 |
| 旧 E3 收据含两路线同世界的逐选项数值 | 可只读计算**指定函数作用于已保存数值**后的假设选择；不能证明真正共运行的双 bank 具有相同状态、教学/复制/时钟或字节输出，仍不能代表四输出字节任务；事后选权重也不能算确认 | 只作工程可行性材料；不为了验证“会相加”重跑学习轨迹 |

例如，对已经保存的 E3 选项数值事后计算 `FE0 + 0.02 × CONTENT`，得到该二选一任务最终已教题 W 97.4%、未教题 W 66.1%、N 49.5%（差 +16.7 点）。这表明“任何简单合并必然失败”也不成立；但 `0.02` 是看过本批结果后筛出的，且四输出字节任务并不在这些收据中，因此它既不是新系统确认，也不构成追加一轮桥接实验的自动理由。

## 进入机制阶段时的一次性防漂移规则

1. **不把新桥接验证设为当前有限主张的默认前置。** 若源锁/收据发现实际错误、原生写入因果对照失效，或要声称超出上述适用域（包括同一系统 E3、更长输入或更多输出），则须另行定义与验证新主张；新能力需求不是旧结论的技术故障。
2. **每个新核心候选先写主张与证据等级。** 若目标是项目级“可复用核心”，E3 必须是实际的晋级终点：未教学关系、先于反馈输出、旧教学的因果对照、延迟与干扰后的表现。E1 保持和新学习是防退化条件，不得替代 E3。若只是机制诊断，则保持诊断标签，不宣称晋级。
3. **比较须说清究竟改变了什么。** 候选与基线在每项任务中得到同样的外部字节、教学/反馈、时钟、任务、决策/输出接口与世界。Full151 内部拓扑和副本数**可以改变**，但必须预声明它们是否正是待测干预；若新增输入通路或存储容量，要提供获得同样外部信息的基线及适当的容量/消融对照，或诚实地把整组改变当作一个架构包，不能把收益独归于某一记忆机制。多任务成绩分开报告；只有同一具体候选配置实际通过所要求的任务，才能声称“同一系统兼有”。
4. **一次冻结、一次检验、明确停点。** 先规定候选结构、主终点、阳性/阴性对照、暴露审计、精确键/规则反模型、世界名册、统计单位、失败分类和资源上限。技术试跑只排除实现错误，不能查看科学终点来调参数。失败便保留失败，不由结果自动生成“再来一个小诊断”或无限权重搜索。已完成的旧或新轨迹不重跑。
5. **“整合”只在需要更强主张时进行。** 组件桥接的阶段出口已经关闭。将来若要声称同一系统既有 CONTENT 水平的已教输出与保持，又有 FE0 水平的 E3，必须在设计时一次性锁定输入、记忆副本数、两种教学的对应关系、输出字母表与选择器、分数标定、任务时钟及成功/失败规则；不能只锁一个 FE0＋CONTENT 权重便把它叫作最终整合。

下一阶段的预先解释矩阵也应写在候选协议中：技术完整性失败只说明那次实现无效；已教输出/保持失败说明候选损害必要记忆；E3 失败或区间跨越零说明未证明复用；两项在**不同配置**下各自通过仍不能称同一核心；只有同一冻结候选配置在必要安全项和延迟干扰后的 E3 都通过，才有该任务家族内的晋级主张。每一种结果都先报告并停止原名册，不自动延长世界数、换题面、改权重或开启下一轮“定位”。

## 下一步决策

**在当前有限工程桥接主张下，无需再运行一个桥接资格实验作为默认前置。** 下一项有意义的工作是设计一个有界的机制候选及其公平基线，把已完成的 CONTENT E1/保持与 FE0 E3 当作两项不同的、已知灵敏度的测量。是否研究双路交互、Full151 内部遗忘或其他结构，应由该候选要解决的具体机制假说决定；不能因“还没整合”就先增加一整轮无终点实验。若用户把“同一系统 E3”设成阶段硬要求，那是**比已执行桥接设计更强的主张**，需要事先写全架构、验收和成本；新验证不能反过来抹掉本阶段已经获得的窄结论。
