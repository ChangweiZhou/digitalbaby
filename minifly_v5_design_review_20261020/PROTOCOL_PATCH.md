# Proposed v5 protocol corrections — review proposal, not an implemented revision

Keep raw bytes, ordinary answer order, generic native circuitry, no attention/Transformer/ELM/backprop, and retained exact unseen addition per all samples and compute.

## Required replacements

| Received provision | Replace with |
|---|---|
| M5 reference = running mean of learned value | A separately specified target-free baseline, validated not to subtract learned signal; reference updates prohibited during scoring |
| Slow warmup unchanged because fast memory decays | Explicit factorization of fast adaptation, code formation and slow commitment; intended full-strength response calibrated before budgets are set |
| D0 hears all arithmetic stages without teaching | Addition-only D0 for this study; correct answer bytes count as representation-training exposure; global held-pair exclusion precedes all data generation |
| R1 stable winners and every unit evenly used | Type-weighted aliasing/confusion plus stable selectivity; unused capacity permitted; no forced rotation just to fill 64 units |
| R2 consistent boundaries | Noncollapsed, nontrivial, useful and causal learned segmentation; evaluator-only checks never become boundary targets |
| R3 correct unseen-answer length as format prerequisite | Separate port acquisition, syntax, semantic length and exact arithmetic diagnostics |
| R4 best possible bound, analysis only | Empirical learned-code fit with a streamed solver, resource caps and separate model-selection/test data |
| R5/R6 broad arithmetic and unspecified controls | Addition-only exact E3 with OLD/NEW/rest, matching pretraining/replay, explicitly frozen query state and no-prior-teaching/shuffled controls |

## Event and state contract to complete

At each input/output event, identify the already available bytes and state; prepare class, segments, activity, baseline and native values without the target; emit the own bit pattern/EOS or receive actual feedback; only then apply allowed updates. A boundary byte starts its own segment if that is the chosen generic convention. Do not close `=` based on an unobserved expected digit. A reply-step counter may be a declared generic IO signal; it must not use expected answer length.

Publish a table for raw prototypes, context counts, class assignments, open/closed buffers, cell thresholds, fast/slow values, q/timestamps/identities, output references and replay. For each state give initialization, update equation, time unit, phase permissions, no-write permission, scoring permission and freeze/version policy.

Commitment requires signed equations, an absolute-value or signed threshold decision, exact below/above-threshold allocation, spacing, contradiction handling and replay provenance. A repeated original record is not a fresh independent sample just because it is replayed later.

## Dose and resource contract to complete

Use measured response curves at the new port's actual strength to choose finite learning caps. Count unique information, all presentations, listening bytes, expected output bytes/EOS, replay and externally fitted labels. Report production, inference, oracle fitting and qualification CPU separately, plus peak RSS and total worker CPU. Sparse KC activity alone is not computational sparsity. No dense 500k×1m feature or Gram allocation is permitted by default.

## Final outcome contract

Byte selectivity and format are E0/E1 diagnostics. Fitted-head success is not native learning. Promotion requires retained exact own-output E3 on globally unseen addition orbits, beyond the native-allocation reference and no-prior-teaching/shuffled/recitation controls, with all information and compute costs visible. Freeze an engineering candidate before a new confirmation split; do not adapt on the final test.

These changes require a fresh written design/parameter lock. This document authorizes no implementation, training, larger brain, extra task, adoption or upload.
