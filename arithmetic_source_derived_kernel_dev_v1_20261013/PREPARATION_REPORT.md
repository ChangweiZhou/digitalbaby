# SOURCE-CELL V1：三循环准备结果

**三次“设计—审核—试跑—修订”完成。源码与接口资格通过，但未发现 ELM 的样本/计算优势；不采纳新核心。** 共10个完整原生技术作业、184,320条外部记录应用、40个相关末态历史，来自一个短剂量与一个完整剂量技术世界。正式DEV/确认作业为0；没有统计显著性、完整四则掌握或机制家族排除结论。

J是既定0–10,240样本历程或共同CPU历程的能力面积，不是末题准确率。共同计算窗口由预定B69-W实测固定为22.493261s。原始四历史、每操作和16组合分量见 [SUMMARY.json](SUMMARY.json)。未出现所有四操作的正因果/shortcut优势；上述成绩不能作为本轮确认通过。

所有臂未见二元乘法均为0/32。ELM的完整混合38个正确中，E6有30个答案为0、只有8个非零正确；E6_FIX有31个为0、只有7个非零正确。两者主要输出少数常见答案如12、15和0。这个事后分解不删除合法的0答案、不改变主指标，却说明它们没有可靠学会混合运算。

已教题也没有学稳。末条真实记录中 embedding、内部MLP、输出头有非零梯度，E6的κ梯度也非零；结合数值源码比对，不支持“没有收到梯度/移植写错方程”作为当前成绩的解释。另一方面，这仍不能唯一定位为读出、表示或训练剂量问题。更丰富的私有状态在这一固定训练配方中没有带来收益；不能扩展成所有ELM或递归机制不可能有效。

## 成本与范围

五个完整作业的主体CPU分别约58.45、59.86、65.94、132.55、121.01s；两个detached worker完成第三循环约262.68s，caffeinate跟随supervisor至结束。主体包括生成器、分支和scorer，独立审核、gzip提交另计。W生产CPU包括模型训练与规定留出自输出，排除另算的审计/反例拟合与E1末端诊断查询。

完整作业进程峰值RSS约256–482MiB，包含PyTorch运行时、数据、曲线、收据与模型，并非隔离的模型张量峰值。参数与RMS等明确状态量有账本；不能以这个RSS或稀疏图宣称实现了事件稀疏或大规模带宽目标。

按本机实测，未来20作业DEV及条件性72作业确认的原生主体有界且远低于10h量级，但不同world生成长度、审核、写盘、归档与最后打包仍须留余量。保守准入必须用完整最慢作业及实测finalization，不保证固定分钟数或自动启动。

## 审计、归档和剩余限制

独立审计核实真值、操作、canonical group、锁定数据与流、128/256唯一留出代表、先回答后反馈、写入许可/真实step、共享prefix和held排除；再次按原生输出独立积分J。N_BINARY旧阶段全部查询与出生一致，N_MIXED全部后期查询与真实W旧末态一致。所有原始收据不变。[FINAL_AUDIT.json](FINAL_AUDIT.json) 区分原生产源码与加强的后审。

原生环境为Python3.11.5、NumPy2.2.6、PyTorch2.8.0 CPU float64；统计fixture单独使用Python3.11.5、NumPy1.26.4、SciPy1.13.1，未参与模型前向或训练。统计gate未在这两个技术世界上运行。

**实际保存缺口：** 本批有原始输入、输出、更新/梯度摘要和收据，但没有学习后的完整参数数组，不能离线诊断最终表示几何。五臂出生数组已由锁定种子无前向重建并逐digest核实；后续worker增加状态保存，往返合成测试通过。没有用重跑生成“本批的最终checkpoint”。这不改变已保存输出和效率的比较，但限定深入机制归因。

整体证据是E0源/接口资格与描述性E1/E3行为。没有正式DEV、确认、核心采纳、宽领域能力或新的家族级排除。完整108/136/254/71/16重叠清单仍保留。
