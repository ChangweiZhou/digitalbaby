# SOURCE-CELL V1：旧细胞源码的端到端四则学习比较

**状态：具体设计，尚未实现、资格验证或开跑。** 本文件把上一轮复盘落实为固定模型、数据、预算和判定方案；不修改 V3 的冻结实验或将它的技术成绩升级为科学证据。

目标保持不变：**从真实到达的反馈中学习，以更少外部训练样本和实际计算，获得并保留对未见四则及混合题的整串自输出能力。** 不是只恢复已教题记忆，也不是优化噪音处理。原 adopted core 保持原样。

## 1. 为什么是这次比较

V3 短试跑的部分模型对全部未见混合题回答 `1`，其他模型立即 EOS；完整 G0 的内容学习和后续字节生成也弱。但 V3 同时更换了旧字节模型的初始化、优化器和读出，其 P 偏置状态又不等于 Full151 的突触记忆。继续扩大原十臂不能清楚回答“继承旧核心后的改变是否有效”。

本次从两份实际源码出发：旧 ANSWER-0 是可兼容的通用字节参考；DevelopmentalELM 提供已实现的私有向量状态、内部非线性映射和稀疏递归消息。**不使用 TemporalELM 冒充同一母体**。Full151/R_center 用于继承真实反馈时序和可冻结状态原则，不声称候选已保留其 fast/slow 突触机制。

源码、版本及完整清单依据见 [SOURCE_LINEAGE.json](SOURCE_LINEAGE.json)。旧证据来自不同任务，只有有限种子、重复呈现且参数不匹配；它支持提出候选，不预示本实验成功。

## 3. 实际前向结构

所有配方接受学习的 categorical byte embedding。256个 payload 值全部合法，BEGIN=257、REPLY=258、EOS=256。每个世界随机重标全部256个字节，逆映射仅在 evaluator 中。

B16/B24/B69 保留旧源码方程：

```text
z = sigmoid(Wz e + Uz h + bz)
r = sigmoid(Wr e + Ur h + br)
g = tanh(Wg e + Ug (r * h) + bg)
h_next = (1-z) * h + z * g
```

不得用 PyTorch 默认 reset-after GRU、AdamW 或参数位移上限替代后宣称等价。旧 NumPy 源码用作数值 oracle；五臂的主比较统一为 CPU PyTorch float64、显式方程和同一手写 RMS，须通过逐事件状态、目标梯度和更新等价检查后才可运行。这样不把 NumPy 与 PyTorch 的运行时差异直接归给细胞。移植不通过则暂停资格，不能跳过等价检查或用弱参考发计算效率结论。

ELM 的逐事件更新继承原细胞：

```text
sources = concat(E[actual_or_generated_byte], previous_activity)
branch_sum = sum(fixed_graph_gather(sources) * syn_weight) + branch_bias
branch_activity = tanh(softplus(branch_gain_raw) * branch_sum)
hidden = tanh(W1_neuron * concat(branch_activity, m) + b1_neuron)
candidate = tanh(W2_neuron * hidden + b2_neuron)
m_next = kappa * m + (1-kappa) * candidate
voltage = dot(m_next, memory_to_activity)
        + dot(branch_activity, branch_to_activity) + activity_bias
activity_next = sigmoid(4 * (voltage - softplus(threshold_raw)))
```

每细胞：8分支，每分支3个潜在感官连接与1个其他细胞连接，内部隐藏12，私有状态6。没有额外工作扫描、循环八遍、可塑拓扑、视觉活动正则或回放。

### 四项必须登记的适配

1. **图像输入→学习的字节向量。** 24维是原每细胞24个不重复感官槽位所需的最小维度。所有24维均被访问但分配到不同分支；这不是感官通道子采样节省。通道没有数字、操作数或运算符意义。
2. **像素空间拓扑→一般固定稀疏图。** 每细胞将24个潜在通道随机排列为8个三元组；从其他63个细胞均匀抽8个不同递归源。无自环槽位，私有状态自身仍递归。图固定，不使用像素位置、latent维度顺序、算术位置或可学习路由。
3. **flash/delay episode→实际字节流。** 每到达一个字节推进一次状态；BEGIN 清空题内状态，同一题面、REPLY 和答案期间连续携带状态。仅在自己生成时使用生成字节作为瞬时上下文，不能将它写为教学真值。
4. **十类图像头→通用字节头。** 为使训练差异不与细胞混在一起，所有模型继承 ANSWER-0 的共同头：`u=concat(activity,1)/norm(concat(activity,1)); logits=u@V`，257类，V出生全零。这是 ELM 读出的显式适配，不称为完整原图像网络原样复制。

原细胞初始化保留：感官权重σ=.24、递归σ=.16，分支bias=-.05、初始正gain=1，神经元逐个 Xavier 内部矩阵，mem/activity映射σ=.30、branch/activity映射σ=.10、活动bias=0、初始正阈值=.75。κ范围[.08,.995]；六个初始τ在1.5到32之间对数等距，`κ=exp(-1/τ)`，加原σ=.06抖动并裁剪到原内部边界。E6_FIX 使用与 E6 完全相同的 κ 出生数组。

GRU 与 embedding 初始化保留旧源分布：Rademacher embedding/√embedding宽度，输入矩阵 N(0,1/√embedding宽度)，正交循环矩阵、零门bias。不同形状的 GRU 不能称为逐元素相同出生。各臂的 W/N/SH 出生严格相同；E6/E6_FIX 除冻结许可外逐元素相同，独立可变存储。图、embedding、细胞和读出初始化采用分开的任务无关种子流，算法与生成的出生数组全部锁定。

## 4. 共同学习规则与状态

- 只对实际允许到达的答案 payload 与 EOS 计算 CE，按一个记录的目标数取平均。题面字节被读取但不作为额外预测损失；没有 counting warmup、隐藏预训练或未收费样本。
- 参数在整个记录内固定，真实 EOS 到达后联合更新一次。各臂学习步数相同，不再出现320次与80次更新混比。
- 使用旧 RMS：lr=.001，β=.99，ε=1e-8，全参数梯度L2 clip=1，float64，decay=0。`v←βv+(1-β)g²; θ←θ-lr*g/(sqrt(v/(1-β^step))+ε)`。无 Adam 一阶矩、位移cap或视觉损失。
- 每目标信用范围32个事件，保留所有允许目标的损失和梯度，不能只保留最后窗口的损失。前向递归状态可以读取更长输入；32是梯度祖先上限，不是砍掉输入的算术截取规则。当前任务训练帧应全部在32事件内，由静态审查核实。
- 全部语义部分可学习，包括 embedding、细胞/GRU 和头；E6_FIX 的 κ 是唯一刻意冻结的细胞参数。零输出头意味着初始第一个更新的 embedding 梯度可以为零；不能误报为断路。
- 跨记录知识是参数及 RMS 状态。ELM 私有向量和活动是题内工作状态，在 BEGIN 复位；它们**不是 Full151 fast/slow 突触存储**。
- no-write 冻结参数、矩、step、pending梯度及学习RNG；读取相同流只推进瞬时状态。生成和查询不改变学习状态，探针也不进入任何缓存。
- 名义24h为参数不演化的空闲，不能声称测到生物时间衰减；持久性压力来自后续混合算术学习。

所有配方同一代码跨操作、任务阶段和 opaque世界运行。无 Transformer、注意力、query-key/内容加权记忆检索、输入加权池化、算术 parser、数值标量目标、操作数角色、运算符分支、数字/进位特征、解题轨迹、答案候选表或数值渲染。`einsum` 的固定参数内部 MLP 允许，它不做注意力。

## 5. 数据、剂量与暴露审查

严格继承 V3 的 [worlds.py](../arithmetic_kernel_no_attention_dev_v3_20261013/worlds.py) 和 evaluator-only [validate_design.py](../arithmetic_end_to_end_design_v1_20261013/validate_design.py)。复用的是数据源码，不是 V3 模型或成绩。

- seed范围0–15，SUM/PRODUCT各136个无序family，各32个完整非平凡family留出，104个用于训练。加法/减法和乘法/整除按原交换与逆运算闭包隔离。
- 二元观察总预算依次256、512、1024、2048、4096、8192，各操作平衡。具体实际顺序是固定操作顺序的微块加各操作pool洗牌循环，不再将其描述为打乱了操作顺序。
- 混合题为完全括号化两步表达式，16个 inner/root 操作组合。512个训练group、256个留出group；交换和同操作结合闭包隔离。两个 primitive 都来自二元训练pool，但从不把中间值或 AST 送入核心。
- 混合观察预算64、128、256、512、1024、2048。总 W 外部观察10,240条。每次重复都重新收费，不将呈现次数报成不同知识数。
- 无 primary noise 调参、额外更简单任务或人工规律支持流。任意字节是合法 payload；运算表达式只是外部数据，不是核心特殊协议。
- 自输出最多16个 payload，另给一次 EOS 决策机会。资源耗尽明确 TRUNCATED，不算自行结束；正确必须 payload与实际 EOS 全部匹配。

暴露审查在任何核心运行前锁定全部world manifest，核实 exact/canonical train-held不重叠、mixed不包含被留出的primitive、实际字节支持、帧长度和所有查询的预学习选定代表。整组未教，不因某个呈现形式不同就冒称 E3。

## 7. 主测量：能力对样本和计算的曲线

在 W 观察坐标 `0,256,512,1024,2048,4096,8192,8256,8320,8448,8704,9216,10240`，查询全部128个二元留出代表和256个混合留出代表。三个旧prefix使用相同计划；N_MIXED的旧阶段引用其真实W父prefix曲线，混合阶段才产生独立探针，不重复训练或把父曲线冒充新运行。包含二元阶段的零样本混合预测，不能将未测部分填零或用后来成绩倒填。

`A(k) = .5×四操作等权留出整串准确率 + .5×16操作组合等权留出整串准确率`。

- **J_sample**：A在0..10,240外部样本坐标上的左连续阶梯积分/10,240。各区间使用前一个已测checkpoint，不做最佳点挑选。
- **J_compute**：相同A的阶梯，坐标换为累计 W 生产CPU。计题面读入、训练前向/反向、RMS更新、出生探针、全部规定查询、自生成与EOS决策。A从查询付费完成时才可使用；完成全预算后只保持最后能力，不增加学习。
- 固定共同计算范围 C*：使用预定 cycle3 完整 B69-W 的生产CPU末值，在 DEV 前锁定。它只确定相同测量窗口，不按候选行为选预算；若耗时计量失败，不得凭估计发布计算效率结论。
- 为避免初始探针免费，计算阶梯在其付费完成前为0；样本阶梯可在k=0使用其出生准确率。两种度量的坐标明确不同。
- 同时报告终点每操作保留、每混合组合、相对 no-prior-teaching 效应及原始错题数量。J是整个学习历程的能力面积，不能单独证明终点保留。

50/50权重是“二元与组合两部分等权”的预先定义，非算术特殊表示或宣称最优。必须公布未合成的全部分量，不能靠整体均值遮住减法、除法或某种组合完全无效。

CPU、wall、前向/反向访问、参数与矩、工作状态、峰值临时字节、clone/digest/audit成本分开记录。近参数量不能代替实测成本；稀疏图不等于事件稀疏，本 ELM 每字节仍更新全部64细胞和内部MLP。不宣称已满足未来大规模核心的所有带宽要求。

## 8. 反例模型与资格证据

反例菜单预先固定：raw exact-key、canonical-group exact-key、global reply众数、prompt长度众数、最后两个raw字节众数、raw字节bag众数。仅 evaluator 使用训练反馈拟合，不给核心其预测或表示。每个分层取菜单准确率最大值作为宽松shortcut envelope；任何 learnable新反例不得事后改门槛。

当前缺少一个满足全部约束且已在本任务上成功的阳性学习模型。旧 ANSWER-0 的已教获取是来源依据，不是当前任务的阳性泛化控制。独立算术 evaluator 是数据正确性/可解性 witness，绝不是模型。通用字节因果、非算术nonce序列和源逐步等价 fixtures 检查通路，不能证明四则可被该模型学会。

因此，失败可否定固定预算下的候选改善，不能证明整个端到端四则问题不可学。资格时必须记录训练目标payload与EOS各自的梯度、损失与预测，不能只验一个合并非零norm就宣称所有语义部分得到有用信用。

## 9. 固定 DEV、确认和判断

**DEV**：4个全新world `202610138101–202610138104`，五臂同流，20完整作业/655,360记录。不可把技术world加入这4个world。

候选需在4-world均值上同时满足：

1. J_sample、J_compute都高于 B16/B24/B69各自均值；
2. 最终四个二元操作各自的 `W−max(N_BINARY,SH_BINARY,shortcut)` 为正；
3. 最终 mixed 的同一对比和 `W−N_MIXED` 均为正。

这只筛选预定正方向，不是显著性或能力合格线。无候选则明确完成为 NO_ADVANCE，不补样本、换配方或另加机制。

如两个候选都通过，按 `min(J_sample−maxGRU_J_sample, J_compute−maxGRU_J_compute)` 排序；依次以较低生产CPU、较少可训练参数、E6_FIX优先作确定性tie-break。基准参考从三个 GRU 中按最高mean J_sample、最高J_compute、较低CPU、ID字典序选定。选择名单与全部DEV结果写入不可变 SELECTION_LOCK。

**确认**：24个未查看world `202610138201–202610138224`，只跑所选ELM、已锁定GRU参考、另一ELM twin；72完整作业/2,359,296记录。twin仅诊断，不能事后替换主候选。确认数据不能再修改初始化、步数、学习率、剂量或选择规则。

固定8个主检验，全部要求正方向并通过 Holm α=.05：

| 数量 | 配对world差值 |
| ---: | --- |
| 2 | 候选−参考的 J_sample 和 J_compute |
| 4 | 四个操作最终各自 `W−max(N_BINARY,SH_BINARY,shortcut)` |
| 1 | 最终mixed `W−max(N_BINARY,SH_BINARY,shortcut)` |
| 1 | 最终mixed `W−N_MIXED` |

对非恒定配对world差值使用预定单侧均值 Student-t 检验；单个双侧95% t区间为描述，不冒充同时区间。若差值完全恒定，mean≤0令p=1；否则用差值∈[-1,1]的保守 Hoeffding 上界 `min(1,exp(-n*mean²/2))`，不因样本方差为零赋p=0。单独披露这一保守fallback及正态近似局限；不换检验救结果。

零是“没有获取因果/效率增益”的自然界线；α控制检验错误率，**不是随意设定的80%、90%能力门槛**。24world是目前有界预算，并未宣称保证检出某个细小效应；不显著可为未决，不等于无效。

全部主检验通过，允许结论为 **BOUNDED_KERNEL_IMPROVEMENT**：有限范围的保留E3与相对样本/计算改善。它不等于四则混合目标已经全面解决、不等于学会通用算法、也不等于生物局部学习或NLP能力。原始各操作/组合错误必须随结论发布。未通过则 NO_CONFIRMED_REPLACEMENT，描述性收益与twin机制信息仍保留。
