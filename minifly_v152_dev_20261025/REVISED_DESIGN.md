# V152-R1 — isolate generic sequence-output acquisition, retain the native lane

25 October 2026. **Revised proposal only; not implemented or run by this exercise.** This supplements the immutable V152 design and its accepted negative calibration. It does not overwrite that result, restart its trajectories, or authorize a new experiment.

The goal remains better retained, complete own-byte/EOS unseen-addition generalization per total sample and actual compute. Gradual warmup, local candidate updates, raw-byte input/output and the native Full151/R_center lineage remain required. No attention, Transformer, ELM, numerical input feature, arithmetic relation, forced EOS, position-specific answer head or vocabulary mask is introduced.

## What changed our diagnosis

V152 qualified the derivatives and native adapter, then completed exactly its six fixed calibration groups. R_BP, R_LE and R_LE0 all produced zero complete taught answers at both rates. All 9,216 immediate post-update probes also failed. By OLD pass 8, every W prompt produced an empty EOS response. This failure preceded NEW interference. Loss reduction was real but did not establish acquisition.

The exact-BPTT comparator therefore did not become a working positive control. Its failure cannot be attributed to truncated local credit. Conversely, its failure does not show that Full151 cannot acquire or generalize: native learning histories were never admitted. The current gate coupled two independent research lanes too tightly.

A learned context-independent bias can reward a marginally frequent EOS, but that explanation is still a hypothesis. V152 did not perform a causal reference-bias ablation. We must not silently change the teacher, add task structure, enlarge the decoder, extend training, and claim that any recovery identifies the cause.

## 1. Keep two independent admission lanes

**Native E1 lane:** N_A, N_2B and N_2B_Q on the existing calibration world's same frozen OLD/NEW stream, with unchanged native equations, C16 port, warmup and signed update. Retain W/SH_OLD/N_OLD. These native histories were not executed in V152, so this is a prospective comparison, not a rerun. A failed independent BP reference must not prevent measuring the actual native candidate's taught acquisition and retention.

**Recurrent diagnostic lane:** R_BP_Q0, R_LE_Q0 and R_LE0_Q0. Keep V152's exact forward dynamics, 64 units, graph, initialization, C16, update timing, clipping, phase lengths and selected common rate η=0.03; hold only additive q identically zero. Compare with the already saved q-enabled η=0.03 calibration results. Do not rerun those three completed q-enabled histories. This is a one-factor generic bias-path ablation, not a promise of a better kernel. All input/recurrent/output parameters other than q still learn; there is no frozen-feature/ELM path.

The two lanes answer separate questions. Native efficacy is not inferred from a recurrent result. The q ablation cannot identify the best recurrence, input mapping or learning rule.

## 2. Keep the information and dose fixed

Reuse the calibration world only for this explicitly labeled development diagnosis: 64 OLD and 64 NEW relations, each eight passes, same predeclared orientations and orders. The world is already outcome-exposed, so this is not fresh confirmation. Record the original V152 15,360 applications / 43,344 targets as historical research exposure; do not erase them from program cost.

Expected answer bytes and EOS remain the real feedback. Preserve `s(n)=1/16+(15/16)min(n/1024,1)` and advance n through repeated and inhibited observations. No supplementary arithmetic examples, reverse-orbit augmentation, counting stream, teacher guesses or hidden answer-length cue is added. An output must emit its own payload and EOS, under the same four-decision cap.

Each of six new groups has the original three correlated histories and five physical phase streams: maximum 15,360 new main record applications / 46,080 reply/EOS target positions. A maximum 32 technical records / 96 targets is a separate reserve. New work has a separate, explicit 7,200-CPU-second / 10,800-wall-second ceiling with 600 CPU seconds reserved for audit, one worker/thread, and 1 GiB RSS target. Do not grant each arm a new clock or retry an interrupted history. Report actual cumulative targets and total research compute, including V152 and new validation/probe costs.

No fresh assessment is authorized by this revision. The existing 50-relation assessment sets remain unscored. A later assessment requires a separately locked, authorized design.

## 3. Measure acquisition and output collapse directly

Keep the original immediate post-write own-answer probes, OLD/NEW checkpoint probes, no-prior-teaching contrast, later no-write control and idle retention probe. Read-only probes continue from their own generated prefix; teacher-forced scores use independent clones.

Report, at each checkpoint and by branch:

- Complete correct payload plus own EOS, not only token accuracy or BPS.
- Empty EOS rate, CAP rate, first-payload argmax accuracy and true-EOS argmax accuracy.
- Teacher-forced payload loss separately from EOS loss; changing their weights is outside this one-factor comparison.
- Core/input/head/bias gradient norms, actual update norms, clipping/projection counts and parameter drift, recorded during already budgeted training. No new labels or unbudgeted update probes are introduced.
- Retained OLD, NEW acquisition and W versus SH_OLD separately. Exact taught recall remains E1.

Update the deterministic exact-key, canonicalized-key, favorite-complete-reply and position-frequency countermodels online from the already logged feedback, counting their state and compute. They do not answer on behalf of the candidate. A frequently repeated correct answer is not evidence of learned arithmetic.

## 4. Decisions fixed before running

- If Q0 recovers acquisition while the saved Q-enabled reference fails, bias-path competition is implicated **in that recurrent comparator**. Check payload and EOS behavior; do not infer native benefit or a universal anti-bias rule.
- If both fail, q alone is insufficient to explain the failure. Do not automatically widen rates, add passes, change architecture or open unseen scores.
- If BP_Q0 acquires and local Q0 methods do not, a temporal-credit comparison becomes interpretable within the same forward model. Until then, calling the failure a local-rule problem is unsupported.
- If a native arm acquires and retains taught answers, its native lane is qualified for consideration of a separate unseen-addition development experiment, independent of the recurrent lane.
- Native E3 still requires complete answers on never-taught whole orbits, prior-teaching controls beyond frequency/recitation and delayed/intervening retention. Native E1 success is not promotion, and no native path is automatically adopted.

A nonzero acquisition change is a minimal assay-readiness condition, not a useful-accuracy threshold. Publish the full count and effect, including small/mixed outcomes. This calibration comparison is not a statistical family-wide verdict.

## 5. Engineering revisions retained from the exercise

Use semantic checkpoint equality: parameter arrays, recurrent/native state, graph/codebook, counters, clocks and predictions. A pickle-file hash proves artifact integrity; it does not prove two numerical states differ. Preserve both measures with their distinct purposes.

Serialize a completed evaluation row before assembling its outer metadata, so a schema error cannot discard the raw response. Qualification should exercise result/receipt serialization with saved synthetic outputs before any calibration query. All interrupted/discarded probes remain charged. Completed histories must never be replayed to repair a report.

The V152 technical attempts and their limits remain documented: 53 technical records / 106 targets, 69 technical query pairs including the 64 discarded startup baseline queries. Their counts and failure traces are preserved; those discarded baseline prediction rows were not retained. No calibration training record had been applied at either repair point.

**Current delivery stops here:** V152's three cycles are complete, its negative gate is accepted, and this revision is a concrete next proposal. There is no claim that the revised model works before it is tested.
