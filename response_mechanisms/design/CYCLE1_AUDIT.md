# Independent audit and disposition, cycle 1

Reviewer: independent coordinating agent, 2026-10-01, before pilot. Overall: sound separate program and controls, with the seven following required changes.

1. Raw RMS can be interaction noise rather than learned task response. **Accepted:** save/decompose matched W−N_old tensors at every checkpoint; compute covariance and normalized target-aligned projection for B/F/G/H using evaluator-only ±1 one-vs-rest targets. Projection is mean(component×target_component)/RMS(target_component); target-zero cases are flagged, not divided. Preserve uncentered and decision-space (channel-centered within cue) decompositions. Report all raw tensor data.
2. H subtraction preserving F/G/H is algebra, not biological evidence. **Accepted:** it is a technical invariant. Candidate success additionally requires bias reduction and prospective fresh-world accuracy gain; raw and corrected readings are from exactly the same frozen state.
3. Ratios can rise through denominator collapse. **Accepted:** retain absolute terms, target-aligned terms, and no denominator-zero ratios. Final mechanistic qualification will require both main-effect RMS values at least 90% of paired timing-off control and improved task-aligned interaction as well as behavioral benefit. This is an operational gate, not a biological constant.
4. Prior teacher leakage must be tested across records; H may legitimately reflect previous labels indirectly through its own activity. **Accepted:** separate cue-only sensor resets each record; independent temporal traces contain only its activity, native encoder uses fixed/unsupervised B and no taught state. Multi-record changed-teacher counterfactual checks timing B and eligibility equality. H receives raw pre-teacher own activity only; learned activity can reflect past teaching, as expected.
5. Overall output balance does not constrain row/column effects. **Accepted:** save complete world mapping and report target tensor F/G/H RMS distribution. No attempt to force all random tables to be pure interactions.
6. J capacity, decay, bounds and no-write semantics must be explicit. **Accepted:** four banks of 88×88 float64 synapses, initialized zero, pointwise clip to ±16, exponential decay tau86,400 s, normalized LMS eta .25 with denominator max(1,||eligibility||²), teacher targets ±1. One gain shared across J/J_ADD/J_SHUFFLE. N_old receives only time decay during old phase; its native and J write flags are literally false. Both branches write new phase. All seven arms allocate the same added arrays; operative capacity differs and is separately disclosed. J_ADD uses a linear additive recent/current trace without cue-dependent normalization. J_SHUFFLE uses per-record target-independent coordinate permutation at write, ordinary eligibility at read.
7. Lock multiplicity/contrasts and label-blind scale calibration. **Accepted:** final behavioral family consists of T−T_OFF, H−FE0, J−J_ADD, J−J_SHUFFLE on final old-pair accuracy. All must report two-sided paired world-level intervals and multiplicity adjustment. J versus FE0 is descriptive architecture comparison. Final J gain is a single value from the cycle-1 FE0 pre-teacher decision-space RMS, lower bounded 1e-8, without looking at correctness. All variants retain the same gain. Results from this calibration world remain exploratory.

Implementation clarification: timing updates are computed from pre-teacher cue-only activity but applied only after the native event has captured and taught the pre-update KC representation. Thus the emitted value and its teacher use the same representation; future records see the new weights.

Pilot permission: proceed after technical tests pass. Pilot results never establish confirmatory evidence. The cycle-1 provisional unit gain is intentionally retained in its recorded receipt; the gain-calibration revision will first apply to cycle 2.
