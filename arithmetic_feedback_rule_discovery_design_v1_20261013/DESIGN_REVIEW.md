# RAW-RULE V1 — static design review

13 October 2026. This is a document/source review and arithmetic count check, **not** technical qualification, a three-cycle exercise or an experiment result.

## Changes required by the user

- Remove supplied operand roles, arithmetic relations and operation-specific computations.
- Remove numerical answer targets, ASCII ordinal features, periodic decimal features and numerical renderers from every new learner.
- Retain observed byte feedback, arbitrary payload admission, own sequence generation and learned EOS.
- Keep unseen four-operation ability per sample and compute as the primary objective. NLP is a compatibility motive, not a new benchmark.

## Source checks and interpretation

The earlier addition source uses a fixed additive hypothesis and ordinal emission. VALUE-INTERACT uses whole-prompt projections, numerical auxiliary feedback and independent shared/episodic fits. Neither is imported into RAW-RULE as hidden arithmetic capability. The published generic LEGACY-B reference has an explicitly disclosed numerical input prior and is not a matched architecture control.

The full 108-family comparison and 254-version register were consulted. M001/M007 support investigating generic recurrent state, M024 is a representation-learning reference, and U045 supplies the correlated-update lineage. These are new engineering variants, not previously verified arithmetic mechanisms. The comparison does not filter or replace the full inventory.

## Structural audit

The six new arms use the same raw-byte information and general cell. Frozen twins isolate representation learning at the same depth and confidence. FULL/DIAG twins isolate the declared confidence operation; their real costs and state sizes differ. The depth comparison ties weights and counts extra work. One fitted categorical output avoids uncalibrated independent-logit addition. There is no categorical episodic bank in a new arm.

No implementation exists yet, so absence of forbidden helpers is a design requirement awaiting source/API and tamper qualification. Probabilities, rather than an ID-dependent argmax tie choice, are the correct byte-permutation invariant. The learner package must remain independent of evaluator arithmetic.

## Budget/count checks

Three roots apply 3*512=1,536 arithmetic records. Eighteen retention forks apply 18*32=576 records. Total=2,112 applications per complete job. DEV=8*7=56 jobs/118,272 records. Conditional confirmation=48*5=240 jobs/506,880 records. Maximum=296 jobs/625,152 records. Twenty-one state trajectories share prefixes and are not independent lives.

The scored stopping scenario pays 4n+32 external records, plus the actual production compute of that arithmetic prefix and its own interference fork. Earlier measurement forks do not teach the root and do not contaminate its per-scenario CPU. They are still charged to total experiment execution.

## Statistical and scope checks

There is one DEV-selected FULL candidate and an independent confirmation. The twelve primary tests and two separate mechanistic tests are fully enumerated. The per-operation causal conditions prevent a single operation's gain from being presented as four-operation learning. No arbitrary absolute accuracy percentage is introduced. Error-free bounded-grid competence is reported separately from statistical improvement.

There is no previously demonstrated raw-byte four-operation learning positive control. The analytic evaluator is only a task witness. This limits causal localization of a negative outcome and is stated in the design. No current recipe or whole mechanism family is rejected by this static review.

## Unresolved implementation/scientific risks

1. A generic recurrent learner may still need more data than this budget. Removing arithmetic priors makes this a harder, more honest learning test; it is not a guarantee of success.
2. FULL confidence is approximate when the learned feature basis changes. Stable fitting with a frozen encoder does not establish stability under feature drift. No free transport or confidence reset is assumed.
3. Gradients must respect the pre-update online readout at each event. A naive end-of-record gradient against the final readout is wrong for the specified recipe.
4. The decoder can still learn premature termination. EOS remains legal, while low-budget acquisition and the full error curves expose collapse before confirmation.
5. The interference cohort changes both representation and readout. N_OLD disables old writes only; disabling its later writes would destroy the causal comparison.
6. A dense recurrent vector cell is not biological scalar-cell equivalence or a validated scalable circuit. State, work and bandwidth must be charged.
7. Complete technical-job cost is unknown. Admission requires a measured conservative whole-study estimate within eight hours; an ETA is not inferred from the previous MLP.
