# Provenance and interpretation

Input: the seven-part R3 scientific package shipped to Downloads and archived
unchanged under second_try_copy/R3_OBSERVED_OUTCOME_PACKAGE_20261003. Its source,
canonical Full151 assets and signed teaching implementation are copied into
`vendor/` without scientific edits. The original personal-path redactions remain
as published; README/PUBLICATION_SCOPE are retained in `upstream/`.

Production `centered_core/` is a new engineering adapter, not a modification of
the archived study runner. It implements only R_center. The independent
reference adapter retains the original R3/R_center/R0_signed equations and
records the minimal authorization/bootstrap adaptation in
tests/reference/ADAPTATION.json. No original gate is represented as passed.

The upstream analysis is included as results/UPSTREAM_ANALYSIS.json. It compared
64 paired worlds per arm: R3, R_center and R0_signed. R3 minus R_center in old
causal effect was +1.465 pp, simultaneous interval [-0.610, +3.540] pp, below
the prespecified 5 pp simplification tolerance. R_center final W accuracy was
96.09% old and 94.82% new. The tolerance concerned old causal effect, not every
endpoint. Private-only readout was near ceiling in all arms, so the result
does not establish increased private storage capacity. Learned p was not shown
necessary on that tested history; it is not proven useless in all settings.

Exposure audit: all scored upstream cue/answer associations were directly
taught. Actual received answer bytes supply training. This is E1, and an
exact-key lookup can solve it. Our new engineering fixtures use fresh development
world IDs and the same observable clock; their labels also are taught, and no
E3 inference is made. Engineering tests cannot replace the existing efficacy
study. Their purpose is to preserve its tested behavior in a deployable core.

No efficacy parameter, topology, input code, output rule, alphabet, calibration
or inference threshold is optimized in the three cycles. Shared-bank deletion,
new mechanism search and E3 tasks remain future choices, not implicit additions
to this engineering delivery.
