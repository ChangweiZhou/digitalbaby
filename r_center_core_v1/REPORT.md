## 第一阶段交付是什么

`centered_core.CenteredCore` 提供 `feed`、`predict`、`observe_outcome`、
`flush`、`rest`、`clone`、`save` 和 `load`。既能作为 Python 组件使用，也能
通过 JSONL 接收字节事件。没有教师隐藏路由：实际到来的答案字节构造教学目标，
输出在反馈到达之前产生。关闭教学时，八个存储的两种写入接口都被关闭。

交付包含独立运行所需原生代码和数值模型，不需要旧实验数据。
Python 3.11.5 / NumPy 2.2.6 / SciPy 1.14.1 / Numba 0.61.2 的 macOS arm64
环境已资格化。其他主机需要运行相同资格检查；不承诺任意浮点实现逐位一致。

历史公开包保留了原科学 LOCK.json，但部分个人路径已脱敏。因此这里建立的是
**新工程版本**的 SOURCE_LOCK.json，覆盖实际交付的 110 个执行源文件和资产。
没有修改历史实验、把脱敏副本冒充原锁字节，或在运行时自动绕过失败。

## 结论边界

原 R3 消融结果支持在其预先规定的旧题因果效应容差内采用 R_center 简化。
它不证明 learned-p 在所有任务都无用，也不证明私有存储容量扩大。
原结果是 E1 已教关联学习/保持；本次是 E0 工程等价性验证。

当前接口保留 12 字节提示、四个答案通道和“最近四个非空格字节”的 CONTENT
地址。精确键查表可以解决这些已教题。泛化、无教师学习、长串无碰撞、自动停止
和开放字节生成没有被本次结果证实，也没有被加入此次交付的验收门槛。
这一交付可以作为后续核心机制测试的稳定基线，后续候选与基线应使用相同输入
信息和输出规则。
