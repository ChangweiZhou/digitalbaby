# Cycle 1 — source audit and revision

Audited the independent study learner and native teaching implementations before
the trial. Production has no environment imports, hidden labels, or branch/stage
arguments. Every store is canonical-born independently; clones are reserved for
state forks and read-only probes. Both native and signed write APIs receive the
same explicit learning flag. Private signed coefficients are exactly .25-y.

Revision from the published interface: validate finite monotonic times and byte
types BEFORE mutation; reject a thirteenth cue byte, repeated prediction,
out-of-slot outcome, and a missing newline. The published wrapper incremented
cue_count before a lower-level byte validation and left some illegal sequences
to downstream code. Production now rejects those sequences without mutation.
Valid published histories retain exact native behavior.

No scientific source gate is bypassed: the study remains archived. A separately
documented technical reference removes its archive-only gate calls and changes
one bootstrap import; it cannot authorize old scientific execution. Unused
learned-p bookkeeping is removed only from the R_center production adapter.

Acceptance: exact emitted bytes, exact bank states and exact native values,
eight independent births, clone isolation, all-eight-store write-off regression,
and invalid-operation rejection. Trial result is results/CYCLE1.json.
