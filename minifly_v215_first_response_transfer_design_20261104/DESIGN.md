## 1. 研究问题与判别

V214B 中真实线索相对打乱线索降低了全流压缩损失。单一迁移世界中，24 个先前世界相较 8 个使全流损失上升约 111 bits，却使答案区间损失下降约 10 bits。V215 改测一个直接行为：在看到同一当前故事后，正确的检索线索能否帮助模型第一次独立答对从未教过的状态组合？

若真实线索只改善压缩，或只改善观察正确答案前缀时的损失，则本版保留其预测诊断价值，停止把这一版检索路径作为自主迁移候选。若真实线索提高完整作答，但等暴露的无相关问答对照也达到同等水平，则只归因于当前故事中的检索收益。相关历史的增量效应另行检验。

## 2. 世界、暴露与连续经历

采用 **16 个独立配对世界族**。每族训练两段源世界 A，接一段无关干扰流 B，再从同一个结束状态创建目标探针。每族有 **8 对反事实双生题，共 16 个首次作答机会**。四对在目标事件后提问，四对在目标事件与问题之间加入等长无关事件。两种延迟均已经历同一 B。所有臂在每个目标分支读取相同原始字节。目标分支彼此隔离，从同一父状态开始；分支的作答和反馈均不回写。另设少量同一家族内的已教、仍有效的 OLD 哨兵，在 A 后和 B 后以只读作答分支评分，用于定位作答接口与干扰损失。

目标题锁定的是**事件与状态的组合**。例如，双生题共享拾起物体、移动、放下和末尾无关事件的字面记录集合，且问题字节相同。仅交换移动与放下的先后，正确答案就从地点 B 变为地点 A。源示例覆盖构件与相关任务反馈，保留目标组合及其同义表达、实体重命名和地点互换版本为未教。两条分支中的真实地点可作为当前故事中的事实出现；标准问答对、等价问句下的反馈以及同一语义组合的教学示例不得出现。保持同一事件多重集合、相同问题和匹配末尾干扰，平衡地点频率、答长和 A/B 方向。目标实体与先前实体按实际 tokenizer 规范化后隔离。部分熟悉模板保留，以免把新措辞识别和状态组合混成唯一难点。

评估侧从事件记录重建状态，锁定唯一地点和完整答案。语义暴露清单至少含动作关系、事件序、相关持有状态和真值变化。精确字节、规范化词串、语义等价类三层排重。每对均验证两个答案不同、故事全可观测、无歧义、结尾正确且在输出上限内。正式世界族、工程世界族、生成器版本及种子互相隔离。正式种子以 `SHA256("MINIFLY|V215|FAMILY|" + i)` 的前 64 位生成，i 从 0 到 15；工程种子使用独立命名空间。先锁全组再给模型看数据。任何非法家族必须在训练前解决，开跑后不能替换。

## 3. 主指标与生成接口

**主指标是未教组合的首次完整自主答案准确率。** 对一个问题，模型看到故事和问句到固定的答题起点，随后只读入自己生成的字节。成功要求原始字节逐一等于唯一标准答案，且下一字节由模型自行生成原有的换行终止符 LF。空答、过早终止、错误字节、额外空格、答案后的额外字符，以及达到 **32 字节**仍未正确终止，均计错。每题只取一次；不做答案词表限制、重排、修复或强制终止。换行是原记录的真实结束字节，32 字节仅是失败预算上限。锁定前核实所有标准答案加 LF 均能在上限内完成。

模型按正常因果规则读入故事与问句，允许在线吸收当前世界事实。进入答题后冻结长期计数、GLN 权重、联想写入与文档频率，只用自身生成的前缀推进瞬态字节、词和行状态。沿用 V214B 的条件位预测，以固定阈值逐位贪心生成（概率恰为 0.5 时取 0），八位组成一个字节。所有臂使用同一规则。评估器只负责在字节生成后识别 LF 并评分。模型看不到故事状态、实体角色、正确字节、候选词表或答案长度。该解码使用自身历史前缀，所测是这一固定解码策略的行为。

需要区分两种软件路径：原 V214B 正确位到达后立即更新的流式路径用于历史兼容性复核与压缩诊断；V215 冻结写入的自主生成路径是新接口。若新增有界检索改变原轨迹，单独报告，不能用 V214B 的数值充当 V215 的源等价证明。

## 4. 固定对照与预算匹配

| 臂 | 历史与检索 |
| --- | --- |
| TRUE | A 有相关问答反馈，B 相同。按原始因果线索查询 H1/H2，使用共同有界访问器。 |
| SHAM | A、B 与 TRUE 字节完全相同。H1/H2 使用已观察、预先规定选取方式的错配来源。 |
| NO-RELATED | 使用 TRUE 检索。A 的可观察故事相同，相关问答替换为无关且同样可由源故事回答的问答。匹配教学记录数、答复字节数、外部总字节数和写入机会。B 及全部目标输入相同。 |
| BASE | A、B 与 TRUE 相同，关闭联想检索，保留普通 GLN 字节专家。单列其自然较低的检索成本。 |

TRUE 对 SHAM 检验正确线索的价值。TRUE 对 NO-RELATED 检验**相关问答反馈**的增量价值；两组仍共享源故事，故这个比较不主张移除了所有先前相关信息。若无关问答无法匹配，或意外教了相关组合，不准入。NO-RELATED 的匹配由数据侧在运行前完成，运行时不给模型教学类别。

SHAM 使用可因果获得的错配行，在已观察行内按词长度、行可用性和截断度数分层选择。使用锁定种子、固定候选上限和独立 RNG；不得读取未来数据、正确答案、隐状态或评估标签来选错配。两臂共享候选过滤、缓存、数值路径、写入次数、单次 H1/H2 调用和固定槽访问上限。空槽以统一零贡献填充，记入调度槽数但单列真实行访存。资格阶段冻结分层规则、H1/H2 行访问上限和填充策略，再开启目标世界。禁止在正式结果出来后更换打乱策略。

逐族报告调用数、实际行访问、槽数、非空率、前缀通过率、专家有效率、写入、CPU 和错配可用率。在相同观察前缀上审计两臂，按问题前缀和正确前缀的影子诊断分别报告；自主输出分叉后的工作量和长度单列。技术准入要求相同前缀下调度槽与写入机会一致，H1/H2 分别至少 95% 的有真实来源调用能找到合格错配；在资格世界族中，实际行访问总量相差不超过 5%，并揭示覆盖率和置信度差异。分叉后不得为凑预算让已停止的模型继续答题。若正式共前缀审计违反预锁匹配门，照实标记对照无效，不能用全流 bpb 或 BASE 补成因果结论。资格时仅可根据工程数据细化匹配规则；同一前缀上的语义信息损失是干预本身，不要求两臂预测分布相同。

## 5. 统计与保留的压缩指标

每个臂先计算每个世界族的 16 题准确率，再计算 **16 个配对族的等权平均差**。主要机制比较是 TRUE 减 SHAM。只有该比较满足门槛后，按固定顺序检验 TRUE 减 NO-RELATED。每一步要求配对差的双侧 95% Student-t 区间下限大于 0，且点估计至少 **6.25 个百分点**，对应每族平均多答对一题。这个数是可解释的最低决策收益，不是预估效应。16 族为固定开发规模，不作高功效保证。完整报告每族差、两个区间、短延迟和较长延迟分项、双生题两条均答对的比例、OLD 保留，以及错误终止分类。问题、双生分支、位和字节都不当作独立统计样本。

运行前预锁并逐族评分下列对照：确切问题及标准化问句的最后一次已教答案查找、常数或频率、最近地点、问题实体邻近地点与词袋共现。它们和模型同样只见到合法前缀。语义状态机为评估器的正对照，必须解出每题，永远不向模型供值。双生同问且答案不同，忽略事件顺序的策略不可能在一对上两条均答对；最近地点策略仍需实测。若有捷径可解释表现，只报告该层证据。即使双主比较通过，仍须结合双生题、较长延迟、暴露和捷径检查才可称为本任务族的开发阶段结构复用信号。这个实验不构成正式 E3 认证或核心采用。

压缩指标在**独立影子分支**保留：全流 bits/byte、答案 payload bits/answer、答案终止符损失及非答案损失。影子分支按 V214B 的逐位预测后更新规则读真实流，绝不回写任何自主探针。另报同一状态下真实答案前缀的只读损失，定位条件预测与自由生成之间的差距。历史压缩 bits 可用于重建 V214B 的比值。V215 的效率表以物理输入字节、独立事件、答案反馈字节、实际累计 CPU 与峰值内存分别列账。

## 6. 规模、资格与决策

初始名册为 **64 条训练生命**（16 族 × 4 臂），**1,024 个主探针分支**（64 × 16）。每条生命最多 8 KiB 的 A、2 KiB 的 B，每个主探针最多 1 KiB 的观察前缀，影子压缩流每条生命最多 4 KiB。OLD 每条生命最多 4 个独立作答分支，各至多 256 字节前缀。上述主路径观测预算合计不超过 **2,031,616 字节应用**，含重复前缀；所有自主生成最多 **40,960 字节**。额外的只读诊断、参照和资格工作也逐次入账。建议累计硬上限为 **3,000,000 观测字节应用、1,800 CPU 秒、3,600 活动墙钟秒、1 GiB 峰值 RSS、128 MiB 留存输出**。资格前为建议约束；一经授权与冻结便不得上调以救结果。逐家族串行处理或以实测准入并发，尽量流式聚合，避免把所有分支状态同时存盘。

V214B 的两张固定表本身约 36 MiB（float64 概率和 uint8 计数），此外还要实测 GLN 字典、联想袋、瞬态状态、复制及输出的峰值。保留源级参数与可变存储普查。无界联想存储即使通过本次有限名册，也不能据此称为有界长期架构。

后续实施的三个资格循环，各执行一次**修订 → 审计 → 真实测试**：

1. 恢复并核对真实源的压缩轨迹，测试无未来数据、逐位自回馈、冻结写入、固定 LF 和边界评分。用同一提示、不同隐藏答案证明生成不受未来标签影响。
2. 用独立工程世界验证双生反事实、语义排重、OLD 哨兵、NO-RELATED 匹配、正对照及捷径基线。跑真实 TRUE 与 SHAM，审计有界访问、实际访存和错配覆盖。
3. 用完整入口跑小型工程名册，涵盖四臂、两种延迟及全部诊断。重新计算精确分数，验证状态不回写、收据与资源预测，再锁定正式名册。若全名册资源或对照无法准入，记录原因与 NOT_RUN。

通过资格后仍需另行授权正式运行。有效负结果停止 V215 原样方案的推进。若完整作答提升且对照与暴露审计均通过，才有理由在新世界族上确认同一假设。设计审查不等于运行资格或正式验证。
