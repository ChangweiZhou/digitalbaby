## 仍然存在的实质风险

- signed 原生基底未必像梯度下降，尤其有状态分配与裁剪时；符号及有限性必须实际资格，数学残差正确不足以证明模型会学。
- A1 会改变 PN 分布与支持，不只是打开缺失通道。其有效强度未严格匹配；结论限于接口算子，不宣称单独证明支持变化原因。
- C 使用 STE/meta-BPTT，不能当作硬 top-k 的真实梯度或局部生物学习。
- 稳定 private 不能阻止 shared 旧知识干扰；确认没有专用 frozen controller，因此不作其必要性的独立主张。
- 严格 OLD 无损保持门可能造成未决；这是预定目标约束，没有通过事后容忍带解套。
- 没有已知低剂量原始字节加法神经阳性。负面只排除当前配方/预算，不证明所有原生改造均无效。
- 新任务仍只是两数 0–9 加法组合内插，不能声称长度、其他运算或语言泛化。
