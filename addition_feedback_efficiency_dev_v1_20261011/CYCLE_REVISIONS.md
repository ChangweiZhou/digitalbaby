# Three-cycle revisions and audit record

This exercise does not run DEV or confirmation science and does not select a recipe.

## Cycle 1

Six complete jobs on world 941001 passed independent reconstruction. Baseline equations match the accepted COV-R/DIAG-R sources on 480 local transitions. Before the complete jobs, mutable-payload and estimated operation/traffic accounting were added to the independent snapshot audit; their tamper cases are exercised in cycle 2. No learner failure occurred in cycle 1.

## Revision before cycle 2

Reducer input admission now rejects repeated DEV world IDs, missing roster cells, nonfinite/out-of-range abilities or effects, and invalid resource charges. This prevents duplicated or malformed summary rows from influencing selection. Synthetic tests exercise repeated worlds and NaN rejection. Numerical learning equations, scientific population, endpoints, gates and candidate roster are unchanged. Cycle-1 sources remain in its source snapshot; cycle-2 sources are re-locked before execution.

## Cycle 2 cold-restore fixture failure

The first cycle-2 attempt failed before any complete full job: operations.py replayed the predecessor's synthetic target `(3*i)%9` while the local checkpoint test used `i%9`. Clocks/byte counts matched, learned state did not. The failure is preserved in `cycles/cycle2_cold_fixture_failure`. The restored test input now matches the checkpoint's deterministic continuation. No scientific update, design, gate or prior accepted receipt was changed. Full technical jobs in this failed attempt: zero. Local synthetic tests did execute and remain separate expenditure.

## Cycle 2 and cycle 3

Cycle 2 completed 12 accepted full jobs. Each of the six arms passed a detached cold restore; all 16 tamper classes (17 for replay/extra arms) were rejected on complete receipts. No learning or efficacy gates were changed.

Before cycle 3, descriptive reporting was completed: 75/90% first-observed sample crossings with right censoring, taught-cue readouts, and actual external/extra update counts. A paired-world reducer now checks identical source/streams/configuration roster and keeps learned one-operand countermodels descriptive rather than adding them to the locked shortcut adoption gate. Sources are re-locked for the final qualification; candidate numerical kernels remain unchanged.

Cycle 3 completed 24 accepted full jobs with two detached workers on four family/noise strata. All six cold restores passed again. A separate paired reducer test used six already committed receipts and rejected changed source, changed stream, and duplicate-arm input; it generated no new learning records. The final source lock is cycle 3’s exact source snapshot. Each cycle requires its own accepted summary; completion is not inferred from local unit checks.
