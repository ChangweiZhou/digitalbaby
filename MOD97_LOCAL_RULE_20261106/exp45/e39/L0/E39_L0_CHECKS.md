## Conventions the brief leaves to the worker (recorded, not changes)

- **"State of visit n"** is the state after n visits (visits 0 to n − 1). A resumed life regenerates the earlier visits' stream (no network) to complete the life's stream digest, and asserts each regenerated visit equals the one stored.
- **Answering** uses `arch26.forward` with `local=False` (forward values are the same under either rule), reading each row at its own last byte; generated bytes are appended and all three are generated even after a wrong one.
- **Replay batch order**: the first (1 − ρ)·48 new items, then the replayed ones. Replayed items are drawn from the buffer as it was before the update's own offers.
- **Branch**: the k-th visit of a branch uses `Random(f"world|{S}|branch|{n}|{k}")` with k from 0 and n the state's visits; its event file holds the branch's events only, its counts continue from the state.
- **Scorer**: "the visit's first update" is the smallest update number among the visit's asked items; relearning counts `seen` from the task's first asked item in the visit; kept at return is pooled over items. Which tasks are symmetric is read from the world's task table (the world's seed is the scorer's only other input).
- **CPU** is `time.process_time()` of the life's own process.
