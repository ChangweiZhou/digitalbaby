# NATIVE-BIND V2.1：三轮技术周期报告

2026-10-17。**三轮技术资格通过；正式科学实验未启动。**

目标仍是 Full151/R_center 原生路线在更少全部样本和实际计算下，提高未见加法题的完整自主字节输出，并保护 OLD。没有增加其他任务、算术规则、注意力、Transformer、ELM 或独立答案头。

| 周期 | 实际技术记录 | 核心结果 | 审核后的修订 |
| --- | ---: | --- | --- |
| 1 | 52 | NATIVE 的 MEM/LEGACY 与母体前向完全一致；257 个目标的 ERROR 方程方向与 argmax 正确；5 类 frame 误用被拒绝；九臂均可训练 | 把初始化计入生产 CPU；记录写入端实际收到的教学系数 |
| 2 | 104 | 同流 CUT/THROUGH 首次更新前状态相同；第一次事实写入→以后重询的导数在 CUT 为0、THROUGH 非零；九臂通过非零禁写 | 第三轮以九臂实际加法 OLD/rest/NEW/rest 为主，并把小型记忆探针单列，避免用合成任务代替加法流程 |
| 3 | 256 | 九臂、W/N_OLD 连续流程通过；独立收据审核与选择/统计反例通过；恢复后真实下一段完全一致；四进程兼容性通过 | 发现并修复继承检查点未绑定 cursor/resource 的遗漏；在剩余预算内验证修复与并发。另补模拟 rest 的实际 CPU 计费 |

合计 **412 条完整技术记录应用**，包括母体对照、梯度探针、恢复对照及失败审核后的必要验证；没有超过512上限。九个加法 jobs 属于技术世界和短前缀，**科学 jobs 为0**。单事件方程 fixture、无训练 detached 进程及合成统计 fixture 另列，不计科学样本。

## 得到了什么证据

在两组因子背景中，孤立第一次事实写入对后来重询 loss 的导数分别为：CUT=0、THROUGH=-1.1957106002；CUT=0、THROUGH=-1.2016501727。固定预测信号的原生写入导数相对误差约6.11e-10。它们证明明确的代理信用路径存在，不证明硬 top-k 的真实梯度或生物局部资格学习。

独立 auditor 没有导入或运行 learner；从真实缓存 logits 重算504个预测目标的教学系数、损失、时钟、权限及完整答案分数，并拒绝错误系数、禁写失效、过期 frame、伪造分数和负初始化成本。检查点补丁另拒绝5类 cursor/resource/frame/state 篡改。初次篡改被错误接受的记录原样保留，未从审计历史删除。

## 小型记忆检查不是泛化结果

三个固定锚点都只看两条任意原始字节提示与一字节答案，每条重复12次，合计24次。输出由模型自行生成 payload 和 EOS。

| 模型 | 训练前 | 24次呈现后 |
| --- | ---: | ---: |
| NATIVE | 0/2 | 2/2 |
| F000 | 0/2 | 2/2 |
| F111 | 0/2 | 2/2 |

因此最小答案/EOS学习通路可以工作，不能再把此前所有失败归因于“根本收不到答案反馈”。它不证明多关联容量、阶段干扰或加法规律已经解决，也没有产生候选排名。加法短流程的HELD行只是技术审计样本，不用于推进或采用。

## 设计的实质改进

1. F000现在可按根配方推进；其他候选仍须超过F000。若共同改动已有效，不强迫再加机制。确认F000时不制造S−S比较。
2. 同一 prediction frame 绑定预测与实际写入地址，拒绝重复、过期和跨模型使用。答案只能在预测之后进入。
3. 所有因素看同一ABAB及原定尾窗。C只改变跨记录原生图；π停止梯度的限制明确，不把课程和信用混为一谈。
4. 增加0–4字节后缀下一字节背诵对照；保留全字节/EOS自主输出及样本、CPU、OLD门。
5. 检查点绑定状态、游标、资源和frame序号；初始化与模拟rest真实费用计入。每轮源快照与测试结果保留。

## 运行范围和下一步

已完成的是可执行核心、技术连续历史、独立审计、恢复和四进程短测。四进程试验包含一名反传 worker 与三名只读 worker，不伪称同时测了四个完整反传生命。单进程测试峰值约1.46GiB，保守四worker估计约5.82GiB；完整科学job没有实跑。运行时间仅可由短窗口与满16字节生成测量投影，不能保证。

设计维持 DEV8世界×9配置=72jobs；仅预定赢家进入16个新世界的确认，最多6配置。DEV与确认按四世界会话分段、8h停止准入、10h硬上限。正式启动前只剩campaign控制器/manifest准入和实际会话资源检查；它们不得修改已资格核心、追加学习设计或重跑训练前缀。

**不自动启动科学、不选择技术赢家、不采用新核心、不上传GitHub。**
