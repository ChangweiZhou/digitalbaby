# Recovered MiniFly experiment source
     
This archive preserves the V36–V49 Python sources found in the local MiniFly archive, including the V35 dependency used by the V36 separation runner. The V39 earned-consolidation and V40 complementary runners at this directory's root were published first and match the V188 source lock. Alternate experiments with the same version number have distinct filenames. The V41–V43 runners, build helpers and bundled Python inputs retain their relative archive paths.
     
RECOVERED_SHA256SUMS lists the newly recovered files. From this directory, run `shasum -a 256 -c RECOVERED_SHA256SUMS` to verify them. Python syntax was checked without running the experiments. Some historical build, analysis or execution paths also require external inputs or historical result files. The archive establishes source availability. Each scientific result still requires its own provenance and reproduction check.
