# Read-only evidence census for earned-authority revision

No new learning, no threshold search, no frozen file edits. Source census script and JSON are in /private/tmp/authority_evidence_census_20261007.py and .json.

## Accessible evidence

96 archived ERROR confirmation jobs (48 binary, 48 lifetime), plus 3 full technical DEV jobs from earned-authority V1. The 64-world Latin studies have aggregate analyses but not complete publicly accessible per-option vectors. Available original raw Latin scope remains one R_center science world and an ERROR technical pilot; the V1 Latin development job adds one ERROR world, not a new Latin confirmation cohort.

## Legal signals

Receipts store every ordinary pre-answer shared/private four-channel prediction and the teacher byte only after it arrives. Thus a fixed-size online calibration state can be reconstructed from legal teaching events. For disabled-write records, calibration must follow the relevant causal write flag: it may not use the delivered answer merely because metadata says no native write.

The native CONTENT store has no learned per-key familiarity counter or flag. Its four-byte buffer is sensory state. Its fixed-size lru cache only memoizes deterministic receptor construction. Native adaptation is also driven by unreinforced exposure, so it cannot by itself tell whether the association was reinforced. Native fast/slow contrast mass across output stores is a potential activity-local support signal, but it is not stored in the raw receipts and must not be called calibrated reliability without a new qualification. It can be read over active KCs without a history-sized key table; signed cancellation, initial common state, clipping and decay remain failure cases.

## Main findings

On prequential old teaching, standalone shared/private argmax accuracy is respectively:

- Binary 48 worlds: 39.8% / 95.2%.
- Lifetime 48 worlds: 24.1% / 91.9%.
- Current Latin DEV: 25.0% / 94.3%.

Ordinary teaching strongly rewards ERROR rather than Q_HALF: lifetime 48-world W histories have 5,539 output disagreements, Q_HALF helps96/hurts4,897; binary histories 1,208 disagreements, helps15/hurts1,193; current Latin DEV71 disagreements, helps1/hurts63. These are E1 teaching predictions, not final E3. A global or per-output teacher-calibrated gate is therefore likely to learn full private authority. It does not automatically discover the held-out benefit of half-weighting.

Private normalized final W top-two score gaps differ descriptively by reinforced address: binary taught median1.494 (10–90% .923–2.008) versus heldout .257 (.038–.709). Shared gaps overlap: taught .249, heldout .244. Current Latin DEV private taught median1.686 versus heldout .122. These differences support a familiarity hypothesis, but do not justify choosing a threshold on scored held-out data.

Binary raw four-channel spread is confounded by unused outputs2/3 being suppressed: shared spread≈5.3 versus private≈.84. Authority must use the legal decision roster. A two-option query compares the relevant0/1 values across two contexts, not the unrelated channels2/3.

Latin DEV shows output bias: W shared chooses2 on all4 heldout cues; private chooses1,1,3,3. ERROR0/4, Q_HALF1/4, private2/4; N_old private1/4. These four examples cannot choose a policy, but reject universal assumptions that shared is always the useful route on unfamiliar contexts.

## Design implications

1. Replace an unearned margin heuristic with a precisely named learning hypothesis, not a claimed reliability probability.
2. If ordinary-byte calibration is implemented, keep it bounded, output-permutation-equivariant, update only after an arriving teacher and only under allowed writes, and retain identical baseline learning. Assess class bias separately from uncertainty.
3. Do not expect global teaching accuracy to solve query novelty; it mostly rewards memorisation here. A locality-bearing support feature is necessary for that claim, but a per-KC seen mask can saturate at larger key loads and does not prove familiarity of a conjunction.
4. A bounded sensory-key familiarity sketch could remember reinforced address access without labels or answers; it is legal internal evidence, but it is additional engineered memory and may collide/saturate. It must be compared with an equal-resource neutral/skuffled control if credited as a core mechanism. It cannot create Latin relation information.
5. No authority rule is justified as a universal cure for both task families by the accessible data. Require fresh frozen tests; preserve E1, report E3 separately, and allow a valid negative outcome.
