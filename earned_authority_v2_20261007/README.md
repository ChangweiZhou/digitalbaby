# Earned authority V2 review package

Start with `ITERATION_REPORT.md` and `EXPERIMENT.md`. `STATUS.json` records the deliberate decision not to launch formal science. The native core version is unchanged.

Prototype unit tests, with Python3.11 and numpy2.2.6:

```bash
python -B -m unittest -v test_experience_policy
```

The policy and its synthetic unit tests are standalone. `replay_experience.py` and `qualify_prototype.py` additionally depend on the sibling frozen project/source fixtures and archived receipts referenced in their code. The ZIP includes replay outputs and source references, **not the native assets or archived trajectories**. It is a review package, not a self-contained cloud science runner.

`replay/SUMMARY.json`, `HISTORIES.json` and `ROWS.json.gz` describe new authority-observer learning on old recorded predictions. The 99 referenced native jobs were not rerun. The 48 historical worlds and the one Latin development world are exploratory evidence, not new confirmation seeds.

`SOURCE_SNAPSHOT.json` describes the final prototype sources. `RULE_LOCK.json` existed before the first replay and stayed unchanged. Neither is a release lock for a native worker/supervisor. Native-plus-authority integration, complete joint checkpoints and a production dispatcher are not qualified or supplied here.
