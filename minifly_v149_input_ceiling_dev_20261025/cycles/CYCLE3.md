# Cycle 3: rehearsals and lock (25 Oct 2026)

Two rehearsals were run. The first found a protocol defect, which was fixed, and the second ran the final protocol on a fresh dev text. **Development results**; nothing was scored on the main text.

## Rehearsal 1: Bryant, cycle-2 settings
Command: `python run.py --text bryant --train 40 --calib 5 --held 10 --l2 100,30,10,3,1 --r2grid 0.001,0.003,0.01,0.03,0.1 --maxiter 300 --tag c3_rehearsal`. Output: `results/c3_rehearsal/` and `results_c3_rehearsal.log`. Code hashes were the same at its start and its end.

* **Ladder:** unigram 4.529, bigram 3.712, PPM-2 3.359, PPM-3 3.198.
* **Readout checks:** all pass. Last symbol 3.702, last two symbols 3.264, constant 4.523.
* **Arms (R1 / R2):**
  * PERM-obs 4.080 / 4.383;
  * PERM-x 4.019 / 4.388;
  * FE0-x 3.657 / 4.269;
  * PERM-last 3.722 / 3.888.
* **Registered rules applied to this dev run:** CONTEXT_FIRST, with P1, P2 and P3 as predicted.
* **Defect found.** PERM-x chose L2 = 100, the top of the grid, and its calibration score was still falling there (3.719 at 30, 3.636 at 100). A ceiling chosen at the edge of the grid may be underestimated, and P2 compares exactly that arm. The primary arm chose an interior value (30), so the decision rule was not affected.

**Fix, before the lock:**
* The L2 grid was widened to `1000,300,100,30,10,3,1`.
* `run.py` now records `lam_at_grid_edge` for every fit.
* Re-running on Bryant after seeing its results would mean tuning on the rehearsal text, so the final protocol was instead rehearsed on a fresh dev text: Edgeworth's *The Parent's Assistant* (`edgeworth-parents.txt`, SHA-256 `543b2162…f950`, from the same NLTK archive). No earlier round had used it.
* The checks were re-run on the final code: 18/18 pass. The extra check is the new text's pin and split. `cycles/CYCLE1_CHECKS.json` was regenerated by this run.

## Lock (`LOCK.json`, written by `make_lock.py`)

  * the runtime closure from `sys.modules` after importing the runner: the V149 modules, V148's `corpus.py` and `ladder.py`, `fastmem.py`, and the native stores and reference sources;
  * the native birth assets and the output codebook;
  * the scorer `summarize.py`;
  * the five text files.
* **Settings:** `cycles/SETTINGS.json` (40 / 5 / 10 KB; L2 grid 1000 … 1; R2 grid 0.001 … 0.1; 300 iterations).
* **Decision rule:** margin 0.10 bits.
* **Predictions:** the three predictions as registered in the design.
* `run.py --main` refuses to start if any hash differs or the text is not `brown`.
