The native comparison then stopped because independent births have distinct provenance fly IDs. ## What the saved responses clarify

A separately logged bounded saved-response audit used the last NEW pass's existing pre-update native values only: 44 and 46 target sites. For each rival, the maximum target advantage over all independent gates in [0.5,1.5] is `sum(a)+0.5*sum(abs(a))`, where `a=center(C_y-C_r)*v/4`.

Seven of 44 sites in world 711 and one of 46 in world 712 have a rival that cannot be beaten by any allowed gate at that saved native read. This establishes a specific actuation restriction, not that the entire architecture is impossible. These are pre-update teacher-forced states; subsequent native writes can change the read. Absence of this certificate does not prove joint gate feasibility or policy reachability. No new model query or teaching event was used.

Native value norms were substantial (median approximately 9.50 and 8.59), so these failures cannot simply be described as a zero memory signal. The learned gates moved by as much as 0.124 from identity, yet full-record credit still did not improve exact answers. The experiment leaves actuation, conditioning and fixed-dose optimization unresolved; it does not identify short temporal credit as the sole cause.
