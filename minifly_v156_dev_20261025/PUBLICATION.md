# V156 publication scope

This publication contains the V156 design, implementation, three-cycle reports, aggregate results, revised proposal, audit certificates and compact result bundle. Raw records, checkpoints, feature matrices, witness parameters, per-prefix logits and raw response files remain local and excluded.

The scientific status, package and bundled metadata were sealed before publication; their `github_pushed: false` fields describe that prepublication snapshot. They do not trigger a rerun, and publication does not authorize the revised follow-up experiment. The verified Git commit and remote branch identify the published payload.
