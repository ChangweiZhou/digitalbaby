# Learning-spectrum preflight: reject this candidate; no full run

Three experiment-design → independent-audit → small-test cycles completed. No fresh-world Full151 life was run. The user's necessary theoretical gates failed, so the requested conditional full run was deliberately not started. The frozen candidate was not tuned after these failures.

## Main result: useful geometric change, inadequate learning speed

A single causal elementwise baseline subtraction before recent×current interaction features raises interaction energy from .2145% to approximately2%. Common energy falls from88.44% to approximately52–55%. The native FE0-relative shared-kernel tests pass, including an identity-address negative control.

Nevertheless, the task-relevant minimum normalized eigenvalue reaches only approximately.00089–.00096, below the frozen .009286 requirement. The exact chronological teacher-to-query operator, including nonstationary features, all decay and new-item interference, predicts minimum symmetric interaction formation only1.81–1.84% at old_end, versus20% required, and .204–.207% at final, versus2% required. A preserved shared kernel does not rescue insufficient task learning speed.

The exact added-bank response prediction matches an independent direct four-channel update replay within4.44e-16. No clipping occurred. This validates the finite-horizon calculation for this bank, not a prospective total-model behavioral theory. No independently justified fresh-world native-plus-bank score/margin forecast exists. The report therefore records **NO QUANTITATIVE THEORY PREDICTION** for prospective total accuracy and for every unopened Package A arm. Existing final native values were not silently inserted into a supposedly prospective forecast.

This candidate is rejected at preflight. No claim is made that centering generally cannot work or that prospective science falsified an untested theory. There is no new beta/gain/amplitude/decay/target search and no latent-variable explanation added to reverse the stop decision.
