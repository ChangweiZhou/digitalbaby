# Changes from Claude V6 to V6 R1

Claude's original is retained verbatim with its GitHub blob identity in CLAUDE_SOURCE.json. The revision keeps the motivation for learned recurrent state and removes unsupported causal or performance claims.

| Original item | Revision and reason |
| --- | --- |
| The current fly is simply a fixed linear lookup and cannot compose | Identify the actual native nonlinear value route, separate failed acquisition from held-out failure, and retain the older limited synthetic E3 results. No architecture-wide impossibility claim follows. |
| The 254 mechanisms concern storage alone and contain no state/gating | Review the complete register. Context routing, learned encoders and temporal attribution exist. They are not a validated recurrent arithmetic procedure, but cannot be erased from the history. |
| Blind scaling is not a fix | Incorporate ADDRESS-CAPACITY's favorable E1 result and its 3.15× CPU/4× cell-state cost, rewiring and measured self-gain difference. Keep it separate from arithmetic procedure learning. |
| Learned working memory, rule register, chunking, memory arbitration, sleep replay and optional queue together | One candidate: learned recurrent neural state upstream of native value output. Defer the other mechanisms so the comparison remains interpretable. |
| Carry register and 200-entry arithmetic table as the explanation | No designated carry representation, digit table or semantic intermediate targets. A useful state must emerge from raw feedback. Delete ungrounded sample-count and window-accuracy forecasts. |
| One-step local credit described as approved | Specify a proposed rule explicitly. A prior memo's word “approved” is not human authorization to implement or run it. |
| AuGMEnT listed as an interchangeable nonattention learning option | Its paper explicitly includes attention-related feedback. Do not import it unchanged or infer compliance from the generic idea of a gate. |
| Nonarithmetic task ladder before addition | Restrict preliminary work to bounded technical checks. Keep an early full addition harness and globally excluded operand orbits. No parity/modulo/recall success replaces that endpoint. |
| Warmup and feedback underspecified | Expected observed bytes/EOS are permitted training signals; retain small increasing native and controller updates, count all prompt and answer predictions, and distinguish teacher-forced training from own-prefix generation. |
| Procedure writes its confirmed guesses to memory | Only actual external observations teach native values. Procedure-generated guesses do not become targets. No arbitration is introduced before a procedure exists. |
| More compute treated as an open invitation | Propose a finite ceiling, profile a complete counted history, stop on an infeasible projection and forbid silent roster/range changes. Execution remains unauthorised by this delivery. |

The design deliberately changes the encoder, learning rule and observed-byte supervision scope. Its prospective four-arm comparison holds those interfaces and information budgets fixed while testing controller plasticity and prior-teaching effects. It is not a one-factor numerical comparison with historical R2, and no old score is assigned to a fresh arm.

## Static review limits

This is a design review, not an executed three-cycle exercise. The local Gaussian/Bernoulli score algebra is stated, but no numerical estimator test, learning run, source qualification or performance measurement was performed. The rule may have excessive variance or cause address drift. Those are central test outcomes, not reasons to insert an independent answer network later.

During static credit review, the baseline was changed from an event-updated scalar to a record-start frozen scalar updated only after completion. An event-updated baseline could depend on the earlier stochastic actions still represented in the accumulated eligibility. This correction removes that avoidable source of bias before any implementation; it does not establish that the clipped hybrid update is unbiased or effective.

No claim is made that all arithmetic can be learned, that this is a literal human mechanism, or that sparse activation yields sparse computation. The intended endpoint is exploratory E3 in the declared addition distribution, with meaningful E1 acquisition and retention reported alongside it.
