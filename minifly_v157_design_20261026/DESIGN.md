## 2. One evidence vocabulary, separate milestones

The roadmap's label “E2 retention” conflicts with the standing objective contract. Preserve that contract:

| Evidence | Meaning here |
|---|---|
| E0 | Interface, coding, numerical or mechanism operation |
| E1 | Acquisition and retention of directly taught associations |
| E1-R | A retention milestone within E1, not a new evidence level |
| E2 | A never-reinforced, label-preserving change in presentation |
| E3 | Never-taught relations, with appropriate prior-teaching and shortcut controls |
| E4 | Only the broader task coverage actually demonstrated |

Reliable acquisition, selective retention and transfer are program milestones. They are not interchangeable scores. More seeds, delay, a good readout or more remembered cues do not automatically advance evidence level. A simple rule learned from feedback can be valid E3; a rule supplied by the architecture cannot.

## 4. A1 — the next concrete native comparison

**Question:** can the same eight presentations of each of 16 NEW records produce different complete acquisition when feedback is clustered rather than interleaved?

Keep `N_2B/P_SLOW`, native Full151/R_center stores, the C16 codebook, q=0, homeostasis off, fresh adaptation, time constants, signed teaching and own generation unchanged. The only treatment is the order of real feedback records.

Use two prospectively locked fresh development worlds, each with 64 OLD and 16 selected NEW records. Prepare W and a matched-observation OLD-write-inhibited SH_OLD, then clone each into the two schedules:

- **INTERLEAVED:** the same fixed 16-record order for eight passes.
- **CLUSTERED:** eight consecutive observations of each record in that order.

NEW writing is enabled in **both** W and SH_OLD. SH_OLD is a control for prior OLD value teaching, not a passive NEW control. Both schedules finish at 128 NEW presentations, eight per cue, identical feedback totals and native elapsed time. At intermediate record counts, unique-key coverage, target counts and recency differ; report them explicitly rather than call them information matched.

The inherited ramp is `s(n)=1/16+(15/16)min(n/1024,1)`. Keep the actual counter, including inhibited observations. After 512 OLD records, NEW begins with n≥1024; this is a late-learning schedule comparison, not a test of early warmup. Do not reset, steepen or accelerate the ramp.

At NEW positions 16,32,64,128 in each branch, add one discarded matched no-write record fork and one duration-matched idle fork from the same parent. These 32 no-write observations are charged. They identify sampled local write effects; they do not explain every intervening write.

**Primary descriptive endpoint:** CLUSTERED minus INTERLEAVED complete NEW answers at the equal-dose 128 boundary, separately in both worlds and prior conditions. Report OLD retention, delay, immediate acquisition and margins beside it. No average margin, lower loss or threshold chosen after outcomes replaces complete answers.

**Addition endpoint:** once every branch is frozen, score 50 never-reinforced orbits per world before feedback, at final and delayed boundaries. The same-schedule W−SH_OLD contrast estimates reuse of **OLD value teaching conditional on common NEW training**. It does not isolate all prior experience. Two development worlds are descriptive, not confirmation or proof of equivalence.

## 7. C — computational functions remain an independent question

The architecture annex isolates **native memory influencing subsequent learned state transitions** from simply adding more state. It requires a workspace-OFF/ON causal pair, a native baseline and a separately counted capacity control. Learned keys from B are an optional later contrast, not a prerequisite.

A recurrent state must affect the operative native cue/read path; a hidden vector that never influences decisions is not a computational architecture. Native memory values must be read before the current target is revealed. No evaluator decoder supplies them. Ordinary recurrent gates are permitted; attention and arithmetic roles are not.

The annex fixes the functional questions, diagnostic boundaries and control obligations. It deliberately does not invent an unqualified local learning rule and label it launch-ready. Exact dimensions, equations, source, warmup, supervision timing and costs must be written before C implementation. That specification work can proceed in parallel with A1 even while B is stopped.
