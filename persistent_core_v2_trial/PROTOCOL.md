# Persistent core V2: corrective writing and selective durable replacement

Authorized 3 October 2026. Execute three design–audit–trial–revision cycles,
then the frozen comparison. No encoder, task-family expansion, NLP, scaling,
evolution, output alphabet expansion, or automatic rescue experiment is added.
Historical code and experiment gates remain unchanged. Negative results are
completed results. The scope is a bounded persistent core with modest reuse.

## Objective and common architecture

Maximize capability gained from a fixed quantity of byte-level knowledge at a
measured computational cost. Exact recall is a component, not the objective's
sole endpoint. Every configuration has the SAME four shared FE0 Full151 stores
and four private CONTENT stores, each independently canonical-born. Keeping
the existing eight-store V1 as the common architecture preserves the qualified
similarity input for the additional reuse measurement; the previous physical
deletion result is not retroactively promoted. Output scales and argmax remain
the frozen V1 values. Four configurations form one 2x2 comparison, not a sweep:
V1, ERROR, REPLACE, BOTH. Only private update dynamics change. Shared writing,
bytes, clocks, records, input information, probes and output organs are equal.

## Exact mechanisms

V1 private coefficients are c=0, s_j=.25-y_j. ERROR uses
pi=softmax(private pre-outcome values / inherited private scale), temperature
1, and s_j=pi_j-y_j. The prediction is computed before the arriving outcome;
no stage or target map enters the core. This changes correction magnitude,
not merely a write permission gate. No extra teaching records are introduced.

REPLACE first applies the SAME signed native update. Let S be the native
non-plastic slow state after advancing that event's time, and delta the slow
change from the actual signed write. On currently active KC coordinates only,
count successive conflicting visits S_i*delta_i<0, capped at three; an agreeing
active visit clears its own count. Inactive counts remain unchanged. At count
three, replace slow_i with .5*S_i+delta_i instead of S_i+delta_i. Fast state,
adaptation and non-conflicting slow coordinates are not patched. The evidence
array is bounded at four bytes per KC (four uint8 banks), has no key dictionary,
and is frozen when writing is disabled. BOTH uses ERROR coefficients and this
same replacement rule. Native signed alpha dose and additional removed slow
L1 are reported separately: gains cannot be described as dose-conserved.
This is an engineering hypothesis, not a proven biological mechanism.

## Existing tasks and evidence boundaries

Reuse the preceding compact study's full lifetime: 32 old keys, 32 new keys,
eight changed old targets, 12 teaching bouts each, 24 h simulated rest after
each stage. Four histories W/N_old/N_new/N_revision have identical bytes and
times; a literal branch-by-stage permission table clamps ALL eight stores and
replacement evidence. Six saved checkpoints distinguish initial correction
from later rebound. Direct arbitrary fact learning is E1. All-cue scores use
24 unrevised keys, 32 new keys and eight changed keys; old answers on revised
keys are never counted as successful retention.

Additional measurement reuses the existing wrapped V9.8/V9.9A relation family,
without adding a new task: six random symbols, six taught cross-class edges
in both orientations (12 cues, 144 records), three never-taught edges in both
orientations, one disjoint later cohort (six cues, 72 records), and two days.
The inherited fixed internal two-option organ compares its own binary channel
utility u_1-u_0 on the two ordinary option streams and emits L/R. Both orders
are scored; no taught/held-out status or target is supplied to the organ.
It is an instrumented model-output assay, not evaluator-picked alternatives.
Each candidate has the identical organ. W/N_old differ only in prior writes;
later teaching is permitted in both. No held-out cue receives feedback.
Old-end, day, later-cohort-end and final probes are saved. Transfer is E3 only
if taught competence guards pass and the final W-N_old effect is positive.
An exact/canonical pair table ties on withheld edges (50% balanced choice).
Symbol frequency and position have no fixed class mapping; a class rule
learned from teaching is a valid simple explanation. No broader intelligence,
arithmetic generalization, natural text or teacher-free learning is claimed.

The tasks run as separate lifetimes of the SAME architecture and mechanism
configuration. They are NOT evidence that the same trained state solves both
tasks at once. No future combined-task claim can be inferred from this run.

## Fixed roster, inference and version qualification

96 fresh paired worlds 501001–501096, every arm on both reused tasks.
768 world/arm/assay jobs, 2304 logical lives. Engineering worlds 500101–500103
are excluded from inference. No sample extension or result-driven tuning.
Knowledge accounting distinguishes 12 old directly taught relation cues and
six later cues from 144/72 repeated records. Lifetime supplies 64 distinct
keys and eight changed answers (72 stage-specific knowledge items), not 864
independent new facts. Ratios do not pretend redundant exposures are new
knowledge. The core always responds before the observed outcome byte.

One independent observation is a world-level mean over all its cues/options.
For three candidate configurations, there are seven one-sided comparisons per
candidate (21 family bounds, alpha .05/21): old accuracy minus V1 > -.03;
new accuracy minus V1 > -.03; revision gain over V1 > .20; absolute final
revision accuracy > .90; final E3 W-N_old > 0; E3 effect minus V1 > -.05;
and E3-effect-per-CPU-second improvement over V1 > 0. These are prespecified
Student-t world-mean intervals, approximate rather than finite-sample exact
coverage. A zero-variance observed statistic is UNRESOLVED, never certified by
a collapsed interval. No held-out labels are used to calibrate a rule.

Additional hard floors are final old/new means >=.90, total CPU ratio <=1.5,
and relation taught guards: old-end W >=.80, final W >=.70, new-end W and
N_old >=.65. Qualification needs ALL guards and seven bounds. The 90% reliability
target is retained; an improved but unqualified candidate is not adopted V2.
Rank qualified candidates by final E3 gain per CPU, then lower compute cost.
If none qualify, retain V1. E1 improvements and E3 measurement are still
reported separately. This finite comparison does not launch another experiment.

The resource-normalized effect for a world is its final E3 W-N_old divided by
mean W/N_old process CPU seconds (including birth, probes, checkpoints and
audit). Report it per 12 old taught cue-outcome items and per CPU hour alongside
raw effect, accuracy, memory and latency. Audit and checkpoint overhead are
also itemized; the conservative whole-job cost is used for the primary ratio.
All configurations receive identical knowledge and teaching budgets; wall
worker seconds and CPU seconds are both saved. n=96 is fixed for paired
estimation, not a promise that every useful effect can be certified.

## Three cycles and execution

Cycle 1: mechanism equations, independent births, V1 parity, true write clamps,
arrived-byte routing, held-out exclusion, model output, and hostile receipt
tampering; correct implementation defects only. Cycle 2: every configuration
on complete engineering lifetimes of both existing tasks, independent receipt
audit and resource census with final logging; do not tune on performance.
Cycle 3: stopped/resumed fresh-process trajectory equality including conflict
evidence, corrupt/resealed cursor and array rejection, completed receipt skip,
parallel four-worker smoke and final source seal. Three audit reports bind the
final exact source; any edit invalidates qualification until affected checks
are repeated. No science data are used in these cycles.

Four background CPU workers, one BLAS/Numba thread each; detached supervisor
owns caffeinate. Full learner/stream/evidence and cursor checkpoint every 32
records, immutable compressed receipts and per-job logs. Job cap 3600s, worker
RSS 1GiB, experiment storage 4GiB and cumulative worker budget 80h. Timing
qualification can block an unaffordable launch, not truncate the roster.
No automatic restart or retry after scientific/integrity failure. Existing
completed receipts are skipped. Analyze only a complete audited roster, produce
REPORT.md/SUMMARY.json/FINAL_AUDIT.json, package, and upload this experiment
folder to codex/persistent-core-v2-20261003. Publication failure does not rerun
science. Keep future scaling requirements separate from these active gates.
