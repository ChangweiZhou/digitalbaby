本文件保留三周期前的静态审查快照，下文“尚未实现”描述的是当时状态。当前实现和资格以实现目录QUALIFICATION.json、REPORT.md和results/FINAL_AUDIT.json为准。

## 审核范围

完成母体源码、已有机制来源、学习信用、对照、成本、统计和任务隔离的静态审查，并由三个独立审阅任务分别审查原生接口、统计预算及特殊机制。本记录不等于三轮实现资格：没有编写运行内核、没有训练或科学轨迹，技术周期数为0。

独立的评估器数据检查生成了20个计划科学世界的划分：各世界60 OLD/20 NEW/20 HELD、交换轨道不泄漏、OLD覆盖全部19种答案；最多23次输入覆盖拒绝抽样。见DATA_AUDIT.json。它没有导入或运行模型。

## 已修订的问题

| 问题 | 设计修订 |
| --- | --- |
| 当前读出反传在零记忆时无信用 | 四记录原生写入与查询的有界反传，公开窗口和detach边界 |
| 可训练表示可能利用FrozenReader拟合残差 | 精确expression记忆差；母体同轨迹单独评分原读出和新读出 |
| 两种基线读出被合并收费，夸大候选计算优势 | 独立逻辑生产CPU台账；额外比较费用另列；自主生成独立副本 |
| DEV预算依赖入选者，入选者又依赖DEV计算成绩 | 全六臂运行时间先确定C_dev，选择前固定C*=2 C_dev |
| DEV事后才知道CPU预算，不能回补触发快照 | DEV仅用已有样本检查点的CPU阶梯积分，禁止重跑训练 |
| OLD必须超过精确受教键查表，形成不可能门槛 | HELD用完整shortcut envelope；OLD用原生、N_OLD和答案众数，查表只作上限 |
| FB内层tanh并未限制外层矩阵幅度 | 外层tanh将反馈逐通道限制在±0.5 |
| FB可能从目标写入后状态取值 | 固定advance73 pre-write rm、通道索引/顺序/尺度及target-invariance测试 |
| 特殊冻结控制只在确认时出现，未经资格 | 预先资格全部8种可能物理配置，技术记录总上限不变 |
| 缺少特殊候选1STEP却承诺确认时间必要性 | 缩窄特殊候选确认归因；保留4臂，不虚构缺失控制 |
| 64维模块可能承担规则计算，却声称规则必在旧记忆 | 主张限定为原生整合版本；交叉快照作有限分工诊断 |
| signed活动历史被误称精确脉冲阈值机制 | 明确为适应性启发的有符号rate历史反馈 |
| 特殊机制只确认G却可能声称G/Q双增益 | 相对BIND的Q描述性，单独机制归因与整体模型G/Q主张分开 |

## 仍须实现资格解决的事项

- 源忠实functional mirror的全部forward parity；包括裁剪、dt、native/signed写入和独立出生。
- STE与原生精确导数分开测试，冷启动实际信用与硬KC变化，禁止把非零代理梯度当作能力。
- 原生状态/θ/优化器全部禁写、输出无目标泄漏、所有byte/EOS以及只读查询。
- 新增内部计算可能学习规则，但没有证据保证2048条记录足够；剂量是预定成本条件，不是生物机制家族的可学性下限。
- 全8配置的内存/CPU/恢复/并发与分析打包资格；4-worker十小时会话内是否可行尚未实测。
- 没有已验证在该原始字节预算下成功的神经阳性学习器；评分阳性fixture只验证评分合同，负面不得解释为任务不可学。
