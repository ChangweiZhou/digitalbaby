# Ordered-byte front end development run

The test asks whether byte order alone improves native use of a taught opcode law on two withheld graph families. It retains V216 NORMAL at width 64 and compares the stock, ordered, and order-removed front ends. Success can support E3 within this graph task if causal attribution also passes. Taught cases measure E1. The run uses two development births for a descriptive comparison.

## Held panel and exposure

The primary panel keeps 32 paired quartets per block. Each family contributes four cases where both laws have opposite answers within the pair, four where the designated route's three bits are identical between prompts, and eight where the designated route changes. In the latter 12 cases one law has a within-pair flip and the other has a within-pair invariant. Each primary case requires at least one within-law difference and at least one cross-law difference on identical input bytes. All cases match raw byte counts, endpoint opcode counts, and the last eight bytes within each pair. The independent graph oracle infers the active opcode from teaching witnesses and solves the four answers in every quartet. It also audits exclusion of direct-only and two-hop interpretations. Withheld topology path signatures are disjoint from all teaching signatures. Held names are disjoint from feedback names and no held answer is supplied.

All records now use eight edge rows, including feedback records, so a train-to-test record-length shift does not contaminate the contrast. The two additional teaching rows are disconnected from the queried path. This raises each event from 49 to 55 predicted symbols, including EOS. The schedule has 32 actor, topology, and row-order environments per phase, two location relabelings and 64 balanced opcode masks per environment, giving 4,096 literal teaching prompts. The schedule repeats randomized complete epochs while retaining each checkpoint as an exact prefix. Outcome bytes only reflect the currently taught law.

Canonical and literal exact lookup give no held coverage. Bag, recent-only, and endpoint-count shortcuts cannot solve any quartet because each pair requires different answers under at least one law. Evaluate designated-route parity and exhaustively maximize over one, two and three fixed edge roles per topology and a Boolean function of their active bits. Give this comparator oracle role identity and opcode semantics, and even allow its feature subset and function to differ by law. Treat its per-topology sum as the registered shortcut ceiling. Arbitrary larger programs are beyond this shortcut class. Evaluator code never enters the learner input or updates.

## Locked dose, controls and decision

For each of two births, run all three encoders under both opposite histories. Score at birth, after 10,000 A records and after 100,000 A records. Continue through 10,000 B records, then fork matched 10,000-event A′ edit and no-edit branches. The A′ prefixes, timing and update rule are identical across the fork. Both B and A are probed after the edit and the no-edit continuation. Report previously correct B outputs preserved and actual old-to-new corrections on previously correct flipped A outputs. Full main roster is 1,560,000 training events and 85,800,000 predicted symbols. Store per-run checkpoints, counters and generated native outputs.

At A 100,000, require ordered to score at least 8/32 and at least four items above both stock and the registered shortcut in each block. Keep exact native answer plus EOS, first byte, own EOS, taught acquisition, and within-law exact results separate. Record both family scores. If the native ordered arm clears this screen, run a matched no-teaching A history per block for ordered before claiming causal reuse. These histories have identical prefixes, timing and births, with both incompatible outcomes alternating per rendering across epochs in place of a consistent law. Both laws are tested on each sham's frozen state. Positive attribution also requires ordered to beat sham by at least four per block. A failed native screen closes this development comparison at the locked dose without launching the conditional controls. A fitted readout is outside the native run and may be studied separately.

Use lossless packed encoder caching only over the fixed feedback roster and compare stock and candidate update/generation parity before launch. An encoder cache is fixed sensory computation, separate from learned state. The experiment uses the unchanged local update and performs no model selection during training. Abort on oracle, feature parity, nonfinite state, or source-lock failure. Independent external review remains pending and the two-birth run is development evidence.
