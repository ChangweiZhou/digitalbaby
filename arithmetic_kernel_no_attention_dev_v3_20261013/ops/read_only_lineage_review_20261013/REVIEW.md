## 2. V3 一次改变了太多东西

| 项目 | 旧 ANSWER-0 | V3 G0 | 审查判断 |
| --- | --- | --- | --- |
| GRU 更新 | 自定义 reset-before，候选项使用 `U(r*h)` | PyTorch reset-after GRU | 是动力学改动，不是等价改写。 |
| 初始状态与权重 | 循环矩阵正交初始化，离散随机 embedding，零输出头 | 循环权重均匀初始化，Gaussian embedding，Xavier 输出头 | 确定性初始化解决复现，不证明这些新选择更易学习。 |
| 读出 | 归一化 `[h,1]` 后线性分类 | 原始 h 的 affine 分类 | 改变学习几何；没有本任务的受控优势证据。 |
| 优化 | float64、RMS 二阶矩 β=.99、逐真实 EOS 联合更新 | float32、AdamW、参数更新 RMS 上限 | 均属工程选择，不能在架构比较中默认为免费改进。 |
| 信用范围 | 32 个事件 | 最近 128 个事件 | 当前算术训练帧无需 128 才能覆盖；不能据此宣称更长信用有必要。 |

这些变量同时变化，意味着“更复杂任务后成绩变差”不能单独证明某种核心机制坏了。旧任务也不能被重新设为成功标准。

V3 的 P 是 32 维神经元偏置调制，不是 Full151 的 fast/slow 突触存储；R 的工作状态在 BEGIN 复位，也不是跨经验持久知识。应区分：题内工作状态、跨经验学习的参数、独立的快速/慢速突触痕迹。名称中出现 memory 或 persistent 不使它们等价。

## 3. 收据实际说明了什么

### 短试跑没有显示有效解题

同一短世界 W 给每个模型 256 条二元训练和 64 条混合训练。G0、G1、R1、R8、RU8、C 对全部 128 道未见混合题都输出同一个 `1`，于是得到 8/128。G4、P、P_STOP、P_RESET 对这些题全部直接输出 EOS，得 0/128。这些输出已经保存在收据里，无需新增模型运行才能确认。

G0 等有 320 次优化更新，G4/P 组只有 80 次。P 对 G0 的比较混合了结构、宽度、梯度累积与优化步数；P 的停梯度和复位对照具有较好的配方内可比性，但还不能给 P 家族下总体结论。保存的最后窗口 P 策略梯度范数约 0.01075，不能说策略根本没收到梯度。

R8 作业主体 CPU 为 20.67 s，G0 为 3.73 s；这次约 5.5 倍的成本没有得到短预算优势。它淘汰的是这次短预算下的优先投入理由，不是所有循环计算。

### 完整剂量也尚未把已教内容学稳

完整剂量仅运行了一个 G0 技术世界；候选机制没有相同完整剂量结果。

| G0 的最终 W 分层 | 整串正确 | 进一步观察 |
| --- | --- | --- |
| 已教二元题 | 56/415，13.49% | 其中 36 个正确答案为 0；非零答案仅 20/375。 |
| 未教二元题 | 6/128，4.69% | 没有 0 答案；不足以宣称发现四则规律。 |
| 已教混合题 | 120/512，23.44% | 其中 57 个正确答案为 0。 |
| 未教混合题 | 42/256，16.41% | 24 个正确答案为 0；非零答案 18/226，7.96%。 |

0 也是合法答案，不能从正式分数中移除。这个事后分层用于识别成绩结构，不是新增门槛或重定义成功。完整未见混合分数只比原固定 shortcut envelope 高 3.13 pp，且来自一个技术世界。

最终已教二元题的 359 个错误中，215 个从第一字节就错，144 个第一字节正确但后缀或结尾错。未见混合题中，128 个第一字节错，86 个第一字节正确但后续错。完整 W 的这些最终查询没有空 EOS 或截断，主要问题不是“不会停”。

实际训练记录最后至多 256 条/操作的在线预测中，加法首字节正确率为 69.5%，后续内容字节仅 12.5%，EOS 为 99.6%；其余二元操作的 EOS 也约 99%。这是各条训练记录更新前、此前真实答案字节作为前缀的预测，不是最终权重上的统一 teacher-forced 测试。因此它不能精确量化生成误差累积，但已经表明内容学习本身很弱，不能全部归咎于自由生成时第一步出错。

### 训练剂量存在明显混杂

完整 G0 的字面题平均重复次数为：加法 10.61、减法 5.54、乘法 10.45、除法 11.38；512 道混合训练题各重复 4 次。旧 ANSWER-0 的加法约 280 次/字面题后才达到已教题 100%。两个任务的输入分布、训练顺序和优化实现还不同。

这解释了为何不能用短试跑判定整个机制家族失效，也不能说通用字节接口必然记不住。**但“只增加重复次数”也不是下一版答案**：旧模型充分重复后未见乘法仍只有约 0–2.7%，学习新操作后旧未见加法也很弱。目标仍是每个外部样本、每单位算力获得更多保留的未见题能力；重复和内部回放必须收费。

## 4. 哪些原因有证据，哪些仍是推测

| 判断 | 证据等级 | 不能跨越的边界 |
| --- | --- | --- |
| 短试跑主要是常数输出或立即结束 | 已存输出直接计数 | 不是循环、局部网络或持久状态家族被否定。 |
| 完整 G0 的内容与后续字节学习不足 | 已教整串结果、在线内容/EOS 分解 | 不能唯一定位到 embedding、GRU、头、优化器或数据。 |
| V3 不是旧字节基线的等价实现 | 两份源码直接对照 | 不能将其性能差异解释为某一项改动的因果效果。 |
| 增加混合学习后旧题下降 | 同一 G0 W 的前后收据 | 下降可能混合遗忘、表征漂移和输出分布变化，尚未分离。 |
| 回复边界可能压缩题面信息 | 早先 RAW-RULE 保存的特征几何诊断 | V3 未保存最终权重，不能声称已测得同样的 V3 几何。 |
| 多状态细胞可能保留更丰富的题内信息 | 旧 ELM 源码及其他任务证据 | 还没有本四则任务上的优越性证据。 |

V3 的 931 项检查主要限定接口、状态、分支、字节合法性、若干梯度坐标和防篡改。它们重要，但不等于 931 次学习效果验证，也不能取代获得真实题面相关行为的证据。循环更多次、状态更宽、跨记录信用更长都不是自动有效的机制。

另有一项旧证据本轮实际恢复：ELM 的完整细胞与稀疏 GRU 在 Fashion-MNIST 延迟任务上分别约 75.88% 与 68.58%；参数为 21,642 与 7,050。只有 seed 7，1,000 个不同例子实际呈现 150,000 次，参数不匹配。固定时间常数与线性树突版本分别约 75.55% 与 75.02%，所以这组结果尤其不能证明“学习时间常数”或“非线性树突”本身是关键。

这使旧 ELM 成为**有真实实现依据的候选母体**，并不证明它会学会四则。它的私有向量是题内动态状态；它没有因此恢复 Full151 的跨经验 fast/slow 突触存储。原图像 episode、像素拓扑和十类分类头也不能直接搬入字节任务。恢复的原源码和六个摘要存于 [original_sources](original_sources)，出处记录于 [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json)。

## 6. 下一步判断

不支持把现有 R8、RU8、C 或 P 配方直接升级为大规模正式比较。下一份设计应以 **旧 ANSWER-0 的忠实字节参考 + 真实旧 ELM 细胞的字节适配候选** 为明确来源，Full151 保留为反馈时序与独立存储的历史依据，而不是隐含声称已经在候选里。

这种方向有三项必需适配：学习的离散字节 embedding；逐事件的细胞状态推进；通用 256 字节加 EOS 的自回归读出。不能加入数字顺序、左右操作数槽位、算术 AST、中间结果、数值渲染或注意力。对题面信息在输出期间如何保留，应显式描述并付出状态/算力成本；当前只支持将其作为假说，不能假装已经证实其原因。

母体以外的优化器、初始化、状态数、时间常数和连接变化要逐项登记。旧实现能原样保留就保留；因接口不兼容而改动须指明原因；效果未明的选择配匹配对照，不再一起更换后宣称是同一核心的升级。

当前任务、未见组隔离、真实反馈分支、整串自输出和样本/计算收费不变。已教获取曲线作为已有测量，用于判断模型是否进入内容学习；它不能取代未见泛化成为终点。此处确定的是后继设计依据，**没有新实现、运行授权、资格通过、正式显著性或核心采纳结论**。更具体的边界见 [NEXT_DESIGN_BASIS.md](NEXT_DESIGN_BASIS.md)。
