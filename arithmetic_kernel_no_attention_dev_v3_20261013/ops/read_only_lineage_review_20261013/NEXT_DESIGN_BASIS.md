# 后继设计依据：从旧源码重建，而非继续扩大 V3 配方

状态：**设计依据，未实现、未资格验证、未科学锁定、未开跑。** 本文件没有改变任何已完成实验的目标、门槛、样本数或结果。配套事实与局限见 [REVIEW.md](REVIEW.md)。

## 固定目标和接口

从实际到达的反馈字节学习，在较少外部样本和实际计算下，提高保留的未见四则与混合题整串自输出能力。256 个 payload 字节没有数值意义；采用学习 embedding，模型自己产生内容与 EOS。沿用现有任务、闭包隔离和 W/no-write/shuffle 等因果历史。

不允许算术解析器、操作数角色、数值目标/渲染、运算符专用模块、预置算术关系、解题轨迹、任何形式 Transformer 或注意力。通用 BEGIN/REPLY/EOS 是已有接口协议，不提供算术信息。

## 三条来源不能混写

1. **参考：旧 ANSWER-0。** 保留 reset-before GRU64、embedding16、正交循环初始化、归一化含偏置读出、原 RMS 更新与真实 EOS 联合更新。首先按源码运行同一当前任务；如果为了运行速度移植到另一框架，需逐步/梯度/状态等价，而不是改用框架默认 GRU 或 AdamW。旧成绩只是谱系锚，不能将旧的较容易任务重新作为主试验。
2. **候选母体：恢复的旧 ELM 细胞。** 来源是 DevelopmentalELM 的稀疏分支输入、每神经元私有向量、内部 MLP、泄漏更新和标量递归消息。只抽取通用逐事件动力学；不继承图像 episode、像素位置、二维视觉偏好或十类读出。TemporalELM 是相关但不同实现，其初始化、阈值与证据不可冒充完全相同。
3. **历史持久记忆：Full151 / R_center。** 保留真实反馈晚于预测、同一预反馈状态用于读写、显式可冻结的学习状态等原则。ELM 的题内状态不等于这里的突触存储。如果另加 fast/slow 突触机制，必须成为单独可识别改动并承接 M022/M035/M041 的负面先例；当前不默认加入。

## 必要适配及其理由

| 适配 | 为什么必须改 | 约束和代价 |
| --- | --- | --- |
| 学习 byte embedding 取代 image784 输入 | 原感官接口不是字节；禁止人工语义编码 | 每个通道都是学习值，不使用 ASCII 连续性或数值特征。原 ELM 每细胞 24 个不同感官连接的约束要求至少 24 个可选潜在通道，或明确改变连接规则；不能偷偷沿用 16 维而声称原拓扑不变。 |
| 原逐步细胞更新从图像 flash/delay 变为每到达一个实际字节推进 | 当前协议是字节流 | 私有状态在同一题面与答案生成期间连续传递；复位边界一致；不按运算符做专用动作。消息仍是固定图连接上的一般神经元活动。 |
| 十类头变成 257 类 affine 头并自回归 | 任意字节与 EOS 是任务要求 | 输出头学习反馈；没有候选答案表、数值最近邻或题型 mask。模型生成的字节不作为新教学真值。 |
| 将视觉位置拓扑移除或换成一般固定稀疏潜在图 | 原像素空间是任务专用输入结构 | 这是实质性拓扑适配，不能报告为原图完全复用。初版固定图，不同时追加可塑拓扑、学习门控调度或额外消息轮数。 |

原 ELM 的矩阵收缩 `einsum` 是固定参数的神经元内部 MLP，不是 query-key 相似性注意力。禁止注意力应按信息流判断，不能以函数名代替审查。

## 需要保留为假说的事项

- **输出期间保留题面信息。** 早先 RAW-RULE 显示共同边界可能压缩上下文；V3 的第一/后续内容字节错误也提示这一风险。但 V3 最终权重未保存，当前不能说它已被证明是唯一原因。原细胞状态连续推进是来源继承；另加 REPLY 快照、独立 decoder 状态或常量条件通道则是新通用机制，须明确额外状态和匹配消融，不能直接并入“原细胞”。
- **丰富私有状态。** 旧 ELM 的 64 细胞×6 状态、8 分支×4 连接、内部隐藏12 来自原配置，属于来源继承，不是为算术手调出的成功参数；现有证据没有证明它们对本任务最优。不得一次加入更多状态或神经元并称为机制发现。
- **训练实现。** 初始化与优化均能影响已教获取，不得同时换架构和训练实现后将差异归给细胞。源实现的既有梯度训练是工程参考，不是飞行昆虫局部学习的证据。不同母体的比较应说明参数/计算预算；“旧 ELM 优于稀疏 GRU”的其他任务成绩不是等预算因果证明。
- **重复/回放。** 更多呈现可能恢复已教获取，但旧 B 已证明这不保证保留的未见规则。内部回放收费；不设一直延长直到出现泛化的开口预算。

## 在同一目标下验证，而不增加诊断轮换

后继实验把实际获取、题面相关输出、未见整串答案、干扰后保留、样本曲线和成本一起记录。获取不是新的阶段目标，未见混合题仍是结果评价的一部分。no-write、shuffled 和固定 shortcut 继续限定因果；事后 0/非零及首字节/后缀分解只解释错误结构，不能用来挑选更容易的子任务。

短测试必须能说明接口、梯度和真实内容学习状态，并记录每个字面题的暴露次数及真实优化步数；不能把只输出 `1` 的 8/128 作为机制信号。正式比较时固定相同外部流，并同时报告各臂实际优化次数、计算、参数和状态量。有限稀疏连接不意味着事件稀疏工作：原 ELM 每个事件仍更新所有细胞，需计全体工作和内存移动。

V3 的十个配方和负面原始结果作为历史控制保留。它们不会自动成为后继正式实验的十臂名单，当前也不产生新的剩余机制数量或家族级排除。后继具体名单、额外机制与预算需要一份独立设计明确锁定，不能从本依据文件推断已获运行许可。
