## Findings

**Substantial NEW learning interferes with OLD.** In Cycle1 SNAP final OLD payload bits were69.1%, versus94.9% in the matched continuation with NEW value writes disabled. The earlier weak-NEW result did not establish a good retention/plasticity trade-off. These are paired observations from one engineering world, not a general capacity estimate.

**Normalization is promising for payloads, not a working-memory result.** Cycle2 SNAP final OLD/NEW bit accuracy:

| Address / write rule | OLD bits | NEW bits | Complete own-EOS recall |
|---|---:|---:|---:|
|RAW / current residual|70.9%|87.3%|0% /0%|
|RAW / target-only ablation|69.7%|84.4%|0% /0%|
|STD / current residual|77.3%|97.3%|0% /0%|
|STD / target-only ablation|74.8%|96.1%|0% /0%|

The prediction-dependent term has a measurable favorable payload effect in this world. The result does not justify calling the native rule pure summation. Neither normalization nor that term repairs complete recall. No candidate is adopted.

**Read-history alignment was not a rescue.** The fixed-length worlds remain at zero whole-value recall under the tested read views. Some bit scores differ slightly. Full per-view/control rows and sampled influence tensors are retained; there is no post-hoc per-item selection of read protocol.

**EOS calibration has not demonstrated causal complete recall.** In Cycle3 SNAP final NEW, calibrated W=2/18 and N=2/18 in the18-fact evaluation world. W's successes were one3-byte value and one empty value; equal aggregate performance does not mean identical solved items. In the36-fact world W=0/36 while N=4/36, explained by immediate-empty defaults. Final OLD remained0 in both W evaluation worlds. Do not interpret control success on empty values as memory or absence recognition. No presence classifier is implemented; never-written queries remain false-retrieval diagnostics, with empty-list placeholders explicitly excluded from success claims.

## Evidence and audit

E0 interface checks and E1 taught-association diagnostics only. All facts were directly reinforced; an exact table can solve them. There is no E3 unseen-addition result or broad-core promotion. The source engine, native population, local learning equations and gradual schedule were preserved; only the explicitly labeled address normalization, residual ablation, readonly protocols and offline EOS threshold differ.

Total executed: **13,228 physical full-record applications,66,140 main native events and312 synthetic prefix/perturbation events**. Counts include passive controls and calibration episodes. Shared OLD states in S_NEW forks are not re-executed: charge an additional2,036 OLD record-equivalents to descendants for information accounting, giving15,264 logical record-equivalents. These are correlated branches, not independent samples. Native write-term arrays, read margins, outputs and phase-end checkpoints are retained. Sum of timed cycle CPU bodies: approximately219.3 seconds; imports and final delivery/audit overhead are additional.

A separate artifact-only process recomputed outputs/counts and prediction terms, checked per-cycle source snapshots and the unchanged arithmetic-pointer hash. Calibrated outputs were also reconstructed from saved margins and frozen thresholds without rerunning native learning. This is an independent reduction process, not an independent reviewer. Scalar native parity is inherited; full runtime dependency locking, process-tree RSS/headroom admission and direct persistence of normalization/recruitment statistics remain qualification gaps. No claim that all prospective production policies were implemented is made.
