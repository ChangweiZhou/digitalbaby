# V173 design: gated recurrent microcircuits with exact within-circuit forward sensitivity, on the delayed-copy task (28 October 2026)

**Owner's words, verbatim:** "Activate the recursive improvement skill. We can do both A and B here." Option A of `minifly_next_steps_20261028/NOTE.md` §3. B runs as V174.

**Caps:** the defaults, since no number was written: 2 CPU-h, 5,000 learner records, 3 test cycles. No official run, no adoption, no pointer update.

## 0. Question and what it can and cannot show
**Question:** does restricting recurrence to small, isolated, gated circuits preserve the delayed-dependency learning that a dense recurrent network achieved only with BPTT (V164)? In such circuits, exact temporal credit is computable forward in time with circuit-local machinery.

**Evidence the question rests on:**

| Source | Result (S-COPY, target x_{t−8}) |
|---|---|
| V164, dense 256-unit tanh RNN | BPTT 1.152 bits; TBPTT-1 2.473; RAND-R 2.858 |
| V164, COLA | equal to TBPTT-1 |
| V168, KF-RTRL on the memory loop | too noisy |
| V168, e-prop | equal to one-step truncation for the query weights |

**A property of the architecture, stated in advance.**
* The circuits do not communicate recurrently, and the readout is linear.
* So the forward sensitivities E_t = ∂s_t/∂θ of each circuit, contracted with the one-hop readout error, give **exactly** the BPTT gradient of that circuit's parameters (with parameters fixed within a batch of lines).
* The candidate (MC-RTRL) therefore equals the architecture's own BPTT reference up to floating-point order. C1 checks this identity.

**What the experiment can show:**
1. Whether the architecture can learn the task at all under exact credit (C0 ceiling).
2. Which ingredients matter (C2 ablations): the cross-neuron sensitivity terms, and learned retention gates.
3. The cost of exact local credit.

**Assumption, declared:** every arm receives the exact one-hop readout error Wᵀ(p − y). Learning that feedback locally (Kolen–Pollack) is option C, not tested here.

## 1. Task, data and schedule: V164's, unchanged
* **Task:** S-COPY, target x_{t−8}. 8 symbols, lines of 120.
* **Splits:** 100 train, 20 calibration and 50 test lines, regenerated by V164's `synth_split`.
* **Schedule:** batches of 16 lines; AdamW (lr 1e-3, weight decay 1e-4); gradient-norm clip 5; at most 10 epochs, patience 3; best calibration epoch kept.
* **Loss:** cross-entropy on scored positions only.
* **Scoring:** test bits per scored position, with the SD from a line bootstrap against V164's per-line sums (1,000 resamples).
* **References:** V164's dense TBPTT-1 (2.473) and BPTT (1.152). Midpoint M = 1.8125 bits.

## 2. Architecture (MC)
* **Size:** 32 circuits × 8 neurons = 256 state units, matching V164's H. Each circuit receives the one-hot input symbol (8 channels).
* **Neuron i of a circuit** has two rows of parameters over v_t = [x_t; s_{t−1}; 1], which has 17 entries:
  * q_t = tanh(A x_t + R s_{t−1} + b_q);
  * g_t = σ(C x_t + U s_{t−1} + b_g);
  * s_t = (1 − g_t) ⊙ s_{t−1} + g_t ⊙ q_t.
* **Readout:** logits = W [s¹; …; s³²] + b over the 8 symbols. The state is reset at each line start.
* **Size:** 34 parameters per neuron; 272 per circuit; 8,704 recurrent plus 2,056 readout parameters. V164's dense RNN has about 68,000.
* **Initialisation** (seed 0):
  * input columns N(0, 1);
  * recurrent R and U drawn N(0, 1/8);
  * biases 0;
  * readout as `torch.nn.Linear`.

## 3. Learning rules (arms)
* **MC-RTRL (candidate).**
  * Exact forward sensitivities within each circuit: E_t = J_t E_{t−1} + P_t, where:
    * J_t[j,k] = (1 − g_j)δ_jk + g_j(1 − q_j²)R_jk + (q_j − s_{t−1,j})g_j(1 − g_j)U_jk;
    * P_t holds each neuron's own row derivatives.
  * The gradient is Σ_t E_tᵀ δ_t, with δ_t = Wᵀ(p_t − y_t)/N.
  * It is computed forward in time, with no backward pass through time. Updates are per batch.
* **MC-DIAG.** Keeps only each neuron's sensitivity to its own row parameters, propagated by J_ii. This is the e-prop or diagonal-trace analogue.
* **MC-LEAK.** No gate: g fixed at 0.5 (the gated arm's initial value), with full forward sensitivities. Ablates learned retention.

**Evaluator references** (autograd; testbed only; 0 learner records):
* **MC-BPTT:** the architecture's exact-gradient ceiling.
* **MC-T1:** one-step truncation, the floor.

## 4. Cycles and rules
**C0 testbed** (references only, before learner code):
* MC-BPTT and MC-T1 at the shared 10-epoch budget. MC-BPTT also at 20 epochs, descriptively.
* **Continue if:**
  * the ceiling passes: MC-BPTT at 10 epochs ≤ M;
  * and the floor fails as required: MC-T1 > M, with MC-T1 − MC-BPTT ≥ 0.3 bits and ≥ 3 SD.
* **If the ceiling qualifies only at 20 epochs:** amendment (testbed_invalid). C2 then runs MC-RTRL and MC-DIAG at 20 epochs (4,000 records) and drops MC-LEAK.
* **If neither budget qualifies:** CANNOT_TEST_CLAIM_AS_SPECIFIED. That reading is itself informative: the isolated circuits cannot learn the task even with exact credit at this budget.

**C1 technical** (float64, 2 lines):
* MC-RTRL's gradient equals autograd BPTT on MC: relative error ≤ 1e-9.
* MC-LEAK's forward gradient equals autograd BPTT on the leak architecture.
* MC-DIAG equals MC-RTRL when R = U = 0, where the cross terms vanish.
* Training is deterministic.
* Cost per epoch is measured.

**C2 dev:** MC-RTRL, MC-DIAG and MC-LEAK on S-COPY, at the budget fixed by C0.
* **P1 (primary):** MC-RTRL test bits ≤ M, and better than dense TBPTT-1 by ≥ 3 SD.
* **P2 (cross-neuron terms matter):** MC-DIAG − MC-RTRL ≥ 0.3 bits and ≥ 3 SD.
* **P3 (learned retention matters):** MC-LEAK − MC-RTRL ≥ 0.3 bits and ≥ 3 SD.
* **Reported:**
  * MC-RTRL against MC-BPTT (the identity at scale);
  * RAND-R;
  * epochs used;
  * whether the budget was cut off;
  * multiply-accumulates per step for forward sensitivity against BPTT.

## 5. Readings fixed in advance
* **P1 passes:** an architecture whose exact temporal credit is local and forward recovers at least half of what dense BPTT gains on delayed copy. The architectural route to temporal credit is viable, and integration into the generic predictor (text and addition streams) is the next step.
* **P1 fails with the ceiling passing:** impossible by the identity, unless floating-point divergence matters. Reported if it occurs.
* **P2 passes:** the cross-neuron terms within a circuit carry the needed credit; diagonal traces do not suffice, even in small circuits.
* **P2 fails:** diagonal traces suffice in gated circuits. That would be cheaper, and it would be a finding against the cross-term requirement in this architecture.
* **P3 passes:** learned retention is necessary for this dependency.
* **C0 CANNOT_TEST:** isolated 8-neuron circuits cannot learn an 8-step delay at this budget, even with exact credit. The architecture, not the credit, is then limiting.
