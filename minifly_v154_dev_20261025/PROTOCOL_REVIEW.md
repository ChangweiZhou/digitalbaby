## Limits and departures to retain in interpretation

1. **No unnormalized receptor-magnitude log was retained.** The frozen collector saves the operative RHO and normalized instrument features, plus exact collision summaries. It does not save the separate pre-normalization trace magnitude mentioned as descriptive logging in the design. No fitted feature or native state was changed to compensate. Raw-magnitude hypotheses therefore remain untested.
2. **One synthetic nonplastic parity schedule is a qualification, not exhaustive empirical parity.** Endpoint checks cover every payload byte, but the taught/no-write activity check uses one arbitrary-byte schedule on each front. The circuit's unchanged nonplastic equations supply the structural basis; this is not a proof about every possible future implementation.
3. **Native input-path effects include write-gain effects.** The registered coefficients were not recalibrated. Synthetic expression-displacement measurements differ across fronts. A performance effect therefore cannot be called pure information preservation.
4. **Normalized external features differ from native feature scaling and state reachability.** Within each probe family, online and batch instruments share their objective and parameterization. Across those instruments and native fast/slow storage, scale, decay, reachable states and event timing differ. A gap is not evidence that locality alone fails.
5. **An unconverged finite optimizer is not an encoding ceiling.** Every stopping reason and gradient residual is preserved. No failed fit gets a larger rate grid, iteration budget or new data. Even qualified fits support claims only about the declared regularized linear family, not arbitrary decoders or mutual information.
6. **Readiness is minimal acquisition admission, not useful arithmetic accuracy.** All readiness decisions across both worlds are locked before any assessment score. Missing held scores are not zeros. Admission can be satisfied by small or frequency-explainable improvements, which remain visible alongside the countermodels.
7. **There are two data worlds, not thirty independent replications.** The thirty W/SH_OLD/N_OLD histories share streams and prefixes. Native initialization is canonical. Native byte positions, immediate probes and repeated presentations are correlated observations. No statistical confirmation or adoption follows.
8. **Training and evaluator costs are separate.** Presented records include inhibited observations and repeated feedback. Batch optimization pays for virtual target reuse. Own/teacher-forced pairs, checkpoint ablations, source checks and saved-output reductions are additional evaluator costs. Native query clones and global encoding sorts are counted; this implementation supplies no scalable-work or biological-energy claim.
9. **Time attribution is finite.** Actual native training, encoding, clone, readout and paired-evaluation clocks are logged. Countermodel fitting was charged in the shared controller clock but lacks a separately sampled runtime/RSS clock. Supplemental reconstruction cost is reported as audit cost, not retroactively presented as the original countermodel runtime.
10. **No post-hoc retraining.** The old V152 bias interventions are evaluation at jointly trained checkpoints. Removing q at evaluation differs from training with q fixed to zero. The observed stopping effect does not authorize a Q0 retraining campaign or explain away failed complete acquisition.

## Resolved operations defect during Cycle 3

The original controller exited after saving the first diagnostic fit because the logger received a duplicate `CPU` keyword. `FAILURE.json` and the original failure-time status/counts/launch snapshot are preserved under `cycles/logging_failure/`. The operations continuation renamed the cell timing field to `cell_CPU` in a separate logger adapter; it did not edit frozen scientific sources. It verified and reused the already completed fit and first feature cache, then executed only the 47 unstarted registered fits and seven unstarted feature collections. It replayed zero native histories and zero completed fits. The original CPU, wall clock, counters, limits, roster and settings carried through the interruption. `OPERATIONS_SOURCE_LOCK.json`, `OPERATIONS_CONTINUATION.json` and the closure audit document this repair. This was a controlled technical revision within the requested exercise, not a scientific retry or an enlarged run.
