# MiniFly V77 / Iteration 22 — 误差参考、纠正目标与重复间隔

2026-09-14。32/32 冻结任务完成；18,432 个终点记录、27,648 个逐 bout 写入诊断。接受的学习参考仍为 full5177 / iteration5-bi（iteration10 实例化）和冻结 current_RBF64。没有模型晋升。

**V77 对 V76 的主要反例给出了较强的因果定位：用当前总输出追求精确的 2 Hz 目标，会把暂时存在的 α-fast 表达补偿进持久状态。改变误差读取的状态，或停止压低已经足够正确的响应，都能大幅缓解正确再教学造成的损伤。间隔重复也有明确作用，甚至在不改学习规则的原生模型中显著改善修订。**

但这些办法并未同时解决其他旧记忆的损伤。全部八个“新规则 × 间隔”组合仍未通过完整诊断保护条件。改善特定反例、提升容量或修订，不等于取得合格的持久学习核心。

## 对建议的实质修订

采用附件提出的“教学参考 × 纠正目标”交叉设计，并纳入本次讨论中的间隔重复。目标幅度、归一化、写入目的地暂时固定，避免同时搜索全部变量。

附件还正确提醒：V76 中龄目标最初只有 17/32 正确，最新目标是 32/32；两组不是相同记忆被随机分配到不同年龄。V77 记录初始正确、保留与恢复，按相同原生状态比较干预。本轮最新目标最初为 **31/32** 正确；后面的 32/32 包含保留这 31 个和恢复另 1 个。

| 维度 | 实现 |
|---|---|
| 教学参考 | TOTAL：当前总响应；NOFAST：在独立观测克隆中排除 α-fast 后的当前响应 |
| 纠正目标 | POINT：向精确的 ±2 Hz 靠近；MARGIN：正确方向达到 2 Hz 后，停止这部分 α 纠正 |
| 重复间隔 | 每个完整 bout 仍为 A30秒、休息135秒、B30秒、休息135秒；在第2至12个 bout 前额外休息0或900秒 |
| 固定项 | V76 的归一化、2 Hz目标、0.5更新系数、全慢 α 注入、原生 γ 事件和衰减、读出阈值、全部 KC 与连接矩阵 |

NOFAST 仅改变教学计算读取的状态，真实运行状态中的 α-fast 保留并正常衰减。它不是未来一天的预测，也不能称为纯慢状态：γ、适应及其他当前过程仍参与输出。**这是带特权信息的机制诊断。** 当前全局归一化、成对观测和末尾提交也仍是工程权限；本轮没有宣称果蝇实现这些计算。

MARGIN 的公式为 `r max(0, 2 − r y_ref)`，POINT 为 `2r − y_ref`，`r=2×实际收到的标签−1`。学习器只收到当前线索和实际教学标签；干净目标、延迟探测与无写入对照从未送入更新。

## 2. 逐次写入记录支持了什么机制解释

在预先设置的负载96、最新STABLE、基础间隔、第一轮正确再教学中，16个共同原生状态的正确方向分数为：总输出均值 **8.925 Hz**，排除 α-fast 的当前参考均值 **1.348 Hz**。它们是同一输入和同一适应状态下的输出差，不能把二者差值直接称为任意非线性状态的独立加和贡献。

| 规则 | 第一轮反向纠正正确标签的比例 | 待写向量平均L1 | 该次α注入对独立次日实际margin的平均影响 |
|---|---:|---:|---:|
| TOTAL_POINT | **15/16** | 774.831 | **−8.965 Hz** |
| NOFAST_POINT | 6/16 | 204.804 | +0.609 Hz |
| TOTAL_MARGIN | 0/16 | 7.214 | +0.090 Hz |
| NOFAST_MARGIN | 0/16 | 131.792 | +1.505 Hz |

这里的末列在每次真实注入后，从独立评价克隆中删去仅该次α注入，比较它们一天后的输出。γ事件、其他已有状态和之后的等待相同。该反事实没有反馈给学习过程，也不是“从头删除该写入再重跑全部后续历史”。向量L1单位是模型状态单位，不是Hz。

这比仅观察即时通过、次日失败更直接：**当前输出超过精确目标，会实际产生反向的持久写入；改变误差参考或取消对正确超额响应的向下纠正，可以改变这个结果。** 后面几轮的纠正方向会改变，但不能据此认定最早造成的损伤已充分修复。

两类干预都改变了写入方向和数量，表中保留了这些差异。因此结论是“这个教学定义和写入接口造成的损伤可以被干预”，不是在相同写入剂量下已经证明某种空间选择更优。也不能从这个局部反例推导所有干扰都源于 α-fast。

## 3. 间隔重复确实有效，但依赖具体规则

12个bout的刺激数、奖励/惩罚数和单次时长不变。900秒方案在11个轮间增加合计9,900秒。COMMON把基础间隔的分支在训练后补齐同样时间，使两个方案总时长均为13,860秒；LAST则分别从各自最后一轮算起。这样同时保留“等总时间”与“等训练后时间”的解释。延迟的一天不是额外训练。

以下REV计数合并两负载、两目标年龄，分母64；MIXED为共同终点之后，再学12个新关联、各6bout，然后等待一天。

| 规则 | COMMON + 1天：0 / 900秒 | MIXED + 1天：0 / 900秒 |
|---|---:|---:|
| REF 原生 | **42 / 59** | **38 / 59** |
| TOTAL_POINT | 61 / 55 | 57 / 41 |
| NOFAST_POINT | 60 / 55 | 57 / 39 |
| TOTAL_MARGIN | 62 / 59 | 58 / 53 |
| NOFAST_MARGIN | 61 / 56 | 58 / 44 |

原生规则不变，只重新安排休息，COMMON次日修订增加 **26.56点 [15.63, 37.50]**；MIXED次日增加 **32.81点 [20.31, 45.31]**。这些是预设的描述性历史配对比较，不属于前述十项主要检验。它说明先前基础节奏下的失败不能全部归因于学习公式。

但休息更久没有普遍帮助所有规则。例如 NOFAST_POINT 的最新STABLE成功从32/32降到26/32，修订在后续学习后的成功从57/64降到39/64。TOTAL_MARGIN加间隔能将最新STABLE提高到32/32，却没有在后续修订保持上超过同间隔原生对照。

原生间隔收益也有代价：REV的最初正确旧选择丢失比例增加 **1.13点 [0.66, 1.57]**，MIXED后增加 **0.79点 [0.28, 1.44]**；该比例的分母是全部非目标旧记忆。本轮未为原生新节奏单独完成生理资格验证，不能仅凭修订提升就把它改成默认训练安排。[完整间隔比较](/Users/pencilbard/Documents/second_try/minifly/iteration22/results/spacing_contrasts.csv)

这次的900秒是**完整bout之间的额外休息**，不是Huang论文中CS+/CS−之间ISI的直接复现。我们没有发现15分钟普适最优，也没有搜索1—15分钟的曲线。实验只是把用户提出的时间因素纳入了严格计数和时钟对照。

## 5. 从零开始的学习有容量收益，独立干扰问题仍在

另外16个全新历史从零训练 REF、TOTAL_POINT、TOTAL_MARGIN，均使用基础节奏，不根据接管面板选择幸存者。全慢规则从未产生α-fast，故在此分布下TOTAL与NOFAST的参考完全相同；启动检查验证了这个等价性，没有浪费任务运行重复臂。

| 累计关联负载，训练后一天 | REF | TOTAL_POINT | TOTAL_MARGIN |
|---|---:|---:|---:|
| 48 | 76.56% | 83.46% | 83.59% |
| 96 | 71.03% | 76.11% | 76.30% |

负载96时，POINT比REF高 **5.08点 [3.26, 6.97]**，MARGIN高 **5.27点 [3.52, 7.10]**。这是相同输入历史、不同规则产生的不同训练状态之间的描述性比较；不等于从共同状态改变误差参考的单因素作用。

基础间隔下，自己的状态接受修订并经历混合新学习后，POINT/MARGIN均为 **60/64** 修订成功，REF为 **48/64**；新关联联合表达分别为 **87.76% / 87.24%**，REF为72.40%。然而最初正确旧选择丢失比例为 **11.68% / 11.76%**，REF为7.08%；只以各自最初正确旧记忆为分母，丢失率也为 **14.41% / 14.51%**，REF为9.83%。各组原有记忆不同，不能把这些全部差异当作相同受害集合上的因果损伤。

独立OWN历史中的原生间隔对照也将次日修订从51/64提高到60/64，MIXED后从48/64提高到60/64。

这个面板不应被忽略，也不应被包装成失败皆由原生α-fast接管造成：从零的全慢学习器确有5—7点容量收益，同时仍丢失旧选择。其no-write对照、平均与最差margin损失均在完整表中。由于预状态不同，OWN表中的“直接相对REF最差差异”包含既有状态差异，不能照搬成共同状态下的新增损伤估计。

## 下一步建议

V77使“正确再教学为什么损伤目标”从一个猜测变成了可干预、可记录的具体问题。下一轮应保留这里的STABLE反例、修订和混合学习三项约束，分开推进两件事：

1. **减少教学计算的特权信息。** TOTAL_MARGIN配合间隔已有明显收益，可以作为不读取α-fast分解的工程对照；进一步比较固定或局部可实现的增益控制，量化放弃全局归一化的代价。不能直接把NOFAST宣布为可部署的果蝇机制。
2. **处理持续新写入对其他记忆的损伤。** 从共同原生状态和自身训练状态都保留no-write及原先正确选择的受害集合。目标被修好而其他旧选择丢失，不是可接受的终点。V77没有证明某个新增保护变量必需，也没有为重新开放大规模机制搜索提供理由。

原生间隔重复是值得继续验证的强对照：它在两组新历史中都提高修订，且不增加教学次数；但还需要独立的训练时序/生理范围检查和旧记忆代价评估。现有证据支持继续收窄教学目标与时间接口，同时承认持久干扰仍是独立瓶颈。
