**MiniFly has started as executable code, with a full reference and five reduced circuits.** The practical result is a 4,083-neuron circuit that preserves much of the tested taste and antennal-mechanosensory response of a 127,400-neuron FlyWire model. Ordinary neuron sampling performs substantially worse. However, the compact circuit does not meet the prespecified temporal-fidelity target, and it contains no Kenyon cells. It is a useful sensorimotor approximation, not yet the persistent learning core we ultimately want.

The new BANC file was also analyzed. Its principal mushroom-body spatial test does **not** establish replication of the earlier hemibrain teaching-address result. Both findings matter: functional circuit reduction is feasible, but neither broad brain function nor a conserved local teaching mechanism can be inferred from this first success.

Start with the [run instructions](README.md), [sampling figure](figures/sampling.png), and [functional-fidelity figure](figures/functional_fidelity.png). All underlying tables and scripts are included.

**What was actually built.** I used the attached suggestions as proposals and narrowed the first milestone to a validated executable reference, functional reductions, and independent BANC spatial evidence. I did not introduce a V55-style learning rule or fit task labels into a teaching signal.

| Artifact | Neurons | Directed weighted connections | Purpose |
|---|---:|---:|---|
| Full FlyWire v630 reference | 127,400 | 14,687,178 | Published fixed-weight LIF reference |
| `activity_core` | 1,722 | 85,465 | All training spikers, plus declared interfaces |
| `guard_core` | 4,083 | 321,087 | Activity core plus five strongest incoming partners per core neuron |
| `guard10_core` | 5,832 | 521,756 | Ten incoming partners; second-stage candidate |
| `guard20_core` | 8,783 | 885,655 | Twenty incoming partners; second-stage candidate |
| `guard_MB_core` | 9,619 | 865,046 | Five-partner core plus annotated MB populations |

Every reduced network is an induced subgraph of the same FlyWire v630 reference. Its retained weights are unchanged. No neuron or edge was imported from BANC or hemibrain. “Five strongest partners” means the top five by absolute incoming weight, including partners already present, in one nonrecursive pass. The models retain 234 declared sensory neurons and five readouts, even for conditions that do not stimulate all of them.

The 4,083-neuron circuit occupies **3.87 MB in graph arrays**, or **0.91 MB compressed**, compared with 176.76 MB of graph arrays for the full reference. Runtime state and Python libraries require additional memory.

**The full reference is affordable on this Mac.** The published release uses FlyWire materialization **630**, not 783. The authors now also provide a v783 graph; substituting it would change the reproduction target. I pinned the original model repository at `91bdd1e7dcf193f3e7ca5a8933497fcef63b7960` and historical annotation release v1.1.0 at `df6bb136f5b3d91c3992df4e8de2642329e2a384`. All 14.7 million edge-row ID/index correspondences were checked. Historical annotations match 127,322 model neurons; 78 remain unmatched. A downloaded current annotation table was recognized as a different version and excluded. [Authors’ repository](https://github.com/philshiu/Drosophila_brain_model), [historical annotations](https://github.com/flyconnectome/flywire_annotations/tree/v1.1.0).

The implementation uses the published membrane/synapse equations, signed weights, 0.1-ms step, 1.8-ms delay, and refractory behavior. It skips neurons that have never received input, which remain exactly at rest in this zero-baseline model. This is an exact execution optimization, not neuron removal. In particular, Brian2’s `unless refractory` flag blocks synaptic writes as well as state integration; the implementation was corrected and tested against that behavior. [Brian2 documentation](https://brian2.readthedocs.io/en/stable/user/refractoriness.html).

Four differential tests against Brian2 2.9.0 pass: excitation/inhibition motifs, frequent refractory collisions, zero input, and a real 350-neuron FlyWire subgraph with 11,870 edges. All recorded spike identities/times agree exactly; maximum voltage discrepancy is below 7×10⁻¹² mV. This validates the tested execution semantics; it is not a biological validation of LIF assumptions. See [differential results](results/engine/differential_tests.json).

For the authors’ explicitly labelled **100-Hz sugar** example, 30 new trials reproduce the released 30-trial neuron-rate pattern:

- Pearson correlation **0.999697**, using the union of 388 active non-input neurons, with silent neurons and directly stimulated neurons excluded.
- Relative L2 rate error **2.25%** on that same set.
- Left MN9: released **67.03 Hz**, new **67.87 Hz**; difference **0.83 Hz**, approximate Welch 95% interval **−1.99 to 3.65 Hz**.

The unlabelled `sugarR.parquet` is not a 150-Hz reference merely because the current code default is 150 Hz: its sensory neurons average 196.75 Hz. A separate **inferred 200-Hz** comparison gives correlation 0.999872 and 1.20% non-input rate error. That input rate is inferred from the released spikes, not recovered from missing run metadata. The explicitly labelled 100-Hz result remains the primary reproduction check. See [source audit](results/source_audit/released_reference_comparison.csv).

Across the 132 initial full-network trials, a simulated second took a median **0.89 seconds**, maximum **2.98 seconds**, excluding initial graph loading. These trials activated 61–660 spiking neurons; this is a sparse stimulus panel, not a worst-case runtime guarantee. Full-reference preparation peaked at approximately 0.92 GB RSS; the reduction process peaked at 1.14 GB. No full Brian2 speed comparison was run.

**Sampling was tested by its functional consequences.** The first construction panel comprised eight conditions × three seeds: sugar, water, bitter mixtures, Ir94e, and several Johnston’s-organ groups. The initial holdout used sixteen different conditions × three new seeds, including left-side sugar, new mixtures, new intensities and a pulse. External input streams are keyed by the original parent neuron index, so each full/reduced pair receives identical events. Construction trials cannot leak into the holdout through new neuron selection.

Uniform and type-stratified sampling were evaluated at 50%, 25%, 10%, 5%, 2% and 1% of neurons, with three sampled graphs at each size. Both preserve the same sensory/readout interface. Type strata use historical cell type, falling back through hemibrain type, morphology group and class, then split by side and transmitter annotation. Proportional largest-remainder allocation meets the node budget; it does not guarantee retention of rare strata.

The comparison below uses the **same six held-out conditions** for sampled models and fixed cores. Sample errors pool three graph draws; each fixed core is evaluated once with the same input seed.

An additional inverse-retained-fraction weight scaling sensitivity does not rescue sampling. Some uniform reductions become worse. This rescaling is **not an unbiased reconstruction of dynamics**; in the type allocation, some strata have zero retained neurons, so an ordinary Horvitz–Thompson interpretation is invalid. The intact graph’s spatial, recurrent and inhibitory relationships are not recovered by matching expected current alone. See [all sampling results](results/summary/sampling_pooled.csv).

A further practical constraint: preserving at least one neuron in every one of the chosen 10,620 type/side/transmitter strata, plus all interfaces, requires **10,821 neurons (8.49%)** before testing any function. That is a floor for this particular stratification policy, not a biological lower bound on a minimal brain.

**The successful compression has a sharply limited domain.** The activity-only core reproduces all 24 construction trials exactly in retained-neuron spike counts and 50-ms bins. That success is expected: a neuron that never spikes cannot influence other neurons through this model’s spike-triggered connections. It is therefore a weak generalization test by itself.

On initial holdout, the 1,722-neuron core loses the left-sugar motor response entirely. Adding the strongest anatomical incoming partners largely restores it without using the holdout responses to choose neurons. Across all sixteen initial conditions, the 4,083-neuron core has **5.97% motor-rate error** and **29.88% error in 50-ms motor bins**. It retains sugar-intensity responses, bitter suppression and Johnston’s-organ output selectivity in these tests. These are simulated neural outputs associated with behavior, not a rendered or embodied behaving fly.

The timing error exceeded the predeclared 20% target. I therefore disclosed a second development stage, constructed larger guards from the **original** training core, and evaluated them on twelve fresh conditions × three fresh seeds. No fresh-response spikers were added to any candidate.

**None passes all three targets.** The 4,083-neuron model is the default economical rate approximation, not a declared winner on full dynamic fidelity. Larger guards offer modest improvement but do not resolve timing. Fresh validation is a model-development validation set, not an untouched final biological test. See [fresh contract](results/dynamics/fresh_validation/contract.json) and [results](results/dynamics/fresh_validation/summary.csv).

Relative L2 means `sqrt(sum squared model–reference differences / sum squared reference values)` pooled across the stated trials and neurons/bins. It is not “percent behavior correct.” Removed neurons have zero predicted output. “Internal” excludes the entire protected interface, avoiding an artificially favorable score from preserved sensory firing. The five readouts are left/right MN9, DN1_1, DN2_l and aBN1. Some are command/intermediate neurons rather than motor neurons in a strict anatomical sense; “motor error” is shorthand for this fixed readout panel. Conditions with zero reference readout activity still contribute any false positive predictions to the numerator.

For context, independent full-model seeds differ by about 53–62% in 50-ms readout bins on these panels. This indicates considerable stochastic timing variation, but does **not** replace or relax the stricter paired-input target. Only three validation seeds per condition were used, so rare failures and robustness outside the tested envelope remain unresolved.

**The current small core is not a mushroom-body learner.** The 4,083-neuron core contains **zero Kenyon cells**, 12 annotated DANs and 52 MBONs. Its performance therefore cannot demonstrate associative memory, local teaching, or a general purpose brain core. Its 2,703 retained annotation strata also do not preserve whole-brain type coverage.

For the next stage, `guard_MB_core` retains all **5,177 KCs, 326 DANs, 97 MBONs**, MBINs and APL/DPM candidates, totaling 9,619 neurons. Its initial tested readout responses are identical to the five-partner core’s, but this is an anatomical scaffold: neither odor encoding/conditioning nor any plasticity rule was implemented or validated. The published LIF model treats connections as fixed signed current contributions; it does not supply dopamine-specific teaching dynamics. [Shiu et al., Nature](https://www.nature.com/articles/s41586-024-07763-9).

The compact readout uses the previously motivated form `q(d|k,o) ∝ f(k,d) R(d,o)`, fitted with whole-KC cross-validation and compared against 199 shuffled-training controls. Its apparent gain over a KC-only baseline is not significant against that matched control in the primary BANC scope.

The broader all-ROI sensitivity shows small compact-readout effects, p=0.005 on both sides, while the spatial MI tests remain p=0.437 and 0.073. These exploratory results do not rescue the primary replication. Other retained sensitivity tables cover shorter distances, size thresholds and one row per KC presynaptic coordinate. They are not independent specimens and were not used to choose a positive result.

The BANC export lacks the explicit pre/post axon–dendrite labels used for the strict earlier hemibrain test. Only about 6–7% of primary-scope DAN terminals belong to KC/ROI groups containing multiple DAN types; median nearest distances are about 18.2 and 24.6 μm under the documented v2 nanometer convention. Thus the null has limited exchangeable information, and a nearest-terminal assignment does not by itself demonstrate biochemical proximity. **Replication is not established in this export; the biological hypothesis is not disproved.** The magnitude of any power loss has not been established by a matched downsampling experiment. [BANC maintainer documentation](https://natverse.org/bancr/reference/banc_synapses_enriched.html).

There is also an important encoding trap: raw neurotransmitter fields and `syn_top_p` contain values as large as 15,360, not ordinary probabilities. Reinterpreting their uint16 bit patterns as IEEE float16 yields probability vectors summing to within 0.001 of one in every complete vector across three separated sampled row groups. This is strong evidence for the encoding, still labelled an inference. No raw `syn_top_p ≥ 0.9` cutoff was used. Neurotransmitter confidence would not be synapse-detection confidence in any case. [Encoding audit](results/source_audit/banc_transmitter_encoding.csv).

**What we can learn from this stage.** For the tested fixed-weight model, preserving a stimulus-relevant pathway and some of its incoming context is much more effective than preserving a random fraction of neurons or the overall type distribution. That is a reproducible compression result. It does not identify a new species-level learning mechanism. The active-neuron criterion alone is brittle, temporal fidelity remains unresolved, the small circuit omits MB encoding populations, and BANC does not yet independently confirm the strongest earlier teaching-address effect.

The next useful work is to use the full reference as an affordable comparator, extend the protected MB scaffold with same-specimen olfactory interfaces, and add conditioning only after specifying and validating the required physiology. Temporal fidelity should be assessed on pulse responses and population-level distributions as well as paired spike bins, with acceptance criteria fixed before further tuning. More whole-brain behaviors and unseen sensory channels are needed before naming any circuit a general fly core. Coarse-graining or response-preserving optimization can then be compared with these sampled and induced-subgraph baselines. There is no reason to restart dozens of unconstrained synthetic learning variants now.
