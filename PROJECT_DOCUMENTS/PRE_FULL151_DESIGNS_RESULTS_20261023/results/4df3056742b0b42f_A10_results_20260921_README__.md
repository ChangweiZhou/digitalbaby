## 核心结果

下表来自独立 Phase B，P1 准确率效应单位为百分点。区间采用预定的配对世界 Student-t 方法，对 24 个主要比较作 Bonferroni 校正（族错误率 0.05）；近似正态性是分析假设。

| 效应 | canonical 均值 [区间] | K8 均值 [区间] |
|---|---|---|
| 固定两条反馈路径后的 B 基础效应 E0 | +2.34 [1.23, 3.46] | −2.16 [−4.94, 0.61] |
| 分配响应贡献 EP | −0.56 [−1.01, −0.11] | +7.82 [5.47, 10.18] |
| 完整 B 相比 REF | +1.78 [0.79, 2.77] | +5.66 [3.98, 7.34] |

分配响应在两种任务中的贡献方向不同：canonical 略为负向，K8 明显正向。K8 下 E0 的准确率区间跨零，尚不能确定方向。教学反馈 EA 及交互 J 在准确率上观测为零，但样本零方差不证明等价或机制无效；K8 signed margin 上仍有微小非零效应。完整精度、全部区间及状态见 results/PHASE_B_CONFIRMATION.md 和 results/SIMULTANEOUS_INTERVALS.csv。

这支持对指定代码干预的机制解释，不证明生物学必要性、机制占优或实际重要性，也不能回答神经元容量是否不足。本实验未改变神经元数。

## 条件和效应定义

REF：参考模型；B00：分配 p 与教学 A 均使用参考值；B10：p 自由、A 固定；B01：p 固定、A 自由；B11：两者自由，完整 B。

E0 = Y00 − YREF。
EP = 0.5 × [(Y10 − Y00) + (Y11 − Y01)]。
EA = 0.5 × [(Y01 − Y00) + (Y11 − Y10)]。
J = Y11 − Y10 − Y01 + Y00。
E0 + EP + EA = Y11 − YREF；J 单独报告，不再次加到总效应中。Endpoint Shapley 是另一类诊断，不能与轨迹干预贡献混用。
