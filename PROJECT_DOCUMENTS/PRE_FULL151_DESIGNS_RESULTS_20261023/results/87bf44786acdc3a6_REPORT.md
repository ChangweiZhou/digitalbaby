**MiniFly iteration 8 — sensory-access experiment and independent feedback audit**

13 September 2026. **A fixed reader using the model's existing sensory activity passes all eight declared engineering gates, without a reset clone at runtime or additional persistent state. The learning core itself still has a retention–revision tradeoff.** The preferred learning parent remains iteration 5; iteration 8 supplies an optional engineering observer, not a new biological memory mechanism.

On 12 new input banks, the primary reader gives **96/96 five-minute choices, 94/96 24-hour choices and 12/12 revisions**, with **0/960 single-cue and 0/480 pair false alarms** in the declared no-learning panel. Its baseline prediction error is **0.171 Hz**. A separate audit using actual sequential readout exposures confirms 94/96 delayed choices and 12/12 revisions without cloning. These are model tests using engineered inputs, not measured animal behavior.

![Main results and feedback audit](figures/history_readout.png)

**The feedback contains real graph measurements, but the proposed compression is not established.** I independently recomputed the operators from the existing FlyWire v630 graph. Claude's three count-matrix effective ranks reproduce almost exactly: **224.36 for PN→KC, 51.69 for KC→MBON and 10.34 for their linear composite**. The numerical ranks are 296, 96 and 96, rather than the quoted 302, 97 and 97; matrix dimensions are not necessarily ranks. The composite's 90%/99% squared-singular-value energy dimensions are indeed 2/4. However, incoming-column normalization changes those dimensions to **6/27** and the composite entropy rank to **30.76**. These spectra depend on weight convention and do not measure retained information, nonlinear learning capacity, or a percentage of the brain's computation. [Operator audit](results/operator_audit.csv).

The signature claims have a likely units problem. The source graph stores **signed synapse count × 0.275**. A graph-weight threshold of one retains at least four synapses; a threshold of two retains at least eight. Recomputing physical-count thresholds gives:

| Minimum physical count | KCs with surviving MBON output | Distinct binary output supports | Distinct / surviving |
| --- | ---: | ---: | ---: |
| 1 | 5,177 | 3,168 | 61.2% |
| 2 | 5,175 | 2,792 | 54.0% |
| 4 | 5,159 | **2,029** | **39.3%** |
| 8 | 4,179 | **664** | **15.9%** |

The distinct-support totals at four/eight reproduce Claude's 2,029/664 exactly; surviving totals differ by one cell. The input-side **4,640/4,757** also reproduces exactly at four synapses. Without the original script, this is an inference about the cause, not proof of how it was computed. At one physical synapse the actual interface has **4,854 reachable KCs and 323 unreachable**, not 4,757 reachable. All **5,177 full weighted output rows are distinct**. The weighted-row column in the audit counts original full weight vectors among the surviving cells, before thresholding their individual weights. Equal binary supports alone do not permit merging neurons with different inputs, weights, histories and teaching updates. [Signature audit](results/signature_audit.csv), [count/accounting audit](results/claim_audit.json).

I found neither Claude's scripts/DoOR input files nor the chat review's claimed rerun records in the project. The chat review's reported iteration-6/7 numbers agree with our local results, but that does not verify its claimed independent execution. Claude's DoOR dropout accuracy, 647-KC learning equivalence and historical `j_ratio` correlation remain unverified here. The cited Hallem study measures odorant-receptor responses using an empty-neuron preparation; mapping those measurements to FlyWire glomerular labels is a cross-dataset functional assumption, not same-specimen measured PN activity. The public database is a useful possible input source, but a receptor→PN transformation must specify inhibition, gain, missing channels and units. [Hallem and Carlson, 2006](https://www.sciencedirect.com/science/article/pii/S0092867406003631), [DoOR source](https://github.com/ropensci/DoOR.data).

A 647-KC version would contain 20,728 bytes if all four existing arrays were shrunk proportionally, about an eightfold state reduction. That is accounting, not a demonstrated learner. A reduction in edge count is also not directly the reduction in this model's state, which is allocated per KC rather than per graph edge. Odor identification under an assumed dropout process cannot establish association capacity, interference retention, revision or physiological fidelity. **No KC reduction was adopted in this iteration.**

**Why this experiment followed the data.** The reproduced iteration-7 failure was missing history: the same input has different non-learning output after sensory exposure. Code inspection identified four anatomically weighted current KC sums that determine the existing parent's nonplastic output. This justified testing access to those existing signals before adding a new history store. Both iteration5/bi and iteration6/equal_allocation retain exactly their earlier parameters, input encoding, adaptation, teaching, feedback and local plastic updates.

The instrumented learner exposes the effective presynaptic activity already used in each event: encoded KC activity multiplied by the average of adaptation before and after that event. The reader pools this through the existing KC→gamma1/alpha3 weights into four values. It receives the same event's sensory activity and observed alpha3 responses. It sees no plastic traces, reset responses, cue IDs, task labels or future events. This is an **internal model sensory port**: the fitted comparator's physical implementation and access to a separate nonplastic reference are not established by the connectome.

An analytic reference computes the parent's known nonplastic response from those four sums. It matches offline reset targets within **2.14×10⁻¹⁴ Hz**, as expected from the equations. It is an information-sufficiency diagnostic, not a recovered biological mechanism or a fitted-reader success. The actual candidate learns a different, generic approximation from **no-learning development responses**: 64 fixed radial-basis features plus four linear inputs, standardized, followed by ridge regression and output clipping. Centers and width use development inputs only. The penalty and feature count were fixed before fitting, with no hyperparameter search. The fitted reader's prediction path calls neither the analytic baseline nor a reset copy. [Frozen protocol](PROTOCOL.md), [configuration](config.json), [reader code](src/readout.py).

We separated the contributions of information and function approximation. The equally sized unadapted reader receives the same KC encoding without adaptation. A scalar-history control uses the unadapted encoding multiplied by one instantaneous mean activity/adaptation gain. A current linear reader omits radial-basis features and has lower fit capacity. Twenty controls permute anatomical weight rows within KC type, side and four-output support-mask strata while preserving those supports, column sums and block weight multisets. They receive the same current sensory activity and have equal fit capacity. This is a fine-weight-alignment control for the frozen parent, **not a full-connectome strength-preserving null or an independent biological specificity test**. The frozen iteration-7 LH8 mapping is also retained, with thresholds recalibrated under the new calibration histories.

The panel uses **864 new patterns**: 16 development, eight calibration and 12 test banks, each containing 24 patterns, disjoint from each other and all earlier specified input banks. Development/calibration cover naive input, repetition, recovery and intervening cues with plasticity disabled. There are **4,544 probes**, including 1,280 development, 640 calibration, 2,496 new-test and 128 retrospective regression observations. The two old failed revision banks are separate from new-test counts. Whole-bank bootstraps describe generated-input variability, not biological replication. [Split inventory](results/split_inventory.csv), [panel receipt](results/panel_run.json).

The primary reader uses 1 Hz cue and pair thresholds. It detects **654/661 changed probes (98.9%)**, with **661/661 correct signs**. The two missed delayed choices abstain; none chooses the wrong option. All eight primary engineering gates pass. Zero observed false alarms on these streams do not establish a universal zero rate. [Summary](results/readout_summary.csv), [single-cue metrics](results/single_cue_metrics.csv), [decisions by phase](results/pair_decision_metrics.csv), [acceptance checks](results/acceptance_checks.json).

The anatomy-weighted current reader improves delayed choices over the same-capacity unadapted reader by **49.0 percentage points**, with a whole-bank 95% bootstrap interval of **36.5–62.5 points**. This controlled difference supports the value of current sensory history. But the scalar-history control also satisfies the numerical usefulness criteria: its delayed result differs by just one pair, and its interference difference from the primary is not statistically resolved in this small panel. A detailed local-history requirement is therefore **not established**. Nor does this show that one stored scalar can replace all KC histories: the control computes its instantaneous gain from the existing 5,177-cell adapted activity. [Paired effects](results/paired_effects.csv).

The twenty fine-weight controls have baseline RMSE **1.097–1.332 Hz** and 62–79 correct delayed choices, worse than the real-weight observer. Those results show that alignment with the parent's fixed output weights matters for predicting that parent. Because the prediction target itself is generated using those weights, this should not be sold as independent validation of a biological computation. [Routing-control audit](results/routing_control_audit.csv), [final control metrics](results/routing_control_final_metrics.csv).

The exact analytic reference passes the original 24-hour memory criterion on **93/96** pairs, while the fitted reader chooses correctly on 94. The extra choice is bank 801202, pair 5: its true memory contrast is −0.769 Hz and its predicted score −1.089 Hz. Approximation error moves it across the 1 Hz decision threshold. It is not an extra stored memory or performance beyond an information ceiling. The analytic baseline is a ceiling on baseline accuracy, not a universal upper bound on thresholded choice counts.

**Stronger storage becomes more usable, but revision still fails.** With the same fixed current reader, equal allocation gives 96/96 delayed choices and 47/48 correct post-interference choices, compared with 94/96 and 42/48 for the parent. Its actual half-retention count is **45/48 versus 16/48** under the original independent storage criterion. But revisions fall from **12/12 to 8/12**. The paired post-interference advantage is 10.4 points (95% interval 4.2–16.7); the revision difference is −33.3 points (−58.3 to −8.3). A better reader reveals this tradeoff; it does not repair it. [Parent storage metrics](results/parent_storage_metrics.csv).

Both old equal-allocation failures reproduce: bank 601002 remains at **−1.621 Hz**, and bank 601004 at **−14.257 Hz** after reversal. The fitted reader chooses the old option in both cases. It correctly reveals the failure instead of hiding it behind abstention. The corresponding parent reversals remain positive and correctly read. [Old revision regressions](results/old_revision_regression.csv).

**The actual serial runtime path was checked separately.** After the primary results, I added a deployment audit because the declared panel used non-writing observation copies. This secondary schedule instead presents A then B to the running learner, and those readout exposures update its state. It uses no observation or reset clones, no refit, and does not replace the original acceptance panel. The parent again gives **96/96 five-minute, 94/96 delayed, 42/48 post-interference and 12/12 revision choices**; the no-learning serial controls produce **0/300 pair false alarms**. Equal allocation retains 96/96 delayed choices but falls further to **6/12 revisions**. This exposes sensitivity to the extra presentations, an additional reason not to promote the allocation variant. [Serial decision table](results/online_serial_decisions.csv), [deployment audit](results/online_audit.json).

Biological fidelity remains a separate, unchanged scorecard. The equal-allocation perturbation still worsens the original effective model's conditioning RMSE from 4.127 to 5.896 Hz and spacing RMSE from 4.396 to 14.838 Hz, while improving the extinction-ratio error. Those values are **carried from the verified iteration-6 table, not newly fitted or rerun physiology**. The readout is trained against simulated parent responses; no new biological odor→PN calibration, measured KC activity or physical comparator has been validated. [Carried physiological comparison](results/carried_physiology.csv).

**Executable deliverable and limits.** All **58 implementation checks pass**: the sensory port preserves both parents' rates, arrays and counters; fixed coefficients reproduce from development data; thresholds reproduce from calibration alone; old failures, routing controls, input disjointness and 27 frozen parent/protocol hashes verify. Persistent parent state remains **165,688 bytes** through 1,024 patterns and exact save/resume; the reference adds **zero persistent mutable bytes**. The primary reference has **170,008 fixed numerical bytes**, mostly its anatomical pooling matrix. Transient sensory/output arrays and bounded pair-comparison buffers are not learned state. No neuron compression was performed. [Verification](results/implementation_verification.json), [capacity checks](results/capacity_checks.csv).

The complete reproducer runs in about **42 seconds** on this Mac; panel generation's measured process RSS was approximately **335 MB**. This is a process measurement, not a total-system peak. The sparse graph audit uses the existing graph, and the large BANC mother table is unnecessary. The [entrypoint](run.py) also runs a real online demonstration without reset calls; [instructions](README.md) describe the internal sensory interface and supplied models.

The defensible advance is a usable engineering readout of the existing model, together with a sharper failure measurement for storage and revision. Keep the iteration-5 learner and this optional observer as the reference for future changes. A 647-KC proposal can now be tested against actual choices, retention and revision rather than accepted from spectral rank or identification alone. Its claimed DoOR scores still require the exact data version, receptor/glomerulus mapping and perturbation script to reproduce. No new memory mechanism, universal compression ratio or complete persistent fly core is claimed. The compact bundle includes final evidence, new code/models and checks; datasets, raw streams, previous releases and unchanged dependencies remain in the parent project and are referenced by hash.
