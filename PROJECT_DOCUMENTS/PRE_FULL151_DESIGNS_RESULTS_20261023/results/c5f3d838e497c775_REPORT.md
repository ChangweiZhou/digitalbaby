## 建议保留的部分

- B/FB2/FB4/FB8 同世界配对；所有 FB 臂保留同一个八中心地址字典，只改变物理存储共享。这比同时改变 router 中心数和存储数更容易解释。

- 暂不加“同容量巨型单 bank”控制可以接受。设计已经限定这是资源曲线，不能唯一分离容量与隔离；不应为回答另一问题无限扩张本轮。

## 1. [P1] 事件顺序与原实现冲突，不能靠“继承原生”一句话消除

位置：[§5.4](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:356>)、[Q5/Q6](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:1148>)。

文档先 advance shared state、衰减所有 bank，再暴露选中 bank、计算 allocation 和写入。实际合格实现是先按当前静态 x 选 bank，把**事件前** alpha 状态装入 native scratch，调用一次原生 B event，然后衰减 bank 存储并用原生更新后的选中 bank 覆盖该槽位。[fv3_model.py:31](</Users/pencilbard/Downloads/second_try_copy/PostV5_FULL_v3_20260921/fv3_model.py:31>)

这不是可交换的顺序：B 保存事件前 adaptation/alpha，用它们算 allocation 与 eligibility，再补 B correction；native update 的形式是 `(old + write) * decay`。预先衰减后再调用原函数，会改变反馈/分配，甚至重复衰减。[model_bkr.py:23](</Users/pencilbard/Downloads/second_try_copy/WorkstreamBKR_v5_20260920/model_bkr.py:23>)、[model73.py:58](</Users/pencilbard/Downloads/second_try_copy/minifly/iteration18/src/model73.py:58>)

修正：从合格 wrapper 机械继承，唯一新操作是 `route_class → storage_bank`。明确选中 bank 在 native event 内衰减一次，未选中 bank 被动衰减一次；共享状态只调用一次 native event。Q5 的“delayed probes”须区分真实 rest 已经推进的时间与只读 probe 的临时 clone，probe 本身不能推进 live learner 时钟。

验收：B/FB1 和 R0 FB8/S_FIXED 在非零前态的 active、nonplastic、idle、long-rest 事件上，逐步比较状态、写入及后续 probe，而不仅比较最终正确率。

## 2. [P1] 已修正过的稳定遗忘窗口又被写错

位置：[§11–12](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:545>)。

提案多次写 `+24h → +7d`。冻结端点实际是 `block7_day → final_7day`，两个 checkpoint 相差 **604800 秒**，相对最后一次全局教学为**第1天 → 第8天**。不是相差六天的第1天 → 第7天。[冻结端点字典](</Users/pencilbard/Downloads/second_try_copy/CORE_RECOVERY_POST_V5_FULL_V3/ENDPOINT_DICTIONARY.json>)、[eligible_stable](</Users/pencilbard/Downloads/second_try_copy/PostV5_FULL_v3_20260921/fv3_engine.py:33>)

文档还把“窗口内没有任何教学”弱化成“没有该 fact 的教学”。如果以后允许其他教学，测到的将包含学习干扰，不再是同一个被动遗忘窗口。

修正：沿用 checkpoint ID、精确 elapsed 差和窗口内 teach-event count=0；明确所有个体 fact 的年龄仍可能不同。保留 |E|、common-known 数、两臂起点正确数和终点损失数。common-known=0 时只能记无共同已知支持，不能宣传为零遗忘。该比较中 common-known 集合随候选而变，跨 K 的稳定损失不能被当作固定同一记忆人口的剂量曲线。

## 3. [P1，需先作设计选择] 合并层次不是均衡的 bank 缩减

位置：[§4](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:253>)、[§27 的“需要多少隔离”结论](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:1283>)。

按提案的四个 seed、合格源的 5177 维中心生成方式、最大 centroid cosine 的逐次合并，实际得到：

|seed|FB4 每 bank 包含的地址类数，排序后|FB2 地址类数，排序后|
|---|---|---|
|R0=2026092101|1, 1, 2, 4|2, 6|
|R1=2026092111|1, 2, 2, 3|2, 6|
|R2=2026092121|1, 2, 2, 3|2, 6|
|R3=2026092131|1, 1, 3, 3|3, 5|

R0 的 FB2 实际分组是 `{0,1,2,4,6,7}` 与 `{3,5}`。把已有48个 S_FIXED 世界的塑性事件计数按该映射归并，约为 **74.54% / 25.46%**；这只是已有事件的计数归并，未运行 FB2，也未预测其学习表现。

因此 K 下降同时改变了物理 bank 数、每 bank 地址类数及负载不均衡。**FB2 失败不等于“两 bank 的容量不够”。**设计确实限定了“此特定层次”，所以这个实验不是数学上无效；但最后“只有八 bank 工作就说明需要大量隔离”的结论超出了这个限制。

推荐：在科学前改为预定的平衡嵌套层次。八中心先按几何相似性做最大总相似度的完美匹配，形成四对；四个 pair-centroid 再作一次完美匹配，形成两组四地址。冻结精确相似度、并列规则和 cluster 编号。这样不增实验臂，也不按行为优化分组。**地址类均衡仍不保证事件频率均衡**，bank utilization 必须照常披露。

若坚持原层次，也可以运行，但名称及结论必须明确是“这个不均衡层次的资源曲线”，不得将低 K 阴性解释为普遍容量下限。

## 4. [P1] 未决推断和候选标签的失败处理不完整

位置：[§17](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:779>)、[§19–20](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:928>)。

Satterthwaite 在所有 strata 样本方差为零时出现 0/0。文档列了 `INFERENCE_INCOMPLETE`，但没有规定该情形、缺失世界或无法估计 guard 如何进入最终选择。`SMALLEST_CONFIRMED_GAIN_ARM` 只要求“没有确认的 guard harm”，容易让**guard 根本没算出来**的候选通过。上一轮代码显式要求所有正式区间可估计，这一保护不能丢掉。[fv3_analysis.py:6](</Users/pencilbard/Downloads/second_try_copy/PostV5_FULL_v3_20260921/fv3_analysis.py:6>)

修正：

1. 固定 roster，任何缺失/损坏/不完整世界不得换 seed、补“好跑”的世界或作完整案例选择。
2. 零样本方差不自动生成零宽区间或恒等证明；无预先成立的解析恒等证据时按未决处理。
3. 选择标签必须同时要求：primary estimable 且 lower>0、所有15个 guard estimable、无确认损害。不能只检查“harm 列表为空”。
4. 恢复独立 `RISK_UNRESOLVED` 字段：保护区间仍包含损害方向时，研究推进不等于安全/非劣。
5. 某一个 fixed seed 的收益/损害必须单独披露。等权平均正收益不证明四个初始化都可靠；若要加 seed-wise 正式通过门槛，需重新分配推断家族。

## 5. [P1] 动态诊断目前不是可执行、可计费的合同

位置：[§14–15](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:653>)。

“8 canonical + 8 K8 世界”只限制世界数，未限制每世界的臂、事件、查询、扰动幅度、方向及 suffix replay 数。896 是主科学轨迹数，**不是总执行预算**。这个遗漏足以把一个收敛的资源曲线重新扩成大实验。

还有两个定义问题：

- `r^T Φ w` 是沿指定轨迹的局部线性传播对象；跨 active-set/clip 分支的 actual-write-scale 干预是**有限幅度因果差**，不能无条件叫该 Jacobian kernel 的估计。应分别命名，只有额外小尺度稳定性检查支持时才讨论线性近似。
- 当前 fact 是两个 cue 的对比，两个 cue 分别选 bank。[learn_pair](</Users/pencilbard/Downloads/second_try_copy/minifly/V82E/src/model_evo.py:315>)、[probe](</Users/pencilbard/Downloads/second_try_copy/PostV5_FULL_v3_20260921/fv3_model.py:61>)。`a(x_mu)` 若把 mu 当关联 fact，并没有唯一地址。应以单 cue/presentation 为基本路由单位，关联用两个地址组成的 tuple；查询边际是有符号的两 cue 差。固定同一 cue 在静态编码下的 route consistency=1 是验收恒等性质，不是泛化证据。

科学前必须冻结：世界ID、arm、event/checkpoint ID、干预位于 B 校正/衰减的前后哪一侧、slow/fast/两者何者被改、对照和扰动幅度、后续外生事件相同但内生反馈重新计算、连续 margin/discrete choice 的提取规则、每世界方向数、总 replay 次数、按 native event 工作量折算的 full-life-equivalent 上限。

扰动的状态轴必须包含真正持久的 `bank_fast/bank_slow` 及相关共享状态，不能只改 `m.slow` 或 `m.fast[:,1]` 这些临时装载槽位；后者会在下一个event被bank数组覆盖，制造虚假的“传播为零”。也不能把scratch和对应bank作为两份独立科学状态计入传播维度。

写入加权 collision 还须说明用原始 qs、B 校正后 qs−cB，还是乘 decay 后的真实增量；“retained slow-write”须锁定终点T及指数权重，区分逐次写入范数之和与最终净状态范数（存在抵消）。这些字段不需要保存每个 fact 一份完整状态，可以 evaluator 端流式累积；严禁诊断缓冲成为 learner 可读记忆。

我建议把昂贵 replay 限为独立、有明确上限的描述性附录。主实验继续四臂，不因几何故事不漂亮而补跑或筛选诊断事件。

## 6. [P2] “有益”“保住八 bank 收益”“边际收益递减”是三种问题

位置：[目的](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:8>)、[§18.1](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:853>)、[§20/22](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:977>)。

当前正式检验回答“FB2/4/8 是否优于 B”和两个相邻差异。它不能回答“FB2 保住 FB8 的大部分收益”。例如 B=50%、FB2=52%、FB8=75%，FB2 可以得到显著收益标签，却没有保存主要增益。设计已有“不等于等效”的正确提醒，但标题目的和结尾仍容易把两件事混为一谈。

推荐不急于发明非劣界值：把本轮目标明确为**条件资源—表现曲线及最小的已确认有益臂**。若确实要证明“保住”，必须在新世界之前确定有任务意义的允许损失，加入直接 FB2−FB8 比较并重新冻结家族；不能拿历史SD当允许损失。

同理，`RESOURCE_CURVE_SHOWS_DIMINISHING_FIRST_USE_GAIN` 没有对应判据。2→4增加两bank，4→8增加四bank，若谈单位资源边际收益，应比较 `(Y4−Y2)/2` 与 `(Y8−Y4)/4`（或者除以实际新增字节），而不是两个不等跨度的显著性。可只画描述性曲线并删掉正式“递减”结论；若正式检验二阶对比，要增加预声明 contrast 和调整 M。

## 7. [P2] 样本数可以保留，1.40 pp 精度预期过于乐观

位置：[§18.1](</Users/pencilbard/Downloads/minifly_FB1_fixed_bank_resource_curve_design_20260921.md:885>)。

文档已承认 B−REF SD 只是示例，不是保证；问题是已有更接近当前干预的方差可作敏感性参考。读取旧48个 R0 控制世界：S_FIXED−B 的 paired-world SD 为 **8.201 pp**，S_LOCAL−B 为 **7.759 pp**。以128世界、四等大 strata、等方差下 df=124、alpha=.02/M=5作规划计算，半宽约为 **2.13 pp / 2.01 pp**，而非1.40 pp。

这不是新臂方差估计，也不能给 FB4−FB2 或 FB8−FB4 的功效保证，更不能据此改动样本来追显著。建议保留96/128的固定规模，列1.4/2.1/更大半宽的敏感性，并明确：它可能足以确认较大的固定 bank 增益，却未必区分细小的资源边际差异。

## 9. [P2] 桥接证据、seed分层和报告链路仍需补上最后的合同

**历史桥接。** 原compact receipts保存最终状态/write digest、route counts及汇总结果，但没有逐事件route sequence、全量checkpoint预测和完整bank数组。§9不能假设归档里存在这些对象。科学前固定少量旧control world ID，同时重放旧锁定 S_FIXED 与新 FB8，先核旧重放匹配原receipt的digest，再比较两版详细轨迹。不能把重跑的旧世界计入新科学n。若使用容差比较，需明确哪类操作；不应一边允许位差、一边对同一对象要求原始字节hash相等。

**seed×rotation。** 原K8 constructor wrapper用 `rotation=i%8`。[fv3_prepare.py:44](</Users/pencilbard/Downloads/second_try_copy/PostV5_FULL_v3_20260921/fv3_prepare.py:44>)。新稿只规定每seed32世界，尚未冻结联合分配。若直接写seed=i%4，每个seed只看到两种rotation。旋转在可交换donor假设下未必造成偏差，但这是可避免的设计耦合：建议预先排成每seed×每rotation各4个K8世界，且诊断子集也均衡，禁止依照结果换分层。

**报告链路。** 上一轮720轨迹完成后才因缺少matplotlib而中断报告。[恢复记录](</Users/pencilbard/Downloads/second_try_copy/CORE_RECOVERY_POST_V5_FULL_V3/results/REPORT_RECOVERY.json>)。新资格检查应在技术fixture上走完“全臂提交→区间/标签→绘图→报告→ZIP→manifest校验”，而不只检查learner数值。再冻结4 workers、停止/续跑规则、资格/诊断计算预算；不要只写磁盘上限。

## 我建议的修订后边界

1. 保留B/FB2/FB4/FB8、96 canonical/128 K8、四固定seed；不加自适应router或参数搜索。
2. 原封不动继承native事件顺序，使用精确checkpoint时钟和共同已知覆盖记录。
3. 科学前选定平衡嵌套规则，或明确接受原不均衡层次并收窄所有容量结论。不能事后选择哪种合并好看。
4. 补齐未决推断、完整数据门槛和独立风险字段。主结果是条件资源曲线，不宣称非劣、安全或最小核心。
5. 精确定义cue级collision/真实增量加权；闭环有限扰动另列为有上限的描述性附录。
6. 先完成旧源桥接和包含绘图/打包的端到端试跑，再冻结新世界并决定启动。

这轮有机会把“8-bank固定路由的强信号”转成可比较的资源曲线。它不能单独证明果蝇采用字面上的bank，也不能唯一分开容量与隔离，更不能用低K不显著来证明低K不可能。
