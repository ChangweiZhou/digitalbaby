# V67 准备报告：从干扰表达，追到写入形成

**状态：设计准备完成，未运行 V67 实验。** 当前最新完成版本仍是 V66／Iteration 11。未来执行 V67 时对应 Iteration 12。

建议把 V67 的主要问题收紧为：**当前 γ 历史反馈究竟在帮助形成有用记忆，还是增加无关记忆的损伤？现有局部状态能否提供区分持续反转与附带干扰的信息？**

我保留了附件提出的三段工作：补查 V66 的扰动幅度、干预反馈形成、满足条件后最多测试一个修复。具体设计在 [DESIGN.md](DESIGN.md)，机器可读的待冻结协议在 [protocol_draft.json](protocol_draft.json)。附件是设计参考，不构成运行授权。

这次核对实际代码后，有六项重要调整：

1. **写入量问题仍需保留。** V66 主要预测有正有负的影响 E。正负抵消时，写入量可能不能预测 E，却能预测绝对扰动或严重损伤。因此计划补查 |E|、E²、负向损伤和方向×幅度交互；这些将是旧数据的探索性再分析，不冒充新的独立确认。本轮尚未计算。
2. **γ 历史反馈必须定义到具体接口。** 教学计算使用 γ 和 α 输出，而 γ 又能进入 α 输出。完整的 γ 历史干预必须重新计算这条间接通路；仅替换直接 γ 输入是另一个问题。当前两个间接增益确实极小，但不能在实现时悄悄省略。
3. **“去历史”“断反馈”“清空记忆”必须分开。** 本轮设计的反事实只在教学计算中替换历史贡献，保留当下感觉、适应、先天反馈和实际存储状态。它不同于现有 `feedback_block`，也不同于部署一个能访问无记忆克隆的控制器。
4. **α 干预是近零对照，不能要求严格为零。** 冻结模型的 α→DAN 最大有效连接系数为 1.372×10⁻⁹，γ→DAN 则可达 0.327；这些是模型参数，不是新生理测量。应使用带增益和输出界限的误差检查，区分合理微小效应与实现错误。
5. **不能把停止学习包装成保护记忆。** 每个干预同时测新关联收益与旧关联损伤，并比较固定学习衰减对照及匹配慢状态写入范数的诊断对照。不按事后学习成绩挑“匹配成功”的样本。
6. **真正反转与一次错误反馈应有相同前缀。** 第一次矛盾事件结束前，两类历史完全相同，因此因果模型不可能靠局部信号提前区分其未来类别。测试重点是证据积累后的分离，同时检查重复无关学习是否也会触发相同的“解锁”。

准备后的执行顺序如下；现在均未启动：

| 阶段 | 拟解决的问题 | 限定范围 |
|---|---|---|
| V66 旧数据再分析 | 幅度是否影响扰动风险，而非仅影响符号？ | 现有 16 个普通流；不增加学习轨迹 |
| V67 写入形成诊断 | γ 历史反馈对有用学习和附带损伤的因果贡献 | 16 个新普通流；四种教学历史条件，固定对照 |
| 局部信息检查 | 现有状态能否在证据出现后区分反转、无关重复和单次异常？ | 复用这 16 个检查点；不开展分类器竞赛 |
| 条件性单候选试验 | 一个运行时可实现的改动是否优于少学一点？ | 最多一个候选，独立 16 个验证流；条件不满足则跳过 |

候选必须从零开始形成自己的记忆，测量所有已学习关联在负载 12、24、48、96 时的表现，并检查不同记忆年龄和次日反转。共享父模型检查点上的干预结果不能代替这种端到端验证。

Huang 的来源审计可约束反馈改动，但当前 γ 历史替换并不等同于实验中的神经元阻断。使用已能重建的反馈/条件化数据时，必须先列清对应关系和观测定义；未解决的 Fig. 5k、部分归一化与拟合数据差异不能变成方便的数值门槛。没有新生理拟合，也不重新开展 Oja、睡眠、额外记忆层或 KC 压缩搜索。

**当前结论是设计判断，不是新实验结果。** 已完成的工作仅包括阅读建议、核对旧报告和代码、查看冻结参数、撰写设计及记录来源哈希。没有生成 V67 气味库，没有推进学习状态，没有拟合分类器，没有计算新的 V66 统计，也没有修改父模型。当前 V66 发布包与既有结果保持不变。
