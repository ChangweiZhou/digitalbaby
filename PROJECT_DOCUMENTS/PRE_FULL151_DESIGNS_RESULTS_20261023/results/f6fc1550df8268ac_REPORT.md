# Step 8 result: FE0 recognizes a shifted cue, but learned value does not reliably follow it

The prospective 32-world assay completed all 64 W/N science trajectories without a scientific failure. The independent receipt audit passed. Its frozen verdict is **`FE0_SHIFT_E2_NOT_DEMONSTRATED`**. On the never-taught one-position-right-shifted cue, W scored **55.2%** and the no-write N control **51.0%**. The paired world-level W−N effect was **+4.2 percentage points** (two-sided 95% Student-t interval **−7.2 to +15.5**), so the primary gate failed. W's absolute interval was **46.3–64.2%**, failing the separate above-chance guard. These percentages pool three pair choices per world for description, but inference uses **32 worlds**, not 96 choices as independent observations.

The positive control did work. On the directly taught canonical frame, W scored **83.3%** and N **50.0%**, a paired effect of **+33.3 points** (95% interval **+22.8 to +43.9**). Thus the run confirms that the unchanged FE0→Full151 route acquired the taught association in these worlds. Its failure on the shifted frame is a transfer failure, not a failure to learn the canonical task. At the shifted frame W beat N in 11 worlds, lost in 8, and tied in 13; the W pair-margin mean was approximately zero (−0.00036).

The read-only code check is informative but was **not** a decision gate. After training, a shifted cue's FE0 code was nearest to its own canonical code in **72.7%** of six-way comparisons, close to Step 7's separate 74.7% access census. Yet canonical and shifted learned pair margins correlated only **0.097** across the 96 pair instances; the shifted margins did not carry the canonical positive separation. This supports a narrower diagnosis: coarse cue identity can often be recovered from FE0 code distance, while the existing native value readout remains sensitive to the exact activity pattern. It does not by itself prove which synapses or readout operation cause the loss. Merely seeing code overlap is not enough to claim value transfer.

Each world used three random uppercase symbols and balanced cyclic labels. All six ordered cues were taught 12 times in the canonical 12-byte frame (`8 spaces || x y || 2 spaces`). The shifted probe (`9 spaces || x y || 1 space`) kept the same two bytes and total duration, had **zero teaching exposures**, and was read on discarded clones for the first time before any shifted feedback. W and N had identical bytes, labels, clocks, and predictor learning; native value writes were enabled only in W. A raw exact-12-byte table would have no taught shifted entry, whereas an explicit ordered-pair canonicalizer could pass. This is an **E2 changed-presentation test at most**, not an E3 unseen-relation test; no autonomous choice, byte emission, reward discovery, arithmetic, or durable lifetime claim was tested.

Technical world 9799 was excluded from science. It passed Step 5 FE0 state parity after every teaching record, read-only probe purity, W/N birth equality, predictor equality, clocks, and teaching count. The independent reducer checked source hashes, world roster, fixture/schedule hashes, cue hashes, eight probe rows per world, raw value-to-margin-to-choice arithmetic, packed-code Hamming arithmetic, exposure and teaching counts, and the fixed intervals. Four in-memory tamper controls (raw value, code, cue hash, exposure count) were rejected. All 32 science receipts were committed once; none was rerun. The science runner was kept awake by `caffeinate` until exit.

The next scientific question should target the **address-to-value interface** rather than reopen Full151's entire memory search. One narrow option is a fixed, predeclared pooling or canonicalization rule that maps both frames to the same teaching/readout address, with matched controls that check it does not erase byte order. That would test whether stabilizing the address rescues changed-presentation retrieval. It would be a new architecture and new assay, not a reinterpretation or repair of this failed result.
