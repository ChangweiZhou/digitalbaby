## 开始实现后、正式开跑前必须闭合的四件事

### 1. 三个 slot 仍是候选方向，不是三套已定义好的学习器

S 的优先级最高：源码已有 [V24BankMemory](/Users/pencilbard/Downloads/second_try_copy/elm_fly_local_memory_v24.py:6347)，有固定/自适应路由的共同初始化。但该类原来的四输出读出权重不是当前 fast/slow 状态。需要明确 bank 哪些状态、原生反馈读什么、未使用 bank 如何衰减，以及 B 在路由前后哪一步执行。增加八套状态可能有效，却首先是增加资源后的完整架构效果；没有等资源控制就不声称收益来自更高存储效率。v3 的资源/Pareto 和单独 adaptation control 足以容纳这一边界，无需再加一整套科学面板。

W 最容易映射出错。当前 [advance73](/Users/pencilbard/Downloads/second_try_copy/minifly/iteration18/src/model73.py:9)对 fast/slow 做加法和衰减；[expression](/Users/pencilbard/Downloads/second_try_copy/minifly/iteration18/src/model73.py:108)的 −11.2…19.96 是输出截断，**不是 slow 权重的上下界**。不能把这些数字直接填入“突触 headroom”。若要引入有界权重或新的局部有效权重坐标，需明确属于 SOURCE_INSPIRED_NEW_PORT，记录新边界与状态映射。若控制只关闭 reopening 而保留新边界，才有机会定位 reopening 的增量；否则只能解释整套“边界+更新”的行为效果。已有资料或技术状态上的 headroom 审查应先于该移植，不必硬凑第三臂。

H 需给实际解剖分区索引、两种 policy 方程与 read integration；“Aso-style”不是可执行参数。现有 fast/slow 两时间尺度也不能自动算成新解剖 policy 分区。解剖来源真实、规则固定，是资格；这是否有效则是后面的科学问题。

每个 slot 只冻结一套具体映射。资格样例允许检验时钟、符号、更新路径、边界、clone/save/restore、module-OFF=B 和数值正确性，不能反复用旧行为结果选最佳超参，再把它叫技术资格。无法获得清楚映射就按 v3 结束为 NOT_INSTANTIATED；不算该机制家族失败。文献机制本身的逐式来源核查应在 Candidate Lock 中完成，本次不把作者名字视为已经核实的公式。

### 2. 新 stable-loss 指标可用，但端点时钟和覆盖面要写准

v3 [第 316 行](/Users/pencilbard/Downloads/minifly_post_v5_next_round_FULL_SAMPLE_v3_20260921.md:316)规定 +24h→+7d。源码却不是“教学结束第1天到第7天”：原生 [LIFE](/Users/pencilbard/Downloads/second_try_copy/V88/minifly_rce_v87_followup_runner.py:89)先休息 86,400 秒，在末尾再休息 604,800 秒。

本次只读核对了 V5 CONF canonical_000 与 k8_000 的已有 event stream，按原生每个 teach-pair=330秒累计：

| 世界 | block7_day | final_7day | 两 probe 间隔 | 相对最后一次 teach |
|---|---:|---:|---:|---|
| canonical | 1,693,440 s | 2,298,240 s | 7天 | +1天 → +8天 |
| K8 | 5,685,120 s | 6,289,920 s | 7天 | +1天 → +8天 |

这些是既有文件的时钟核查，不是新实验；不得据此断言全部新世界已经合格。每个 fact 的最后教学时间又可能更早，应保留 fact age。

**建议最小修订：**本轮继承现有两个精确 checkpoint，正式名称改为 `STABLE_LOSS_LAST_DAY_TO_FINAL_PLUS_7D`，写清 +1→+8天和无中间教学；不改老世界日程。若必须测相对教学结束的第7天，则在只读 clone 上增加确切第7天 probe，不能直接改掉既有 final_rest 或混称原来 usefulness_7d。

不能从 [旧 extra extractor](/Users/pencilbard/Downloads/second_try_copy/WorkstreamA8_baseline_transfer_20260920/analyze.py:8)聚合所有 day checkpoints 的 usefulness_24h，再与一个终点相减；stable loss 需要同一事实、同一 truth、同一对精确时点。

新估计量还满足

\[
D^{stable}_{c,w}=\frac{|G_{c,w}|}{|E_w|}
\left(\ell_{c\mid G,w}-\ell_{B\mid G,w}\right),
\]

其中 G 是 24h 时两个模型都正确的子集。它是按整个 eligible 人口缩放的共同已知记忆损失差，允许正负，定义有效；但 G 随 candidate 变化。G 小甚至为零时，D 接近零不能说明“不遗忘”。新学习保护指标降低了少学的诱因，却不能保证 G 足够大，也不能排除换了一批会学的项目。

因此固定保存 |E|、|G|、G/E、两模型初始正确数、两个转移计数；|G|=0 时按现公式 D=0，同时标记 `NO_COMMON_KNOWN_SUPPORT`，不把它解释成保留能力相等。绝对 Q/R 和 acquisition/delayed guards 继续披露。此处不必再改 primary 或扩样；只须把 estimand 与覆盖率讲清楚。终端无写入窗口主要测被动表达/衰减，不能单独代替持续新学习造成的干扰遗忘，后者仍由其他能力与尾部指标反映。

### 3. 决策代码要消除“研究推进”和“风险未决”的歧义，并继承零方差规则

v3 的 [第 601 行](/Users/pencilbard/Downloads/minifly_post_v5_next_round_FULL_SAMPLE_v3_20260921.md:601)允许 primary 显著、guard 无确认损害时 advance；[第 621 行](/Users/pencilbard/Downloads/minifly_post_v5_next_round_FULL_SAMPLE_v3_20260921.md:621)又把 guard 太不精确标为 risk unresolved。二者可以共存，但必须明确，不能由 runner 根据分支顺序任意选一个。

建议实现为两个独立字段：

- `advance_for_followup`：有确认 primary 收益、无确认 guard 损害、要求的结果完整；仅表示进入后续研究。
- `risk_status`：保护指标是否仍跨越有害方向，及尾部覆盖情况；不因前一个字段为 true 自动消失。未定义实际容忍量时不要写主观的“wide”。

缺失/无法估计的 guard 不能因为比较 `None` 或 NaN 得不到 harm，就自动 advance。区分“有可估计但跨零的区间”与“推断无法完成”。没有用户容忍阈值也不妨碍推进研究候选，不必发明安全认证。

当前 [V5 interval](/Users/pencilbard/Downloads/second_try_copy/WorkstreamBKR_v5_20260920/analyze_bkr.py:7)已在 sd=0 时输出 `INCONCLUSIVE_ZERO_VARIANCE`，而非 [mean,mean]。v3 只明确绝对 Q 的零尾部警告，对新增 stable loss 同样要继承这个规则：没有确定性恒等证明时，全零样本不构成总体零风险。稀疏但非零差的 paired-t 仍是近似推断，报告该限制；任何额外稀疏区间处理必须事前锁定，不能结果出来后挑有利方法。

## 样本、精度与存储复算

重算采用文档给定的历史 SD，t 临界值 `t(1−.025/(2×24), n−1)`：

| 量 | 复核值 |
|---|---:|
| canonical，n=184，SD=10.094 pp | 区间半宽 2.47980 pp |
| K8，n=152，SD=5.398 pp | 区间半宽 1.46411 pp |
| 主科学轨迹上限 | 4×336=1,344 |
| 控制轨迹上限 | 3×48=144 |
| 加资格/诊断名义上限 | 1,536 |
| 按旧世界文件平均体积估计的新世界文件 | 24.171 MiB |

这些数与 v3 相符。两个正式行为家族 alpha=.025，总体 union bound 为 .05，前提仍是各 paired-t 区间近似适用；机制家族另有 .05，不应宣称行为加机制全部结论共同享有同一个 .05。

存储估计只覆盖科学世界规格，不是证明三种新模型的 diagnostics 和同时临时文件已适配预算。最终实现仍需按64 MiB持久/256 MiB增量磁盘做资格，同时测 RAM。保持 <10 MB交付包，引用未变父资产。
