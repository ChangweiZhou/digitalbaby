# MiniFly V9.10B — a native write has broad effects, but useful relational transfer is not established

**Four-world causal diagnostic; no model promotion.** V9.10A showed that an external graph fit can turn REF's taught-pair outputs into 76.17% accuracy on never-taught comparisons, versus 60.74% for its direct readout. The present experiment asks a narrower causal question: when one teaching record is written into REF, does it move never-taught comparisons in the direction of the relation they should express? The answer is **not convincingly, at the single-event scale tested here**. Writes perturb held-out margins, especially for pairs sharing a byte with the taught pair, but their truth-aligned effects are small and generally uncertain across four worlds. This does not negate the aggregate benefit in V9.10A or V9.9C; one-shot effects need not add linearly over a training history.

## Matched-prestate intervention

The unchanged V9.7 `REF` and V9.2 checkpoint were run on the existing V9.9B ranked-byte fixture in four new worlds (1801–1804). At an `early` parent state and a `late` state after 160 native-written old records, every one of the 40 ordered taught cues was applied independently to two identical clones. The clones saw the same bytes, feedback, and time; only the native write flag differed. Both were queried at the same post-record time on the event's own pair and the eight never-taught pairs. The frozen impulse table records `ON − OFF` in canonical byte order, **before** a separate scorer uses hidden ranks to orient it. There are 320 interventions and 2,560 held-out impulse measurements. This isolates the combined native write effect, not an alpha-only or anatomical subcomponent.

| Prestate; candidate label | Self-pair truth-aligned impulse | Held-out signed impulse: shares byte | Held-out signed impulse: no shared byte | Shared − disjoint absolute impulse |
|---|---:|---:|---:|---:|
| Early; neutral | +0.02785 | +0.00101 | −0.00395 | +0.00918 |
| Early; aversive | **−0.00482** | −0.00092 | −0.00095 | +0.00144 |
| Late; neutral | +0.01958 | +0.00078 | −0.00143 | +0.00471 |
| Late; aversive | +0.00405 | +0.00009 | +0.00030 | +0.00128 |

Values are world means in native value-margin units; no behavioral percentage is inferred from them. For the within-event *truth-aligned* shared-minus-disjoint contrast, the means and exploratory 95% Student-*t* intervals are: early neutral **+0.00497** [0.00078, 0.00915]; early aversive **+0.00003** [−0.00094, 0.00100]; late neutral **+0.00220** [−0.00026, 0.00466]; late aversive **−0.00021** [−0.00141, 0.00099]. Only the first interval excludes zero, and it is a small four-world diagnostic with multiple inspected strata, not a confirmatory finding. Early aversive teaching actually moves the event's own pair the wrong way on average in all four worlds; later in training its mean self effect becomes positive. The result warrants inspection of valence-dependent write/read dynamics, not a claim that aversive teaching always fails.

The **absolute** impulse is larger for shared-byte than disjoint targets in every prestate and valence stratum. However, shared targets also have greater frozen-KC code similarity to the teaching cue (mean cosine about 0.87 versus 0.80). The locality in magnitude could therefore follow ordinary code overlap. This experiment does not identify a relation-specific transfer rule. Neutral events also cause larger held-out absolute impulses than aversive events despite smaller fast-state write norms, so state-change size alone is not a useful proxy for correct transfer.

## What this changes

V9.10A established a **recoverable task relation in the collection of learned pair outputs when an external analyst supplies graph aggregation**. V9.10B does not find a clean, immediately useful native one-write transfer kernel that would explain that result by a simple `identity + relational + nuisance` decomposition. Together they keep the write/read interface as the next target, but they do not settle whether the main defect is native credit assignment, accumulation over records, retrieval, or an interaction among them. In particular, externally fitting eight symbol potentials after training is **not** an online learned MiniFly component and does not establish a persistent learning core.

A defensible next constructive comparator is a **bounded online shared learner** on the same frozen KC codes and the same teaching stream, scored on never-reinforced first responses and after unrelated new learning. It should be treated as a diagnostic reference until it also survives a relation family that a scalar rank potential cannot solve. There is no basis here to install a shared/private two-channel architecture or to launch a broad mechanism search.

## Checks and limits

Engineering preflight passed clone identity, same-clock/predictor checks, no-write label inertness at both prestates, two-OFF numerical identity, finite outputs, and roster checks. The canonical impulse tables were hashed before the hidden-rank scorer ran. Scoring checks passed; an independent audit reconstructed every scored row and summary. Exact-pair lookup remains 50% on these never-taught edges; the taught-label analytic rule reaches 100%, confirming that the task contains transferable structure. The intervals use **four worlds**, not 2,560 independent observations. The `late` state is one fixed training point, not a lifetime persistence test. All results are descriptive and specific to REF and this rank fixture.
