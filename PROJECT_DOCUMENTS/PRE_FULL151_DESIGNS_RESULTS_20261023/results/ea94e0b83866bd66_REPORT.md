**MiniFly iteration 4 — a causal persistence candidate, with unresolved biological failures**

13 September 2026. This iteration is complete as a bounded experiment. The persistent learning core is not yet established.

We can replace a schedule-dependent forgetting rule with a small, resumable memory state that learns from events as they arrive. It fits the standard physiology measurements somewhat better and retains the observed preference for intermediate training spacing. However, it predicts the separate spacing/extinction conditions worse overall than the original model, and the data do not determine its slow lifetime. A second experiment rejects 64 simple passive-recovery settings as repairs for iteration 3's excessive-training failure.

The deliverable is an executable **candidate with four dynamic scalars per effective cue address**, supported by measurements, software checks and explicit rejection tests. It is not a four-neuron brain, a proven biological minimum, or an anatomical FlyWire learning implementation. Start with the [runner](README.md) and [evidence figure](figures/evidence_summary.png).

**Why this iteration focused on state rather than another graph reduction.** The previous anatomical work identified interfaces worth preserving, but it did not establish that proximity identifies the functional teaching neuron. The prior BANC spatial replication remains unestablished. Iteration 3 also showed that exact reduction depends on the allowed sensory repertoire, and that source-model higher-order learning fails specificity or training-dose tests. Adding another graph motif would not resolve those failures. This iteration instead asks whether the existing physiology supports a compact, causal memory state and whether ordinary forgetting repairs the missing behavior. The [protocol](PROTOCOL.md) records the primary fit and secondary grid before their execution; the later state/edge diagnostics are explicitly post-fit.

**Evidence and fitting boundary.** The primary source is Huang et al., *Dopamine-mediated interactions between short- and long-term memory dynamics*, [Nature 2024](https://www.nature.com/articles/s41586-024-07819-w), and the [authors' released model](https://github.com/schnitzer-lab/Luo_Huang_2024_MB_model), commit `5d7c08a9a88f923169a0c3008aca68af421e9a7f`. This is the same study used previously, not an independent biological replication. I extracted 86 available mean/SEM pairs from the original [conditioning workbook](../paper_refinement/sources/huang_model/data_and_parameters/Imaging_24hr_data.xlsx), preserving sheet and cell addresses in [conditioning_means.csv](sources/conditioning_means.csv). Missing measurements remain missing. The source file was read without modification; its SHA-256 and extraction layout are in [provenance](sources/workbook_provenance.json).

The fitted comparison uses 60 available measurements for gamma1 and alpha3 DAN/MBON roles across attractive and repulsive odors, CS+/CS− and available time points. Alpha2 measurements are retained in the extraction but excluded from this two-module comparison. That choice follows the previous two-module audit and does not establish that alpha2 is biologically dispensable. Circuit gains, odor inputs, gamma1 decay, adaptation and learning coefficients remain at the released two-module mean-parameter values. Only the alpha3 forgetting kernel is fitted.

The objective is the sum of squared `(prediction − observed mean) / SEM`. These 60 means are not 60 independent flies; shared cohorts and repeated measurements prevent treating this objective as a fully specified likelihood. No significance claim, information-criterion proof or molecular identification follows from the fit improvement. The inherited circuit parameters already saw these data. The separate protocol checks also inherit the source model's prescribed baseline reset and shock scaling. They are kernel predictions without tuning to those outcomes, not a completely blind validation of the whole model.

**The causal defect and its repair.** The supplied batch model identifies the last scheduled training bout by looking through the whole event sequence, then switches alpha3 forgetting three hours after that bout. This is usable as a fitted retrospective protocol description, but an open-ended learner cannot know its last future training event. In a direct counterexample, appending a later training session changes an earlier predicted response by **5.047 Hz**, although the earlier input history is identical. The new implementation gives identical predictions for that shared prefix.

For effective cue address `i`, the new state is:

| State | Role |
|---|---|
| `gamma[i]` | Short-lived gamma1 plastic trace; affects feedback teaching |
| `alpha_fast[i]` | Fast component of alpha3 plastic trace |
| `alpha_slow[i]` | Slow component of alpha3 plastic trace |
| `adaptation[i]` | Cue-specific sensory adaptation inherited from the source |

The alpha3 readout uses `alpha_fast + alpha_slow`. Every locally addressed alpha3 update is split between these components, then each decays exponentially. Its impulse kernel is `K(t) = (1 − f) exp(−t / tau_fast) + f exp(−t / tau_slow)`. Cue activity and the circuit's dopamine-relative teaching response determine the update, using the original equations. Rest only evolves existing state. There is no future schedule scan, three-hour transition, or copying of short memory into long memory during rest.

This is a candidate implementation of persistence, not evidence that the fly has two particular biochemical pools. Both components receive each update immediately. Delayed consolidation mechanisms could produce similar measured responses. Signed effective inputs, baseline-relative firing and clipped rate responses remain inherited modeling assumptions; these variables cannot be pasted directly onto positive cholinergic KC synapses in the fixed-weight spiking engine.

**Fit and prediction results.** Full tables are in [standard fits](results/kernel_fit_summary.csv), [condition-level standard predictions](results/conditioning_predictions.csv), [challenge predictions](results/challenge_predictions.csv) and [challenge summary](results/challenge_summary.csv).

|---|---:|---:|---:|---:|---:|
| Original three-hour switch | 0 | 136.06 | 4.319 | **3.683** | **0.238** |
| Causal single exponential | 1 | 163.07 | 4.905 | 7.264 | 0.313 |
| Causal two-component kernel | 3 | **115.37** | **4.127** | 4.396 | 0.273 |

The two-component kernel lowers the standard weighted residual sum by about 15.2% relative to the frozen source, but uses three newly fitted parameters. Its separate spacing error is about 19.4% higher and extinction-ratio error about 14.5% higher. It therefore provides a causal alternative worth retaining, not an overall predictive improvement over the original source. The source numbers here use the released mean parameters; they are not the published ensemble medians. The earlier mismatch between source equations and released model medians remains unresolved.

The main positive result against the fitted single exponential is 24-hour memory after six-minute spacing: measured mean **−15.124 Hz**, single-exponential prediction approximately **−0.000023 Hz**, two-component prediction **−14.950 Hz**. The two-component model also preserves the nonmonotonic spacing pattern: its 24-hour predictions for 1-, 6- and 15-minute intervals are **−6.501, −14.950 and −11.229 Hz**. The last of these is too strong compared with the observed **−4.267 Hz**, falling outside the previously derived pointwise 95% bootstrap interval for that mean.

Several extinction failures remain. At three hours, attractive control and early-extinction ratios are predicted as **0.280** and **0.371**, versus observed **0.641** and **0.692**. The repulsive control ratio is **0.643**, versus **1.192** observed. Late attractive extinction is retained qualitatively: prediction **0**, observed **−0.054**. Overall 10 of 14 causal two-component predictions lie inside the inherited pointwise mean intervals, versus 11 of 14 for the mean-parameter source model. These counts are descriptive: the intervals omit model uncertainty and are neither simultaneous intervals nor a formal validation test.

**Persistence is present, but its lifetime is not identified.** The fitted fast alpha3 time constant is **3,487.6 seconds**, about 58.1 minutes. The slow fraction is **0.118**, and the slow lifetime reaches the imposed upper limit of **10 million seconds**, about 115.7 days. That is a numerical boundary, not a biological lifespan or memory-duration estimate. The inherited gamma1 lifetime is 1,874.6 seconds, about 31.2 minutes. Full parameters and bounds are in [fit results](results/fitted_kernels.json) and [fitting code](src/fit_memory.py).

Fixing the slow lifetime and refitting only the fast lifetime/fraction shows the problem clearly. At 260,000 seconds the weighted residual sum is 118.51; at one million seconds it is 115.96; at ten million seconds it is 115.37; at an effectively nondecaying mathematical limit it approaches 115.32. The last measured conditioning time is 24 hours. The [lifetime profile](results/slow_lifetime_profile.csv) supports a persistent component within this model but cannot distinguish many long lifetimes or determine permanent storage. Its fitted-Jacobian condition number is about 10 million. Seven- and thirty-day outputs in [retention extrapolations](results/retention_extrapolation.csv) are unvalidated extrapolations, not experimental successes.

**What cannot be compressed into the current output.** A constructed pair of model states has identical initial alpha3 response, 5.839 Hz, but allocates the same trace to fast versus slow storage. After identical 24-hour rest and an identical probe, their responses are 14.741 versus 5.916 Hz. A state consisting only of the current summed output cannot reproduce both futures under the same time-homogeneous rule. This [state-sufficiency diagnostic](results/state_aliasing.csv) explains why compression must preserve relevant hidden memory state. It is a mathematical test within the candidate model, not proof that those two constructed histories occur in real flies or that no other compact realization exists.

**Feedback still matters within the inherited model.** In a post-fit diagnostic, removing only the gamma1-MBON-to-alpha3-DAN coefficient while freezing other parameters raises spacing RMSE from 4.396 to **15.968 Hz**. The attractive late-extinction ratio changes from 0 to **0.425**. Three repulsive ratio predictions become undefined because their five-minute denominator is zero; they are flagged and retained, not counted as successes or silently dropped. The remaining five ratio predictions have RMSE 0.481, which is not comparable as an all-eight score. See [all raw numerators and denominators](results/feedback_diagnostic.csv).

This supports preserving short-memory-dependent teaching feedback in this particular reduction. It is not a refitted necessity test or a new physiological intervention result. The interpretation remains the source paper's: prior memory changes how a later cue is taught. A rich graph or two decay constants alone does not supply selective teaching.

**The separate higher-order branch fails a useful falsification test.** Rachad et al., [Cell Reports 2025](https://doi.org/10.1016/j.celrep.2025.115593), supplies the gamma1/alpha-prime2 circuit used in iteration 3. Alpha-prime2 is not Huang's alpha2 or alpha3. I retained the iteration-3 local eligibility hypothesis and tested passive recovery of gamma1 and alpha-prime2 effective weights toward their initial values. Each lifetime took eight values from 10 minutes through one day plus infinity, giving 64 combinations. The model uses a 600-second gap before each trial after the first, including the stage boundary. This is an explicit approximation of the paper's ten-minute interval protocol: the within-trial odor pulses and durations are not simulated continuously.

The declared engineering criteria required a substantial paired three-trial bias, negligible novel-alone and gamma1-intervention biases, and a nine-trial bias magnitude below half the three-trial magnitude. **Zero of 64 combinations passes.** Twenty-five retain sufficient three-trial transfer, all 64 pass the two specificity thresholds, and zero passes the nine-trial decline criterion. Three settings produce smaller nine-trial than three-trial magnitudes, but all have negligible initial transfer, below 0.00016 bias magnitude, and none halves it. No model was selected. The reserved six-trial measurements were generated only after this decision and cannot rescue a failed selection. See [complete grid](results/recovery_grid.csv), [reserved checks](results/recovery_grid_with_reserved.csv) and [summary](results/recovery_summary.json).

For illustration, gamma1 recovery of one hour and alpha-prime2 recovery of two hours merely delays saturation: paired model bias goes from −0.044 at three SOC trials to −0.235 at six and −0.333 at nine. The original local-eligibility branch goes from −0.0755 to −0.333 to −0.333. This rejects the tested passive-recovery family under the stated criteria, not every possible forgetting mechanism. It does not justify adding an arbitrary task-dependent reset. The original CT state and eligibility rule are still hypothetical and are not calibrated molecules.

**Software and memory checks.** Eleven causal invariants/differential checks pass. With a constant alpha3 kernel, responses agree with the original equations within **7.11 × 10⁻¹⁵ Hz**, and plastic states/adaptation match exactly. Random 500-event, four-address streams give identical shared prefixes and checkpoint continuation. Inactive addresses follow exactly their expected passive decay while other cues learn; splitting rest into 24 pieces changes state by less than **6 × 10⁻¹⁷**. In the separate recovery branch, a new random overlapping repertoire compresses 2,000 modeled KCs into 15 equivalence groups and matches full execution/checkpoint continuation within **9.67 × 10⁻¹³**. This is another software grouping result, not a universal 15-unit brain. Infinite recovery lifetimes exactly recover the iteration-3 local-eligibility baseline. Details: [causal verification](results/causal_verification.json) and [recovery verification](results/recovery_summary.json).

There is a material numerical limitation: the source uses a bout-average adaptation/update approximation. Dividing a 30-second active, punished bout into thirty one-second bouts changes a plastic state by **4.96 effective weight units** in our diagnostic. Rest partitioning is exact; active-bout partitioning is not. Therefore the runner consumes defined behavioral bouts and should not be presented as a calibrated continuous-time simulator. Removing this sensitivity would require a continuous-time reformulation and a new physiological fit, not a silent implementation change.

The causal learner uses eight dynamic scalars for two effective addresses, plus constant parameters, bookkeeping and transient outputs. The verification process peaked near **153 MB RSS**, mostly Python/JIT libraries, and the fit took approximately 2.7 seconds after loading its dependencies. This iteration needed no large-table rescan or new download. The existing BANC mother table and all specimens remain separate and unchanged. The interface accepts activity at effective addresses; deriving those activities from real odor pathways and their overlaps is still missing.

The release audit also found that the working copy of `iteration3/src/anatomy.py` differed from the frozen iteration-3 ZIP: it omitted cross-hemisphere paths and one type-aggregate export. I preserved that copy and its restoration diff, then restored the source from the hash-verified archive. All prior scientific files now match the frozen release; only parent navigation documents and release packaging change. See the [restoration/provenance record](results/prior_release_verification.json). The saved snapshot is audit material, not an alternate analysis to run.

**What we should carry forward.** Preserve cue-addressed memory, at least the hidden state needed to predict future responses, and feedback that makes teaching depend on prior memory and current activity. Preserve compartment identity: the gamma1/alpha3 and gamma1/alpha-prime2 models cannot be joined merely because both use fast and slow variables. The current evidence does not establish a biological minimum number of neurons or a transferable persistent-learning algorithm.

The most useful next empirical discriminators are longer longitudinal retention measurements with fly identities/covariances; time-resolved teaching and readout measurements during matched early/late cue-only extinction; and raw higher-order learning data across three, six and nine trials with matched controls. These would distinguish a hidden persistent trace from delayed consolidation and constrain what must reverse during excessive training. Before connecting this candidate to the anatomical engine, resolve event-time discretization, physical signed teaching/baselines and same-specimen sensory addressing. Re-running the large BANC spatial table is not the immediate bottleneck.
