# A8 — 固定局部基线的慢→快转移：E1 报告

2026-09-20 · FULL_151 冻结参照 · 4 workers · 288/288 E1 trajectories completed

**结论：A8 得到了值得独立确认的正向机制结果。** LOCAL 在新的标准完整生命中改善相关记忆、新学习及其 24 小时保持；同一份基线在 K=8 中也改善均值。因此，这轮没有观察到“保护旧记忆只是换来新记忆学不牢”的平均表现。但个别事实仍受损，尤其在 K=8；E2 尚未运行，尚未证明最小核心、真实果蝇机制或跨任务通用性。

标准生命当前有用记忆从 **94.98% → 96.72%**，配对提高 **1.75 pp [1.48, 2.05]**；60/64 条历史提高，4 条持平。24h 新学习提高 **2.68 pp [2.27, 3.11]**，7d 有用记忆提高 **3.26 pp [1.95, 4.56]**。K=8 当前有用记忆从 **71.05% → 77.29%**，提高 **6.24 pp [5.27, 7.29]**，8/8 blocks 提高。

## 1. 设计的实质修订

- 四臂在所有完整生命中运行：REF、LOCAL_BASELINE_TRANSFER、OOB_DROP、OOB_TRANSFER。LOCAL 是主检验，两个 OOB 是使用外部标签的解释性比较，不是上界。没有行为门槛筛选历史、臂或结果。
- C 使用 64 条完整原生标准生命校准一份固定 b；另 8 个 C K8 block 只校准该条件的 OOB 模板。E1 为另 64 条标准生命及其 8 个 K8 组合；E2 的 64 条独立标准 worlds 已生成并封存。C/E1/E2 的原始 cue 和 world seed 互斥，并排除了已有 572 份 world 文件及继承的历史 cue 集合。K8 与标准生命共享所在 panel 的素材，不算第二批独立样本。
- LOCAL 每个塑性子事件只用 native u、p、h 和固定 b：`b=sum_C(p*u)/sum_C(p*h)`；严格零分母取零；`c=p*h*b`，`slow_write -= c; fast_write += c`。不读取任务、目标、正确性或上下文标签，不调 gain，不重新训练 b。
- A7 的离线 donor 均值依赖检查点前缀，不能被一个固定模板的在线轨迹全部重现。我们分别验证了 A7 每个检查点自己的重建，以及 A8 全 C 固定模板的新映射。**A8 并非 A7 +6.1 pp 的直接复制，差异也不能只归因于在线反馈。**
- 从实际代码确定一个 pair 为 30s 呈现、135s idle、30s 呈现、135s idle。OOB 在最后 idle 开始前施加 `c=exp(135/tau_s)*mu_g`，保证 pair 结束的 slow innovation 恰减 `mu_g`。TRANSFER 同时把 c 加入 alpha-fast。使用 acquisition/challenge × delivered role 四组；K8 只干预 non-target cohorts，标准生命干预每个 pair。不同条件的 OOB 模板分别从 C 估计；LOCAL 始终同一 b。

预衰减总 alpha 写入守恒只适用于 TRANSFER 的同一前态比较。不同衰减率和后续反馈会改变总状态、后续驱动和行为；**没有整体轨迹等剂量或即时行为不变的主张**。

## 3. 尾部：均值改善并不保证每个记忆安全

下表只统计已经得到反馈、当前仍相关的事实；每个条件各 19,200 次 fact×checkpoint 决策，**不是 19,200 个独立样本或不同记忆**。过时答案不混入保护指标。incoming/all-informed 的对应表也完整保留。

## 4. OOB 解释性比较

OOB_DROP 的 P1 改善：标准 +1.33 pp，K8 +2.92 pp；OOB_TRANSFER 分别 +1.44 pp、+3.18 pp。各自与 REF 的全部 11 项端点及区间见 `endpoint_summary.csv`。

在相同模板规则下，TRANSFER 相对 DROP 的 P1 增量较小：标准 **+0.109 pp [0.032, 0.195]**，K8 **+0.260 pp [0.098, 0.423]**。标准新学习 +24h 另提高 +0.279 pp，但标准 P4 反而 −0.078 pp，P6/P7 为零；相关事实对→错也由标准 11→15、K8 233→255 增加。全部预先指定端点的直接对比保存在 `oob_transfer_minus_drop.csv`；这只是新增的汇总展示，没有新模拟或选择端点。

因此，临时保留被移出 slow 的成分有部分增益，但**不能据此证明所有干扰的根源都是时间尺度分配**。LOCAL 与 OOB 的作用位置、标签权限、校准模板和 K8 干预覆盖不同；LOCAL 较大的改善不能换算成“超过 oracle”或“恢复多少 headroom”。

## 5. 实际更新发生了什么

LOCAL 的 `sum|c| / sum|native slow write|`（每臂自身已改变的轨迹）为：

| 条件 | acquisition | challenge |
|---|---:|---:|
| 标准 | 5.174% | 6.153% |
| K8 | 5.242% | 6.197% |

每个塑性子事件的平均 |c|：标准 acquisition/challenge 为 2.989/6.414，K8 为 3.061/6.610。challenge 上确实较大，但新学习也被修改；这还不能等同于识别了有害更新。相对 native 非零 alpha 坐标，slow 写入符号翻转比例约 0.20%（acquisition）和 0.33–0.35%（challenge）。这是小幅、带符号的基线校正，不是直接清空慢记忆。

标准 checkpoint clipping 平均由 8.18% 降至 7.38%；K8 由 16.43% 降至 9.80%。LOCAL K8 最大已记录 |slow coordinate| 305.13，REF 为 445.37。它们与工作范围改善一致，但没有把 clipping 改善隔离成独立因果中介。没有新增 state clipping；逐事件记录的 response clipping 是当前校正前的 native response，和 checkpoint clipping 分开报告。

校准所得 5,177 个固定 float64 参数增加 **41,416 bytes**；其中 1,712 个非零，范围 −20.177 到 +12.841。native 可变神经数组仍为 165,664 bytes；固定基线不是免费容量，也未压缩为最小规则。b 仅在原 alpha teaching support 内非零。校准记录矩恒等式误差 2.27e−13，但这不保证新轨迹的慢写入均值为零。

## 7. 科学判断与下一步

**H1 得到 E1 支持：** 在这个冻结模型和任务分布上，一份独立校准、无标签的局部 baseline 能改善完整生命中的均值共存、修订和新学习保持，且同一 b 可以用于 K8。

**H2 得到有限支持：** OOB 中临时 fast 补偿对部分指标有小幅额外收益；不能推广成普遍病因。**H3 观察到条件差异：** LOCAL 的实际校正量在 challenge 中更大，但尚未证明它选择性识别 harmful component。

最有价值的下一步是保持 b、代码、端点不变，人工审阅后用封存的 E2 做确认。确认之前不压缩 b、不加入优化器或进化搜索。若确认成立，另立实验比较剂量匹配的简单增益/符号校正和打乱坐标基线，区分“这些坐标的均值有特殊价值”与“一般性的减小慢状态偏移也有效”。A8 没有这些控制，所以不能排除后一种解释。

本轮没有新增 fly connectome 或重建生理实测 baseline。结构、reader 和 genes 都继承同一真实数据约束的模型；b 来自人工任务轨迹。这是模型内的干预证据，并非果蝇采用该公式的证据。新 fixture 家族、不同个体 connectome、长期无限流和更小状态预算上的推广均未建立。

**决策：保留 FULL_151 为正式参照；将 A8 LOCAL 标记为值得独立确认的候选机制；本轮停在 E1，E2 未运行。**
