## 1. 已经值得保留的设计

八臂全因子、相同外部事件流、新的独立确认、禁止看结果后调参、以完整 world/block 为统计单位、学习器与 evaluator 标签隔离，这些都合理。B 的非零等价验收比只验 baseline hash 更可靠；T 的终态单位账本也修正了旧稿把衰减前后写入混用的问题。

T 的恒等式确实成立：令 `m=d_s*r`、`c=promote(p_d,m)`，则 `p_new=p_d-c+m`、`w_T=c/d_s`，所以 `p_new+d_s*w_T=p_d+d_s*r`。这仅为有符号终态转移恒等式，不能推出 L1 守恒、表达量守恒或行为改善。稿件对此已有正确限定。

“均值改善、明确权衡、风险未解决”分开报告也比单一总分合理。不要求放宽判据，但要接受严格判据可能留下未决项。

## 2. 必须先修正的问题

### A. T×C 仍允许微小获准写入触发完整收缩

定位：tournament §7.3，尤其第 352–390 行。

实际 [model74.py](/Users/pencilbard/Downloads/second_try_copy/minifly/iteration19/src/model74.py:5) 的直接收缩为：

`V_C = -[1-(1-rho)^(dt/30)] * 1(s*w_T<0) * s`。

提案用 `kappa=abs(w_T)/abs(r)` 缩放。它保证**固定其他量时，kappa 趋近零会使收缩趋近零**；却不保证 **w_T 本身趋近零时收缩趋近零**。

反例：`dt=30s, s=100, r=-epsilon, p_d=-d_s*epsilon`。此时 `w_T=-epsilon, kappa=1`，所以无论 epsilon 是 0.001、1e-9 还是 1e-12，`v_C=-5`。这是精确算式的问题，不是浮点容差问题。

因此，“an infinitesimal promoted amount cannot trigger a full contraction”必须撤回。两种诚实处理：

1. 保留当前公式，把它定义为**相对承诺比例门控**，接受其绝对小信号不连续，并把该边界写入验收与解释；或
2. 若绝对小信号连续性是科学要求，另行明确一个绝对幅度约束，例如 `abs(v_C)<=K*abs(w_T)` 且 K 固定。这是**新规则**，不能当作无影响修补，也不能声称由数据唯一推出。

现有 C-alone 可以继续作为历史对照。TC/BTC 已是混合规则，应单独命名其修改。由于 C 的实现还依赖 T 是否开启，因子交互只能解释为这些具体组合规则的交互，不能自动归因于两个固定生物模块之间的协同。

### B. 正式比较缺少“是否超过已经有效的 B”

定位：§14–15、§20。

全部正式区间都是 arm−REF；BT−B、BC−B、BTC−B 只是次级条件效应。这样，一个完全依靠 B 获益、T/C 没有增量甚至拖累 B 的组合，仍可能被列为相对旧 REF 有益的候选架构。

应保留 FULL_151 作为正式历史参照，同时把 B 定义为当前候选机制基线。预先指定需要正式回答的增量对比和端点，并纳入相应的多重比较预算；不必把所有两两比较都升级。构造性实验的主要问题应是：**T 或 C 给 B 增加了什么，代价是什么？**

这不要求把 B 自动晋升为项目的正式核心。

### C. K8 缺少持久学习最直接的延迟端点

定位：§12.2。

canonical 包含新学习/修订 +24h、usefulness +24h/+7d；K8 的六项 essential vector 没有这些延迟端点。T 恰好改变写入持久存储的时间，C 恰好主动削减既有慢状态，在最拥挤条件下只检查即时及重激活表现，会遗漏关键保持代价。

建议预先补入 K8 的延迟新学习、延迟修订和长期 usefulness，沿用已实现的 A9 取数定义，再重新确定正式检验族。A9 已有这些数据，并不存在不可测的障碍。

此外，§13 的尾部表不进入 §15 的正式分类。即使每个**平均能力端点**都改善，仍可能有具体记忆受损。`STRICT_LOSS_PROTECTED_IMPROVEMENT` 最好改名为“所列平均端点上的严格优势”，或始终附完整限定。若要宣称降低个体记忆损伤，需要单独预定 world-level 损伤指标；不要把“每条记忆零损失”偷偷变成所有改进的硬条件。

### D. T 的“重复证据”实际是约一小时尺度的坐标符号一致

定位：§6、§9；依据 A8 的 SOURCE_LOCK 与实际 native event 实现。

冻结父模型的 `tau_fast=3375.6201s`，约 56.26 分钟。T 直接继承这个衰减：

| 间隔 | 未获准 probation 剩余比例 |
|---|---:|
| 165 秒 | 95.23% |
| 330 秒 | 90.69% |
| 1 小时 | 34.42% |
| 3 小时 | 4.08% |
| 24 小时 | 约 7.66e-12 |

原生一次 cue-pair 教学是 `30s 呈现 +135s 空闲 +30s 呈现 +135s 空闲`，不是一次不可分割的更新。因此，后一个原生子事件或相邻学习材料在同一坐标上产生同号写入，就可能促成 commitment。它不要求同一关联再次得到独立证据，更不是天级间隔复习模型。

这不否定 T：它是一个可检验的短时有符号滤波器。但新稿必须说明该时间尺度是继承的工程选择。现有 provenance 除同/异关联外，还应统计上次贡献距今时间、同一 cue-pair 内子事件和跨 teaching bout 的比例；这些标签只供审计，不进入学习器。

T 同时改变时间分配、可见写入量和静默存储。八臂比较可评估其整体作用，不能单独证明收益来自“可靠性识别”或“延迟本身”。

### E. K8 世界构造与精度承诺需要补全

定位：§11、§14、§17。

当前 `t_capacity(...,8,'fixed_per_fact')` 从 **8 个互不相同的 canonical donor worlds** 构造一个 K8 world。新稿的“8 rotations × 8 independent base worlds”仍需定义 rotation 对 cue 顺序、角色、目标和队列的具体作用。不能只把不同 target label 当成新重复。

若 DISC 的 32 个及 CONF 的 64 个 K8 worlds 全部独立，需要 768 个互不重叠的 canonical donor worlds，加上两个 canonical panels 的 96 个，合计 **864 个 base worlds**。这是素材数；science lifetimes 仍是 1536。需显式排除 A9 E3 的 worlds/cues/seeds，不再仅写“reserved A8 E2”。

若固定平衡八种 rotation，统计模型也应明确估计八种条件的等权均值，而不是无说明地假定它们完全同分布。Bonferroni 校正不能修复无效的单个 t 区间；极稀疏、离散端点需要在锁定前审查其适用性。

所以 A9 one-shot v3 关于“先冻结再打开 E2”的要求已无法满足。新实验应使用新名称与新数据；已有 E2/E3 是历史证据，不能重新包装成对新规则的封存确认。

更重要的是，K8 的 TRUE 固定 REF 轨迹加权残差 L1/L2 比为 **1.318 / 1.186**，均大于 1；在线行为却更好、慢状态更小。canonical GENERIC 的慢状态范数更小，也没有复现行为收益。新稿的“符号正确 + 坐标正确 ⇒ 一阶矩消除”不是充分识别条件。

A9 one-shot 的正反方向/固定剂量点、baseline 稳定性分析可保留为后续候选；但重复已完成的大部分臂不是当前最高信息量工作。256 个影子 shuffle 也不能保证四个 online shuffle 的行为代表性；“central bulk”的阈值和未通过时如何处理必须预先指定，不能看过分布再挑控制。

### C 已有明确的收益和负向效应

[Stage 3B 原始确认表](/Users/pencilbard/Downloads/second_try_copy/CORE_RECOVERY_stage3b/runs/transfer_20260919/SUMMARY_CONFIRMATION.md) 的 32 对 worlds：

历史 `TRANSFER_UNRESOLVED` 指相对于当时设定的允许损失界限未决，**不等于相对于零效应没有负向证据**。这里引用的是当时的区间，不是把它们事后重新计算成新稿的 simultaneous intervals。

重测 C 作为同批次对照合理，检验 BC/TC 能否缓解损失也合理；但应把首次返回列为已知风险。不要重复旧证据记录里过于宽泛的“neither harm nor safety”表述。

## 4. 严格分类的精度：提前承认可能未决

本审计只重算既有 A9 表格，没有运行新的模型。

按新稿 CONF 每 panel n=64、canonical 7×9 项、K8 7×6 项、各 alpha=.025，t 临界值分别约 **3.7422 / 3.6163**。用 A9 E3 canonical 的 B−REF 配对方差作精度示例：

| 端点 | 已有平均效果 pp | 按拟议 n 与校正的半宽 pp | 示意下界 pp |
|---|---:|---:|---:|
| P1 current usefulness | 1.834 | 0.676 | 1.158 |
| P6 anomaly recovery | 1.484 | 1.362 | 0.123 |
| P7 reactivation 4 | 1.302 | 2.109 | −0.807 |

这不是新的确认，也不是正式功效估计。它说明：已经重复改善的 B，仍可能达不到“每一项下界均非负”。当某项真实效果恰好为零时，严格下界非负通常需要非常罕见的正向抽样波动；扩大样本不能把严格优势检验变成等效检验。

可以保留零界限，也可以接受 `BENEFIT_WITH_UNRESOLVED_LOSS_RISK`。不应为得到好看分类事后改阈值；也不应承诺一次固定规模实验必然关闭搜索空间。T/TC 没有历史配对方差，REF 的 SD 只能作背景，不能当作它们配对差值方差的已知上界。

## 5. 建议的下一步顺序

1. **保留当前 A9 结论与 FULL_151 参照。** 八组合进入新版本；A9 one-shot 不重新覆盖已完成实验。
2. **先明确科学任务。** 若要解释 A9，优先比较固定 REF 写入重放和允许状态反馈改变写入的轨迹，并用原生非线性 readout 检验方向价值。若要构造更好的核心，八组合可独立进行，但主问题改为“是否给 B 带来可复现的增量”。两者不能用同一组均值相关性互相代替。
3. **冻结前修正以上五项。** 小信号语义、B 增量对比、K8 延迟端点、T 时间尺度与子事件语义、K8 构造及统计单位。
4. **保持边界。** T、TC/BTC 为新工程候选，尚无本轮新果蝇数据直接确证。无论结果好坏，都只裁决这些固定实现及任务族；不裁决整个三状态/遗忘机制家族。

若以后做 REF 重放，A9 的稀疏 u/p/h primitives 可重建校正和 alpha 写入，但没有保存每个 checkpoint 的完整 gamma/adapt/fast 向量；receipt 只有终态 hash。需要受控重捕获完整 REF 状态。不能拿这些 hash 当可恢复的检查点，也不能在非线性 readout 前只比一个全局范数。
