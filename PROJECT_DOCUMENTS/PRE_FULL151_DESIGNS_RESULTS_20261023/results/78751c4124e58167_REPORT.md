# MiniFly byte core V9.2 — completed experiment

## Verdict

V9.2 passes the **pre-registered narrow byte-learning gate**. A single model
receives continuous raw bytes, predicts the next byte before observing it, and
learns both 256-cue identity and ordered-pair tasks in six fresh controlled
worlds. After training on 200,098 bytes from Austen and Wells, the frozen
checkpoint beats a train-only Markov-2 baseline on both the full raw stream and
Unicode letter/number bytes from **each** of two previously reserved authors.
The choice of 3–4-byte context and its learning rate used Carroll DEV only.

This establishes a usable engineered byte prediction interface for the MiniFly
fork. It does **not** establish NLP competence, a fly-derived temporal
mechanism, or preservation of Full_151's association capacity under joint
byte-and-reward training. The predictive route is an added 1–4-byte temporal
population; the inherited FE0→PN→KC fast/slow value route remains in the same
checkpoint but does not produce these byte probabilities.

## Locked architecture and experiment

The parent Full_151 source is unchanged. V9.2 uses 256 last-byte cells and two
fixed hash banks each for the preceding 2, 3 and 4 bytes: 2,816 input rows,
256 byte outputs, and 720,896 mutable predictor weights (2,884,608 bytes).
An observed-byte local prediction error changes only active rows. It sees no
task label, slot index, hidden reward, future byte, or per-record state reset.
The checkpoint includes the inherited 165,664-byte mutable value state. See
`DESIGN.md`, `brain_v92.py`, and `PILOT_CONTEXT.json` for the locked rates and
DEV-only selection.

The full assay reused the frozen V9 stream generators, scoring, no-write arm,
counterfactual, and acceptance rules. DEV used worlds 11/12 and Carroll.
CONFIRM used worlds 101/102/103 plus Doyle and Stevenson. All scores are
frozen-parameter, predict-before-observe scores. The two-author text decision
rule was recorded before V9.1's natural-text result in the parent
`BYTE_CORE_V9/TEXT_DECISION_RULE.md`; no confirmation score selected V9.2.

## Results

| Confirm task | Worlds | Target BPB | Target accuracy |
| --- | --- | ---: | ---: |
| 256-cue identity | 101 / 102 / 103 | 0.1225 / 0.1252 / 0.1199 | 99.68% / 99.66% / 99.66% |
| Ordered pair | 101 / 102 / 103 | 0.0307 / 0.0309 / 0.0307 | 100% / 100% / 100% |

Swapping cue order in the frozen ordered-pair test adds 12.997–13.013
bit/target byte on non-invariant pairs. Every controlled confirmation gate
passes, including the matched no-predictive-write arm. These synthetic tasks
are deliberate interface tests, not measures of natural language skill.

| Independent author, 20,000 bytes | V9.2 full BPB | Markov-2 full BPB | V9.2 content BPB | Markov-2 content BPB | 8-gram full BPB |
| --- | ---: | ---: | ---: | ---: | ---: |
| Arthur Conan Doyle | 2.8096 | 3.0010 | 3.1465 | 3.3300 | 2.6384 |
| Robert Louis Stevenson | 2.7214 | 2.9256 | 2.9829 | 3.1971 | 2.6028 |

Both authors pass all four locked checks: V9.2 beats Markov-2 and the matched
no-write arm on full-stream and content-byte BPB. The no-write arm remains at
8.0 BPB. The 8-gram is reported as a stronger engineering reference and beats
V9.2 on both authors. At 10,000 training bytes V9.2 was worse than Markov-2;
it crossed the baseline by 100,000 and improved further at 200,098 bytes.
Carroll DEV was 2.8429 versus Markov-2 3.0153 full-stream BPB.

The confirm assay took 2,011 seconds and peaked at 349.3 MiB RSS. The model
checkpoint is 985,151 compressed bytes; exact save/load roundtrip passed.
Three unit tests cover predictor state, causal frozen scoring/checkpointing,
and inherited Teach/value-path equivalence.

## Interpretation and next bound

The prior V9.1 predictor learned controlled byte tasks but missed the text
Markov-2 gate (3.177 versus 3.015 BPB on Carroll). V9.2's bounded 3–4-byte
context fixes that specific deficit on DEV and two new authors. It does so
with engineered temporal memory roughly 17.4 times the inherited mutable
state, so it is not yet a minimal fly-like solution. The causal lesion shows
that removing this temporal route collapses prediction while removing the
native predictive route has no effect because none is wired in V9.2.

The next necessary acceptance experiment is joint operation: stream bytes and
teach associations to the **same** checkpoint, then test whether Full_151's
previous association/retention benchmarks and V9.2's byte scores both survive.
Only after that should this fork replace the accepted Full_151 reference or
be used for broader NLP tasks. No source dataset or parent asset is duplicated
in this result folder; `MANIFEST.json` points to them.
