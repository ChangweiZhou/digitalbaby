# Step 5 result: the protected temporal branch did not add learned order value

**Decision: `TEMPORAL_E1_NOT_DEMONSTRATED`.** The fixed 16-world delayed-order
assay completed, and the independent receipt audit passed. At the final
12-bout endpoint, the temporal Full151 branch scored **64.6%** with native
value writes and **64.6%** without writes. The paired choice effect was
effectively **0 percentage points** (two-sided 95% Student-t interval
**−19.5 to +19.5 pp**). Its written branch was above nominal 50% chance by
the specified interval, but the same absolute score in the no-write branch
means this does **not** establish value learning from the teaching signal.

The control paths worked. The protected FE0 branch scored **90.6%** with
writes versus **49.0%** without, a paired **+41.7 pp** effect (95% interval
**+22.8 to +60.6 pp**). The separately trained one-byte FE0 positive control
had a **+62.5 pp** paired effect (95% interval **+35.9 to +89.1 pp**). Thus
the assay was capable of detecting a native write effect, and FE0 itself
could use these two-byte ordered cues at the inherited timing. This agrees
with Step 4's warning that unequal FE0 codes cannot be treated as an alias.

| Order route | Before teaching W−N | Bout 6 W−N | Bout 12 W−N |
|---|---:|---:|---:|
| FE0, choice | 0 pp | +39.6 pp | +41.7 pp |
| Temporal, choice | 0 pp | +25.0 pp | 0 pp |
| FE0, mean value margin | 0 | +0.0451 | +0.0638 |
| Temporal, mean value margin | 0 | +0.0918 | +0.0132 |

The bout-6 values are trajectory diagnostics, not another success endpoint.
They suggest that the temporal branch's early separation failed to persist
through the full fixed exposure, but this experiment does not identify the
mechanism of that loss. At the pre-teaching probe, the reversed-pair KC-code
Hamming distance averaged **67.1** in the temporal branch versus **7.5** in
FE0. Greater code separation therefore did not translate into a stronger
final learned value contrast here. A change in predictor state also affects
the no-write branch, which is why its final **64.6%** cannot be credited to
native teaching.

This is **E1 evidence only**. All six scored ordered cues were taught 12
times. Exact-cue recitation is a sufficient countermodel; there is no
never-reinforced relation test, output fusion, router, arithmetic, or
autonomous byte/action output. The interval is also wide enough that the
experiment does not prove the temporal branch can never help. It does close
the narrower proposal to promote this protected temporal branch directly
into a router based solely on its larger KC distance.

The technical world **9499** reproduced a standalone FE0 state after each
of 72 order records and reproduced its readout. Predictor, clock, teaching
count, and read-only probe checks passed. The 16 fresh science worlds
**9501–9516** each produced one immutable receipt; none was selected or
rerun after an interim result. `audit.py` checked the source hash, world
roster, generated schedule hashes, exposure counts, receipt arithmetic, and
the fixed intervals without replaying native synapse dynamics. An in-memory
score-tamper test was rejected by the audit check.

The next iteration should be narrower still: characterize *why the temporal
code loses the W−N contrast between bouts 6 and 12* using a fresh technical
diagnostic of KC occupancy and native write eligibility, with FE0 held as
the working route. There is no reason from these data to add an untested
fusion rule or to repeat another full memory search.
