# MiniFly V78 / Iteration 23：间隔收益来自什么，少提交是否真的保护记忆？

**结论：V78 明确推进了因果定位，但没有产生可以替换原参考模型的新核心。** 在当前冻结模型中，原生间隔收益主要由适应恢复推动；“等 α 快记忆消退再写入”不是这项收益的主要解释。把相同更新由十二次合并为六次没有改善；在线计算后再合并，会重复计算尚未生效的纠正需求，增加写入和旧记忆损失。

本轮完成 16 组全新输入历史、2,944 个挑战分支、17,664 行端点结果和 35,328 行逐轮记录。75 项启动检查通过；独立审计通过 294 组检查和 7,627,449 个数值比较，重放 34 条完整关键分支，最大差异为 1.36×10⁻¹²。**三个接受完整保护检查的候选均未通过，未提升模型版本的科学资格。** 保留 5,177 KC 原参考模型与冻结读出器。

## 1. 对建议作了哪些实质修订

两份附件作为参考意见使用，没有当作执行指令。最终设计见 [PROTOCOL.md](PROTOCOL.md)，参数见 [config.json](config.json)。

1. 把 α 快状态、γ 快状态、适应恢复拆成完整的 2×2×2 小因子设计，既测单独作用，也测其余作用存在时移除一个因素。慢状态在这八个条件中都正常衰减，另有全部冻结和无额外间隔对照。
2. 区分**提交次数、更新向量、写入量**。先固定十二个更新向量，只改变它们何时释放，并精确补偿慢衰减；再单独把向量减半；最后才测在线重新计算的六次提交规则。
3. “900 秒预测”只衰减观察副本中的 α 快状态，保持当下活动、γ 和慢状态不变。因此称为**有限 α 快参考**，不能称为整个脑状态的未来预测，也不是已实现的局部生物电路。
4. 所有挑战结束后的新学习统一使用同一原生规则。这样 MIXED 差异来自挑战留下的状态，不混入之后使用不同算法的差别。
5. 不把正的慢状态投影当作“原记忆完整保存”的证据。记录剩余支持、去裁剪和去快状态能否恢复选择，明确这些观察不能唯一识别旧痕迹与新竞争痕迹。

没有开展种群搜索、阈值优化、时间常数扫描、SPACE 组合或新增记忆库。未重新拟合生理数据。

## 2. 比较条件与统计口径

16 个 seed 对应不同输入历史，**不是 16 只果蝇或 16 个独立连接组**。共生成 3,840 个互不重复、与既往使用输入库不重叠的 8-of-88 PN 模式。每段历史用原生规则习得 96 个关联，在负载 48/96 各保存一个共同起点，分别挑战中间或最新的关联。

- STABLE：原标签重复十二次；REV：相反标签重复十二次；ANOMALY1：一次异常标签后恢复原标签。
- 每次挑战包括十二对完整刺激；原有每对 330 秒时序不变。额外间隔为 0/300/900/1800 秒。
- LAST：各自最后一对刺激之后。COMMON：统一补足到起点后 23,760 秒。各测立即与 +24 小时。
- MIXED：COMMON 后再学十二个新关联，每个六轮，全条件均使用原生规则；再测立即与 +24 小时。
- 每个条件都有相同时序、相同感觉输入及相同状态干预的无写入对照。它保留适应与衰减过程，但不发生 γ/α 学习。

选择成功仍要求实际记忆边际与冻结读出器边际同时 ≥1 Hz。被反转的目标从旧记忆保护集合中排除。正文的旧选择损失率默认以“挑战前正确的非目标旧关联”为分母，先在分支内计算，再按历史平均；正式主要比较和原保护门槛还保留“丢失数/全部非目标旧关联”的原始口径，两者不混用。

推断单位为 16 段历史，先平均负载和年龄；STABLE 最新目标主要比较只平均两个负载。15 个预定主要比较使用双侧配对符号翻转检验并统一 Holm 校正；5,000 次固定随机种子 bootstrap 区间为描述性区间，未经同时区间校正。其余曲线和痕迹分解均作描述性报告。

**与 V77 的区别：** 本轮 COMMON 多容纳了 1800 秒间隔条件，且 MIXED 改为共同原生后续学习；又使用全新历史。因此不能把两轮 MIXED 百分比直接相减当作版本提升。继承的原生、TOTAL_POINT、TOTAL_MARGIN、NOFAST_POINT 挑战语义已在启动测试中核对一致。

## 3. 原生间隔收益：适应恢复是主要推动因素

以下为 REV、COMMON +24 小时，两个负载、两个年龄合计 64 个评估分支。成功计数用于直观说明，统计仍按 16 段历史进行。

| 间隔处理 | 修订成功 | 旧正确选择损失率 | 每段分支最坏旧损伤的均值，相对无写入 |
|---|---:|---:|---:|
| 无额外间隔，结束后补齐时间 | 49/64，76.56% | 6.71% | 2.29 Hz |
| 900 秒仅慢状态衰减 | 49/64，76.56% | 6.71% | 2.29 Hz |
| 再允许 α 快状态衰减 | 49/64，76.56% | 6.71% | 2.29 Hz |
| 再允许 γ 快状态衰减 | 40/64，62.50% | 6.51% | 1.59 Hz |
| 再允许适应恢复 | 63/64，98.44% | 11.85% | 8.50 Hz |
| 全部正常演化，900 秒间隔 | 60/64，93.75% | 8.14% | 3.99 Hz |

主要检验给出：

- 完整间隔相对密集训练提高 **17.19 个百分点**，区间 [9.38, 26.56]，Holm p=0.0391。
- 仅适应恢复相对仅慢衰减提高 **21.88 个百分点**，[14.06, 31.25]，p=0.0117。
- 从完整间隔中移除适应恢复，成功率由 60/64 降到 40/64；完整条件的优势 **31.25 个百分点**，[20.31, 42.19]，p=0.00366。
- 单独加入或从完整条件移除 α 快衰减，选择结果没有变化。
- γ 单独衰减的选择变化方向为负，但未通过多重比较校正；不能把它写成已确认的普遍有害机制。

这支持“适应恢复对本模型的这项间隔收益有关键作用”，但**不支持立即采用只恢复适应的规则**：它获得 63/64 修订的同时，把最坏旧记忆损伤推到 8.50 Hz，旧选择损失率也明显上升。

时间曲线同样不是越长越好：原生额外间隔 0/300/900/1800 秒，COMMON +day 修订分别为 **49/64、57/64、60/64、55/64**；共同后续学习后的 MIXED +day 为 **47/64、55/64、57/64、54/64**。这是四点描述性曲线，不是优化得到的生物最佳间隔。

## 4. 一个重要边界：适应恢复也显著改变有效写入量

本轮找到了有作用的状态变量，但尚未证明它带来了超过剂量变化的学习效率。

原生条件下，按每对刺激结束时的净慢增量计算 L1 累积，密集训练约 **743.30**，完整间隔 **1,386.32**，仅恢复适应 **2,695.81** 个模型权重单位。后两者分别约为前者的 **1.87 倍、3.63 倍**。这是包含对内衰减/抵消的净慢写入代理，不是原始突触事件总量，也不是 Hz。

因此可以说“适应恢复使活动/教学过程重新具备更强写入能力”；还不能说它以相同写入预算更好地分配了信息。只恢复适应时的严重旧损伤，使这个区分尤其重要。

对冻结参数作的**后验静态审计**进一步限制了解释：当前有效 MBON→DAN 系数中，γ 来源最大绝对值约 **0.327**，α 来源最大约 **1.37×10⁻⁹**；α→γ DAN 系数为零。它们是解剖路由比例乘上继承的有效生理系数后得到的，见 [feedback_parameter_audit.json](results/feedback_parameter_audit.json) 与原 [hybrid.py](../iteration5/src/hybrid.py)。

这说明本参考模型里 α 输出对原生教学反馈几乎不起作用，所以 α 快状态衰减不推动原生间隔收益并不意外。**不能反推真实果蝇的 α 反馈不存在或不重要。** V77 的另一项结果仍然成立：当工程教学器显式读取总 α 输出时，α 快成分可以污染慢学习的纠正信号。这是不同的因果路径，两轮结果不矛盾。

## 5. 少提交：固定更新向量无收益，在线合并会过度补偿

先固定 M12 在线产生的十二个向量。BATCH6 每两轮提交一次，并把较早向量按其等待时间衰减。半剂量条件把同一组向量乘以 0.5，再比较十二次与六次提交。

**全部 384 个配对传输证书通过：** 全/半剂量各 192 个条件，最终慢向量最大坐标差为 4.97×10⁻¹⁴。提交顺序改变并没有凭空减少最终叠加在慢状态上的干扰。完整端点里，相同剂量的十二/六次控制得到相同选择结果。

| 规则 | COMMON +day 修订 | MIXED +day 修订 | COMMON 旧选择损失率 | COMMON 最坏旧损伤均值 |
|---|---:|---:|---:|---:|
| M12：在线、十二次提交 | 57/64 | 59/64 | 8.46% | 3.68 Hz |
| 相同向量、六次提交 | 57/64 | 59/64 | 8.46% | 3.68 Hz |
| 半剂量、十二次提交 | 44/64 | 45/64 | 6.56% | 1.84 Hz |
| 同一半剂量、六次提交 | 44/64 | 45/64 | 6.56% | 1.84 Hz |
| ONLINE6：在线重算、六次提交 | 58/64 | 59/64 | 9.25% | 4.21 Hz |
| M_SPACED：900 秒间隔、十二次提交 | 54/64 | 59/64 | 7.41% | 2.75 Hz |

半剂量确实减少伤害，但修订损失 **20.31 个百分点**，区间 [14.06, 26.56] 的下降幅度，Holm p=0.00635。其旧损失按“全部旧关联”分母减少 **1.37 个百分点**，[0.89, 1.87]，p=0.00366。这是明确的学习量—损伤权衡，不是提交次数带来的突破。

ONLINE6 的目标增益只有 **1.56 个百分点**，[0, 4.69]，p=1；旧损失按同一“全部旧关联”分母却增加 **0.54 个百分点**，[0.26, 0.83]，p=0.0322。请求向量的总 L1 从 **1,230.51** 升到 **1,406.42**，增加约 **14.3%**。

逐轮记录提供了具体解释：第一轮纠正尚在队列中时，第二轮仍按未改善的状态计算。第二轮请求 L1 从 M12 的 **333.87** 升至 ONLINE6 的 **656.73**。这是延迟反馈下重复计算需求；本轮没有加入一个可识别“已有待提交纠正”的额外预测器。

这个负结果针对**目前的双轮在线批量规则**。它并不排除有选择的证据积累、不同的局部资格迹或其它带反馈补偿的时间规则。但本轮不支持继续把“单纯少提交”当作保护旧记忆的主要希望。ONLINE6 还需要 41,416 字节临时队列，并没有获得压缩优势。

## 6. 有限 α 快参考不足以替代 NOFAST 诊断

这里的 900 秒只在观察副本里保留 α 快状态的 exp(−900/3487.58)=**77.25%**；没有让整个模型经历未来 900 秒。

最新 STABLE、COMMON +day，共 32 个负载—历史条件：

| 教学观察/目标 | 成功数 |
|---|---:|
| POINT，当前总输出 | 6/32 |
| POINT，α 快成分按 900 秒衰减 | 10/32 |
| POINT，去掉 α 快成分 | 32/32 |
| MARGIN，当前总输出 | 26/32 |
| MARGIN，α 快成分按 900 秒衰减 | 27/32 |
| MARGIN，真实 900 秒额外间隔 | 31/32 |
| 原生，无间隔 / 有间隔 | 32/32 / 32/32 |

有限参考相对当前 POINT 的原始提高是 12.5 个百分点，但 Holm p=**0.875**，未通过主要检验。不能选择这个时间点作为已验证的新教学器。NOFAST 仍是有解释力的特权诊断；它的 STABLE 成功也没有自动转化为更好的完整持续学习表现。

## 7. 旧选择失败多数不能靠简单改读出来恢复

例如 M12 在 REV、MIXED +day 的旧损失中有 **344 个评估实例**：

- 152/344（44.2%）仍有正的慢状态投影；这既不保证达到 1 Hz，也不证明该支持属于原来的痕迹。
- 300/344（87.2%）的慢投影低于相同时序无写入分支。
- 仅 8/344（2.3%）在去掉 α 输出裁剪后恢复完整选择。
- 去掉两个快成分恢复 0/344。

这些是重复条件中的评估实例，不是 344 个独立动物；判据可重叠，不是互斥分类。在 +day 时快成分本来已经大幅衰减，所以“去快成分无帮助”不能排除早期表达问题。去裁剪也只测试了一个固定反事实读出，不能证明所有可能的读出都无法恢复。

但本轮确实没有支持“主要只是快状态遮住旧记忆，清掉它就好”的解释。相比之下，慢支持的降低及其与固定读出共同决定的失败，需要继续正面处理。

## 8. 完整保护门槛没有通过

对 M12、M_SPACED、ONLINE6 保留原有 64 项诊断标准，分别比较同样间隔的原生参考；不因某项成功率高就放宽旧损失或最坏损伤门槛。

| 候选 | 通过 / 全部 | 未通过 | 决定 |
|---|---:|---:|---|
| M12 | 31/64 | 33 | 不提升 |
| M_SPACED | 40/64 | 24 | 不提升 |
| ONLINE6 | 31/64 | 33 | 不提升 |

例子：ONLINE6 在负载 96 的 COMMON/MIXED REV 中，相对原生的旧选择损失增量上界都约 **2.63 个百分点**，超过 2 pp 门槛；每段分支最坏旧实际边际的直接损失均值约 **4.15/4.20 Hz**，远大于 0.05 Hz 门槛。它虽然通过部分修订增益标准，却没有通过保护标准。

原生间隔本身也带来代价：COMMON REV 的旧选择损失按全部旧关联增加 **1.01 个百分点**，描述区间 [0.50, 1.57]；相对无写入的最坏旧损伤增加约 **1.70 Hz**。因此也不能把自然间隔效果直接包装成无代价的新默认学习策略。

全部标准见 [acceptance_checks.csv](results/acceptance_checks.csv)；最终决定见 [decision.json](results/decision.json)。本轮没有自己的完整历史训练或新增生理验证，即使某个诊断条件表现优秀，也不足以提升生物学资格。

## 9. 文献的作用及下一轮优先问题

[Huang 等，2024](https://doi.org/10.1038/s41586-024-07819-w) 的局部原文明确讨论适应与 γ 反馈的相反时间影响，这比“等 α 快记忆消失”更贴合本次原生模型结果。但原论文的 ISI 与本项目的额外间隔不是同一操作。[Zhao 等，2023](https://elifesciences.org/articles/83516) 对两种干扰的区分，支持我们同时报告目标修订与旧关联代价。[Comyn 等的实验](https://elifesciences.org/articles/92085/figures) 则提醒我们，真实间隔还能改变代谢状态；当前模型不含该状态，所以不能把本轮解释扩张成完整生物机制。核对范围见 [SOURCE_REVIEW.md](SOURCE_REVIEW.md)。

**下一步应优先检验：适应恢复的好处，能否在严格匹配实际写入预算后保留下来？** 本轮的适应手术没有匹配写入量，因此不能跳过这一层，直接再设计一种门控器。

可把下一轮限定为当前共同起点上的两个分解：先区分适应改变的活动/写入分配与总写入量，再区分 γ 反馈保留与其随间隔衰退的作用。使用既往已建立的严格剂量对照方法，保留旧选择和最坏受损记忆为硬约束。若收益只来自多写，就应承认这一点；若同量写入仍更有选择性，才值得做由局部活动状态控制的学习规则。

这也需要尊重已有负结果：[V67](../iteration12/REPORT.md) 的 γ 历史删除没有胜过匹配慢状态范数的对照；不把同一个删除规则当作新发现重试。γ 条件若再出现，应服务于上述适应—间隔交互问题。[V74](../iteration19/REPORT.md) 中把适应恢复时间减半曾改善开发集修订，却使独立生理 RMSE 从 4.196 升至 6.958 Hz；因此 V78 的状态手术不授权直接把时间常数减半作为新模型。

暂不推进通用提交障碍、新慢库或种群搜索。V78 排除了若干很具体的捷径，但没有证明所有时间门控都无效，也没有把尚未检验的机制空间压缩成一个可信的有限方案数。

## 10. 可复核性与交付

- 科学配置、协议、runner 和四个科学源文件在生成结果前冻结，运行后哈希全部通过；冻结后没有修改科学实现。
- 16/16 任务完整收据通过；75 项启动检查、384 个相同向量传输证书、294 组独立审计通过。审计从保存向量重建全部端点，重算主要统计和 192 项接受检查，并用普通 PN 事件调用与独立提交公式重放 34 条分支。它共享原 EVENT 核和固定读出，不是另一个连续时间求解器。
- 总运行约 **11 分 56 秒**，两个进程；单进程峰值 **636,403,712 字节，约 607 MiB**。没有内存溢出或任务因数值容差被舍弃。
- 最終表格、三组 PNG/PDF 图、配置、必要的新代码、检查和外部资产清单放入紧凑结果包。原数据、每 seed 原始输出、检查点、缓存和旧归档不重复打包。

复核命令见 [RESULTS_README.md](RESULTS_README.md)；主要结果见 [primary_contrasts.csv](results/primary_contrasts.csv)、[endpoint_summary.csv](results/endpoint_summary.csv)、[trace_fate_counts.csv](results/trace_fate_counts.csv)。所有静态模型参数与生理限制维持原状，包括未由长时程数据充分识别的慢衰减寿命；没有把仿真成功率当成果蝇行为准确率。
