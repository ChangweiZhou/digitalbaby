# MiniFly iteration 10 — what simple KC sampling preserves and loses

13 September 2026. Executed against the existing FlyWire-derived interface in this project. No new source data, physiological fit, plasticity formula or readout fit was introduced.

**No reduced family qualified for preservation of the current reference.** All 97 declared realizations completed: the 5,177-KC reference and 96 reductions crossing three sizes, two sampling methods, two gain treatments and eight sampling draws. Fixed output-gain calibration recovers a substantial part of the loss caused by direct deletion, but does not establish equivalence. The calibrated 2,588-KC stratified family is relatively close on some endpoints; its uncertainty and other failures prevent acceptance. At 647 KCs, delayed learning performance falls materially and the unchanged reader also develops no-learning false positives.

This answers a question the previous iterations had not tested directly: **physical KC reduction contributes to the observed failures, but it cannot explain the full-size reference's existing interference and revision problems.** The experiment does not establish a minimum biological KC count or rule out better compression. The preferred learning parent remains iteration 5/bi with the iteration-8 observer head.

## Design and separation of causes

The [frozen protocol](PROTOCOL.md) and [configuration](config.json) were committed to local hash records before primary outcomes were run. The [execution freeze](sources/screen_execution_freeze.json) includes input banks, model inventory and six source modules. External ChatGPT and Claude documents were treated as proposals. Their Oja/normalization, gating and meta-learning proposals were not mixed into this experiment. In particular, the four-gain calibration here is not an implementation or test of Oja learning.

Each reduced model physically retains 2,588, 1,294 or 647 of the parent's 5,177 KC identities and associated mutable arrays. Uniform sampling uses a random permutation. Stratified sampling preserves representation of the 23 existing KC-type × side strata, then assigns remaining quotas proportionally. Five singleton strata are deliberately overrepresented by the minimum-one rule. There were no invalid constructions, redraws or performance-based seed choices.

RAW directly slices PN→KC connectivity, output projection Q, teaching matrix T and side metadata. CALIBRATED retains the same sampled identities but scales Q's four columns to match the full model's mean unadapted drive on the original 16 unlabeled development stimuli. These four constants use no new task labels or learning outcomes. T, feedback matrices and learning equations are unchanged, although changing Q naturally changes drive entering the recurrent circuit. Calibration preserves four development-set means, not each novel input or each subsequent memory trajectory.

The original top-5%-per-side encoder is retained. Its absolute active population decreases from 259 KCs to roughly 130, 66 and 34. Consequently, this intervention changes representation, signal aggregation and memory-state count together. It measures sampling under an unchanged encoding rule; it is not an isolated manipulation of abstract storage slots. Even the reference is an effective model: 302 PNs grouped into 88 input channels, selected KC states, four effective teaching and four effective output units, not a literal whole fly brain.

The unchanged four-input RBF reader head receives the reduced model's own current sensory projection. It shares that model's Q and retains no removed KC states. An analytic plastic-reset-equivalent baseline is used only by the evaluator to check actual memory contrast; it is not available to runtime decisions. A separate no-learning model follows every training stream, allowing reader errors to be separated from memory generated by prior learning.

Eight new streams each contain 96 association pairs and eight untrained probe pairs. Punishment roles are counterbalanced within every twelve-pair block and stay fixed on repeated presentations. This changes the earlier all-A-punished task distribution, so all comparisons use a freshly executed full-size reference on exactly the same streams. The 3,328 new screening and reserved-confirmation cues are unique and disjoint from prior saved inputs. No confirmation cues were evaluated.

Training uses six bouts per pair. Declared tests include isolated acquisition, 5-minute/24-hour delays, cumulative loads 12/24/48/96, separate non-writing snapshot and actual serial readout branches, age-matched isolation, untrained probes, and 0/6/12-bout reversal. Delayed reversal endpoints share a common elapsed-time endpoint. A reversal only earns the joint criterion when the model retained the old association before reversing it.

Each family is evaluated across eight subsets × eight shared streams. Crossed bootstrap intervals resample the two axes independently, with 2,000 replicates. Preservation requires all 24 declared gates, including a five-percentage-point noninferiority margin and at least seven of eight draws within that margin on each behavioral endpoint. Loads 48/96 are reported stress tests. The resulting intervals describe this finite engineered experiment, not animal-to-animal variability. No family passed; the prespecified conditional confirmation stage was therefore not run.

## Memory, readout and untrained generalization

At load 24 plus a day, actual-memory diagnostic accuracy for calibrated stratified 2,588/1,294/647-KC models is 85.16%/80.47%/74.35%, compared with runtime choices of 84.96%/80.40%/73.89%. The full reference is 88.02% on both. Thus the reduction penalty cannot be assigned entirely to the reader. The diagnostic measures expressed plastic memory contrast under current dynamics; it does not assert that every hidden trace is erased when the criterion fails.

Aggregate equality can conceal individual disagreements. The full model has three oracle-only and three reader-only successes among 192 load-24 pairs. The calibrated stratified 647-KC family has 37 oracle-only and 30 reader-only successes among 1,536 pairs. See the full [reader/memory diagnostic table](results/screen_reader_memory_diagnostics.csv).

The no-learning control exposes an additional reader problem at the smallest calibrated size:

| Model/family | Baseline RMSE | No-learning pair false-positive rate |
|---|---:|---:|
| Full 5,177 | 0.208 Hz | 0/1,024 |
| Stratified 2,588, calibrated | 0.266 Hz | 0.012% |
| Stratified 1,294, calibrated | 0.376 Hz | 1.477% |
| Stratified 647, calibrated | 0.641 Hz | 9.583% |
| Uniform 647, calibrated | 0.537 Hz | 5.664% |

Reduced-family denominators here are 8,192 no-learning pairs, with two cue observations each. Both calibrated 647-KC families exceed the frozen 5% pair false-positive limit. All other families pass the three absolute observer gates. Matching development-set mean drive therefore does not guarantee that the unchanged nonlinear reader remains reliable on all reduced representations.

Separately, after learning 24 associations the full reference expresses a preference on 33/64 untrained pairs (51.56%). The calibrated stratified rates rise to 57.23%, 58.98% and 66.21% as N decreases. These are learned-network generalization measures, not the no-learning false-positive rates above. Untrained pairs have no target valence; a nonzero preference is not automatically an error in an animal. The experiment nevertheless fails to preserve the reference's rate within its declared margin.

## Compression is not the only remaining problem

The newly run full model's snapshot choices decline from 89/96 (92.71%) at load 12 to 169/192 (88.02%), 309/384 (80.47%) and 566/768 (73.70%) at loads 24, 48 and 96 after a day. It is already imperfect without deleting any KC.

For the first eight associations, the age-matched isolated full-model control retains 63/64 correct choices at both load-24 and load-96 ages, while the loaded full model retains 57/64 and 48/64. In the calibrated stratified 647-KC family, the corresponding load-96 counts are 438/512 isolated versus 333/512 loaded. Both full and reduced models therefore show a later-learning deficit beyond time-matched isolation. These branches do not share the same acquisition/adaptation history, so this comparison alone is not a pure causal decomposition of new writes. Iteration 9's separate same-checkpoint no-write intervention remains the stronger prior evidence for a write-related contribution. See [matched age controls](results/screen_matched_age_control.csv) and the [iteration-9 report](../iteration9/REPORT.md).

Revision remains limited even at full size. The reference retains the old target immediately before reversal in only four of eight streams. Six reversal bouts yield three of eight new choices after a day, but **zero of eight joint old-retained/new-correct events**. Twelve bouts yield seven of eight new choices and three of eight joint events, or three of four on the fixed reference-eligible streams. Counting only the seven new choices would overstate durable overwriting.

The calibrated stratified 2,588-KC family averages 45.31% joint successes versus the reference's 37.50%, but its paired difference interval spans −12.50 to +31.25 points. This is too uncertain to establish preservation, much less improvement. The reference just meets the minimum of four eligible streams; the revision comparison has limited resolution. The six-bout joint gate also has a reference floor of zero, so passing it is not evidence of successful revision. Conditional and per-bout results are in [reference-eligible revision](results/screen_revision_reference_eligible.csv) and [revision trajectories](results/screen_revision_trajectories.csv). The [role audit](results/screen_role_audit.csv) preserves A/B outcomes separately; counterbalancing does not remove temporal-order effects.

The unchanged reader head adds 4,344 fixed numeric bytes at every size and no mutable state; Q is shared. Numeric counts exclude interpreter/object overhead and are not process memory. The same sharing convention is used for the full reference. We do not credit removal of a redundant reader matrix as biological compression. Coverage, gains and serialized-model costs are in [construction statistics](results/screen_construction_summary.csv) and [calibration/coverage](results/screen_calibration_and_coverage.csv).

The 97 realizations generated 788,416 pair records and 10,088 diagnostic reversal-trajectory records. Two workers peaked at 231,555,072 bytes each or less. Recorded per-model elapsed times were 4.33–49.73 seconds, summing to 2,075.83 seconds across overlapping workers. That sum is not campaign wall time or a controlled speed benchmark. The source synapse table was not scanned or duplicated.

## Audit, correction and delivery

The 34 pre-run fixtures and 38 final implementation checks pass. Full-size reconstruction matches the previous learner's state/rates exactly. Reduced save/resume is exact, foreign-model checkpoints are rejected, analytic diagnostics match reset-clone observations, evaluator-only roles cannot change predictions, and current punishment cannot affect the pre-write MBON prediction. Stable arbitrary assignments are learned on 16/16 old positive-control pairs. Independent unrevealed outcomes give 495/1,024 pre-feedback hits, consistent with chance (two-sided exact binomial p=0.3024); this checks the declared control, not a universal proof of absence of leakage.

**A reporting defect was caught and corrected after the first aggregation.** Pandas interpreted the literal task name `null` as missing data. The raw no-learning records were present, but the initial summaries were NaN and their observer gates failed spuriously. The first aggregation and original source were preserved locally. The sole frozen-source amendment changes raw CSV reading to preserve literal strings and adds assertions requiring 1,024 no-learning rows per model and finite endpoint values. It changes no model, prediction, task, threshold, bootstrap rule or preservation gate. All non-null metric rows and all non-observer gates match the initial aggregation exactly; every raw model-output hash is unchanged. The final maximum no-learning actual-memory contrast is 1.24e−14 Hz, consistent with floating-point zero. The decision remains no qualifying family.

The [correction record](sources/csv_parser_correction.json) identifies the original and amended hashes. Nine of ten execution-freeze files remain byte-identical; the tenth is this documented parser amendment. Post-launch reporting modules only aggregate diagnostics, plot, audit and package. All ten [final audit checks](results/final_audit.json) pass, in addition to the [implementation checks](results/implementation_checks.json). The earlier checker was insufficient to detect an empty control selection; explicit control-row and finite-value checks now prevent that failure. The prior iteration-5 through iteration-9 archives and their referenced dependencies were checked unchanged in [prior-release checks](results/prior_release_checks.json).

The compact delivery contains this report, final aggregate metrics, two figures in PNG/PDF, new experiment/model code, one reduced model, configuration and audit records. It excludes source datasets, previous archives, caches, raw per-draw/stream/pair collections, reconstructed checkpoint collections and unchanged third-party implementation code. MANIFEST.json references excluded and unchanged assets by path and SHA-256; a standard-library verifier checks the supplement and, when supplied, its parent assets. No outside download or user intervention was needed.

## What this changes for the next experiment

Simple sampling has now been tested directly. Gain calibration is a necessary control for interpreting deletion, but neither calibration nor KC-type stratification establishes a preserved persistent core. The 647-KC geometry proposal should not be treated as a learning-equivalence claim. Conversely, failure of this strict screen does not prove compression impossible: representation, aggregate drive, sparsity and reader extrapolation all change under this intervention, and some half-size endpoints remain statistically unresolved.

The next mechanism experiment should use the unchanged full-size parent to isolate the write interference already present there. A bounded candidate is to compare matched later-learning streams with high versus low overlap in the old association's effective KC/output teaching support, while matching duration, dose, baseline drive and active-count distribution; include no-write branches and delayed revision. Support and controls must be defined before outcome inspection. This can test whether overlap-specific new writes explain signed loss, without pretending that a new normalization formula has anatomical validation. Only an intervention that repairs that measured failure should advance to a separate, fixed-budget learning-rule test. Further size optimization and reader refitting should remain separate experiments.

More connectome data alone would not resolve the missing physiological input mapping, slow lifetime or durable revision constraints. This iteration adds a measured compression response and a runnable reduced implementation; it does not yet distill a validated persistent learning core.
