# V9 text decision rule — locked before the DEV text case completed

The controlled ID/ORDER gate in `DESIGN.md` tests byte identity and two-byte
order. It does not certify usefulness on prose. The DEV result file contained
the four controlled cases and **no `natural_text` case** when this separate
secondary rule was written on 2026-09-25 at approximately 22:25 UTC.

For the author-separated CONFIRM test, call the byte-prediction interface
*practically useful on this small prose diagnostic* only if the **same frozen
checkpoint**, trained solely on the two training authors, has lower
full-stream bits per raw byte **and** lower Unicode-letter/number byte BPB
than the train-only Markov-2 baseline on **each** of the two test authors.
It must also beat its identical no-predictive-write control on each author.
Show the 8-gram comparison whether favorable or unfavorable; beating 8-gram
is not required by this narrow rule. Do not average authors to hide a failure.

Even a pass establishes only causal byte-sequence learning on these held-out
historical-English excerpts. It does not establish general NLP ability,
semantic understanding, or that inherited FULL_151 fast/slow plasticity
produced the text prediction. Keep the latter attribution separate through
route lesions and the native F3 regression/preservation tests.
