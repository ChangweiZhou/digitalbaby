# MiniFly V9.10A — external aggregation recovers native taught-edge evidence

**Read-only diagnostic, not a new learner.** From V9.9C's 64 previously confirmed worlds, an externally fitted eight-symbol graph potential scored **76.17%** on the eight never-reinforced rank comparisons when fitted to the REF `D` branch's *native taught-pair margins*. The native `D` direct reader scored **60.74%** on the same held-out pairs; the world-paired external-minus-direct difference was **+15.43 percentage points** [10.59, 20.27]. A no-old-write `Z` branch processed identically scored **50.39%** under the external potential. Thus native teaching generated edge outputs that a task-specific graph operation can aggregate much better than the native direct pair read. This does **not** show that REF stores an explicit rank variable, nor does it identify the writer or reader as the sole bottleneck.

## What the decoder was allowed to see

The prediction phase read only each world's 20 *taught* edge margins at V9.9C `old_end`. These archive margins are already oriented by the true **taught** outcome. It converted them to a fixed ascending-byte orientation, then fitted eight anonymous byte-symbol potentials by unregularized graph-incidence least squares. It constructed eight held-out queries as unordered canonical byte pairs. It saved and hashed all **4,096 predictions before the separate scorer opened any held-out outcome, held-out native margin, or score**. The positive control uses taught labels alone, which solve all eight held-out edges on this fixture. Exact-pair lookup has no answer on those edges (50%). The decoder introduces symbol parsing and a transitive-potential assumption externally; it was never installed in the fly.

## Results

Values are means across the same 64 V9.9C confirmation worlds. Intervals are descriptive paired or absolute 95% Student-*t* intervals; this posthoc diagnostic has **no new confirmatory E3 claim**.

| Readout on never-taught pairs | Mean choice | 95% interval |
|---|---:|---:|
| Native `D` direct | 60.74% | 56.62–64.86% |
| External potential from native `D` taught margins | **76.17%** | 72.75–79.59% |
| Paired potential `D` − direct `D` | **+15.43 pp** | +10.59 to +20.27 pp |
| Native `Z` direct / external potential `Z` | 46.68% / 50.39% | 42.19–51.17% / 45.84–54.94% |
| External potential from native `D−Z` taught-margin change | 70.31% | 66.60–74.02% |
| Direct `D−Z` held-out margin-change sign | 59.18% | 54.90–63.46% |
| External potential from signs of native `D` taught margins | 76.37% | 72.55–80.19% |
| External potential from taught labels alone | 100% | analytic fixture control |

The external `D−Z` potential beat the sign of the **direct** `D−Z` held-out margin change by +11.13 pp [6.22, 16.05]. The `D` versus `Z` potential difference was +25.78 pp [19.69, 31.87]. Removing the native taught-margin magnitudes while retaining their signs changed the external score by only −0.20 pp [−3.78, 3.39]; this task's graph aggregation depends mainly on whether each taught native edge points the right way, not on calibrated edge magnitude. `E` and `L` potentials scored 72.85% and 71.48%, respectively. All external fits remain below the taught-label-only 100% control.

## Interpretation and next test

This answers a limited question: **learned native pair outputs contain enough distributed signs that an external, task-aware graph fit can make more accurate held-out choices.** It does not show whether REF writes an internally shared relational trace. Twenty separately remembered taught pairs could produce the same result once an external analyst imposes transitivity. It also does not establish a durable online mechanism; the fit was performed after training on saved outputs. The earlier frozen-KC linear probe's 82.23% is another external decoder, not native behavior.

The next causal test is a small pre-event clone assay: for each selected taught record, feed the same bytes to writing and no-writing clones from the **same state**, then read the change on taught and held-out pairs at a common time. That single-event response may reveal where useful versus harmful transfer arises. It requires replay because V9.9C did not save intermediate states. It must not be described as a linear decomposition of the full lifetime or as an alpha-only effect: the native write flag controls more than one state component.
