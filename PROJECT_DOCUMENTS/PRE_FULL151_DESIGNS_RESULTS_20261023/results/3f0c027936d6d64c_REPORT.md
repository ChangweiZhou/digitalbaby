# Step 9 — calibrated single-cue output on never-taught relations

**Result (27 September 2026): E3 was not demonstrated.** The 16-world trained-cue pilot passed every prespecified feasibility gate. All 64 fresh confirmation worlds completed. At the final held-out probe, the two-store emitter answered correctly on **51.04%** of never-taught cues with old teaching enabled (W), versus **49.48%** with those old native writes disabled (N). The world-paired difference was **+1.56 percentage points**, with a two-sided 95% Student-*t* interval of **−1.97 to +5.10 points**. Its lower endpoint did not exceed zero; W also missed the frozen 60% aggregate and 55% answer-0 guards. The independent reducer verified the `NOT_DEMONSTRATED` verdict and all 64 receipts.

## Question, exposure, and output

The [frozen design](DESIGN.md) asked whether the Step 8 fading-pair byte input, two native Full151 value stores, external Boolean teacher, and training-only scalar baseline could use earlier teaching to emit `0` or `1` for **never-reinforced** combinations in the V9.8 synthetic symbol-class relation. Each world had 12 old taught ordered cues (144 records), six held-out ordered cues from three withheld symbol pairs, a 24-hour gap, 72 records on six new taught cues using disjoint symbols, then another 24-hour gap. Every old symbol appeared equally in both positions; old and held-out answer classes were balanced. The six held-out byte expressions were absent from all teaching records and received no feedback at any probe. A strict exact-pair or canonicalized-pair table has no stored answer for them; fixed answer defaults and position/frequency shortcuts are balanced at chance. A class rule learned from old teaching could solve the relation, but that would be a **limited within-family E3** result, not unseen addition or general language use.

W and N received identical bytes, outcome labels, teacher calls, and clocks. Only W allowed the old cohort's native writes; both learned the new cohort. At each cue, the model's two native stores supplied values before feedback, and the frozen output rule emitted `1` iff their difference exceeded that branch's mean of the last 12 **training** differences. The baseline never used probe labels. Each probe ran on a read-only clone and returned one byte at a fixed response point. This is prompted binary output with an engineered scalar decision rule and external teaching, not autonomous timing or self-derived reward.

Technical world 12000 passed. Pilot worlds 12001–12016 computed **only directly taught-cue outputs**, passed all seven trained-cue gates, and were excluded from confirmation. Confirmation used exactly worlds 12101–12164; no outcome-driven replacement or optional stopping occurred.

At final held-out, W accuracy was **43.75%** on answer `0` and **58.33%** on answer `1`; only the latter passed its 55% class guard. All seven confirmation trained-cue guards passed, including W old-end ≥80%, W final ≥70%, both W final classes ≥60%, W−N final ≥10 points, and both branches' new-end ≥65%. The final trained W−N interval also excluded zero. The held-out primary and two absolute performance guards failed. The primary interval treats the **world** as the independent unit, not each byte response.

## Read-only post-run diagnosis (exploratory)

Using only recorded native value differences, final held-out score ordering was nearly random: world-mean AUC **0.533** for W [0.485, 0.581] and **0.493** for N [0.441, 0.545]. Final **taught** cues, in contrast, had W AUC **0.954** [0.940, 0.969]. Within each withheld reversed pair, W ranked the correct orientation above its reverse in **108/192 comparisons (56.25%)**, versus N **88/192 (45.83%)**. This small relative signal is post hoc, W's own interval includes chance, and it does not satisfy the emitted-byte endpoint. Held-out W AUC was 0.528 at old-end and 0.533 at final, so there is no strong early transfer signal that was simply lost overnight. Post-hoc threshold checks likewise did not reveal a large hidden binary classifier. These diagnostics **do not create a new confirmatory test**.

The failure is specific to this integrated **two-store, opponent-taught, single-cue emitter**. It leaves the earlier taught-expression recitation and Step 8 taught-cue retention intact. It also does not negate V9.9A's limited E3 result: V9.9A let an evaluator compare two orientations through a single native valence store, whereas this run required an absolute `0`/`1` byte from two stores. Input features, teaching geometry, and decision geometry differ across those experiments, so the cross-experiment discrepancy cannot isolate one culprit. Within Step 9, the chance-like held-out native ordering makes a scalar-threshold-only repair unlikely. The narrow next test is a **single prespecified role-separated input feature** with memory, teacher, output rule, and chronology fixed, gated first on taught-cue competence and then on fresh held-out emitted responses. It is a hypothesis, not a demonstrated fix. A separate arithmetic capacity and multi-byte-output program should remain separate from this relation-transfer diagnosis.
