# Output Step 1: native Full151 plasticity drives a prompted four-way byte choice

The prospective experiment completed **32/32 new worlds** and all **96 branch lives** without an execution failure. The independent receipt audit passed. Its frozen verdict is **`FOUR_BYTE_E1_PASS`**. After 48 directly taught records per life, the true-teaching branch emitted the correct ASCII byte `0`–`3` on **127/128** final read-only probe calls (**99.2%** across four taught cues per world; world-level 95% Student-t lower bound **97.6%**). The matched no-write branch scored **32/128** (**25.0%**); the misrouted-teacher branch scored **0/128**. True teaching beat each control in **32/32 worlds**; the two-sided exact lower bound on that win proportion is **89.1%**. The mean paired W−N difference was **+74.2 percentage points** (world-level 95% Student-t interval **+72.6 to +75.8**). All prespecified gates passed.

This demonstrates that an output byte can be **selected from copied native Full151 value state before feedback**, rather than assembled by an evaluator comparing supplied answer strings. Each of four fixed output channels has its own copy of inherited Full151 fast/slow state, and a fixed argmax policy maps the winning channel to one of four ASCII bytes. The visible `=` is the prompt; the environment calls the output policy at that time. The model does not decide *when* to speak, produce multi-byte text, or free-run. Copying four entire learners is a feasibility architecture, not a compact biological compartment implementation. The original single native value path remains unchanged.

The causal controls are strong within this narrow task. All channels and branches received the same question bytes, true teacher digit, newline, and clock. W and P each made 192 native writes per life; N had the same teaching calls with writes disabled. P redirected the same teacher to the next output channel and emitted that wrong, shifted target on **127/128** final probes, while scoring zero against the true answers. This makes a fixed output bias or sensory exposure alone implausible as the source of W's result. During training, the first emitted byte was logged **before** the teacher digit arrived; W's descriptive first-choice accuracy rose from 8.6% in the first bout to 85.9% in the last bout. The final score used read-only clones without teacher or grade.

The teaching mechanism has an important boundary: the environment's fixture supplies the correct class to the compartment-routing rule after first choice. The teacher digit is also presented as a byte, but this experiment **does not prove that the fly decodes that digit through FE0/KC and derives its own teaching signal**. It is privileged, class-targeted supervision applied to inherited native plasticity. The four cues each contain their own directly taught two-letter key; an exact-key table could also pass. Thus the earned evidence is **E1 learned recitation and prompted one-byte output**, not E2 changed-presentation reuse, E3 unseen arithmetic, teacher-free learning, or a persistent learning core.

Technical world 11099 was excluded. It checked birth equality, read-only clone purity, first-choice ordering, identical FE0 state across all class copies, clocks, teaching counts, and write counts. The independent reducer checked source hashes, all 32 world rosters and schedules, cue/teacher hashes, byte range, class-value-to-argmax arithmetic, correct-answer arithmetic, receipt completeness, world-level intervals, and gate logic. Four in-memory tamper controls (class value, emitted byte, schedule hash, write count) were rejected. Completed worlds were never rerun, and `caffeinate` stayed attached to the science runner until it exited. The audit does not replay native trajectories or independently reconstruct every training-time class value; source integrity and chronological code inspection support those parts of the contract.

The next output experiment should retain this fixed-prompt E1 positive control while closing two gaps separately: make the *arriving teacher byte* causally select its update channel without reading a fixture class variable, and emit a sequence (`digit` then `;`) through the model's own recurrent output state. Only after both work should directly taught `1+2=3` be used as an E1 recitation diagnostic. Unseen operand pairs and delayed reuse require later, distinct E3 gates. The four full learner copies should eventually be replaced by local writable output compartments and requalified; this result does not validate that cheaper implementation.
