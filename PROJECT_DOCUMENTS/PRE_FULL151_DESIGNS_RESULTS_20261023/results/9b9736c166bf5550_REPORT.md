# Byte-arithmetic warmup: bounded preflight

**26 September 2026. Decision:** an answer-revealing warmup is worth testing, but adding it to the present V2 learner does not yet produce reliable arithmetic on unseen byte expressions. This is a small diagnostic, not V3 confirmation or evidence of a persistent learning core. The completed V2 result remains unchanged.

## What the completed evolution actually found

V2 evaluated 1,024 candidates for 128 generations (131,072 candidate evaluations), with 16 sealed worlds and 512 grade-only examples per life. All three arithmetic stages failed their acceptance checks. At the 512-example checkpoint:

| Sealed stage | Learned exact on novel expressions | Matched no-write exact | Constant-zero exact |
| --- | ---: | ---: | ---: |
| One operator | 1.3% | 7.7% | 7.7% |
| Two operators | 3.5% | 4.5% | 4.5% |
| Four operators | 3.1% | 3.2% | 3.2% |

The search did **not** form a continuous 128-generation lineage: 325 family-generation extinctions triggered reseeding, including 204 in the final stage. Its code also admitted 20% random immigrants whenever a family had survivors. Because every Stage-3 candidate missed the absolute survival threshold, later generations there repeatedly started anew. These numbers bound what V2 found; they do not establish that arithmetic is impossible with a different representation or curriculum.

## Two independent warmup diagnostics

**Current MiniFly/V2 features.** I fitted only the existing V2 linear numeric readout to correct answers during an early warmup. The input still passed through the Full151 byte sensor; the recurrent representation and topology were fixed. The subsequent phase used V2's original, unsigned five-band punishment update. Two independent worlds per stage gave 144 untouched, canonically distinct test expressions per stage. The table shows the 256-answer cell:

| Stage | Constant-zero exact | Warmup-only exact | Warmup-only MAE | After 128 grade-only questions: exact / MAE |
| --- | ---: | ---: | ---: | ---: |
| One operator | 6.3% | 4.2% | 16.28 | 1.4% / 17.44 |
| Two operators | 4.9% | 4.2% | 9.63 | 1.4% / 10.42 |
| Four operators | 4.9% | 2.8% | 16.62 | 1.4% / 17.72 |

The one-operator mean absolute error (MAE) was 28.81 without labels and 16.28 after 256 correct answers. Thus labels convey some magnitude information, but exact answers on new expressions remain at or below the zero shortcut. The later grade-only updates often erase the small exact gains; with two worlds this is a warning, not an estimated population effect. The warmup is a privileged ridge fit to fixed features, not an implemented biological teaching rule.

**Trainable raw-byte sequence control.** A separate, deliberately non-MiniFly embedding–GRU–numeric-head model read only successive ASCII bytes. Training/validation/test expressions were canonically disjoint and balanced across the four operators. On two independently generated one-operator splits, each with 512 answer-labelled training expressions and 128 untouched test expressions:

| Split | Constant-zero exact / MAE | Trainable GRU exact / MAE after 512 answers |
| --- | ---: | ---: |
| A | 10.2% / 26.41 | 10.9% / 4.00 |
| B | 6.3% / 27.57 | 5.5% / 3.92 |

The GRU has learned a rough numeric mapping on novel expressions, but not dependable exact arithmetic. Its training exact rate reached about 50–54%, while test exact did not beat constant zero consistently. Changing the objective to answer classification yielded 9.4–14.8% exact over six fits, with MAE 17–26 and almost no correct addition or subtraction; answer-frequency shortcuts explain much of that apparent exact gain. These controls show that the poor V2 result is not solely a missing target signal or a scalar-regression loss. They do **not** show that every trainable byte architecture would fail.

## Interpretation and exposure audit

- In both diagnostics, the input was a newline and raw expression bytes ending in `=`. The V2 diagnostic precomputed fixed features and fitted the readout **offline** to warmup answers; the GRU also used ordinary supervised training. Neither implemented a post-choice answer-byte teaching episode. The V2 diagnostic's next phase used only scalar grades. Scored first responses received no feedback. Canonical expression overlap between warmup, grade, validation, and scored sets was zero, so an exact-expression cache has no scored hit.
- The visible task family, digit vocabulary, operator identities, and many operand values recur across the splits. A distribution shortcut can therefore score nonzero without computing the relation; constant-zero and the classification probe expose that weakness. A learned arithmetic rule would be valid transfer, but is not demonstrated by the current exact results.
- V2's completed run tested an integrated learner, but its warmup probe trained only the new fixed-feature output head. The GRU probe is an independent engineering control with no Full151 attribution. Neither probe tested retention after delay or intervening learning. The evidence is a **diagnostic of access and coarse unseen-expression numeric estimation**, not an E3 exact-arithmetic success for MiniFly and not a persistent-core result.
- The warmup probes lacked a matched-answer-shuffle sensory control and did not implement correct-answer bytes as part of the learner's own teaching interface. Those controls are required before attributing a later gain to learning from the visible answer stream.

## Next decision

Introduce an answer-revealing **training-only** phase, with the correct answer shown *after* the fly's first response. First test whether a trainable byte-time representation plus a small writable state can use 32–384 examples to raise **first-response exact accuracy on unseen expressions**, by operator, over constant-zero and matched no-prior-teaching controls. Then fork the same post-warmup state into frozen, true-grade, and grade-shuffled continuations to see whether removing answers preserves or destroys what was learned. Increase operation length and tighten elimination thresholds only after that gate passes. Keep top-ranked lineages breeding below the final qualification threshold; do not silently reinitialize whole families.
