**剂量差异没有消失，但规模已量化。** 标准 TRUE 的 acquisition/challenge 实际 `sum|c|/sum|X|` 为 **5.114% / 6.123%**，四个 shuffle 为 **5.126–5.129% / 6.155–6.162%**。K8 TRUE 为 **5.189% / 6.169%**，shuffle 为 **5.195–5.199% / 6.208–6.216%**。它们十分接近而非严格相等；REF-shadow 和 realized 的全表都保留，没有按 E3 剂量重新调系数。GENERIC 始终为 **5.67633%**，与 TRUE 的事件/上下文分配不同。

检查点的 retained-write 计算使用事件开始时间：X、c 均为衰减前写入，必须包含事件自身的衰减。自有轨迹的累计 `(X−c)` 与原生 slow state 在每个 probe 比较；REF-shadow moment 和在线真实 state 分开报告。weighted moment 的摘要先在每个 history 内平均 checkpoint，再跨 history 汇总；单独的 checkpoint 分布和原始表保留。

REF_SHADOW_DOSE 与 ONLINE_REALIZED_DOSE 对应不同问题：前者固定前态，仅比较公式；后者允许反馈改变下一次的 p/h/u。校准匹配不被称为在线等剂量。DOSE_SUMMARY.csv 中的 median_of_history_event_medians 不是全部事件混合后的中位数。

## 7. 结论和后续范围

保留 FULL_151 为正式参照，把 A8 LOCAL / A9 TRUE 视为在本任务族得到重复支持的候选机制。GENERIC 和四个预定分层打乱未能解释或替代它。快补偿有附加收益，暂不删除。

下一轮优先做一个有边界的因果拆分：比较固定 REF 写入重放与允许后续原生更新改变的在线轨迹，分清收益依赖哪些状态反馈，以及哪些投射方向决定选择。保留本次 q、时序与任务，不用全局范数下降作为成功目标。只有解释清楚这层差异，再决定怎样用少量局部/解剖变量压缩 b；本轮不因 P1 为正就直接进入大规模压缩或新增生物机制。

尾部仍需作为独立结果保护：任何后续简化都应继续报告具体的对→错、最差 cohort-history 和延迟新学习，不能只保留净均值。

本轮没有更换参照、拟合新 gain、改变 topology/神经元数/时间常数、引入新记忆痕迹、压缩 b 或启动进化搜索。结果仍限于同一个固定模型和生成任务族；b 来自任务校准，并非实测果蝇生理参数。未证明跨个体 connectome、跨任务或无限长期流上的普遍机制。
