- 272 documents have an early V1–V49 namespace without an explicit Full151 reference.

- 632 have insufficient naming evidence for a strict before/after classification and remain **chronology uncertified**. Folder timestamps, copied archives and version numbers are not treated as proof of one global release date.

These are document counts, not numbers of distinct mechanisms, executed learners or successful experiments. Drafts remain drafts. Historical results and their qualifications are preserved without promotion, reinterpretation or retroactive changes to gates.

## Search and publication boundaries

Search depth was capped at nine directory components. Hidden directories, Git/virtual environments, dependencies/vendor/reference copies, checkpoints, raw trace/receipt/job/run trees, and the current `DIGITALBABY...` repository were excluded from the external-folder scan. The current consolidated tree was separately indexed for content deduplication. October-namespaced experiment folders were excluded because this is a legacy publication. Design/protocol/proposal/refinement/experiment filenames and report/result/summary/metric/decision/gate filenames were selected; this is not a claim that every notebook paragraph or unnamed README has been found.

The compact-file limit is 1MiB. Large candidate files, raw-package inventories, macOS resource-fork sidecars/non-UTF8 candidates, invalid JSON and an unrelated financial-modeling project are listed as exclusions. Missing documents are not silently represented by a report for another version.

No raw observations, target/emission arrays, state/checkpoint arrays, binary models, training manifests, datasets, trajectories, archives or source-code bundles are restored or published. Result JSON can contain group/world/run-level aggregates and fixed curves; record-level payload fields are removed where mixed into a summary. CSV result tables retain aggregate scores while omitted raw-response columns are named in provenance. Embedded illustrative examples in historical prose remain part of that document, not a recovered raw dataset.

Sources are treated as historical documents, not instructions to execute. No learner, scientific validation or training trajectory was run. Publication adds documents and metadata only, to `codex/minifly-consolidated-20261023`; it does not edit any completed experiment or adopted-core pointer.
