# Iteration 9: finite association load and reversal exposure

Frozen before the new campaign. No model, threshold, gain, routing, or learning parameter is fitted. Preferred learner is iteration5/bi; equal allocation remains a rejected physiological comparator. The fixed iteration8/current_RBF64 observer is unchanged.

## A. What the present learner can retain

Eight new independent synthetic input streams each contain 192 disjoint A/B cue pairs and eight untrained control pairs. A cue has eight active channels among the same 88 PN-type channels. Streams and new revision inputs are unique and excluded from every saved earlier input. One association means one A-punished/B-unpunished discrimination, trained for six 330-second bouts (1,980 seconds); it does not mean one 24-cue bank. Loads are nested prefixes of 1, 4, 12, 24, 48, 96, and 192 associations. Roles are predetermined by random cue order, never selected by anatomy or outcomes.

Run parent, equal allocation, and no-learning controls. At each load, examine 300-second and 24-hour delayed snapshots. All loaded pairs are scored using the fixed sensory observer and the equation-derived memory contrast. Main observations are independent, non-writing diagnostic branches from the same state. An additional forward serial A/B readout on a separate branch lets every probe update the learner; those probes never feed the main training stream or another load. Report old/new age quartiles and untrained-cue responses as well as aggregate decisions. The no-learning arm measures observer false alarms; responses to untrained cues after learning measure generalization, not observer calibration alone.

For every pair, an independently trained isolated control is rested for the same time since that pair finished training. This controls memory age but not sensory state during acquisition. A stronger within-state causal control follows the first four jointly trained associations: subsequent events are either REST or SENSORY (same exposure/adaptation, all plastic writes disabled), with the same event durations as full interference. This separates passive decay, sensory-history changes and later writes for that focal cohort.

Report observed correct-choice curves with 2,000 stream-block bootstrap intervals. A descriptive reliability boundary is the first tested load below 87.5% mean correct decisions (carried from the earlier 7/8 criterion), separately for observer and actual memory, 5 minutes and 24 hours. This is a task/schedule boundary, not maximal neural capacity or a confidence-certified threshold. Neither flat success nor failure establishes a KC lower bound. No 647-cell recommendation or compression experiment follows automatically.

## B. Reversal dose and its cost

Reconstruct the exact twelve iteration-6 reserved banks and use the twelve iteration-8 test banks as retrospective panels. Add twelve untouched new banks. Analyze them separately. No claimed pre-reversal checkpoints were found in iteration6; reconstruct and save new checkpoints, then validate six-bout retrospective results against stored metrics. Initial training is four pairs followed by eight more. Two histories are tested: the original non-writing observation schedule, and the iteration-8 serial schedule with actual four-pair probes after initial acquisition and interference.

From each pre-reversal state run 0, 6, 9, and 12 reversal bouts, with A unpunished and B punished. Higher dose is more repetitions, not greater shock amplitude or longer individual presentations. Report immediate outcomes, outcomes at a common 12-bout elapsed-time endpoint (REST padding), and 24 hours after that endpoint. Both allocations receive exactly the same schedule. Snapshot-history endpoints use independent diagnostic probes; serial-history endpoints use actual sequential probes, target pair first. Record target revision and all eleven non-target discriminations, including acquired/lost decisions relative to the zero-dose time-matched branch. No stop-on-success optimization.

Record target memory before reversal, its net displacement, signed decision, unclipped versus clipped expression, and the actual teaching payload. A net output displacement is not itself a physiological teaching drive. Extra-dose rescue establishes dose dependence in this model; it does not erase the fixed-dose tradeoff, prove biological acceptability, or justify an intermediate timescale. Physiology is carried unchanged from iteration6. No new allocation mechanism is proposed in this experiment.
