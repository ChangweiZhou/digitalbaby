# MiniFly V9.9C — rank-relation write-dose localization

**Prospective design, 26 September 2026.** This is a diagnostic on the unchanged V9.7 `REF` learner, V9.2 checkpoint, and V9.9B rank fixture. It does not select or alter a fly model. Engineering world 9903, pilot worlds 1601–1612, and confirmation worlds 1701–1764 are disjoint. Code, design, parent assets, worlds, and analysis are hashed before the pilot. All 64 confirmation worlds run irrespective of pilot efficacy; only a technical failure stops the run. Pilot estimates never enter confirmation.

## Claim and exposure (E3 diagnostic, not promotion)

Eight random uppercase bytes carry hidden ranks 1–8. The same 20 undirected rank pairs as V9.9B are taught in both orientations; the same eight undirected pairs are withheld in both orientations. Each taught orientation occurs once in each of eight bouts: **320 old records**, with 40 records per bout. All arms receive exactly the same byte strings, outcomes, labels, order, engineered predictor updates, and clock times. The first four bout permutations use V9.9B's generator unchanged; bouts five through eight extend it. The later 72-record cohort uses three disjoint symbols. No held-out pair is ever reinforced, including during the later cohort. All probes are read-only and the first held-out answer precedes any feedback on that pair.

The four old-teaching branches are exact birth-state clones: `Z` (zero native value writes), `E` (writes in bouts 1–4 only), `L` (writes in bouts 5–8 only), and `D` (writes in all eight bouts). Their native old-write counts are 0/160/160/320; equal *sensory* information does not imply equal value-write budgets, because write dose is the intervention. At the fourth-bout probe, `E=D` and `Z=L` must have identical states. At the eighth-bout probe, all arms share a clock and engineered-predictor digest. `D−L` estimates the causal effect of the additional **early** 160 writes given identical later sensory history and later write flags; it does not isolate a context-free scalar dose parameter. `D−E` and `L−E` distinguish schedule sensitivity but are secondary.

Raw or canonicalized exact-pair lookup can only tie (0.5) on withheld pairs. Each symbol's frequency and byte position are balanced. A win-count rule computed only from the 20 taught edge labels solves all eight withheld pairs; this is a task-solvability control, not a fly decoder. Exhausting binary categories gives an oracle maximum of 0.75 on the withheld pairs; it is an upper bound for that countermodel, not an expected fitted result. A learned simple feature rule is legitimate E3 within this synthetic family, but this diagnostic alone cannot promote a general persistent core.

## Endpoints and interpretation

Probe trained and withheld pairs after bout 4 (`half`) and bout 8 (`old_end`). The **sole confirmatory contrast** is world-paired `D−L` withheld-pair native choice at `old_end`, with a two-sided 95% Student-*t* interval over 64 worlds. Call it positive only if the lower bound is above zero; negative only if the upper bound is below zero; otherwise unresolved. Define +5 percentage points prospectively as the smallest practically interesting gain for deciding whether more writes could plausibly close a substantial part of V9.9B's gap. If the interval's upper bound is below +5 pp, exclude a gain of that size under this schedule. This rule does not convert a nonsignificant result into evidence of zero effect.

At the same times report absolute native scores, `D−Z` and `L−Z`, trained-pair choice, pair margins, and per-edge results as descriptive evidence. To support a dose-bottleneck diagnosis, both trained and withheld native behavior must improve; a trained-only increase is not transfer. An absolute withheld interval entirely above 0.75 is needed for a *separate* beyond-one-bit claim, never to rescue the primary. Code collision, predictor mismatch, exposure violation, read-only mutation, nonfinite results, or clock mismatch invalidate the world and stop the batch.

The old-end `Z`, `L`, and `D` states continue for one day. Each then forks into `S` (same new sensory/feedback stream, native new writes off) and `W` (same stream, native new writes on). Probe withheld old and trained-new pairs at new-cohort end and after another day. Probe old trained pairs at the final day too. These are secondary persistence/interference and new-learning guards; the primary old-end result remains valid if continuation is negative. An improvement that exists only immediately is not a persistent-core improvement. The absent passive `R` arm means `S` cannot separate passage of time from unreinforced sensory exposure; `W−S` still isolates the later native write flag under that sensory stream.

## Frozen-code decodability diagnostic

At `old_end`, use only `Z`'s frozen 5,177-dimensional KC codes. Construct 20 training difference vectors from the two orientations of each **taught** unordered edge, oriented using its taught labels. Fit one linear ridge probe with a fixed dimensionless regularizer of 0.1 after scaling by the training vectors' RMS norm; also report grouped leave-one-taught-edge-out accuracy. The independent scorer applies the fitted vector to the eight held-out orientation differences. The fit never receives hidden ranks, held-out labels, held-out outcomes, or held-out scores, and no hyperparameter is chosen by confirmation outcomes. The probe's score is an external decodability diagnostic, **never** the fly's behavior or a deployable replacement for the native value circuit. A successful probe with weak native transfer points to the native teaching/readout interface; a failed linear probe does not prove the code lacks information.

## Staging, checks, and compact delivery

1. Preflight world 9903 verifies pair exposure, 0.5/0.75/1.0 analytic controls, clone identity, `E=D` and `Z=L` at the half probe, write ledgers, predictor equality, code distinction, no-write label inertness, probe purity, aligned clocks, and finite measurements. Hash all sources before pilot.
2. Run the fixed 12-world pilot for runtime and technical feasibility. It has no efficacy gate, parameter adjustment, or inferential role. A technical failure is documented and stops the batch.
3. Run exactly 64 untouched confirmation worlds without optional stopping. Independent reduction recomputes metric rows, primary interval, all source hashes, and checks. Report negative or unresolved results equally.

The result bundle contains this design, runner, independent audit, compact final metrics/summary, acceptance checks, report, and manifest pointing to unchanged parent assets. It copies no checkpoint, raw datasets, caches, old archives, or raw per-seed state files; target <10 MB.
