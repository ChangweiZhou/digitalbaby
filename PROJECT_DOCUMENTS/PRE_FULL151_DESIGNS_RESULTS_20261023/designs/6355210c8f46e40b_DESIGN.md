# A8 frozen design — local baseline transfer

Date: 2026-09-20. Four scientific arms: REF, LOCAL_BASELINE_TRANSFER, OOB_DROP,
OOB_TRANSFER. No optimizer, dose sweep, classifier, task-gated LOCAL, rewiring,
turnover, new mutable neural state, or automatic scientific promotion threshold.

## Primary question and panels

LOCAL is the primary mechanism probe: does a frozen, label-free, coordinate
baseline improve relevant-memory coexistence without losing durable acquisition,
revision or individual memories? OOB arms are privileged comparators, not bounds.

C consists of 64 newly generated canonical lives and their eight FPF8 transforms.
LOCAL b uses all plastic subevents of the canonical C lives only. E1 consists of
64 different canonical lives and their eight FPF8 transforms; all four arms run
on every complete life. Standard P1–P7 are retained; delayed acquisition/revision,
24-hour/7-day usefulness, full revision/return curves, and signed choice/margin
tails are reported separately. Canonical is primary, K8 is secondary. Within a
panel K8 reuses its canonical constituents: these are not independent replicates.
E2 has 64 further cue/seed-disjoint canonical worlds generated and sealed but
is not evaluated in this iteration. New worlds exclude historical raw cues as
well as all other new panels; the inherited generator and scoring are unchanged.

There are 72 calibration trajectories and 288 E1 trajectories, plus ten technical
identity trajectories. Four processes, one BLAS thread each. Data flow and source
hashes are locked. Behavioral performance never determines arm execution.

## LOCAL

u is the actual native predecay total alpha write; h=dx*dt*alpha_scale/90;
p is the original pre-event allocation function. Calibrate
b_i=sum_C(p_i*u_i)/sum_C(p_i*h_i), with exact zero where the denominator is zero.
No epsilon, clipping, gain tuning or context conditioning. Freeze b once.
At each evaluated native plastic subevent, c=p*h*b; slow'=slow_write-c;
fast'=fast_write+c. LOCAL sees no evaluator labels, cohort/target IDs or probes.
External labels are used only to annotate its already executed updates.

This preserves predecay total alpha write on a common pre-state, not endpoint
state or later raw write volume. Additional immutable parameters: 5,177 float64
values (41,416 bytes). Mutable neural array bytes remain unchanged. Coordinates
with zero exposure/support receive b=0. Nonzero c when u cancels to zero on an
active supported coordinate is permitted; signed writes are a declared change.

## OOB estimator and the prefix issue

A7 Phase A source rows are outer 330-second teach-pair slow innovations. Its
role/context donor means depend on the donor prefix at each checkpoint. One
constant event template cannot reproduce that whole family of retrospective
checkpoint operators simultaneously. The old checkpoint-specific equivalence
is tested separately and not presented as a single online causal trajectory.

A8 uses event-pooled full-C templates, fixed before E1, with the same four groups:
acquisition/challenge × delivered role. Separate templates are estimated from
complete canonical and K8 C trajectories to avoid imposing K8's state/history
distribution on canonical comparison. The LOCAL baseline is identical in both
regimes. Canonical OOB acts on every teach pair. K8 OOB acts only on non-target
cohorts, matching the A7 source convention; designated target is block index mod
8. Calibrated K8 template sums use the same exclusion. No current activity mask
is applied to dense OOB. This is explicitly a different information/action class
from LOCAL, not an upper bound or equally deployable competitor.

Native measured slow innovation per eligible pair is
xi=slow_end-exp(-330/tau_s)*slow_start. The donor mean is mu_g=sum(xi)/n_g.
A8's fixed-template checkpoint predictor is P_T=sum(exp(-(T-t_end)/tau_s)*mu_g).
It shares A7's group/retention construction but has fresh full-calibration
estimates. No claim is made that it must reproduce A7's numerical +6.1pp gain.

## Unique native inverse map and timing

The inherited pair dispatch is 30s presentation, 135s idle, 30s presentation,
135s idle. In model76.step_encoded, the idle path is exactly diagonal decay:
slow*=exp(-dt/tau_s), alpha_fast*=exp(-dt/tau_f). No feedback write occurs there.

At the start of the FINAL 135s idle only, define c=exp(135/tau_s)*mu_g.
OOB_DROP subtracts c from slow. OOB_TRANSFER subtracts the same c from slow and
adds c to alpha-fast. Then the original idle routine runs unchanged. Thus the
pair-end slow innovation changes by exactly -mu_g on that pair's native stream;
the transferred fast component at pair end is exp(-135/tau_f)*c.

This boundary timing is fixed by the existing idle segment; it is a privileged
pair-level write, not an activity-local plasticity claim. DROP vs TRANSFER
measures the effect of that explicit transient compensation. Once their states
diverge, native feedback and all subsequent writes are allowed to respond.

## Qualification

Full-life observer and zero-arm checks must match REF checkpoint arrays, final
fast/slow/adaptation/clock state, P1–P7, revision and return counts exactly in
canonical and K8 block 0. Unequal-count mean tests, source/heldout exclusion,
signed split, exact-zero policy, immutable parameters, inverse-map algebra and
nonconservation formula are tested. A7 prefix-specific shadow reconstruction is
checked on block 0 at every archived checkpoint, and varying prefix means are
quantified rather than concealed. For each A8 life, streaming fixed-template
shadow weights/vectors are independently reconstructed from event end times.
Actual nonzero OOB pulses and LOCAL writes carry native state-equation checks.

Reordered arithmetic uses 1024*float64_epsilon*max(1,relevant state/value scale).
No metric, gain, cosine, clipping or tail-harm threshold qualifies science.
Numerical/identity/source failures stop execution and are reported.

## Endpoints and tails

Report paired LOCAL/DROP/TRANSFER minus REF, never an oracle-recovery fraction.
Use 64 canonical histories or eight K8 blocks as statistical units; descriptive
95% paired bootstrap intervals use 5,000 fixed-seed resamples. No multiplicity-
corrected discovery claim is made. Preserve all P1–P7 and parent scoring semantics.
Report acquisition and revision at 24h, usefulness at 24h and 7d, and curves.

For currently relevant facts at canonical checkpoints, report wrong→correct,
correct→wrong, per-fact margin q10/q50/q90, cohort×checkpoint accuracy harm rate,
worst cohort-history accuracy delta and number of worse histories. Also retain
all-informed and incoming fact populations separately. Never pool obsolete
truths into relevant-memory protection or score pre-feedback revision as failure.

The mechanism ledger records each plastic event's c L1, ratio to native slow
write L1 (undefined when denominator is zero), actual fast/slow L1, sign reversal,
correction at zero u, state magnitudes, and native pre-correction response clipping.
Checkpoint readout clipping remains separately scored. LOCAL correction vectors
are stored sparsely for independent inspection. Dense OOB pulses are reconstructible
from fixed templates, groups and their recorded interval. Templates, baseline and
exposure counts are saved. Label-based summaries occur only after execution.
