## Refinements decided before outcomes

1. “Moved mass” means NET removal and NET addition on disjoint coordinates, each equal to SPACE's external event/route/sign budget. Fractionally removing and returning mass at one coordinate cannot meet this definition. Exact net dose is checked, not a book-keeping sum of transfers.
2. The blind allocator receives only its original increment, fixed group identity, external budget and seed. It never reads slow state, old cues, target labels or outcomes. Random feasible donor partitions are followed by the same proportional fractional removal/addition used by SPACE. This preserves allocation style instead of changing to concentrated boundary-only recipients. The partitions need not match donor counts: this tests this specified location policy against this null, not every possible spatial null.
3. To find a disjoint partition, draw 128 independent Bernoulli-half partitions. Accept the first whose donor and recipient original-mass capacities both cover M. If none is found, solve the same binary subset feasibility constraint with a seeded random linear objective (2-second limit). This is a prespecified computational feasibility branch, not a scientific alternative or outcome-dependent retry. Solver failure/time limit is unresolved, distinguished from proven capacity/partition infeasibility. No solver-feasible label overrides direct floating-point checks.
4. An infeasible/unresolved sham branch terminates at that event and produces no later outcomes. No reduced-dose fallback is scored. A cell is resolved only if all eight sham trajectories realize every preceding budget. Do not select a surviving subset. If a primary cell is unresolved, the corresponding load gate fails as unresolved, not as evidence that location has no effect.
5. If Block B runs, water filling uses |slow+u| as receiver base occupancy, including the original current write. Using |slow| alone omits capacity already about to be occupied. Fill a_i=min(|u_i|,max(0,lambda-|slow_i+u_i|)). This only approximates liability; no claim that slow magnitude counts stored memories.
6. Full-trajectory BALANCED is externally yoked to SPACE's budgets as well. Its own conflict donors and nonconflict receivers must have enough capacity; otherwise the comparison is unresolved. Common-prestate tests isolate receiver placement without that trajectory issue.
7. The 0.01-Hz floor is a new declared mechanism-screen threshold, not a correction of an “unrealistic” V69 rule. V69's original architectural relevance result remains failed. Missing the floor does not establish that the earlier effect was caused mainly by dose confounding.
