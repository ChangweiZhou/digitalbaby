# Step 12 — locate the fading-pair held-out baseline and old-teaching signal

This is one bounded diagnostic of the byte encoder → single-store Full151 value-memory interface. It does not propose a new front end, a parallel bank, an output system, or an improvement claim. Step 11 found FE0's final held-out W−N choice advantage exceeded FE0+fading-pair's by 28.13 percentage points, but PAIR's N control reached 65.63% and Step 11 omitted the old-end held-out probe. This run locates when those effects appear.

Use the frozen V9.8 E3 symbol-class generator, V9.2 parent checkpoint, native Full151 write rule, read-only relative native-value scorer, FE0 and Step 6's fading-pair front end, with no parameter change. Same fresh world and exact old/new bytes, labels, clocks and teacher calls are shared by all branches. W enables the 144 old native writes; N disables them. At the old-day state, fork each W/N branch into ON and OFF: both see the same 72 new records, while ON enables new native writes and OFF disables them. No held-out cue is ever reinforced. The first held-out probe precedes all teaching. A raw or canonicalized exact-pair table cannot answer the three held-out edges; fixed class, position and frequency shortcuts have no universal label, while a class rule learned from the old records can solve the relation. The only permitted E3 statement is limited within this synthetic family; this diagnostic does not seek a fresh E3 promotion result.

Read-only probes on discarded clones record both `choice` (sign of the three pair margins, ties 0.5) and the continuous signed native margins. At `birth`, probe held-out on one shared birth state per route. At `old_end` and `old_day` probe W and N on held-out and old taught pairs. At `new_end`, probe all W_ON/W_OFF/N_ON/N_OFF states on held-out and new taught pairs. At `final`, probe those four states on held-out and old taught pairs. No probe teaches, changes the learner, or supplies a label to a learner. The evaluator makes the relative choice; the model does not emit a byte.

The fixed roster is technical world **12700**, excluded, then **32 fresh paired worlds 12701–12732**. No previous trajectory is rerun or used for tuning. Source and configuration files are hashed before technical execution. Technical qualification must establish branch-state equality at fork, preserved PAIR transient state, identical predictor histories and clocks, exact write flags, source fixture hashes, read-only probe purity, and a complete probe roster including the previously omitted `old_end/heldout`. No science starts if technical qualification fails. After each world, commit one atomic receipt; a scientific exception stops the run with no replacement or automatic restart.

This is a localization assay rather than a new efficacy confirmation. Its predeclared descriptive quantities, each with a world-level two-sided 95% Student-t interval, are:

- `old_end` and `old_day` W−N held-out choice and margin for each route: was an old-teaching signal present, and did a day change it?
- `final` W_OFF−N_OFF versus W_ON−N_ON: does later teaching alter the old-teaching effect beyond matched sensory exposure and time?
- `final` N_ON−N_OFF and N_OFF versus birth/old-day N: did the PAIR no-old-write baseline rise from later writes or earlier code/exposure?
- FE0 versus PAIR versions of those contrasts, paired by world. New-cohort taught ON versus OFF and old taught W versus N are positive controls.

Interpret stage differences without turning several descriptive intervals into multiple success claims. If PAIR lacks W−N at old end, a shared-feature/code issue is plausible. If it has W−N at old end but loses it in OFF, delay/sensory history remains a candidate; if loss or N elevation appears only in ON, later new writing is implicated. If the PAIR birth baseline is high, fixed code/checkpoint geometry must be examined before attributing it to later learning. These are conditional interpretations, not automated follow-up experiments. Complete all 32 worlds, report uncertainty, and stop. Do not choose a bank weight or launch a parallel-bank experiment from these worlds.
