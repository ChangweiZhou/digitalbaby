# MiniFly: one bounded integration campaign after iteration 4

## Objective
Build one runnable, fixed-capacity learning demonstrator using the existing MiniFly anatomical work and the iteration-4 causal candidate. This is a step toward the project's bounded, biologically informed persistent learner, not a claim to reproduce a whole fly or to solve autonomous byte-cue formation. Do not start another open-ended sequence of paper reviews, mechanism proposals, or neuron-count reductions.

## Frozen evidence
- MiniFly's 4,083-neuron reduction preserves some tested sensorimotor mean responses, not demonstrated learning. Temporal fidelity remains insufficient. The 9,619-neuron memory-preserved scaffold retains relevant annotated interfaces, but is not a validated learning system or a biological minimum.
- Iteration 3 exactly groups a particular published 2,000-cell model into six equivalence classes for its fixed stimulus repertoire. Broader input repertoires can destroy that compression. Keep this as a scoped optimization, not a capacity claim.
- Iteration 4 removes the original batch model's dependence on future training schedules and provides resumable state. All 11 supplied causal checks were rerun successfully in the present review.
- Iteration 4 is a candidate, not biological ground truth. Standard-fit RMSE improves from 4.319 to 4.127 Hz, but separate spacing RMSE worsens from 3.683 to 4.396 Hz and extinction-ratio RMSE from 0.238 to 0.273. Inherited parameters and conditions prevent calling these entirely blind whole-model tests.
- The fitted slow lifetime hits its upper bound. There are no observations beyond 24 hours in this fit; do not interpret the approximately 116-day parameter as measured retention.
- All 64 tested passive-recovery combinations fail the specified higher-order training-dose requirement. Archive that family with its scope; do not extend its rate grid.
- Anatomical proximity is not identified teaching responsibility. BANC spatial replication remains unestablished. Keep anatomical specimens separate; use justified type-level correspondence only.

## One engineering integration, with explicit limits
Use the current candidate rather than introducing a new teaching family. Preserve the existing published-source and single-exponential references as controls, not things to retune into matching the candidate.

1. **Input and capacity contract.** Supply activity through a fixed set of coding units. Do not allocate one new state bank for each new odor identity. The current four-scalars-per-address implementation is fixed-size only when the set of addresses is fixed. A type-level or reduced activity model is permitted, but label it honestly and identify its same-specimen anatomical provenance. Missing odor-input partners may require adding cells to the 9,619 scaffold; its count is not a constraint or minimum.
2. **Time contract.** Keep the released bout-based reference unchanged. Its active-bout partition dependence is known (approximately 4.96 effective weight units in the reported diagnostic). Any continuously integrated alternative must be explicitly marked as a model change, checked for numerical convergence under the same physical input, and evaluated on the existing conditions without fitting to previously examined challenges. Do not claim arbitrary-stream fidelity for the original bout update.
3. **Teaching interface.** Keep baseline-relative teaching changes separate from nonnegative firing rates and ordinary synaptic current. Do not turn negative effective input coefficients into negative excitatory physical synapses. Record the calibration and unresolved mapping rather than inventing anatomy-derived values.
4. **End-to-end witness.** An input must change the demonstrator's stored state and a later readout must depend on that changed state. Resetting learning, blocking teaching, and interrupting feedback must test the actual implemented path—not a separate reference model running beside the anatomical network.

The deliverable may be an explicitly hybrid anatomical/effective model; do not require full spiking reconstruction or exact agreement with every published figure before a bounded learning experiment can be informative.

## Fixed evaluation surface
Keep biological-fit scores and engineering learning scores separate. Use the existing conditioning, spacing, early/late cue, and feedback-intervention conditions, retaining all known failures. Add a single fixed-capacity learning panel with new cues, overlapping cues, intervening learning, and revision. Count unique examples, total presentations, runtime, and all mutable state. Preserve the no-learning and feedback-block controls. Do not train to the test metadata or insert a trial-count reset to force extinction.

Do not require this first demonstrator to solve both papers' different circuits. Higher-order learning remains a failed regression case / separate unresolved scope, not an excuse to keep changing the working model.

## Budget and stopping behavior
Use one agreed compute budget and at most one declared interface reformulation. Calibrate on the allowed development data, freeze, and run the whole evaluation panel. Do not perform unlimited post-result tuning or initiate a new family after failure. If integration fails, return the smallest reproducible failing case, the affected assumption, and the completed results. An inconclusive or negative integration report is a valid completed deliverable, not a request to continue until v100.

## Communication and artifacts
Keep original releases immutable. Maintain one `PROJECT_STATE.md` containing the fixed goal, accepted findings, failed scoped constructions, current runnable model, and unresolved interfaces. Log internal runs in machine-readable files; do not request a new conversational version for routine repairs, execution, or aggregation.

Return one short decision report, one reproducible entry point, a manifest with source hashes, condition-level results, and checkpoints. Report whether there is an end-to-end working learner, whether state stays fixed as cues increase, what survives intervening learning and revision, and what remains unvalidated. Further compression is justified only after a runnable parent learning behavior exists.
