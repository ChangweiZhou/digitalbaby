# MiniFly V9 — continuous raw-byte reading, with a versioned FULL_151 structural fork

**Status:** pre-run experimental contract, 2026-09-25. This folder is a new candidate; the frozen FULL_151 source and A11 B/HASH8 anchors remain unchanged. An engineering pilot may tune the candidate; any claimed result must come from fresh, locked streams after that tuning.

## Question and scope

Can a small extension of the FULL_151 brain receive ordinary bytes one at a time, preserve byte identity and recent order, and learn to predict later bytes from them? The immediate failure to repair is raw-byte reading, not general NLP. The prior 10,000-byte text check was an external 5.3 MB predictor, not a test of FULL_151's own plastic memory. FE0's old binary association and retention are regression references, not proof of sequence learning.

## Versioned candidate

Retain FULL_151's frozen anatomy-derived PN→KC matrix and FE0 associative value path. Add an explicitly engineered temporal pathway for recent ordered bytes and a 256-output predictive synaptic population *inside* the versioned brain object. The predictive weights update online from the observed next byte using only prior activity and a locally available output error; all mutable weights, temporal state and the old associative state belong to one checkpoint. No task/slot label, record object, token ID, future byte or evaluator truth enters the model. The temporal population and new output neurons are engineering additions, not claimed as fly-connectome findings. Report all fixed and mutable bytes and any collisions caused by temporal hashing.

## Primary controlled streams

Every byte value is ordinary sensory input, including 0xF0/0xF1. No byte itself invokes reward. Streams are continuous, with no hidden per-record reset. The evaluator may know target positions solely to score them; the model sees only bytes and elapsed time. Prediction is saved **before** the target byte is delivered. Training may then use that observed byte. **All persistent weights are frozen throughout DEV and TEST scoring**; transient sensory state continues causally. Any separately measured prequential adaptation gets its own label and cannot enter the primary score.

1. **Identity:** repeated `[marker, cue, target]` triples, cue balanced over all 256 byte values. A *world-specific*, pre-locked random permutation maps cue to target. This asks whether the brain can use an observed byte without a hand-coded task label. Train and test streams draw new orders from the same mapping; development and confirmation worlds use distinct permutation seeds. The mapping is a task generator, not a lookup supplied to the model. Compare target-slot bits/byte and macro accuracy with train-only unigram and last-byte Markov baselines.
2. **Order:** repeated `[marker, a, b, target]` quartets; `a,b` are independently balanced symbols from a 16-byte alphabet, and target is the byte for `(a + 3b) mod 16`. The target is uniform conditional on either input alone but predictable from the ordered pair. Train and test draw new pairs under the same rule. Compare with train-only unigram, last-byte Markov and true last-two-byte Markov baselines. Also test code distinction for `(a,b)` versus `(b,a)` at PN, KC and the new temporal population.

The target marker and byte spacing are fixed before scoring and are visible only as normal sensory data. Each full-factorial cycle contains every ID cue once, or every ordered `(a,b)` pair once, in a shuffled order. The intended per-world budget is 256 training cycles, 8 DEV cycles and 16 TEST cycles, separately shuffled. The mapping/rule stays fixed within a world, while world seeds and stream orders are independent. This gives exact cue/pair coverage at each phase; if measured runtime forces a smaller budget, revise this design **before** final scoring. Include an identical-architecture no-plasticity control and test that reversing temporal order harms order-task performance. For the swap test, report separately the 32/256 pairs for which `(a+3b) mod 16` is unchanged by swapping. Score full-stream bits/byte separately so target-only scoring cannot hide costs on other bytes.

## Secondary natural-text check

Use the author-separated raw UTF-8 files and hashes in `corpus/CORPUS_MANIFEST.json`. Train only on Austen and Wells, contributing the same capped byte count from each; if they are interleaved, the 4 KiB chunking and visible newline separators must be fixed in the run manifest and shown identically to the brain and n-gram baselines. Use Carroll only for parameter choice, and evaluate the **same frozen predictive checkpoint** separately on Conan Doyle and Stevenson. Transient state may reset once at the start of an independent test source and then evolves causally; no reset within a test source. Report full and content-character bits/byte, unigram/true Markov2/8-gram baselines, and resources. The content mask is computed from decoded Unicode categories by the offline scorer only and never enters the learner. This small historical-English corpus is a transfer diagnostic, not broad NLP certification. The old v8 4,000-byte project-document test must not select this model.

## Decision and preservation

The provisional engineering gate for *substantially repaired raw-byte reading* is: every one of at least three fresh worlds has full 256-cue/pair TEST coverage; on ID, target-slot accuracy ≥0.80 and target BPB ≤2.0; on ORDER, accuracy ≥0.65 and target BPB ≤2.0 **and** at least 1.0 bit/target better than the train-only, **target-slot-conditioned** last-byte Markov baseline; both tasks beat the identical no-plasticity brain. On the 224/256 ordered pairs whose correct target changes under cue swapping, a copied frozen-checkpoint swap test must worsen BPB by at least 0.1 bit/target. The all-stream Markov model is also reported but cannot serve as the order gate: repeated markers and cue/target roles contaminate its conditional counts. The target-slot baseline is advantaged because its training counts use the evaluator's score positions; it remains only a benchmark and supplies no model input. Report the gap to true target-slot-conditioned last-two-byte Markov, not merely success versus chance. This gate is intentionally stronger than detecting a nonzero effect and is a decision convention, not a biological threshold. Natural text is a separate criterion; controlled-task success alone is not a language result.

Lesion the native PN→KC contribution, the engineered last-byte pathway and the engineered ordered-pair pathway separately on copied frozen checkpoints. A positive natural-text result that survives native PN→KC and old fast/slow value-path lesions must be called a **parallel engineered predictive branch**, not evidence that FULL_151's original plasticity learned text. No lesion is allowed to alter the training history of another arm.

Before a final run, verify the inherited FULL_151 source and anatomy/readout object hashes with the parent `compute_source_lock()`, and include the resulting identity in the run manifest. After this bounded experiment, any candidate considered for the project's final brain must also pass an A11-style preservation check under a separate lock. A11 itself continues to measure the immutable old B/HASH8 anchors and cannot certify this fork. Do not package source datasets, old archives, caches or raw per-byte trajectories; ship a compact report, final metrics, model/config, acceptance checks and manifest.
