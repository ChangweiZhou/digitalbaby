# MiniFly V9.10D — withheld cyclic relations

**Prospective design, 26 September 2026.** Freeze the V9.10C online 5,177-KC linear head, learning rate 0.5, byte encoder, and native REF reference. This is one bounded test of whether prior byte-level teaching supports a second, non-scalar relation family. No parameter search or topology edit is allowed after pilot outcomes.

## Claim, exposure, and countermodels

The primary evidence target is **E3 within a synthetic cyclic relation family**. In each world, nine randomly selected uppercase bytes are assigned to three hidden classes A, B, C (three symbols each). The relation is A beats B, B beats C, C beats A. For each class pair, the three same-index edges `(A_i,B_i)`, `(B_i,C_i)`, `(C_i,A_i)` are withheld as three disjoint directed triangles. The other 18 cross-class unordered pairs, both orientations, are shown with feedback for eight bouts: 36 ordered cues per bout, **288 teaching records**. No withheld orientation or outcome is ever presented to the learner. Each symbol appears in four taught unordered edges (two wins, two losses) and two withheld edges (one win, one loss). The 12-byte framing, `!` outcome byte, actual pre-outcome `pending_x`, clock, and predictor updates are inherited from V9.10C. First held-out choices are read-only and precede any feedback on those pairs.

An exact raw/canonical pair-key table ties at 50% on the withheld edges. Any scalar score assigned to each symbol, including scores learned from the taught labels, can correctly orient at most two edges of each withheld directed triangle: **6/9 = 66.67%** overall, with ties worth half. A class-cycle rule inferred from the 18 taught labels can recover all nine withheld outcomes; an exhaustive three-class consistency check is an analytic solvability witness, not an input to the fly. Fixed positional and frequency shortcuts have no label information because the two orientations and each symbol's win/loss exposure are balanced. These countermodels must be checked on every generated fixture. A success above the scalar ceiling supports a non-scalar within-family computation; it does not prove biological implementation or E4 breadth.

The engineered `H_W` head updates one shared zero-initialized `float64[5177]` vector online only on presented old cues, exactly as V9.10C. `H_N` sees the same bytes/feedback/clocks and has old head writes disabled. Native `REF_W` and `REF_Z` are contemporaneous reference branches differing only in native old value writes. The head uses the native-no-write branch's sensory code; the inherited native mechanism is not credited for head behavior. No learned symbol, pair, or class slots are added. The full parent encoder and byte predictor remain substantial unchanged assets.

## Schedule and gates

Engineering world 9906 checks the source lock, exposure/label balance, exact 6/9 scalar ceiling, uniqueness of held-out labels implied by trained cyclic labels, identical parent/custom byte-feed semantics, code/write/clock invariants, read-only queries, and KC code separability. An offline fit **on engineering-world codes only**, allowed to see all labels, checks whether the fixed KC representation can linearly separate the 54 ordered cross-class cues; it is an engineering representability probe, never a scored model or a source of later weights. Failure or degeneracy stops the science run and is reported.

Eight pilot worlds 2051–2058 check execution and provide an explicitly nonconfirmatory scale estimate. Then run all 64 untouched confirmation worlds 2101–2164 with no outcome-based stopping. The primary confirmatory cell is **old-end held-out `H_W` choice**. The promotion gate requires its two-sided 95% world-level Student-*t* interval lower bound to exceed 2/3 **and** the paired `H_W−H_N` lower bound to exceed zero. Report the absolute score and both intervals regardless of gate outcome. Native `REF_W−REF_Z`, trained choice, and margins are secondary. A positive causal contrast alone, without clearing 2/3, remains E3 evidence of teaching-dependent reuse but does not exclude a scalar-potential explanation.

At old-end, after one day, after a 72-record directly taught cyclic cohort on **three disjoint new symbols**, and after one further day, probe old withheld pairs. The later cohort is E1 only. Fork identical prestates into `R` (time only), `S` (same new bytes/feedback with head/native value writes off), and `L` (new writes on). The new cohort must be learned relative to `S` before interpreting persistence under intervening learning. Its disjoint symbols make this an easier interference schedule, not a general protection claim. The delayed/final result is a required durability check, but only the old-end gate is confirmatory in this experiment; final intervals are descriptive. A positive old-end gate without final persistence does not earn the project goal of a persistent learning core.
