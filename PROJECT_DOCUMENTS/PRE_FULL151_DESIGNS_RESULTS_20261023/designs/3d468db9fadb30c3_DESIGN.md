# R2/Z1 E3 causal-control correction — v1

## Scope and evidence claim

This is a separate corrective E3 experiment, selected after the earlier three-mechanism run was found to have a nonfunctional `N_old_rel` control. It tests **only** R2 versus its matched R0 control and Z1 versus its matched Z0 control. It does not repair or overwrite the old 256 receipts, claim a global 16-candidate winner, test autonomous unsupervised learning, or change either mechanism's learning equations. The sole mechanism-level primary endpoint is improvement on never-reinforced old relation pairs after a day, an intervening new cohort, and another day.

Use 32 untouched science seeds `172001..172032`; technical world `172000`. The common fixture, byte presentation, four-output learner, teaching schedule, clock, feedback and final binary internal-choice output are inherited from the earlier run. Each world teaches 16 old exact fact keys and 12 orientations of six old relation edges, then 16 new facts and six new relation orientations. The three withheld old edges in both orientations receive no answer during learning; first scoring precedes feedback. An exact-key or canonical-key table cannot answer the withheld pairs. A one-bit-per-symbol class rule learned from old examples can solve them, so success means limited within-family E3, not general intelligence.

Each arm runs W and all four predeclared no-write branches through a complete life; only `W` and `N_old_rel` enter the primary E3 estimate. The latter must see the same bytes, labels, feedback, event times and later learning but perform **zero old-relation native writes**. The other three no-write branches are retained as technical integrity controls. The independent auditor uses a literal branch/domain matrix, not the runner's branch helper. R2 gate uniforms use the same world/domain/record key in all counterfactual branches; state-dependent gate decisions may then differ only downstream of actual write lesions.

Per world and arm, E3 is final held-out choice accuracy `W−N_old_rel`, averaged over the six never-taught old-relation orientations. Primary contrasts are `(R2 W−N)−(R0 W−N)` and `(Z1 W−N)−(Z0 W−N)`, paired by world. Report each mean with a two-sided simultaneous 95% Student-t interval using Bonferroni `m=2`, plus each arm's absolute W/N accuracy, old-end held-out and taught-relation guards, per-item outcomes and actual write budgets. A zero empirical variance does not justify a zero-width success interval; report it as unresolved with a bounded conservative interval. Claim candidate improvement only if its simultaneous lower bound exceeds zero and its own final W−N effect is positive. This selected-subset experiment does not alter the older six-contrast family or the remote 26-contrast family.

The previous source-locked R0 calibration scales are reused unchanged; their file hash is locked. No behavioral result from the technical world may select a scale, threshold, seed or mechanism parameter. The changed code is limited to causal branch routing, branch-common R2 gate uniforms, independently computed audit expectations, and new orchestration/analysis. Technical qualification must run a complete life for every arm on `172000`, prove the exact literal write matrix (W: `768/288/768/144`; each no-write branch zeros only its named domain), equal branch birth, feedback timing, deterministic source/receipt hashes, common R2 gate uniforms and clone isolation. Deliberately corrupt a no-write ledger and require independent audit failure. Source-lock all scientific and audit files plus parent code and environment **after** technical qualification and before any science receipt.

Atomic unit is one complete world-arm life. Never overwrite an existing receipt, replace a world, or auto-restart after a scientific integrity failure. Technical full-life time determines the final resource forecast; predeclared caps are 40,000 cumulative arm-wall seconds, 1.2 billion receipt bytes and 1.5 billion macOS raw RSS bytes. If the technical forecast exceeds a cap, do not start science. Preserve a failure record with committed count on any science failure. Use a detached background process with `caffeinate`; confirm it survives its launching terminal and commits the first new receipt.
