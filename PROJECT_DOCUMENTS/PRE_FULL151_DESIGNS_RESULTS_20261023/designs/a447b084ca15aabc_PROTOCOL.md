# V43 locked implementation protocol

This protocol implements the supplied V43_fast_slow_authority_design.md, preserved byte-for-byte as ORIGINAL_DESIGN.md. The roster is 16 fresh seeds 43101–43116 at total identity loads 64, 128, 256 and 512: 64 physical learning trajectories. Eight online policies share one base/SUPER/SLOTS state per trajectory. Offline SHUFFLED and oracles are read comparisons, not independent learning trajectories. No outcomes select these refinements.

The independent review below supplies the adopted operational resolutions. The specification's Q0–Q10 numbers and Outcome A formula remain unchanged. Load 512 is a stress cell; failed physical validity is reported explicitly. No seed or configuration is added in response to science.

**Execution details.** Load means total identities: keys_per_wave=load//4, repeats=8, trace capacity=512, slot capacity=384. The inherited generator, raw stream semantics, encoder, temperature, base/fast/slow writes, admission, promotion and eviction remain unchanged. No FULL-HYBRID physical branch is needed. The historical READ-HYBRID zero-norm fallback is retained and counted; primary architectures use raw SUPER as their fast distribution. Engineering uses seeds 943001 and 943002 at both loads 64 and 256, disjoint from science. Smoke uses seed 943901, 16 identities and two repeats, and never enters inference.

Evidence uses stable float64 log probabilities and is never clipped. Physical hashes include learned and fixed arrays, context, ordered containers, counters and future-influencing RNG state. Every byte scores all online policies before the common observation. Checkpoints preserve all physical state, virtual ledgers, event records, cursor and metrics. The default checkpoint block is eight complete 14-byte records, an execution setting that may change on resume. Verify atomic current/previous checkpoints, real SIGINT/SIGKILL resume equivalence, corruption and identity rejection, and writer exclusion. Workers are independent seed/load cells. Default concurrency is four, with one BLAS thread per worker.

**Shuffle details.** Compute age quartile cutpoints over all route-G pre-event slot ages within seed/load using NumPy linear quantiles at .25, .5 and .75; assign with searchsorted(side='right'). Ties may leave empty bins. Cross age bins with retained-support and prior-G-use bins. Within size≥2 strata use a deterministic, outcome-independent derangement. Preserve permutation indices and bin assignments. Singleton weights retain their original values for full-G descriptions and are excluded from Q6. Count changed assignments and changed numerical weights separately. SHUFFLED accuracy and checkpoint recall cannot be recovered from saved true-byte probabilities and remain omitted.

**Diagnostic details.** Fixed logistic, spline-logistic and gradient-boosting analyses leave one entire seed out across all loads. Their fits are post hoc analyses, never physical learner updates or qualification inputs. Completed folds are checkpointed. The diagnostic module exports its complete configuration and feature list. No event subsampling or parameter search is planned.

**Output accounting.** Raw A/T/G authority events use compressed columnar NPZ per trajectory, with a combined table/index for analysis. Fast-only bytes retain aggregate counts and losses. Training presentations, online authority events, checkpoint probes and diagnostic fits are counted separately. Completed archives omit finished large physical checkpoints; partial archives retain unfinished ones. Hash manifests cover the outputs.

# V43 independent design review

Reviewed the complete `V43_fast_slow_authority_design.md` and decoded V41 hybrid, memory, and stream implementations before V43 science. This review proposes implementation resolutions; the runner's locked protocol must identify which resolutions it adopts. The scientific roster remains seeds 43101–43116 × loads 64, 128, 256, 512, with every read policy sharing one physical trajectory. No outcome-driven tuning is justified.

## Source facts that materially constrain implementation

1. **Load means total identities.** The inherited four-wave generator takes `keys_per_wave=load//4`; preserve V41's eight acquisition presentations, noise/revision rows, RNG call order, and 512-trace/384-slot caps. Load 128 then reproduces the V41 workload configuration on fresh seeds.
2. **The internal slow-write fallback is the base.** V41's SLOTS lookup receives `base_scores`. READ-HYBRID changes scored predictions only. Feeding SUPER or a mixture to lookup changes admission even if the update code is untouched.
3. **Mature support is exactly two in the locked TRACE-CORR implementation.** Support is retained-anchor cardinality, not hits or distinct lifetime uses. Therefore the 3–4 and 5+ shuffle support bins will be empty by construction. Report this honestly; do not substitute access count to populate bins.
4. **Native allocation IDs are already monotone.** `Memory.serial` is consumed by traces and slots, and mature slot dictionary keys are unique serial IDs. A reused packed-array position, if an engineering representation uses one, must never replace this UID.
5. **No explicit revision-commit event exists.** All exact-anchor observations update the shared slot value with fixed smoothing. The physical learner neither recognizes evaluator revision labels nor emits a semantic-commit event. A concrete causal definition is needed: a revision commit is a change in the slot value's deterministic argmax across one physical exact-anchor update. Reset both local ledgers after that commit. Do not reset on every value update; that prevents evidence accumulation. Do not reset using stream revision/noise tags.
6. **Exact historical READ fallback has a zero-score corner.** V41 uses SUPER scores when their norm exceeds 1e-9, otherwise base scores; SUPER itself is raw SUPER scores. Explicitly preserve that historical baseline or document that the V43 named baseline follows the spec's fast-everywhere table at this corner. Count differences. Physical reproduction concerns unchanged learning state in either case.

## Recommended frozen operational resolutions

### Causality and lifecycle

Classify A/T/G/F using the one inherited nearest-candidate result: an exact mature anchor wins, then exact trace; a nonexact authoritative mature candidate is G; everything else is F. A tentative trace can win the nearest-candidate competition and block a less-similar mature slot. Searching mature slots separately would change the locked addressing rule.

`E2` initialization means actual two-context trace promotion, including ordinary nontarget bytes and promotions occurring at an evaluator exposure other than 2. Before revealing the byte, capture the selected trace's full distribution and the SUPER distribution even when the deployed route is F. Once the unchanged learner actually promotes, initialize LOCAL-E2 with the frozen trace-versus-fast log ratio. Do not infer promotion from labels, scheduled exposure counts, or post-update values. If several transitions occur, apply evidence to the old generation, then removal/birth/reset in actual transition order.

GLOBAL-BAYES accumulates every observed G event over the full trajectory. The specification does not reset its global ledger when one slot revises or evicts; preserve it. Both local ledgers reset to zero on a committed slot revision; evicted generations are removed. Retain historical event records for reporting, without making them deployable tombstones. A generation's prior similarity-use count is lifetime G uses since birth; a ledger reset does not silently reset this age/use covariate. Revision age is undefined until first revision, then elapsed physical bytes since the most recent commit.

Evaluator probes read the *current* causal weights from existing ledgers. They do not update local/global evidence, counters, slot recency, RNG, or any learner buffer. First two aliases being evaluated at E1/E2 is evaluator bookkeeping only. Probe order must be immaterial. SHUFFLED is defined for saved online G events and has no automatically defined checkpoint-probe weight; do not fabricate SHUFFLED held-out scores. SHUFFLED's top1 online accuracy requires full G expert vectors or sufficient exact argmax geometry, not just true-byte probabilities. It is valid to report only its specified loss-based contrast if accuracy is unavailable.

Compute specialist evidence from stable pre-update log probabilities. Do not floor/clamp probabilities in a way that clips the scientific evidence ledger. Stable logaddexp gives mixture loss even if a float64 probability underflows. Preserve the inherited output temperature. All features used for deployed prediction must predate the outcome; `true_byte`, expert correctness, and outcome losses enter only scoring, evidence updates, and offline diagnostics.

### Shuffled control

Use LOCAL-BAYES-E2 weights as the unqualified word LOCAL in SHUFFLED-ALPHA. Fix a definition of age quartiles before science. A defensible choice is full-trajectory G-event age quantiles within each seed/load, computed using a documented quantile interpolation and deterministic boundary rule; ties may create fewer than four nonempty bins. These cut points are offline and cannot enter deployed predictions. Alternatively ranked quartiles with event-index tie-breaking are reproducible, but tie splitting must be explicit.

Cross the age bin with exact support bins {2,3–4,5+} and *pre-event* lifetime G-use bins {0–1,2–3,4+}. Use an outcome-independent deterministic derangement or nonzero cyclic shift within every stratum of size at least 2. Singleton weights remain unchanged for descriptive whole-policy totals but are excluded from the decisive specificity comparison. Report both changed event assignments and changed numerical weights: saturation or equal weights can make the latter zero even under a perfect derangement. Do not retune strata to manufacture 80% coverage.

Multiset identity establishes exact authority-mass preservation; compare sums in an order-independent canonical order or with `math.fsum`, since naive different-order floating-point summation can differ in its last bit. Save permutation indices and bin assignments. Q6 uses LOCAL and SHUFFLED on exactly the same permutable-event subset, normalized by that subset's G count. Full-G policy summaries remain separately available. Require 80% permutable coverage in every load 256 seed as a conservative concrete interpretation of the coverage requirement.

### Endpoint/gate denominators

The scientific unit is the seed throughout. Compute each seed/load endpoint first, then equally weight the 16 seed values. Event-pooled descriptive totals are useful but must not replace paired inference.

* **Durable old held-out accuracy:** inherit V41 `A_after_D_heldout`, the untouched-A identities at alias2 after D. Also retain the stricter same-identity E1-and-all-delays endpoint as secondary; do not substitute it after seeing results.
* **Q0 acquisition:** assess the unchanged physical SLOTS path on all intended current-wave identities at learned aliases0/1 at each after_A/B/C/D checkpoint. Do not condition the denominator on surviving slots or correct acquisition. A cell is acquisition-valid only if every checkpoint reaches 90%; report all checkpoint fractions. Any invalid 128/256 cell prevents the complete preregistered 16-seed qualification; an observed-valid subset may be descriptive but cannot be presented as the full experiment. Load 512 is stress-descriptive when its substrate is invalid.
* **Q1:** both 128 and 256 must have at least 500 G events in every seed; at each load the seed-equal average `(hard loss − event oracle loss)/nG` must be at least0.20. Do not let one high-headroom load rescue the other.
* **Q2:** compute each seed/load A-event mean difference first. Across the 32 values at 128/256 require mean≤0 and maximum≤0.05. Empty anchor samples are unavailable, never zero/passing. This avoids a good seed/load masking a bad one.
* **Q3:** equal-seed comparisons at each primary load 128/256; SILENT-HARD whole-bpb minus READ≤0, E1 difference≥−0.02, and exactly identical physical consolidation counts. Report other loads separately.
* **Q4/Q5/Q6:** retain the numerical thresholds and pointwise paired 95% bounds exactly as written; Q6 uses only permutable G events. Do not silently replace these bounds by event bootstrap intervals.
* **Q7:** a simpler policy matches if, separately at both 128 and 256, simple−LOCAL≤0.01 whole bpb, simple−LOCAL≤0.02 G bpb, and simple−LOCAL≥−0.02 held-out accuracy. This is one-sided practical matching: a clearly superior simple policy also counts. Requiring absolute differences would absurdly disqualify a better simple policy. Report both candidates; if both match, prefer FIXED-50 because it has no learned arbitration state. The spec supplies no confidence-interval gate for Q7, so present point estimates and uncertainty without adding a new test.
* **Q8:** compute each seed's capture fraction then equal-seed average; separately report ratio-of-summed-gains and denominators. Zero/negligible headroom is undefined and cannot pass by setting capture to 0 or 1. Q1 gives the meaningful-headroom prerequisite. Capture can exceed1 because a probability mixture may beat the event oracle that chooses only between fixed experts; do not clip it.
* **Q9:** use the equal-seed mean whole bpb gap at 256≤0.05 and Q5 as specified.
* **Q10:** the word “materially” has no number. A consistent explicit operationalization is no positive LOCAL−HARD whole bpb difference at either128 or256, and the change in LOCAL−HARD durable accuracy from 128 to 256≥−0.02. This reuses the existing 2 pp margin. Report confidence intervals on the load interaction. The original Outcome A formula omits Q10; do not silently rewrite that formula. Report mechanism qualification and scaling status distinctly.

### Statistical family and scaling analysis

Use paired Student-t intervals over 16 seed differences (15 degrees of freedom), alongside seed tables and exact sign-flip sensitivity where useful. Predefine the decisive load 256 family of four contrasts: LOCAL−HARD whole bpb, LOCAL−GLOBAL whole bpb, LOCAL−FIXED whole bpb, and LOCAL−SHUFFLED permutable-G bpb. Holm-adjust these four two-sided p-values if reporting inferential p-values. The SUPER comparison is an engineering-gap contrast, not a fifth mechanistic test. Other endpoints and loads are secondary with explicitly labeled within-load families or descriptive intervals; claiming one omnibus adjusted family after testing4 contrasts × many endpoints is inappropriate. Qualification still uses the spec's effect thresholds and stated 95% bounds, with adjusted p-values reported alongside rather than inventing new gates.

For scaling, use seed-blocked load-specific means and paired-difference regressions on log2(load), with seed clustering; preserve seed grouping across all four loads. Report policy×load interactions from this repeated-measures structure. Held-out L50 is estimable only if observed valid loads actually bracket 50% and the fitted curve supports a crossing; otherwise state not identified in the tested range rather than extrapolate. Dominance ordering is conditional on measured endpoints/loads and can be summarized with seed bootstrap over complete seed blocks, not by treating 64 cells or millions of events as independent.

### Exploratory predictability

Leave one entire seed out, across all its loads, for each fold. Fit all imputation, scaling, transforms, calibration, and any tuning only on training seeds. Do not use slotUID/keyID, the byte outcome, correctness, losses, post-outcome evidence, or eventwise future rank/quantiles as predictive covariates. Physical age, current evidence, expert entropy/margin/agreement/divergence, causal similarities, and prior-use counts are appropriate. The offline diagnostic estimates predictability conditional on G routing; it is not a validated deployable policy and cannot repair failed Q4/Q5/Q6 gates. Report class prevalence and simple constant/logistic baselines along with AUC, logloss, calibration, and headroom capture.

## Interpretation limit

A success would support causal arbitration on the inherited synthetic address geometry, not establish natural-language persistent learning, biological equivalence, optimal forgetting, or independent policy training replicates. E2 seeding is selected on a successful promotion event by design; LOCAL-E2 versus LOCAL-0 helps describe that initialization contribution, but cannot make the selected seed statistic independent corroboration. The shuffled control tests event/object alignment relative to its chosen marginal-preserving strata, not a universal theorem that object-local evidence is necessary.


**Complete-state hashing execution refinement.** To avoid repeatedly scanning approximately 11 MB of unchanged buffers for every byte, the engine uses a complete Merkle representation of the physical state. Arrays are read-only during prediction; all ordered containers, counters, RNG and metadata are traversed. After the single authorized learner update, the changed base bank and fast rows refresh their leaves; new slow-memory array leaves are hashed directly. The cached root is checked against a complete uncached recomputation after every 14-byte record, in engineering and science. Full canonical component fingerprints are also checked at workload checkpoints. This changes verification cost only. Independent native replay must reproduce every physical component, event count and terminal prediction before science. Hash caches are execution bookkeeping, are not physical memory, and cannot enter a prediction or update.

Parent death is checked by each worker at checkpoint boundaries. A killed parent therefore costs at most the currently unfinished block before orphaned workers save and stop; a replacement worker waits for the per-cell writer lock. Top-level concurrent runners are rejected. Engineering replays also save both compared states every eight records. Diagnostic interruption is honored before and after each complete fitted fold. The pause-after-checkpoints option is a per-cell engineering aid, not a scientific stopping rule.
