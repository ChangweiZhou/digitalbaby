# Step 5: equal-write competitor-content crossover

## Claim, exposure, and scope

This is one small **E1 mechanism diagnostic** under the existing FE0 → four copied native Full151 output stores → one-byte argmax interface. It asks whether the *identity of the two competing question strings*, rather than the number or polarity of native writes, changes the learned `0+1=` margin. Every scored expression is explicitly taught its answer 12 times in exactly the frame later probed. A raw exact-key table can pass. No changed-presentation E2, unseen-sum E3, general addition, ten-digit alphabet, or learned stop claim follows.

The same V9.2 checkpoint, FE0, four output bytes `0`–`3`, raw-ASCII answer-byte router, `=` response point, 12 bouts, and 165-second record are inherited. The model's first response to each record is logged **before** its answer byte and native teaching. End probes use discarded read-only clones. No old trajectory is rerun.

## Frozen four-cell crossover

All panels keep `0+0=→0` and the focal `0+1=→1`. The class-2 and class-3 cues are crossed:

| Panel | Class 2 | Class 3 |
|---|---|---|
| A (00) | `0+2=→2` | `1+2=→3` |
| C (10) | `1+1=→2` | `1+2=→3` |
| D (01) | `0+2=→2` | `2+1=→3` |
| B (11) | `1+1=→2` | `2+1=→3` |

One excluded engineering schedule is 11500. Science uses **16 entirely new schedule identities** 11501–11516. For each identity, the same 48 cue-index permutation (each index once in every bout) is applied to all four panels. Thus the teacher-byte order is identical across panels: index `j` always has ASCII answer byte `48+j`. Each W branch delivers all 48 answers and performs **192 native plastic writes** (target `r=0` and three other classes `r=1` per record); each N control sees the same panel-specific byte stream, teacher calls and clock with native writes disabled. Fixed birth state, cue length, exposure count, target frequency and elapsed time are paired. Only the class-2/class-3 **question bytes** differ among panels. The intended output rule and teaching policy never change.

The 16 schedule identities are the inferential units, not 64 independent panel outcomes or 256 probes. They quantify schedule variation for these four fixed panels and checkpoint only. No pilot outcome is used to edit the design.

## Frozen outcome and decision

For each W end probe, the focal margin is class-1 value minus the largest value of classes 0, 2, and 3. The **sole primary contrast** is world-paired `B_margin − A_margin`, using the two-sided 95% Student-*t* interval over 16 paired schedules. If its variance is zero, inference is unresolved. The verdict is `CUE_CONTENT_INTERFERENCE_DEMONSTRATED` only if its upper bound is below zero, `0+1=` is correct in at least 12/16 A cells, and wrong in at least 12/16 B cells. Otherwise the verdict is `CUE_CONTENT_INTERFERENCE_NOT_DEMONSTRATED`; this does not establish equivalence. This rule is fixed before science.

The mixed C and D cells describe which cue replacement is associated with the change. Report their focal margins, all four individual answer accuracies, and the 2×2 interaction `B−C−D+A`, but do not promote post-hoc main effects or interaction to a new primary claim. Likewise report E0 KC geometry as prior context only: Step 3 measured minima 44/28 at initial state and 42/26 after a predecessor for A/B. No numerical KC-distance threshold qualifies learning; Step 8 already showed learned value can fail to transfer when codes remain near their own cues.

## Controls, audit, and next boundary

An excluded technical world must verify all four cue panels, identical index/teacher order, W/N birth equality, per-panel sensory equality, actual byte-derived teaching route, four writes per W record and none per N record, clock alignment, and probe nonmutation. The independent reducer recomputes fixtures, hashes, route and write ledgers, class-value argmax, focal margins, paired estimate, all-four-fact accuracies, source hashes, and tamper rejection. Technical or scientific execution failure stops; no automatic restart or replacement world.

This experiment cannot isolate FE0 from the Full151 synapses: changing question bytes necessarily changes their encoded addresses and subsequent value updates. If content matters at equal write count, a new label-free front end becomes a better-motivated candidate, but it must pass a **behavioral** crowded-E1 guard and a never-taught changed-presentation E2 test. Claude's target-only teaching policy is a distinct follow-up: it changes native plastic writes from four to one per record and must not be called an equal-write arm in this crossover. The eventual project promotion still requires E3 delayed reuse with a no-prior-teaching causal control.
