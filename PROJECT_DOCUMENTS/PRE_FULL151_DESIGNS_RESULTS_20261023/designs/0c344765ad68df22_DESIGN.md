**V42 — read authority on a fixed learning history**

This is a small, post-hoc counterfactual audit of the four existing V41 hybrid histories (seeds 41101–41104). It implements the recoverable chat recommendation: separate memory read authority from the fallback predictor, keep all writes identical, and avoid additional stateful trajectories where the saved data suffice. The complete latest brainstorming text and numerical protocol could not be recovered. The five-policy panel and reporting choices below are explicit refinements, not an assertion that every detail appeared in the unseen chat.

The overarching goal remains persistent non-Transformer learning from sequential byte experience. This round investigates a remaining obstacle inside the strongest V41 composition. It does not introduce a new representation, replay learner, admission rule, utility ledger, capacity sweep, or neuron-count reduction.

V41 established that READ-HYBRID shares SLOTS' exact writing history and achieves strong held-out retention. Its remaining ordinary-byte loss relative to SUPER is concentrated in authoritative exact traces and similarity reads from supported slots. V42 asks what each source of authority contributes when the learning history is held fixed.

| Policy | Exact consolidated slot | Exact probationary trace | Similar supported slot | No memory authority |
|---|---|---|---|---|
| READ-HYBRID | Memory | Memory | Memory | Recorded READ fallback |
| SLOT-ONLY | Memory | SUPER | Memory | Recorded READ fallback |
| EXACT-ONLY | Memory | Memory | SUPER | Recorded READ fallback |

The first four policies form two binary switches: exact-trace authority and similarity authority. Exact consolidated-slot authority remains enabled. The primary contrast is SLOT-ONLY minus READ-HYBRID, with SLOT-ONLY minus SUPER exposing any remaining loss/retention tradeoff. The other two switches identify the contribution of similarity reads. The arbitration rule uses only exact/type/authority information available before the next byte. Target labels, target-versus-ordinary categories, identity, cohort and exposure are evaluation fields only.

Disabling a category substitutes the original raw SUPER prediction on that category. In nonauthoritative situations, retain the recorded READ-HYBRID fallback, including its inherited zero-norm handling. SUPER is reported separately. Verify whether these fallbacks coincide in the saved aggregates; never silently assume equivalence.

**Exact evaluation from existing sufficient statistics.** V41 saved loss sums, counts and correct counts for READ-HYBRID and SUPER in common SLOTS-state strata, separately for target and ordinary bytes. Select the appropriate original predictor within each stratum and sum numerators before dividing. This exactly reconstructs the stateless policies' online loss and accuracy on the same history. It does not approximate an unobserved intervention on writing. Because the two switched categories are disjoint, the additive interaction is zero algebraically; this is not empirical evidence that two biological mechanisms act independently.

V41 also saved individual held-out probe outcomes. Certify by scanning every raw pre-byte context that the alias-2 rendering of every identity never occurred in training. Since the memory stores only observed contexts, alias-2 probes cannot be exact hits. An authoritative held-out probe is therefore a supported similarity read. This recovers E1, E2, delayed old held-out recall and the conjunction of E1 with held-out recall after B/C/D, preserving identity-level joins. In particular, SLOT-ONLY's equality to READ-HYBRID on those endpoints follows structurally from this workload; it is not a fresh generalization discovery.

Historical seen-alias probes lack enough logged type information for the same reconstruction and are omitted. Query final V41 checkpoints read-only to classify and verify after-D seen and held-out probes. These terminal classifications must not be applied backward to earlier checkpoints. Verify the complete learner fingerprints before and after these reads and reproduce the original READ-HYBRID and SUPER terminal outputs. Final current-cohort acquisition and old seen recall are separate from intermediate acquisition.

**Data and sample accounting.** Four reused histories contain 1,096 records and 15,344 byte presentations each: 61,376 historical presentations in total. Each history has 128 identities, 256 distinct target contexts and 272 distinct complete records. V42 adds zero training examples and zero learner updates. Reference preparation performs only raw-context scans and terminal inference. The runner embeds the resulting validated reference records and certificates, so one Python file and one command reproduce the counterfactual evaluation and reports without requiring the historical model files. It exports the reference inputs with their provenance for inspection. It does not regenerate the original V41 learning histories.

**Reporting and interpretation.** Show all five policies, all four seed values, loss by byte category, final seen/held-out recall, E1/E2, and same-identity E1 plus all delayed held-out probes. Attribute whole-stream differences to each read category and report both event counts and loss change per affected read. Report paired seed mean differences, pointwise Student intervals with three degrees of freedom, and exact two-sided sign-reversal sensitivity. The latter cannot attain p<0.05 with four seeds; a parametric test can do so under additional distributional assumptions. No byte-level pseudo-replication or claim of fresh statistical confirmation is allowed.

Do not select a winner with a newly invented qualification threshold. Describe the measured loss/retention tradeoffs. Confidence, agreement and probability-mixture policies require event score vectors that V41 did not log; they are outside this audit. The legacy 4,096-unit distributed predictor and its storage costs remain unchanged. Shared-history read substitutions do not establish standalone compute savings or a deployable general persistent learner.
