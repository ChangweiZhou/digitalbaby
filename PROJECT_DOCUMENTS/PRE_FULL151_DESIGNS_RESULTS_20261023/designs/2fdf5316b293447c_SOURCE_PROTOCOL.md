## 1. 目标与允许的结论

本方案分别测量：

- **存储组织规则的总作用**：同样的可塑容量，几何路由相对于固定哈希路由能改变多少高负载首次返回表现。

### 3.1 固定哈希路由的准确含义

原几何路由：对编码向量与八个冻结高斯随机中心比较，选最大内积地址；再沿原2/8分区映射分配。它保留一定输入几何关系，但不称为训练所得语义路由。

新路由：把**当前实际传入学习器的编码向量**序列化，和初始化密钥一起求SHA-256；取摘要首字节最低3位得到0到7的地址。再使用对应原路由层的2/8分区映射。相同世界的两个新臂使用相同密钥，因而保持2/8分区的嵌套关系。

序列化固定为一维、C连续、小端float64，带固定域标签和维度；把负零规范为正零，拒绝非有限数值。不取Python内置hash，不用对象地址，不量化、不舍入，不加入事件编号或时钟。不用世界ID、输入编号、配对编号、奖励、真值、阶段或未来频次决定运行时地址。

初始化密钥为32字节：`SHA256(UTF8("FB1-followup-route-v1|2026092201|" + panel + "|" + index的三位十进制表示))`。此处panel/index仅由外部调度器在初始化时生成并保存密钥；学习器只接收密钥、K及固定映射，不接收这些元数据，也不在事件中重算密钥。密钥计划在新成绩出现前全部冻结，不再更换。这里“独立随机分配”是固定伪随机密钥设计的操作性简称，必须披露这一实现。

同一世界只有一个哈希复制，目的是估计世界与路由抽样共同变化下的平均效果；不足以估计单一世界内的种子敏感性。不得把两个K或同一世界的查询当成路由独立复制。一个全局密钥的部署泛化不在结论范围内。

输入表中的完全相同编码必须得到相同地址；不得用评估器的输入ID强行拆开。批量与单行路由必须逐位一致。此对照破坏几何邻近性，当前结论仅适用于精确重复编码任务，不外推至噪声、缩放或相似输入泛化。

### 3.2 必须相同与必须承认不同的量

保持相同：原生B更新与读出、感知编码与解剖结构、共享适应与gamma状态结构、每银行快慢数组形状和dtype、K、衰减常数、物理事件序列、奖励与教学预算、每事件原生更新次数、未选中银行衰减次数、测试时点和阈值。

允许且必须报告的差异：地址算法、实际共同存储关系、银行使用率、目标对手碰撞率、实际写入量及其闭环后果、路由固定资产字节和运行成本。它们共同构成路由规则的总效果，不能解释为已经控制负载后的纯几何效果。

不得通过无用中心矩阵或填充数组做总字节匹配。比较匹配的是可塑记忆容量；部署总字节、路由密钥/映射、固定reader、临时空间和观察器另列。新旧路由各自按真实实现计费。

不按观察到的银行占用挑种子；空银行、负载失衡、同编码输入都保留。只记录而不据此替换世界。分阶段报告每银行教学事件数、不同编码数、查询数、`1/sum(p_bank^2)`有效使用银行数；无教学时记NA。按结果、质量或负载做的事后回归不能作为本轮因果主结论。

### 3.3 三个预定主要比较

用Y表示每世界原定义的首次返回正确率，且只使用`exposures=0`、未重新教学的规定查询：

1. `D2 = Y(几何2) − Y(哈希2)`。
2. `D8 = Y(几何8) − Y(哈希8)`。
3. `I = [Y(几何8)−Y(几何2)] − [Y(哈希8)−Y(哈希2)]`。

前两项测固定可塑容量下的路由总效果；第三项测资源扩大收益是否依赖分配规则。第三项的四个值必须在同一世界内先计算后聚合，不把两条旧区间直接相减。`I`不是纯隔离效应。

主要面板仅高负载：128世界，原四个路由层×八种轮换=32固定层，每层4世界。先做世界内配对差，再对32层等权；输出每层均值、方差、SE与Satterthwaite自由度。原路由层和轮换不变。

模块A主比较族alpha=.03，3个双侧Bonferroni区间，每项名义99%。它们仍是看过旧结果后提出的固定旧测试集扩展，不能宣称整个研究具有严格事前覆盖率或一次独立确认。常规面板及其他原指标只作描述，披露分母、效应与异质性，不补显著性星号。

对于D2、D8，预设实用差异阈值为±2个百分点：这是下一步决策尺度，不是假装由旧SD推导的真理。下限>0：该测试集支持几何优势；下限>2pp：支持超过实用阈值；上限<0：支持哈希优势。整个区间位于[-2pp,+2pp]才可称在本测试集上排除了超过阈值的平均差异；不能称机制等价或全是容量作用。其余状态未决。I只判断区间方向或未决，不套用容量归因。

方向证据与实用大小分两列报告。例如[0.3,1.5]pp同时支持正方向与小于2pp的差异，不得将两种结论当作互斥标签。A只估计既定旧世界集合及规定伪随机路由设计下的表现，不把区间解释为对任意新任务或任意部署密钥的保证。

新高负载世界64个：原4个冻结路由层×8轮换×每格2个独立世界；每世界8个独立新供体，共512供体。原世界生成规则、每事实教学预算及事件时钟保持不变。生成时排除全部历史世界、FB1全部1120供体及其种子/感知键/原始输入哈希，并检查本批内部重复。只做生成完整性检查，不按行为选世界。

### 4.2 目标与事件选择：不得挑“已经会”或“刚好遗忘”的例子

只由冻结的事件序列构造候选目标：有规定`reactivation_probe exposures=0`的目标对，且从最近一次目标教学结束到该首次返回之间存在外来教学。

按`SHA256("FB1-followup-target-v1|" + world_payload_hash + "|" + pair_index)`排序，选前2个目标，不按正确率、margin、银行位置或碰撞选择。顺序在两种K之间相同。若目标编码重复，仍披露并按实际编码处理，不换目标。

每个目标选择在上述间隔中、其首次返回之前的**最后8个外来塑性输入事件**；外来是该事件输入编码与目标的两个编码均不相同，不是仅pair编号不同。选择不看写入量、符号、路由或读出。每个目标不足8个时使用全部可用事件并输出数量；没有事件则该目标不支持，不选择替代目标。先对每目标的可用事件等权，再对两个目标等权；若有目标不支持，世界主要诊断标为不完整，不能静默重加权或另补世界。

“最近一次目标教学”是该目标任一相同编码最后参与教学的时刻，包含编码别名对应的教学；仅按pair编号定位会把同一实际输入的重教错当外来写入。目标不足2个也标记不完整。此事件选择使用未来序列信息，属于离线评估器的诊断抽样权利，不属于部署学习器的可用信息。

原生一个教学调用包含哪些输入事件，必须由资格检查确认并用 `(teach_index, physical_subevent_index)`标识；不能假设调用数就等于神经更新数。教学的目标定位只在评估器中使用。

### 4.3 准确干预：事件后读出影子，不建立长寿命保护分支

对选定事件e：

1. 正常模型照常执行一次完整原生事件。事件前评估器保存选中银行的快/慢向量；不改变实际状态。
2. 在实际事件后的状态上做正常目标纯探测。此时共享adapt/gamma、实际反馈历史、时间、路由、reader和其他银行均为正常值。
3. 克隆这个事件后状态，构造影子。如果本事件选中的银行属于目标两个输入的读银行集合，只将该银行的alpha快、慢记忆分别设为`pre_fast*exp(-dt/fast_tau)`与`pre_slow*exp(-dt/slow_tau)`；对应native scratch镜像保持一致。其他状态完全保持实际事件后值。如果银行不相交，影子与实际状态相同。
4. 立即用同一目标和同一评估真值探测影子，然后丢弃。真实轨迹从未被干预的实际状态继续，不从影子分支继续，不把影子写回真实模型。

源B更新满足`post_slow=(pre_slow+rawslow)*ds`及`post_fast=(pre_fast+rawfast)*df`。上述构造移除的是该事件最终经过B修正的完整alpha写入，保留正确物理衰减；不是禁止教学、把dt设零、只删原始未修正写入，或改变共享适应。

它是一个可能不由原生学习规则自然产生的受控影子状态，因此只识别**实际共享状态条件下的直接记忆读出作用**。不声称是“这个事件从来没发生”的反事实，不包含通过共享适应/反馈的其他路径，不测后续重学习、恢复或长期关闭写入的总作用。

所有无银行相交的零效果进入主聚合。仅统计有碰撞事件会造成选择偏差；条件碰撞统计最多作为分开的描述性诊断。

### 4.4 指标与推断

目标是一个输入对。沿用原生actual和fixed两个margin，定义联合判定余量：

`m = min(actual − 1, fixed − reader.pair_threshold)`。

每次干预`d = m(影子) − m(实际)`，正值表示该次实际外来alpha写入降低目标判定余量，负值表示帮助。先按上节聚合为每世界一个D值，再比较64世界的均值，不能把最多16个诊断事件当16个独立世界。

两个主检验是几何2和几何8各自的平均D。模块B族alpha=.02，两项双侧Bonferroni区间各名义99%，使用相同32固定层的配对分层t/Satterthwaite方法，每层2世界。下限>0支持预定窗口上的平均即时直接损害；上限<0支持平均帮助；否则未决。必须披露小层样本下的近似性与全部自由度。

辅助输出包括实际/影子正确率变化、正确→错误和错误→正确两种翻转、每世界正/负/零效应比例、银行相交率、目标起始是否正确、两种K差值。这些均不增加正式检验或支持长期损害结论；不得只展示损害，不展示帮助。两种K已经具有不同正常历史，二者诊断差不能解释为只改变K的一次同状态干预。

合计主比较5项：A的3项、B的2项。预算.03+.02=.05只是预定名义多重比较安排，不抹去A的结果后选题历史，也不保证小样本近似区间精确覆盖。零方差或任何层样本不足则标记未决/不完整；不因重复事件多而伪造精度。

## 6. 实现前资格门槛

以下是新实现完成后、任何新增正式模型轨迹之前必须完成的工程工作，不是本次已执行的测试。

1. 固定哈希测试：跨进程/重启、单行/批量、克隆/序列化、相同输入重复调用地址一致；不消耗学习器随机数；重复编码一致，未教输入也能路由；没有基于全世界输入预建部署查找表。
2. 原生事件测试：同一选中银行的非零状态下与原B更新一致；未选中银行每物理事件只衰减一次；有输入无塑性、空输入、长休息全部覆盖。
3. 原全局银行编号置换必须保持输出；“哈希确实改变共存关系”只做夹具证明，不要求每个正式世界达到人为差异阈值。
4. 影子测试：有碰撞时仅选中alpha银行改变；无碰撞时两探测完全相同；dt和共享状态一致；fast与slow一起处理；B修正增量与显式前态衰减恒等；目标两银行和相同编码情况都覆盖。
5. 观察器纯度：实际状态、源写入哈希、学习器随机数状态不因探测/克隆改变；开关诊断的短固定事件链必须逐事件一致。影子只接收克隆，不能获得回写真实模型的引用。
6. 复用接口：新指标可从逐查询真值独立聚合至同一分母；小型合成fixture检查旧/新摘要拼接；缺失位图的指标明确NA，不调用旧compare()强行重建。
7. 统计与报告：已知效应、帮助、零效果、零方差、缺层、缺目标、重复记录、乱序、部分写入都被正确处理；完整报告和ZIP用明确标注的合成统计fixture检查。
