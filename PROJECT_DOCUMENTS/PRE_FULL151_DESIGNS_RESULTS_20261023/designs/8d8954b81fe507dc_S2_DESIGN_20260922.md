## 1. 本轮只回答一个问题

当输入仍是按时间到达的原始字节时，给 FULL_151 增加多个有真实连接支持的输出地址及稳定、局部的教学通道，能否学会预测 **8 种结果字节**？主要因果比较是：在相同数量的输出模块、相同输入、相同可写状态和相同每事件教学总量下，**结果字节决定各模块教学信号的分配**，是否胜过将同样的教学量平均广播到各模块。

这不是重新解决 V50–FULL_151 已研究的通用写入冲突，也不测试 S3 的“预测误差教学”或 S4 的慢写门。第一阶段 S0 的 `S0-EPISODE` 是接入校准；S2 允许明确可见的短分隔字节，检验下一层多输出能力。S2 成功只支持“这个受约束的多输出接口在该字节任务有效”，不证明果蝇天然预测 ASCII，也不证明最小核心已经找到。

### 待区分的结果

| 观察 | 可支持的结论 | 不能推出 |
|---|---|---|
| 多输出明显胜过同规模广播，且胜过不学习 | 稳定的结果依赖教学地址有用 | FlyWire 指定的地址优于其他同规模地址 |
| 仅理想身份输入 FE-ID 有效，FE0 无效 | 输入接口在这项任务上仍是限制 | 多输出或原有写入规则无效 |
| FE-ID、多输出仍不学习 | 本次输出/教学组合未建立能力 | 所有多输出、所有塑性规则均无效 |
| 多输出与广播相当 | 未显示分地址教学的额外价值 | 输出容量已经充分，或某一机制被证伪 |

## 3. 字节输入与教学信号：只能使用可见的事件

### 3.1 连续输入协议

使用父实验的 F3 原始字节流、时间间隔、R8 世界、休息与挑战日程。在每条记录的结果字节前插入**一个可见字节 `0xF2`**，随后结果字节、换行 `0x0A`；训练和测试的每个模型都看到同一新字节流。`0xF2` 不在键、包装字符或结果字母表内，也不同于 R2 的 `0xF0/0xF1`。它是用户允许的短分隔符，绝不是传给学习器的隐含“结果位置”标签。字节间距沿用“30 s 除以该记录长度”，每记录总时长仍为 30 s，记录后沉默 135 s。

学习器公开 API 只接受 `(byte, time)`。它可以拥有一个**计入状态量的内部相位位**：读到 `0xF2` 时，停止为当前线索累积资格痕迹；紧接的下一字节经普通感受器输入后，同时到达教学投射；换行或沉默重置相位。若分隔符遗漏、重复或错位，不能根据评价器的记录结构自动修复。R8 的 `a`–`h` 可能出现在键中；**仅分隔符后的字节**可触发结果教学。该约定是可见语法先验，不是自行发现语法；要学习语法须另设实验。

### 3.2 线索资格痕迹

前端先固定为 S0 筛出的 **FE0**；FE-ID 仅作不可部署的输入上界。FE0 按每字节更新，KC 编码每字节现场计算。前 `0xF2` 的 KC 活动形成一个有界衰减痕迹 `e_k`（所有模块共享 KC 活动；模块 `c` 只有其真实可读/可写支持上的局部突触能利用 `e_k`）。`τ_e` 在正式锁定前从父 FULL_151 的 30 s 呈现窗口直接指定，**不得通过确认结果搜索**。具体离散式和更新顺序须写入实现锁；默认 `e(t_i)=exp(-Δt/τ_e)e(t_{i-1})+x(t_i)·Δt/30s`，`τ_e=30s`。在分隔符前冻结；结果到来时只用已形成的痕迹写入，结果本身不能倒流进入线索痕迹。记录后清零。`e` 是一个长度 5,177 的临时数组，完整计入峰值状态。

这一步改变了 S0 单次事件适配器的时间接口，因此需要桥接资格检查；若不能复现原始 K=1 情况，则只作 S2 新模型比较，不能声称它是 FULL_151 的精确延伸。

### 3.3 自监督的结果→教学桥梁

复用父实验固定的 256×88 感受器表 `R[b]`。在任何世界生成之前，用独立种子 `BYTE-CORE-S2|SENSORY-DAN|v1` 产生固定的 12×88 感觉→教学投射 `A`：每行不放回选 8 个通道，接触强度独立取 `+1/√8` 或 `−1/√8`；种子字符串的 SHA-256 前 8 字节作为 NumPy `PCG64` 的整数种子。令 `h_c(b)=Σ_j A[c,j]R[b,j]`，`μ_c=mean_{b=0..255} h_c(b)`，`σ_c=std_{b=0..255} h_c(b)`，`q_c(b)=sigmoid((h_c(b)−μ_c)/σ_c)`；`σ_c=0` 则资格检查失败，不补抽。每个模块因此得到 `q_c(b)∈(0,1)`，其中心与尺度只使用**全部 256 个字节的固定感受器表**。`q` 只依赖眼下实际到来的字节，不使用这个世界的键身份、目标答案、评价真值或 R8/R24 的专属索引。固定 `A`、`R`、`q` 及 R8/R24 码字的最小距离都存档；若码字重合或数值退化，报告“教学码不可识别”，**不重新抽种子**。

在结果字节时，各输出模块对自身支持上的 `e_k` 调用 FULL_151 同一 α3 原始更新和快慢分配规则，教学强度取 `q_c(b)`；其他时间不作结果驱动写入。各模块不看其他模块的预测，不做全局误差、归一化或反向传播。该投射是**实验规定的感觉线路**，并非真实果蝇已知能把任意字母识别成相应 DAN 信号。它检验“可感知结果进入局部教学通道”是否足以支撑多结果预测；生物真实性另需证据。

## 4. 预先固定的实验组

**共同条件：**R8/F3、相同世界和重放顺序、FE0（除 FE-ID 诊断）、8 个按上述顺序选择的图模块、同一固定字节→教学投射、同一资格痕迹、同一解码器族。只做一次模型选择：**K=8 对 R8**；不在 K=3/5/8/12 上择优。

| 组 | 操作 | 用途 |
|---|---|
| **S2-LOCAL** | 8 模块，各模块接收自己的 `q_c(b)` | 主候选；可部署字节前端 |
| **S2-BROADCAST** | 同样 8 模块及全部支持；每模块接收 `mean_c q_c(b)` | **主要机制对照**。每事件输入教学强度之和与 LOCAL 严格相等；损失的是稳定的结果地址 |
| **S2-NOWRITE** | 与 LOCAL 完全相同但关写入 | 学习必要性和读取偏置对照 |
| **S2-FEID** | LOCAL 的多输出部分不变，线索由理想身份 FE-ID 给出 | 不可部署的输入诊断上界 |
| **V50-REF** | 父 V50 字节模型，以相同加了 `0xF2` 的流重新运行 | 共同任务标尺；不沿用旧格式结果 |

FE-ID 只替换线索输入，不能传递结果、角色或真值。BROADCAST 的强度总和相等**不保证实际 KC→MBON 写入 L1 相等**：不同支持、前状态和非线性可造成差异。因此逐事件和全程记录真实写入 L1；若差异大于预定的 5%，不能把 LOCAL–BROADCAST 差异单独解释为“地址位置”，只能解释为完整教学策略差异。可追加非部署、逐事件写入 L1 配对的诊断，但不得回填主对比或替换主组。

R2 的 FULL_151 原生 α3/先天惩罚路线只用来做桥接和保持历史可比，**不算 R8 主组**。S0 原先的 `S0-STREAM` 既不被当作 S2 机制对照，也不用于推断先前写入冲突重新出现。

## 5. 读出、终点及判定

在每个结果字节出现**之前**保存各模块响应。工程观测器同步运行一个无塑性参照副本，计算每模块相对于该参照的响应差 `v_c`；参照只供读出，不反馈学习器，状态和计算量单列。固定结果码 `q(b)` 给候选字节一个分数 `s_b = -Σ_c [2q_c(b)-1]v_c/T`，在 R8 的 8 个结果字节上 softmax。方向符号沿用 α3 惩罚降低响应的约定；只允许在独立 CAL 世界上选择**每组一个**标量温度 `T`（继承父项目的网格与裁剪规则），无每模块拟合、无训练过的线性读出。若温度落在网格边界，明确报告不可校准，不扩大网格后重做确认。

主指标完全沿用父项目每世界的预测前相关信息压缩 `η`：R8 每次结果的分母是 `log₂8=3` 位，分子是相对均匀预测节省的位数。主要配对对比是 `η(LOCAL)−η(BROADCAST)`；必要性对比为 `η(LOCAL)−η(NOWRITE)`。与 V50、FE-ID 的差距和每阶段曲线必须报告，但不是选择最优参数的依据。原有稳定、异常、修订、休眠返回、误导提醒、七日返回均保留；每项按已交付结果和时间分层，另报最差世界、旧记忆尾部及首次返回。任何平均提升不能掩盖显著旧记忆损害。

**阳性标准：**在新鲜 CON 世界上，LOCAL–BROADCAST 的配对平均差至少 `δ=0.02 η`，且双侧 95% 配对区间下界 >0；LOCAL–NOWRITE 也须同样满足。两项作为同一家族用 Holm 校正 p 值；不把未调整区间冒充同时覆盖区间。若样本不足以辨认 `δ`，结论为**未定**，不能写成“无效”。达到两项只授予“多地址教学在该任务有效”的机制结论；若旧记忆返回或修订的预定差值显示实质损害，则不得写成实用改进。独立报告是否达到或超过同流 V50，而不设成机制阳性的先决条件。

## 6. 规模、运行顺序和停机条件

1. **资格检查：**2 个工程世界；检查下面的 Q1–Q10。任何失败先修实现，不看开发结果。
2. **CAL：**8 个独立世界，只选择每组的标量读出温度，锁定码字可识别性与动态范围。不得选择前端、K、图模块顺序、`A` 种子或教学剂量。
3. **PIL：**8 个独立世界，报告波动和预计计算/存储；不据此改变主对比和门槛。若单个世界资源超过预先申明的 Mac 限额，写明原因、停止，并发新版设计。
4. **CON：**64 个新鲜、配对世界，5 组，共 **320 个世界×组任务**。固定样本数，无看结果后追加。若 64 个仍不足以分辨 δ，如实判为未定。每个世界和每组单独缓存，可断点续跑；至少保留事件级完整性证书，最终交付小型结果包，不复制父数据或原始逐种子文件。
5. **R24 扩展（条件性、单独报告）：**只有 R8 的两个机制标准通过且无预定旧记忆重大损害时，使用前 12 个图模块、同一 `A` 和 FE0，固定 32 个**新的**世界，重跑 LOCAL、BROADCAST、NOWRITE、V50；FE-ID 只在 8 个诊断世界运行。R24 不调 K、不调投射、不调温度网格规则。它是迁移测试，不补救 R8 失败。

本设计的 R8 主确认量级是 320 个任务，而不是 S0 的 3,072 个。较少的样本意味着小效应可能未定；不能因成本降低而放宽结论标准。若 S0 最终表明 FE0 在 R2/F3 本身不能产生可分辨学习，仍可按上表运行 **FE-ID 的多输出容量诊断**；FE0 主组若运行，只能解释为端到端系统检验，不能把负面结果定位到输出层。S0 结果决定投入顺序与解释，不反向改写本设计。

## 7. 实现前必须通过的检查

| 检查 | 必须成立；刻意破坏版本必须失败 |
|---|---|
| Q1 输入隔离 | 学习器 API 仅 `(byte,time)`；键身份、结果索引、评价真值和记录边界字段传入会报错 |
| Q2 因果顺序 | 预测早于 `0xF2` 后的结果字节；调换两者要被记录/测试捕获 |
| Q3 分隔符 | `0xF2` 唯一且可见；删去、重复、错位时不能通过隐藏记录结构正确写入 |
| Q4 前结果痕迹 | 改变结果字节而不变前文时，结果出现前的 KC 痕迹及预测逐位一致 |
| Q5 教学码 | `q(b)` 只由固定 `R`/`A` 与当前字节决定；跨世界、跨结果字母表一致，码字可识别性存档 |
| Q6 原核心桥接 | 单个 MBON14/PPL106 模块在同码、同标量教学、同时间序列下复现 FULL_151 α3 原始更新；否则不得宣称严格继承 |
| Q7 对照匹配 | LOCAL、BROADCAST 每事件输入教学强度和相等，图支持、可写字节、线索输入与时间完全相同；真实写入 L1 单列 |
| Q8 读出隔离 | 观测器与 FE-ID 不反馈学习器；探针前后可变状态哈希一致；温度只由 CAL 锁定 |
| Q9 来源与世界 | 图、metadata、父代码、固定感受器表、`A`、世界流哈希锁定；CAL/PIL/CON 世界与父确认世界互不重用 |
| Q10 完整性 | 每个结果事件均有预结果预测、交付字节、时间、状态类别及写入量；丢一行会使整世界失败 |

## 8. 若结果为阴性，下一步怎样判读

- **FE-ID 有效而 FE0 无效：**转去改真实字节前端或其时间保持，不再把 R8 失败归因于输出数量。
- **FE-ID 与 FE0 均无效、码字可识别：**检查 S2 的局部教学/读出桥梁和原 α3 的尺度；不得直接改 S3/S4 或增加搜索维度。
- **LOCAL 与 BROADCAST 同样有效：**说明本任务可以利用多输出，但没有证据支持特定地址分配的必要性；不能称为解剖发现。
- **平均提升而旧记忆尾部受损：**只报告能力与代价的权衡，不晋级为持久学习核心。
- **正面通过：**下一轮可独立检验真实输出位点几何是否优于匹配支持重排；本轮类型级模块的阳性不自动具有空间生物学解释。
