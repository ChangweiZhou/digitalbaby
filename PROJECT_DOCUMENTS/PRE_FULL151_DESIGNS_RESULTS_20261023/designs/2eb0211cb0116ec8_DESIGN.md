# Step 6: Stable V9.2 context features into the protected Full151 value path

Step 5's fixed E1 assay found FE0 W−N +41.7 pp, but the V9.2
next-byte-distribution bridge ended at approximately zero W−N. The latter's
reversed-pair KC Hamming fell from 67.1 before teaching to 33.8 after six
bouts and 8.6 after twelve. Since every cue is followed by the same `!`, the
proposed failure mechanism is **prediction-target convergence**: the output
distribution becomes similar even when the four-byte contexts remain
different. This is a hypothesis generated by Step 5, not a proven cause.

This iteration changes only the input projection. The new H4 route takes the
two existing depth-4 hashed feature row IDs from V9.2's `_features()` at the
pre-outcome instant. A frozen, label-free mapping sends each row ID to one
of the existing 256 receptor vectors; their sum is peak-normalized and
mixed with native FE0 at gain 0.5. The mapping never reads predictor weights,
value labels, reward history, world ID, or the task answer. The byte
predictor still learns online and all three routes receive the same stream:
protected FE0, old next-byte-distribution Q, and new H4. Each route has
independent Full151 W/N native banks. No output fusion or router is added.

Technical world **9599** precedes science. It must establish bitwise FE0
standalone parity after every record, equal predictor weights/history across
all routes, native clock and teaching counts, W/N identical before teaching,
read-only probes, deterministic H4 row mapping, and nonzero birth H4 code
distance for each reversed pair. A failed technical gate stops the program.

Fresh science worlds **9601–9616** use exactly Step 5's cyclic three-byte
world rule, balanced six orientation labels, two-byte-delay 12-byte cue,
12 bouts/72 records, byte and record times, and pre/bout-6/bout-12 probes.
Every scored ordered cue is taught in W; N has the same sensory stream,
predictor updates, and teaching calls but no native value write. One world
is the statistical unit. All 16 run regardless of interim observations.

The primary endpoint is bout-12 reversed-pair choice. The H4 component gate
requires all of: (1) FE0 W−N two-sided 95% Student-t lower bound >0 as an
assay sensitivity control; (2) H4 W−N lower bound >0 and H4 W absolute
lower bound >0.5; (3) paired [(H4 W−N)−(Q W−N)] lower bound >0. Report all
absolute scores, margins, q/KC separation, and intermediate trajectories
even if the gate fails. Do not tune mapping, gain, stop point, or world roster
after seeing the science results. A scientific exception writes a failure
receipt and stops without replacement or automatic restart. Completed
receipts are never rerun. The runner uses caffeinate.

**Claim and exposure level:** This can show only E1 component acquisition
and a controlled improvement over the old Q projection on the exact taught
cues. An exact-key table could pass; there are no unrewarded target forms,
held-out relations, delayed interference, self-selected actions, or byte
emission. Positive results would justify a separately designed E2/E3 gate,
not a claim that the overall MiniFly objective is solved. The intervention
cost is two extra Full151 banks per world relative to Step 5, with 16 short
world receipts and no saved event-level stream.
