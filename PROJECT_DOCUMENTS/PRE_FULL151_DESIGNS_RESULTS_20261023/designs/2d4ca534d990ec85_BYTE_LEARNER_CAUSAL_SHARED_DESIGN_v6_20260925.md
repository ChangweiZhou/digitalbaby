# BYTE-LEARNER-1 v6：先资格试跑，再决定正式实验

**日期：**2026-09-25  
**状态：**预正式实验设计。本文取代 [v5](./BYTE_LEARNER_CAUSAL_SHARED_DESIGN_v5_20260924.md)；v5 与此前的[敌意审计](./BYTE_LEARNER_v4_SELF_HOSTILE_AUDIT_20260924.md)保留供追溯。本轮先实现并运行 Q，不启动 CAL/DEV/CON、140 条完整生命或正式文本确认。  
**项目目标：**让一只可修改的人工果蝇从连续到来的原始字符字节中学习，并逐步获得可用于 NLP 任务的上下文能力。可以改变输入器官、PN/KC 连接、教学、记忆和读出；每次清楚报告哪些部分仍由果蝇数据约束。字节接入本身不应被当成一个需要巨大容量的难题。

## 1. 三个不同的结论，不互相冒充

1. `BYTE_INPUT_VALID`：模型仅靠已到达的字节和时间形成因果状态；所有 0–255 字节能被感觉通道接收，输入中的 `0xF0/0xF1` 不会自行触发奖励。这是工程资格，不是学习成绩。
2. `BYTE_ASSOCIATION_LEARNED` 与 `BYTE_SEQUENCE_LEARNING`：分别证明模型学到字节线索的结果关联，以及在未见文本上利用超过极短上下文的统计。这两项可以先分开侦察，不能合并声称“同一只苍蝇”成功。
3. `JOINT_BYTE_FUNCTIONALITY`：同一个训练过的检查点，在没有重建共享核心的情况下通过两项测试，并报告相互干扰。这仍只说明共同字节接口和联合功能可行。一般 NLP 分类、理解或生成能力需要另锁实际语言任务；本轮至多给出 `BYTE_CONTEXT_FOUNDATION`，不直接给出 `NLP_READY`。

先做容易证伪的字节接入，再测可迁移学习。关联任务不成功也不取消文本试验；某个 F3 专用解析器成功也不替代文本试验。上一轮 FEAS-1 的结论仍是 `NO_CANDIDATE_SELECTED`；旧 FE0、FE-TAIL4、FE-ID 的 AUC 只指导工程排序，不能当新协议的成绩。[既有报告](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_FEAS_1_20260923/results/REPORT.md)

**本轮的明确边界：**先做可独立运行的协议层与 `TRACE88`/256 路文本头原型，运行一组小而有故障注入的 Q 测试，再做一次敌意审计。Q 的 10,000 字节可以取自本项目设计文档，记录文件哈希，并只用于时序、有限概率、恢复和吞吐；它不是正式语料，也不产生语言学习或关联成功声明。任何 Q 失败都应修实现后重跑 Q；不得把预试跑中的 AUC/BPB 当作选择正式模型的确认数据。

## 2. 一个共同的、无未来信息的事件协议

**感觉事件** `Byte(b,t)`，其中 `b∈{0,…,255}`；**教学事件** `Teach(r,t)`，其中 `r∈{0,1}`。在两项任务中，`Byte` 的所有取值永远是普通感觉数据。奖励是单独发生的教学事件，像真实强化信号一样可以与感觉通道并存；它不是字符 token、键偏移、标签预告或“文本/关联”隐藏模式。模型始终可以输出下一字节分布和关联价值，评价器只在预定位置读取相应输出。模型不得得到整条 record、未来字节数、预切好的键/词、cue ID、评分前的真实标签或文本 token ID。

在 F3，前缀、头和分隔符逐字节可见；**结果字节和 `Teach` 到来之前**读取关联价值。结果发生时，主协议的固定顺序为：先读关联价值及下一字节预测，保存结果前 KC 状态，再输入原始结果字节 `Byte(b,t)`，随后发 `Teach(r,t)` 并以保存的结果前状态教学，最后输入换行。这样教学不会抢先提示文本头要预测的结果字节。中性结果也有显式 `Teach(0,t)`，避免用“有没有教学事件”提前透露标签。F3 仍由真实结果决定 `r`，但评价器不得先扫描完整记录再给候选任何位置信息；结果事件在实际到达时发出。文本流只含 `Byte`，没有 `Teach`；即使 UTF-8 中出现 `0xF0/0xF1` 也如此。后续若希望把教学完全编码在同一物理字节通道，须另设计统一且转义安全的封包协议；本轮不偷偷切换语义。

**因果时钟：**标准 F3 的 context 是 12 字节，结果加换行后固定 14 字节（[源码](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_1_20260922/bytecore.py:312)）。预先设每字节固定间隔 `Δ=(30 秒×预先选定的 clock_scale)/14`；文本小试默认 `clock_scale=1`。此值不随当前记录长度或未来后缀改变。F3 换行后有原世界的 `135 秒×clock_scale` 无字节间隔，由下个 `Byte` 的时间戳体现；这不是隐蔽的重置命令。文本文件按 manifest 顺序串接；文件间亦用事先固定、可从时间戳看出的间隔，**不在内部文档边界清空状态**。独立测试流起始时，短时感官痕迹按事先规定的冷启动状态设置一次，持久学习参数从冻结检查点复制；任何测试源内不得再暗中重置。

旧 `present(record)` 对一般记录用 `episode/len(record)` 排时间，变量长度时会泄露未来长度（[源码](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_1_20260922/bytecore.py:949)）。标准 F3 恰好固定 14 字节，所以可以另做**遗留回归适配器**，以固定 `30/14` 间隔核对 FE0/FELAG 的结果前码、旧事件顺序和终态。正式主驱动则只按上述因果事件推进。旧 FULL_151 把 `event(30)` 用在结果时，这同时承担写入剂量和内部时间推进；Q 必须对相同结果前码比较 `event(dt=0)`、`event(dt=Δ)` 与 `event(dt=30)` 的状态变化，并报告能否把时间推进与写入剂量拆开。**Q 不替 CAL 选择剂量。**若主驱动改变该语义，须在 CAL 之前写一份固定实现合同，在新主驱动下重新跑 FE0/无写入对照；不能拿遗留适配器的旧 AUC 与新候选直接比较。

**Q 的硬资格：**同前缀、不同未来后缀在分叉点前产生完全相同的 `(b,t)`、状态与预测；文本和合成载荷内的 `0xF0/0xF1` 不误触发 `Teach`；任何预测都早于目标字节或教学；分块馈入与一次馈入相同；保存/恢复与不断点相同；F3 换行/间隔无隐藏 reset；遗留 F3 适配器单独通过数值回归；长度改变后早期时间戳不能改变；错误事件顺序、篡改恢复状态和错误目标字节各有至少一个故障注入，必须被检查抓到。比较使用明确的绝对/相对容差，不能靠散列恰好一致代替数值核对。若主驱动改变 FULL_151 更新规则，不把遗留终态逐位相同当作主驱动的通过条件。

## 3. 可跨两项任务使用的最小输入器官

主候选叫 `TRACE88`，只使用已见原始字节。固定种子产生 256×88 的字节向量 `E[b]`；设置以**字节数**计的 1、2、4、8、16、32、64、128 八个衰减尺度，参考间隔 `Δ_ref` 就是流开始前已锁定的每字节间隔。字节到来前，先把旧痕迹按 `exp(−(t−t_prev)/(sΔ_ref))` 衰减，并从这些旧痕迹给出预测；收到字节后再加 `(1−exp(−1/s))E[b]`。普通间隔下这等于常见指数追踪，长间隔则会使旧痕迹衰减，且新字节的输入权重不取决于未来长度。拼接八组痕迹，经固定、种子锁定的投射、非负整流与归一化形成 88 PN 输入，再进入果蝇来源的 PN→KC 稀疏编码。Q 原型用锁定的 NumPy 随机种子、标准正态 `E` 和按输入维度缩放的标准正态投射；若 Q 显示空码、异常重复码或数值不稳，只能在开发阶段改版并重跑 Q。正式 CAL 前须把种子、生成器版本、非负整流、归一化、零时状态和空 KC 码处理写入配置。初版不加整词表或结果查表；近邻字节顺序若在 Q 中明显丢失，可在 DEV 加一个固定短 n-gram sketch，并作为新版本重新锁定。

这一器官只约束**第一候选**，不是容量上限。若它在同码普通读出下也不能区分必要上下文，可在开发阶段试可学习 256×88 嵌入、小循环状态、更多 PN/KC 或新 PN→KC 连接；变更后要用新的确认数据。果蝇结构保留程度按 PN/KC 数、连接来源、可塑参数、固定参数和可塑状态字节逐项报告。

F3 专用的 `VISIBLE_TAIL4` 保留作**可见解析的工程阳性参照**：逐字节看到分隔符后，才可用此前缓存的载荷末四字节和真实时间戳生成输入。`HASH_TAIL4/HASH_CANON` 可在 Q 做便宜的接线诊断，但不进入主要确认预算，也不能被选作文本器官；整键哈希给新词任意新码。FE0 是共同历史基线，全部在相同新主驱动下重测。

## 4. 关联链：把主预算放在通用器官上

CAL 4 个世界×`FE0 / VISIBLE_TAIL4 / TRACE88`=12 条生命，只拟合并冻结各自概率读出及主驱动的预定写入剂量。DEV 8 个世界×3=24 条，用于锁定 `TRACE88` 的少量参数和读出，不用来挑一个 F3 特化冠军。只有 Q/DEV 通过时间、码碰撞和计算检查后，CON 才在 24 个**新**世界固定运行 `TRACE88 / 同码且同读出的 no-write TRACE88 / FE0 / VISIBLE_TAIL4`=96 条；另在预定 8 个世界运行 TRACE88 的结果拆配 UNP 对照。上限 **140 条完整生命**，但两链小试可在 CON 之前交错进行，避免先耗尽关联预算才发现通用字节器官不能预测文本。

主关联指标仍为结果前、已至少见过一次的正常 `side 0` AUC。`TRACE88` 在 CON 中达到 AUC `≥0.75`，且相对同码 no-write 的世界配对 ΔAUC 95% 下界 `>0.08`，才得 `BYTE_ASSOCIATION_LEARNED`。首次出现、全流、旧返回、修订、异常、side 1、UNP 和 F3 包装 2/3 的只读转移均完整报告；旧记忆必须在该 pair 首次 side-0 反馈之前评分，不能被当次再教学污染。延迟保留若只有方向性迹象，不另贴成功标签。若 `VISIBLE_TAIL4` 成功而 `TRACE88` 失败，只能得出 F3 可见解析有用，下一步应修通用器官；不得把两者拼成同一模型。

## 5. 文本链：先证明原始字节能被学习

文本从独立 UTF-8 文档的**原始文件字节**逐个输入，换行、空格和多字节字符都保留；预切词和词 ID 不进入模型。Q 在 10,000 字节上跑完整前向、256 类更新、存档/恢复、吞吐与峰值 RSS，再按实测锁定不超过 8 小时的训练预算；第一阶段目标约 0.2–1 MB 训练文本，确认文本至少覆盖两个独立来源的多篇整文。正式来源、许可、SHA-256、去重、整文/来源划分、顺序和字节数在确认之前写入 manifest。Q 可用少量本地文本，不能反复窥看正式确认文本来改模型。

先用 `TRACE88→KC→256 路 softmax` 作最小可学习文本头：在字节 `b_t` 到来**之前**，由已有 KC 状态 `x_t` 给 `p_t=softmax(c+Wᵀx_t/√k)`，其中 `k=max(1,活跃 KC 数)`，空码时只有偏置项起作用；评分后才看到 `b_t`，以当前字节的交叉熵梯度更新 `W,c`。初版只训练这个输出头，字节投射与 PN/KC 图固定；学习率从预先写入的小网格在 DEV 选一个，并锁定更新顺序、初始化和数值截断。若普通读出奏效而 FULL_151 式教学不奏效，可以改脑，但不得把普通读出冒称已验证的果蝇塑性。`W` 约 5.3 MB float32 权重只是接线量级；运行内存和吞吐由 Q 实测。

基线用同一训练字节：unigram、仅看最后两字节的 Markov2、以及最后八字节的递归平滑 8-gram。设 `p_{−1}=1/256`，空上下文的 `p_0(b)=(count(b)+α/256)/(N+α)`，更长上下文用 `p_n(b|h_n)=(count(h_n,b)+α p_{n−1}(b|suffix(h_n)))/(count(h_n)+α)`；`α` 仅在 DEV 小网格选择。另报告同参数预算附近的 PN-only softmax 及打乱训练字节顺序的控制。原 v4“同码普通在线头”与主候选若实现相同，就**不重复列成独立机制对照**。

**主要文本读数为冻结参数后的 held-out BPB。** 在测试流里，短时痕迹仍可随已到字节因果演化，但 `W`、投射和其他持久参数不更新；可另列所有模型都允许更新的 prequential BPB，绝不把两种读数混成一个。评价器离线按 Unicode 字符类别定义“内容字符”（字母、数字），把属于这些字符的**全部 UTF-8 字节**计入内容 BPB；再拆出 ASCII 字母/数字、UTF-8 首字节、continuation byte、空格/标点与词界。这个掩码只用于评分，不输入模型。`BYTE_SEQUENCE_LEARNING` 的初步条件是 `TRACE88` 在两个独立来源的内容 BPB 都低于 Markov2，且收益不是只由 UTF-8 continuation byte 贡献；须报告与平滑 8-gram 的差，即使 8-gram 更好。小语料的来源间方向性结果是工程证据，不冒充广泛 NLP 泛化。

一个轻量语言形状诊断可用词项和模板组合均留出的长距离主谓一致最小对：控制词在前文 32 字节以上，插入相反数的干扰名词，两个候选共享紧邻上下文，并平衡正确答案与字形/长度线索。比较同一冻结文本头对候选后续的条件概率，同时给 8-gram 与未预训练模型同题。它失败不否定字节接入或短上下文学习；它通过也只是语言迁移迹象，不自动授予 `NLP_READY`。

## 6. 一只苍蝇的联合检查点

侦察阶段可各自找部件，**联合试验中的每只苍蝇必须共享一套 `TRACE88`、PN/KC、持久状态和两项输出头**。预先固定训练顺序：同一实例先经过文本训练，再连续经历**一个** F3 世界的关联训练，期间不重置共享持久参数；文本头在 F3 字节上仍按同一逐字节规则更新，FULL_151 记忆只在实际 `Teach` 到来时写入。不同 F3 世界是独立重复：可以从同一文本预训练起点复制，但各世界各有自己的连续实例，不能把相互矛盾的世界硬接成一只超级苍蝇。任何可见前缀触发的学习门控必须事先定义，不能由评价器传隐藏的任务模式。每只训练完毕的苍蝇保存**一个联合检查点**。从该点制作只读评分副本，分别测旧关联线索的结果前价值和未见文本 BPB；复制仅为避免评分次序污染，不是为两项任务分别训练模型。同时记录 F3 阶段前后的文本 BPB 变化、F3 学习对旧/新关联的影响及模型状态字节。

先在 8 个新 F3 世界（即 8 个独立联合实例）及两来源短文本上做不作强结论的联合 smoke；若两链独立可行而联合失败，就定位表征漂移、写入互扰或读出冲突，再调整可见门控/局部塑性。只有再用另锁的独立世界与文本确认、并且**每个世界都从其自身的同一个联合检查点**同时评估前述关联和文本标准，才称 `JOINT_BYTE_FUNCTIONALITY`。即便成功，两个头可能各自储存信息；应通过冻结/重置某个头或共享塑性状态的定位对照说明记忆所在，不能凭共同架构宣称发现单一生物学习机制。若要称 `NLP_TASK_READY`，另需预先锁定真正的语言任务、训练/测试组合及对照。

## 7. 开跑前的锁与交付

现在可实施的是因果事件驱动、遗留 F3 回归适配器、`TRACE88`、256 路头和 10k 字节 Q。Q 通过后先写独立的敌意审计，核对检测是否真有机会抓住泄漏、断点偏差与奖励误触发。**各链正式确认开始之前**必须冻结该链的模型、种子、数据划分、指标和更新规则。具体地，关联 CON 需要锁主驱动对 FULL_151 的真实时间/写入剂量约定、CAL/DEV/CON 世界与概率读出；文本确认需要另锁语料 manifest、学习率网格、基线平滑、Unicode 评分掩码和测试冻结规则；联合确认再锁一个检查点的训练顺序与预算。Q 不通过就修接线，不能把驱动错误记作“飞脑没有能力”。

运行中保存必要检查点和在线汇总指标；不逐字节写 5,177-KC 稠密状态。最终只交付 <10 MB 的 `REPORT.md`、指标表、关键图、模型/配置、资格检查以及指向不变父资产的 manifest；不重复复制语料、旧归档、缓存或原始逐种子输出。负面结果按层报告：接线失败、F3 特化成功但通用器官失败、文本不能超短上下文、两项独立成功但联合互扰，各自是不同的下一步。
