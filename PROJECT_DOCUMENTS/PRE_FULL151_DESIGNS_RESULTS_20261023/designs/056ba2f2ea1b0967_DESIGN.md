# Step 4: Does ordinary-timed order create an FE0 alias the temporal route can resolve?

This is a no-label, no-teaching E0 feasibility census. It is not an adaptive
search for high-scoring examples. Enumerate all 325 unordered pairs of
distinct uppercase ASCII bytes A–Z. For each pair, present both orientations
in the inherited 12-byte V9.8 cue frame (`nine spaces + two symbols + space`)
at the inherited 30/14-second spacing, starting from the same frozen V9.2
checkpoint and native prestate. Each orientation is probed on a discarded
clone; the live state is never changed. Both branches use the protected dual
prototype: FE0 gain zero and V9.2 temporal bridge gain 0.5.

For every swapped pair, record FE0 and temporal KC support Hamming distance.
The exact-alias count is the number with FE0 distance zero. The useful-alias
count additionally requires temporal distance greater than zero. A strictly
FE0-safe output gate could only use the temporal branch on those useful
aliases; if there are none or very few, that gate cannot support a meaningful
behavioral order task at this timing. Count all pairs, not a selected subset,
and report the distribution. No reward label, task answer, world outcome or
readout margin is used to choose pairs.

Source and checkpoint hashes, native state purity, exact FE0 parity, and
finite nonempty KC codes are required. This E0 result cannot show useful
teaching, E3 reuse, or a combined output policy. A later behavioral task must
be independently specified and tested on fresh stimuli/worlds.
