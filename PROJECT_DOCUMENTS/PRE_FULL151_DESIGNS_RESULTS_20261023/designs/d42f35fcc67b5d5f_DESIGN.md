# Visible-context → Full151 persistence, fixed E1 scope

**Status:** source-freeze candidate. This is one functional bridge experiment, not an encoder search, capacity curve, E3 transfer task, or mechanism attribution study. No completed parent trajectory is rerun.

## Question, exposure, and countermodels

The question is whether native Full151 can retain **directly taught** byte→answer associations after four cohorts of further directly taught associations through the already qualified fixed visible-context input. The learner sees one byte at a time and emits one of `0`–`3` at `=` **before** the answer byte arrives. That answer byte routes the same four native fast/slow output stores as the completed 16-key bridge. All scored keys have received 12 reinforced presentations, except the old no-write acquisition control; this is E1. An exact four-byte-key table could pass. The fixed last-four-nonspace-byte encoder cannot establish E3 reuse, arithmetic understanding, natural-stream learning, or teacher-free learning.

The inherited 16 old `a+b=` keys use operands 0–3 and their sealed nine-fixed/seven-balanced-shuffled labels. Four new cohorts use four previously unused keys each: one new first operand from 4–9 per cohort, paired with second operands 0–3. Each new cohort has one of each answer label 0–3, assigned by a separate sealed world-specific permutation. All cues have eight leading spaces followed by exactly four visible bytes `a+b=`; their **effective** last-four-visible-byte keys are unique. All branches see exactly the same bytes, teacher bytes, timestamps, and probe opportunities. New cohort membership, labels, and 12-bout permutations are generated before any learning outcome is inspected. There is no feedback on a probe.

## Frozen architecture and timeline

Use the unchanged V9.2 Full151 checkpoint, the frozen `VisibleContextFE` and four native stores. Use the inherited opponent teaching rule (target channel reward 0, other three reward 1); each answer byte makes four native teaching calls when writing is enabled. No encoder, Full151, teaching-rule, or output-argmax parameters are tuned from this experiment.

Teach old 16 keys for 12 interleaved bouts (192 records, 165 simulated seconds per record), with `OLD_W` writes on and `OLD_N` writes off; probe at birth, old teaching end, and after a simulated 24 h rest. Clone the **same OLD_W state after that rest** into `WWWW` and `NNNN`. For each new cohort, both arms receive its 4×12 records and identical clock. `WWWW` writes all four cohorts; `NNNN` makes the same `Teach(write=False)` calls. At each cohort's start, a disposable `S_j` clone of that cohort's exact `WWWW` prestate receives only that cohort with new writing off. Probe old and acquired new keys at each cohort end, then advance all continuing arms a further simulated 24 h and probe all 32 keys before feedback. The 24 h intervals are virtual clock advances, not wall-clock sleeps. Probes use copies and cannot change continuing state.

## Estimand, gates, and stopping

The single primary estimand is the whole-world paired difference in final old-key emitted-byte accuracy, `WWWW − NNNN`, after the second 24 h rest. Its 95% two-sided Student-t interval uses **worlds**, never 16 probe items, as independent units. A zero-SD effect receives a point estimate but no zero-width inferential claim. The correct-class value minus the strongest wrong-class value is reported as a separate descriptive analog readout, alongside immediate-to-final trajectories and per-key losses. No outcome-dependent world extension or replacement is allowed.

Interpretation requires: `OLD_W` acquired the old set relative to `OLD_N` and remains above the 25% four-choice floor at the common prechallenge point; `NNNN` remains above that floor at the final point; each new cohort is acquired by `WWWW` from its exact prestate relative to `S_j`. Report every gate and its world-level interval. If a gate fails, label the persistence comparison `ASSAY_INSENSITIVE` rather than claiming protection. With gates satisfied, call a negative write effect only if the primary interval upper bound is below zero. A claim that average write cost is less than five percentage points additionally requires the primary interval lower bound above −0.05 and the final `WWWW` old-accuracy interval lower bound above 0.8. Otherwise report the estimate and `UNRESOLVED` on that operational bound. These conditions do not establish literal absence of forgetting. For a zero-variance world series, use a bounded 95% Hoeffding interval rather than a zero-width t interval.

The confirmation roster is exactly 64 fresh worlds 29701–29764; one full-chronology excluded technical world is 29600. The technical world is for code integrity, full-life timing, peak memory and receipt sizing, **not** outcome-based model or threshold selection. Technical integrity and an independent receipt audit must pass before confirmation. A scientific failure is reported, never repaired by changing cues, thresholds or worlds. Per-world receipts are atomic and an existing receipt is never overwritten or rerun. Runner stops on error; it does not restart automatically.

## Attribution and resource boundary

The fixed content encoder is a working positive control at 16 keys. This experiment tests whether the old association survives the stated **32-key, four-cohort workload** when new native writes are allowed. `WWWW−NNNN` attributes any contrast to those new writes under shared old learning and matched sensory/time history. The result cannot identify KC overlap as the cause of V9.5's finding: pairwise KC overlap is not zero and task, output, and workload differ. It is not an 80-key certification.

The full technical world must check the key roster, exact source/checkpoint hashes, W/N identical birth and common prechallenge state, exact output-before-teacher order, actual native write-call counts, same-prestate shadows, read-only probes, no answer-label leakage into the encoder, clock/flush equivalence, and positive finite output values. The independent auditor regenerates fixtures, verifies source locks, receipts, branch and probe rosters, argmax arithmetic, write ledgers, and final summaries; it does not claim to replay every Full151 numerical trajectory. Before confirmation, measure the full-life wall time and resident memory, then state the forecast. Cap the run at four wall hours and 100 MB of persistent results; if a cap is reached, stop, preserve completed receipts and report the exact count without shortening the science bank.
