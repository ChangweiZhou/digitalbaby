## Question and scope

V78's native adaptation-only recovery improved COMMON/day revision from 49/64 to
63/64 while increasing the end-of-pair net slow-write L1 proxy from about743 to
2696 and old-choice loss from6.71% to11.85%. These values motivate a confound test,
not a new allocator. Sources: unchanged `iteration23/REPORT.md`, frozen outputs,
and native EVENT implementation in `iteration18/src/model73.py`.

V79 asks whether recovered-adaptation write vectors have a consequential
structure beyond total slow-write magnitude **at a common lower budget**. It also
asks whether that structure resides between exact teaching routes/signs or
within them. The experiment cannot identify a persistent core by itself.

The Downloads V79 proposal is an input to review, not an instruction source.
We retain its dose question but omit `ADAPT_ALLOC`, fitted constants, optional
candidate stages and evolutionary search. Recovery changes the native raw write
already; multiplying allocation by adaptation does not follow from that fact.
No result here can promote a new learner or supersede the accepted reference.

## One donor trajectory and frozen slow-vector consequences

Each trajectory starts from one common native checkpoint. A native dense donor
advances for the assigned challenge. At each pre-bout state, create D and A
shadows. D is unchanged; after the first bout only, A receives

`a <- 1 - (1-a) exp(-900/tau_adapt)`.

This shadow transformation changes adaptation only, with no clock advance and
no decay of either fast state or slow state. It happens once per bout, not per
presentation or numerical substep. Each shadow then runs the complete inherited
30-s presentation /135-s rest /30-s presentation /135-s rest sequence, using
native feedback and plasticity internally. Record raw slow increments **before
decay** at every active event. Advance the donor only through D. No replay arm
can alter future donor vectors.

Replay seven slow accumulators from the same initial slow state:

| Arm | Inserted raw slow vector |
|---|---|
| D_RAW | Dense donor vector d |
| A_RAW | Recovered shadow vector a |
| D_GLOBAL_LOW | d scaled to min(||d||1,||a||1) |
| A_GLOBAL_LOW | a scaled to the same global budget |
| D_ROUTE_SHARED | d scaled within each exact route/sign bucket to its common minimum |
| A_ROUTE_SHARED | a scaled within each exact route/sign bucket to the same common minimum |
| NO_SLOW | Zero challenge slow increment |

For an active duration dt, replay `s <- (s+v)exp(-dt/tau_slow)`; rest decays s
analytically. At endpoints every replay branch receives the donor's identical
fast, gamma, adaptation and clock carrier, with only slow substituted. Thus
D_RAW must reconstruct the dense native donor, including output and clocks.
This is a frozen-source intervention on slow writes; it does not simulate an
autonomous A_RAW learner and need not reproduce V78's63/64.

The eighth arm, N_ADAPT, is the autonomous V78 N001 anchor: actual900-s gaps
between bouts recover adaptation and decay slow, while both fast states are
frozen over the gap. This has its own donor carrier. Its removed-challenge-slow
counterfactual replaces slow with naturally decayed initial slow while sharing
that carrier. Comparing it with D_RAW is a native spacing/surgery reference,
not an exact dose-controlled causal contrast.

### Exact anatomy, zero mass and certificates

Route identity is the exact row `(kc_side,T[:,2],T[:,3])` from this same frozen
specimen model, split by sign of the raw slow increment. No rounding, argmax,
binary support replacement, cross-specimen neuron join or cross-bucket borrowing.
For bucket b, shared budget is min(sum|d_b|,sum|a_b|). A route can reverse sign
under recovery; absent/opposite-sign buckets receive zero in both shared arms.
Record unmatched mass, zero buckets, coordinate sign flips, cosine, support
overlap, raw budgets and retained fractions. Zero common mass is a valid
zero-write contrast, not a failed history. Its information limitation remains
visible in the report.

All rescaling factors are between0 and1. No division by an epsilon or high-dose
amplification is used. There is no infeasible near-zero source extrapolation.
Global and per-bucket equality use tolerance `1e-10+1e-12*max(raw L1)`; actual
errors are saved. Sign/support and no-amplification are independently checked.
Report pre-decay event L1 separately from retained contributions and V78's
end-of-pair net L1 proxy; signed cancellation makes those different quantities.

**Interpretation limit:** A negative lower-budget contrast is not proof that
the complete high-dose recovery effect is dose-only. Route matching can remove
a legitimate route/sign computation; low shared coverage weakens that assay.
These controls are evaluator interventions using paired counterfactual states,
not a claim that flies perform global normalization.

Target endpoints are actual and frozen-reader margin (Hz) and joint correct
choice (both margins at least1Hz). Old memory excludes the focal old association;
NEW leaves all acquired associations in the old set. Preserve initial-correct

mean positive margin deterioration, and worst positive deterioration against
the corresponding removed-challenge-slow counterfactual at the same probe.
All replay arms share that counterfactual; N_ADAPT uses its own carrier version.
MIXED baseline learns the suffix, isolating challenge consequences. Save local
per-memory vectors for audit, but do not put them in the compact delivery bundle.
If no old association was initially correct, conditional loss is unavailable;
keep the assigned history visible and make any affected inference unresolved.

## Prespecified analysis and decision language

Average paired differences over loads and target ages **within history** before
inference. The16-test confirmatory family is two contrasts (GLOBAL_LOW and
ROUTE_SHARED), two endpoints (COMMON/day and MIXED/day), and four metrics
(target actual Hz, target joint choice, conditional old-choice loss, worst old
damage). Report A−D, where positive helps target metrics but harms old metrics.

Two-sided paired sign-flip p-values use65,536 Monte Carlo draws, seed7909003 and
plus-one correction; they are not called exact enumeration. Apply Holm over16.
Ten thousand history bootstrap draws with seed7909001 give marginal95% and
Bonferroni-family percentile intervals (quantiles.0015625/.9984375). These are
finite-sample bootstrap approximations, not guaranteed bounds.
The sign-flip analysis assumes symmetric/exchangeable history differences;
it is a paired-model comparison, not a randomized assignment experiment.

Diagnostic margins, fixed before outcomes:0.25Hz target actual,5 percentage
points target choice,1 point conditional old loss,0.05Hz worst damage. A vector
signal requires actual improvement at least0.25Hz, positive family lower bound
and Holm p<.05. Label it within guard margins only if choice's family lower
bound is≥−5pp and old-loss/worst upper bounds≤1pp/0.05Hz. Otherwise explicitly
label safety unresolved or harm. Mean-Hz benefit alone is not persistent-core
progress. This is a diagnosis, not a candidate acceptance criterion.

“No material difference at common low budget” requires all four family intervals
inside their symmetric margins. Otherwise report unresolved. No permanent
DOSE_ONLY conclusion or branch closure. Every label requires all32 histories;
missing/nonfinite constituents cannot be averaged away. Describe all five cases,
loads and ages, native anchors, raw effects, coverage and MIXED new learning.
Partial runs receive no final scientific verdict.
The guard labels concern the pooled REV contrasts only. They do not certify
STABLE, anomalies, NEW, each individual stratum or whole-learner safety.

The reused sensitivity panel repeats post-checkpoint presentations as either
one30-s event or three10-s events, retaining rest and probes. A REV contrast
changing direction with at least0.25Hz magnitude is a numerical/model-dependence
warning. This is not continuous-time convergence, a physiology refit or fresh
replication. A positive EVENT result stays conditional on that model.
The direction warning does not detect every same-sign attenuation; always show
both subdivision effect sizes and matched-budget coverage.
