# Output Step 2: causal byte-to-teaching interface

This is a bounded **E0 interface qualification with an E1 taught-cue guard**. It changes only the output-teaching router from Output Step 1. Four full inherited Full151 learners, FE0 input, fixed `=` prompt, one-byte argmax output, clocks, four two-letter cues, and 48 directly taught records remain. The fixed ASCII decoder maps an arriving byte `0`–`3` to one of four teaching channels. It is an engineered, externally supervised decoder: it is not self-supervision, native KC decoding of the teacher, arithmetic, E2, E3, sequence generation, or autonomous answer timing.

The world generator knows a randomized cue-to-answer permutation and emits a chronological stream of `(cue bytes, teacher byte)` records. The learner-training function receives **only that stream**, never cue indices, targets, answer-table metadata, or correctness labels. It must emit its first answer before the teacher byte arrives. Each copy receives the teacher byte as sensory input, then the fixed byte decoder routes a native `p=0` write to that byte's channel and `p=1` to the other three. A missing or out-of-alphabet teacher byte makes no teaching call or write. The newline and record clock still occur.

Each world has five matched branches. `W` and `M` receive the same true byte stream and writes; `M` carries deliberately wrong answer metadata outside the training function, so their entire learner states and emitted actions must match bit for bit. `N` receives the same true byte stream with native writes off. `S` receives the stream with only each arriving teacher digit cyclically shifted by one (`0→1→2→3→0`) and writes on. `SN` receives that shifted stream with writes off. The shifted pair separates teaching from sensory exposure to the changed byte. All branches have the same cue order, feedback count, number of native teaching calls, answer clock, and passive tail. Each scored cue was directly taught in the unshifted `W/M/N` stream; an exact-key lookup or a hard-coded byte-label mapping can pass. No result is promoted beyond E1.

The sole technical world is 11200. It checks first-choice-before-teacher chronology, exact `W=M` state/action equality, class sensory equality within each stream, clock and write counts, and missing/invalid teacher bytes causing zero teaching calls. New science worlds 11201–11216 are never reused from Step 1; each is committed once. No tuning on science outcomes, no replacement world, and no automatic restart after scientific failure. The checkpoint and inherited scientific code are referenced by hash, not modified.

The independent reducer reconstructs the fixture and delivered byte streams, checks every route and byte, output argmax, source hashes, receipts and technical negatives. The world is the inferential unit. The prespecified gate requires all structural checks; world-level two-sided 95% lower confidence bounds for `W` against true labels and `S` against shifted labels both exceed 0.75; and exact two-sided lower bounds on the proportions of worlds with `W>N` and `S>SN` both exceed 0.5. Zero-variance all-perfect accuracy uses the exact binomial lower bound over 16 worlds. Other zero-variance effects remain unresolved. All remaining metrics are descriptive. A failed gate is reported, not tuned into a pass.

The next separate question, after this gate, is whether a teacher target can be decoded from FE0/KC activity rather than from a fixed raw-ASCII decoder. That stronger sensory claim is deliberately not made here. Continuous output, compact compartments, and arithmetic also require separate tests.
