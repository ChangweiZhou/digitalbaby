# Full151 bridge write-route × read-route diagnostic, v1

Frozen before any science-world outcome. The preceding [behavioral comparison](../FULL151_BRIDGE_BEHAVIOR_20260927/REPORT.md) found that the fixed V9.2 predictive-PN bridge harmed Full151's synthetic held-out relation choice, already at the old-teaching endpoint. This study asks **which side of the native association matters**: coding at teaching, coding at retrieval, or their combination. It does not change Full151 plasticity, choose a new bridge gain, test arithmetic, or claim spontaneous output.

## Factorial and estimands

Use the same V9.8/V9.9A E3 generator, but only the old 144-record teaching episode and immediate `old_end` probe. Every world has six taught P–N pairings in both orientations and three pairings never reinforced in either orientation. The candidate receives only byte records, common binary teaching bits and clocks. The predictor updates online in all branches, as it did in the failed behavioral comparison. The positive control is FE0-at-write, FE0-at-read. The bridge gain is fixed at 0.5 and its frozen projection unchanged.

Each world has four training branches: `{FE0, BRIDGE} × {W, N}`, where W allows old native writes and N disables those writes while preserving the rest of the byte/teach schedule. At `old_end`, every branch is probed *read-only* twice, once with FE0 and once with BRIDGE. The resulting four paired prior-write effects are `Δ_T,R = choice(T_W,R) − choice(T_N,R)` for training route T and read route R. The displayed 2×2 table is:

| Write-time route | Read FE0 | Read BRIDGE |
|---|---|---|
| FE0 | `Δ_FF` | `Δ_FB` |
| BRIDGE | `Δ_BF` | `Δ_BB` |

The prospectively named localization contrasts are `write_cost_at_FE0_read = Δ_BF−Δ_FF`, `read_cost_after_FE0_write = Δ_FB−Δ_FF`, and the interaction `Δ_BB−Δ_BF−Δ_FB+Δ_FF`. Report two-sided 95% Student-t intervals over 64 worlds for each as **descriptive diagnostics**, without treating them as three independent confirmatory tests. The behavioral outcome is accuracy on the three never-reinforced pairs (ties score 0.5). Immediate taught-pair choice, signed value margins, the no-old-write baselines, read-code pair separation, and last-write-to-read code overlap are diagnostics. The previously observed diagonal `Δ_BB−Δ_FF` is reported for replication, not used to tune a threshold. World indices are fixed at 2301–2364; technical world 2299 is excluded.

Interpretation is conditional. If `Δ_BF` is low while `Δ_FB` is retained, write-time coding is the first target for repair; the reverse suggests read-time coding. If both cross-routes are retained but `Δ_BB` is low, their interaction is the main suspect. If both cross-routes fail, the experiment does not by itself identify a single cause. The bridge contains a V9.2 next-byte predictor, not a trained task-semantic encoder, and the predictor changes online during these records. This study does not separate fixed projection from online adaptation; it only localizes the functional route under that same regime.

## Exposure, controls, and limits

The three held-out pairings never occur in old teaching; no held-out feedback is delivered. Every symbol appears twice in taught pairings and is balanced by position. Exact raw/canonical pair caches cannot answer the held-out pairs; an acquired one-bit symbol class can. The analytic class decoder is an external solvability witness. The source-locked policy compares the two alternative orientations from the same full-state snapshot and returns `L`/`R` according to higher native value. The environment supplies the two options. This is a prompted two-choice readout, not a learned action head or free-running output.

The W/N pair within each training route is the causal prior-write control. Predictor digests and clocks must match across all training branches; write counts must be 144 or 0. Every read-route switch occurs only inside a discarded probe clone. For technical qualification, one fresh engineering world is run through this runner and through the already frozen preceding behavioral runner; the diagonal old-end pair margins must agree exactly. Also test source hashes, clone ownership, read-route restoration, frozen probe weights, no live-state mutation, fixture exclusion and receipt arithmetic. If any technical gate fails, no science world starts. A scientific exception writes a failure receipt and stops without automatic restart or world replacement. Completed world receipts are never rerun. `caffeinate` remains attached while the full runner executes.

Store one compact receipt per world, not event ledgers or model checkpoints. An independent reducer regenerates world fixtures, recomputes choice from pair margins/action bytes, verifies source locks and route/write/clock ledgers, and computes world-level intervals. A negative bridge result is a valid completed result. No threshold crossing permits an automatic new architecture search.
