# Step 8: training-only online output baseline

## Question and scope

Step 7 stopped because its fixed zero-threshold, two-store emitter did not meet the old **taught-cue** guard. Its pilot receipts show 48/48 correctly ranked taught orientation pairs, but batch-centering the *test* cues is evaluator assistance. This experiment asks whether a single learner-local scalar, formed solely from earlier prefeedback **training** margins, improves one-cue emitted-byte accuracy under the same 12-cue workload. The result is E1 only. It does not test any held-out relation instance (E3), arithmetic, autonomous timing, or a byte-derived teacher.

## Frozen source, exposure and intervention

Inherit V9.8 `make_e3`, Step 6's fading-pair frontend, Step 7's two copied Full151 stores, fixed `!` outcome, original bytes/times, W/N old-write contrast and two-channel opponent teaching. Each world has 12 balanced old trained cues presented in 12 balanced bouts (144 records), 24 h, then six disjoint new trained cues in 12 bouts (72 records), and another 24 h. The external Boolean label still routes the teacher; the predictor remains frozen. No held-out cue is probed. An exact-key table could solve the scored task, so the result cannot support a reuse/transfer claim.

For each branch independently, start with empty FIFO and `b=0`. At every training response point, before `!` and before teacher, read native values `v0,v1`, set `d=v1-v0`, and emit two shadow decisions from that **same native state**: raw `1[d>0]` and calibrated `1[d>b]` (tie→`0`). Next append this unlabeled prefeedback `d` to a FIFO containing at most the latest 12 records; set `b=mean(FIFO)`. Only then deliver the unchanged outcome, teaching calls and newline. The baseline never receives label, answer, correctness, cue identity, phase name, hidden class, or test-probe value. It does not change Full151 state or the teacher. During each probe stage, copy the native state and current `b`, emit each cue independently, and freeze `b` across the full probe stage.

Only the 12 old trained cues are probed at old-end and after the first day. At new-end and final, probe those 12 plus six new trained cues. W has old native writes on; N sees the same old stream and teacher calls with writes off. Both write on the new cohort. Probe responses occur before any feedback and do not mutate the continuing learner.

## Roster, test and stop rule

Technical world: **11900** (excluded). Diagnostic worlds: **11901–11932** (exactly 32). These IDs were checked against existing JSON receipt paths before execution. Freeze source/checkpoint hashes and this roster before the technical world; do not choose or replace worlds from outcomes. Run one complete excluded technical life to check fixture balance, clock, native-write parity, read-only output/probes, FIFO ordering, source locks and no held-out probe. After technical passage, run all 32 diagnostic worlds without an outcome-based pilot. An exception writes `FAILURE.json` and stops; completed worlds are never rerun. Use atomic compact receipts, not raw trajectories. Attach `caffeinate` to the active run.

The primary diagnostic is the mean across worlds of **final old-trained W accuracy, calibrated minus raw**, with a paired two-sided 95% Student-*t* interval using the world as unit. A positive verdict requires all of:

1. The primary interval's lower endpoint is greater than zero and its world variance is nonzero.
2. Calibrated W old-end old-trained accuracy ≥80% and final old-trained accuracy ≥70%.
3. The paired final old-trained calibrated W−N interval's lower endpoint is greater than zero, with nonzero world variance.
4. At new-end, calibrated W and N accuracy on the six new trained cues is each ≥65%.

All guards are conjunctive. Report every stage, branch, target set, output mode and class count even if the verdict fails. These are **new** headroom guards, not a retroactive alteration of Step 7. On failure, close this baseline candidate only. On passage, the result is still E1; any E3 trial needs a separate, prospectively locked protocol and fresh worlds.

## Independent receipt audit

An independent reducer must regenerate fixture identities/hashes from the frozen source and verify full world/phase/cue rosters, response times, every training prefeedback margin and FIFO mean, raw/calibrated output arithmetic, no probe update to `b`, write and teacher counts, native-state nonmutation attestations, stage metrics, paired intervals, guards and verdict. Tamper fixtures must reject changed training or probe output, FIFO baseline, cue, event omission, source digest and roster. It does not rerun any learner trajectory. A successful audit does not infer the unrecorded biological mechanism of an output offset.
