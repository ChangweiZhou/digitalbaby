# B/K/R V5 implementation refinement

User-authorized constructive tournament. Proposal: minifly_core_mechanism_tournament_design_v5_20260920.md. Prior A9 is complete; its generic, four shuffles and drop controls are historical evidence, not rerun. A9 open-loop versus closed-loop causal localization remains an unanswered distinct question, not a prerequisite for testing incremental K/R architectures. This tournament cannot identify unique feedback causation.

Eight arms and 1536 lifetimes unchanged. Formal FULL_151 remains untouched; B is the supported incumbent candidate. The cap abs(v_R)<=abs(w_K) fixes the prior relative-gate small-signal defect. R changes implementation when K is enabled; interaction effects describe conditional packages, not invariant modules.

Independent worlds: DISC 32 canonical+32 K8; CONF 64+64. Each K8 consists of eight newly generated, disjoint donor worlds; all 864 donors used once. Cyclic rotation i modulo 8 reorders donors before the inherited fixed_per_fact composition. There is no special scored/learner-visible target. Donors are from the same iid generator, so cyclic reordering preserves the unconditional sampling law. Outcomes are at the K8-life level; rotation is a descriptive stratum, never extra N. Historical exclusion explicitly includes A9 E3 and all discoverable reserved base worlds.

K uses native fast tau=3375.6200637 seconds, at each native subevent. One pair is 30 active,135 idle,30 active,135 idle. It is a short-time coordinate-sign filter, not a same-association or day-spaced corroboration oracle. Sign comparison is implemented as matching positive/negative signs rather than a product, to avoid subnormal underflow. No epsilon or learning cutoff is introduced. The source R gate is imported unchanged.

Provenance is evaluator-only sparse packed rows keyed by (association, revision epoch). It uses lazy exact exponential decay, proportional promotion/cancellation, and removes exact zero floating-point mass only. A proportional fraction is numerically bounded by one in the evaluator so roundoff cannot create negative attribution mass; its reconstructed state must pass the frozen 1024*eps*max(1,state scale) tolerance. Original-source timestamps and same-teaching-bout mass measure the effective lag. Epoch numbers are association-local, not a global truth/age label. Learner K sees none of these variables.

Evidence flags are nonexclusive: SINGLE_ANOMALY means delivered role differs from current truth; SAME_ASSOC_COHERENT is a later same-role teaching bout within the current epoch with delivered role matching truth; CONFIRMED_REVISION also requires epoch>0; UNRELATED_NEW is ordinary acquisition context; CROSS_ASSOC_CONCORDANT means this event promotes positive mass from another association. The latter is fundamentally coordinate-mass based. Summing groups is forbidden. Both raw denominators and promoted-mass fractions are retained. NONE of these labels gates B/K/R.

Reader: original backend only for formal outcomes. On independent clones, evaluate s+p reveal, zero alpha-fast, or zero slow; retain gamma/non-alpha states. Every read verifies parent state digest unchanged. Negative current-truth margins and fixed-reader margins yield the opposite-truth diagnostic at revision observations; final obsolete and untrained probes are retained. No latent diagnostic affects learning.

Endpoints: 9 canonical and 10 K8 including all mandated +24h/+7d endpoints, unchanged A8 extra extractors and native V88 metrics; exposure-zero return is computed from existing reactivation_events. Four simultaneous paired-t families with alpha=.0125 each: 63,70,54,60 contrasts. CONF only is formal. DISC, other metrics and factorial/conditional intervals are descriptive. Factorial effects use sum(sign product * arm mean)/4, so pair interactions are half a difference-in-differences. Zero variance without deterministic proof is inconclusive, not an exact no-loss finding. Categories list observed confirmed benefits/harms separately from formal incompleteness; incomplete vectors cannot be strict dominance. No data-dependent thresholds or sample changes.

Tail: already-informed currently relevant fact-checkpoints primary; all-informed, incoming, obsolete-truth and uninformed populations separate. Inferential unit stays world. World margin quantiles are averaged, not mislabeled as pooled quantiles. Strict dominance concerns mean endpoint vector only; it does not promise protection of every memory.

Qualification uses known E1 lives only. REF/B/R compare every native probe state and final state with original A8/Stage3B source paths. Pure K/R and cap tests, nonplastic decay, clone/resume, provenance reconstruction and source-gating checks precede the scientific lock. A packed sparse-row checksum bug was detected in an early pre-science fixture and fixed; no scientific outcomes were produced before the final qualification and lock.

Replay policy: deterministic same-world retries only, complete paired roster required. Sources, controls, world manifests, full exogenous event streams, scoring, statistics and this file freeze before DISC. DISC archive precedes CONF execution. Final-state archives are written atomically before receipts. Raw per-world outputs are kept in the project; compact bundle excludes them and unchanged parent assets. No separate A9 experiment or automatic model promotion.
