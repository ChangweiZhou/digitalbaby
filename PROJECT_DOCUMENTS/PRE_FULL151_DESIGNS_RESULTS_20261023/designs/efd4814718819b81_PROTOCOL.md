# Analysis scope and inferential boundaries

Written after schema/annotation inspection and extraction, before calculating the structural null results. This is an exploratory audit, not a preregistered study.

Use original positive anatomical counts. BANC snapshot identifiers and hemibrain identifiers remain separate. Primary DAN subset is the literal mushroom-body DAN class intersected with PAM/PPL1 type names. Preserve all presynaptic classes and unknown IDs in denominators. Raw coordinates are used in native units; do not infer a dopamine diffusion distance from them.

1. Replicate the per-neuron, type and receiving-territory input compositions and all-input external relay audit. Report the PAM/PPL1 restriction explicitly.
2. Extract direct and two-hop MBON→OTHER→DAN unsigned operators, with whole-export outgoing-count denominators. Compare spectra, and test whether indirect compression exceeds generic averaging under relay identity permutations matched by side and input/output-strength bins. These permutations preserve each leg's entries and its degree/strength distributions, but do not preserve each relay's attached upstream and downstream type identity.
3. Test direct count structure against two distinct nulls: fixed row/column count marginals (strength, not binary degree), and binary double-edge swaps (exact in/out degrees, with original edge weights randomly reassigned). Also test counts conditionally within source-type × target-type × side blocks, preserving each block's row/column count marginals. Do not call any one null a simultaneous exact degree-and-strength null. Save every null statistic and preservation checks.
4. Compare type-level direct and indirect routing across specimens. The supplied cell_type field and the native instance prefix sometimes disagree. Primary conservative grouping merges every ambiguous relationship in the curated matching table, including comma-separated alternatives. Compare with exact shared supplied base-type labels as a sensitivity, and separately restrict to right-sided annotations. Use row/column marginal-adjusted matrices and correspondence permutations restricted within PAM/PPL1 families. The resulting randomization p-values describe these two graphs, not biological population sampling.
5. Use hemibrain synapse coordinates to compare actual local DAN→KC terminal identity near KC→MBON sites against a neuron-level DAN→KC allocation. Condition permutations on the same recipient KC (preserving each DAN→KC count) and, more stringently, the same KC plus broad ROI. Ask whether site position adds MBON-specific routing information beyond those marginals. Deduplicate polyadic presynaptic sites for spatial queries; use unique connector–partner rows for connection counts. No claimed release radius, efficacy or sign.
6. Evaluate the proposed V53/V54 teaching-function comparison for identifiability. Do not invent a native byte→event-neuron mapping, measured neural activities, or signs merely to produce a benchmark number. A structural allocation result is not a successful persistent learner.

Report effect sizes, null intervals, Monte Carlo resolution, negative controls and mapping/coverage limitations. Use Benjamini–Hochberg adjustment within related test families, not neurons or synapses as independent biological replicates. Retain reproducible scripts, matrices, source hashes, and tables.
