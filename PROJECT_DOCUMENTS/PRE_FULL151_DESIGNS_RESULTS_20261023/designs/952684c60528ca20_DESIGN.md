# W4 bridge routing: one narrow E0 experiment

**Protocol candidate; freeze only after roster/source audit and before the pilot.** The W4 first implementation produced 0/32, 1/32 and 2/64 exact answers on never-taught operand pairs, with no extra exact answers from its native writer. Its raw answer learner refused KC input and the W4 action encoder retained only 32 active question KCs. The new byte→Full151 bridge showed causal KC access on four-letter contexts, but not on a complete W4 question. This experiment asks where information from that bridge reaches the *actual W4 choice interface*. It does not train arithmetic, repair punishment, or launch evolution.

## Claim and level

E0 only. A valid claim is that an earlier learned byte predictor changes (or fails to change) W4's native pre-`=` question code, its selected 32 action contacts and the native scores for the 513 grammar-valid answers. No correct arithmetic answer is supplied to any model; no output accuracy or E1–E3 claim follows. The unchanged V9.2 text checkpoint is an input asset. All parent code and W4 first-step results remain read-only.

## Exact time and routes

Start every question from the same reset-stream checkpoint. Feed W4's `\n<two-digit a><op><two-digit b>=` one byte at a time at `30/14` simulated seconds per byte, with V9.2 predictor plasticity off and no grade, answer, native write or decoder training. The action-time code is `native.pending_x` captured **before** `=` enters FE0, matching W4 `pilot_run._present_question`; measuring after `=` would answer the wrong question.

Four matched routes use the identical V9.2 checkpoint and inherited Full151 state: FE0-only (`gain=0`), intact bridge (`gain=0.5`), bias-only predictor lesion at the same gain, and fixed output-bin permutation at the same gain. The W4 `native_adapter._selected_question` supplies its exact 32 contacts. The W4 `action_code` and `score_candidates` score all 513 fixed answer strings from −256 through 256 on the same native state and time, with no raw model score. The native 513-way ranking is mechanistic evidence only; it is not a valid arithmetic answer strategy or correctness score.

Do **not** use W4's `NativeActionCreditAdapter.clone` with the current bridge. Its shallow brain clone leaves the bridged FE owner pointing to the original V9.2 object. Each probe instead restores a full snapshot into its own persistent `BridgedV92` owner; tests must show clone independence, no source-state mutation during 513-way scoring, frozen predictor weights and identical FE0/native state across routes before readout.

## Two diagnostic cohorts

**R — same-prompt route coupling.** Source-locked, previously unused W4-valid two-digit questions: pilot 1/operator, confirmation 16/operator (64 total). For each, compare intact versus bias-only lesion (and FE0/permutation) at the KC code, selected-contact set, fixed-candidate action code, full native score vector and native-only top answer. Primary descriptive quantities: counts of 64 questions for which intact versus lesion changes (a) the 32 selected contacts and (b) the 513-score vector by maximum absolute difference >`1e-6`. A decision heuristic of at least 48/64 for **each** quantity means the bridge reaches the W4 action encoder and native scorer often enough to justify a later behavioral interface test; it is *not* a learning result. Answers are ordered −256…256 with first-index argmax tie-breaking. Report top-answer changes with both top-1/top-2 margins; near ties do not count as robust choice effects. Permutation is an alignment diagnostic and can also alter contacts; it is not a negative control for mere discriminability.

**E — early-digit non-degradation fixture.** Confirmation includes three pairs/operator (12 pairs); there is no E pilot or inferential acceptance threshold. Within each pair only the tens digit of the first operand changes, while its ones digit, operator and both digits of the second operand remain fixed. Both questions meet W4's syntax and answer-range rules; division is exact with quotient ≥2 and multiplication product ≤256. Consequently the most recent four predictor bytes before `=` are identical by construction: the bridge cannot *add pair-specific first-tens information* at that point. Measure q equality, the PN and KC differences **immediately after** the changed digit by read-only `pn()`/`kc()` calls following that digit's `byte()` return at the same time, and at W4 action time the KC code, 32-contact set and fixed `0;` action code under all four routes. Report how many of the three pairs/operator remain distinguishable by contacts under FE0, intact bridge, lesion and permutation. Any loss is a concrete counterexample to first-digit sufficiency; even 3/3 cannot establish reliable retention. Exact equality of predictor distributions for E pairs is a required causal/timing control.

The maximum available valid two-digit multiplication E pairs is ten; only four remain after excluding **unordered operand pairs** from the three W4 development rosters, and at most three of those are mutually pair-disjoint. All R/E pilot/confirmation questions exclude those old unordered pairs and reuse no unordered pair across the new cohorts. The deterministic roster generator uses base seed `20260927` and records the full roster and source hashes before either run. No independent-life inference is attempted. All counts are descriptive at the question/pair level. Candidate scores, 5,177 KCs and 513 answers are **not** independent replicates.

## Exposure, countermodels, and failure interpretation

There is no new teacher, reward or learner update. Prior text exposure in V9.2 is retained; the arithmetic prompts are generated for this assay and their unordered operand pairs are excluded from the three W4 development rosters. An exact-key cache or arithmetic solver is irrelevant because no answers are scored. The positive control records both PN and KC differences just after the changed early digit arrives. The lesion isolates context-dependent predictor weights; FE0 isolates the existing receptor path. A bridge-vs-lesion difference on the same prompt is causal access, not evidence that text training was better than random features. If the early PN differs but early KC does not, localization is PN→KC thresholding; if early KC differs but action contacts do not, the loss is later in retention/selection. If R fails, the present W4 action pathway mostly ignores the bridge. If R passes, W4's wrong-direction punishment and absent KC-local answer learner still block a four-operation efficacy claim.

## Execution and audit

Generate and hash pilot/confirmation rosters before running either. The engineering pilot checks code path, exact timing, memory and controls; it is disjoint from confirmation. The pilot must stay below 60 s and 1.5 GB peak resident memory on one process, or confirmation does not launch. Confirmation runs once under `caffeinate`, writes compact per-question/pair receipts and a phase summary, and never rewrites a completed receipt. A separate audit checks roster validity/disjointness, source and checkpoint hashes, exact controls and aggregates; it independently recomputes prespecified sample items from snapshots without teaching. On failure, report the actual result rather than retuning or restarting. No full event ledger or extra W4 arithmetic life is produced.
