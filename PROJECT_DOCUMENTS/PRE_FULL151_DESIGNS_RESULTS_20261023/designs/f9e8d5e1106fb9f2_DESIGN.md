# MiniFly V9.10C — online shared pair-KC learner

**Prospective design, 26 September 2026.** One fixed online comparator tests whether the existing byte/KC interface plus the same teaching stream can support a reusable, bounded value readout on never-reinforced rank comparisons. It is an engineered diagnostic, not a biological mechanism claim or a replacement REF. The existing REF remains unchanged. V9.10A's eight-node external graph fit is not installed: it parses task symbols, reads extra counterfactual cue directions, and is unsuitable as a persistence model. A same-checkpoint batch graph fit from REF taught margins may be reported as a read-only diagnostic, never as scored fly behavior.

## Objective, level, and exposure

The primary endpoint is **E3 within the graded-rank family**: the old-teaching-end choice on eight unordered rank pairs whose two ordered byte cues never receive feedback, compared between a head with and without old teaching. A successful early endpoint permits testing delay/intervening learning; it is not by itself a persistent-core promotion. Eight random uppercase bytes carry hidden ranks per world; 20 unordered pairs, both orders, each occur in eight balanced bouts (320 records). Both head arms and native REF see identical 12-byte contexts, `!` outcome byte, label, newline, clock, and predictor updates. No head receives hidden ranks, held-out labels, held-out cues during training, a symbol lookup table, reverse-order scratch queries, or per-pair slots. The head's first answer on each held-out relation precedes any feedback on that relation.

The fixed head has one global `float64` vector `w` of length 5,177 (41,416 learned bytes) and no bias, momentum, optimizer cache, bank, per-symbol state, or task-specific parser. At each actual Teach call, use the pre-outcome `pending_x` captured by the existing byte brain for the **presented** ordered cue. With neutral target `y=+1`, aversive `y=-1`, and `w=0` initially, update only when this head's write flag is true:

`w <- w + 0.5 * (y - w·x) * x / (x·x + 1)`.

At a read-only probe, the head scores each ordered 12-byte cue by `w·x` using the existing KC interface; its pair choice is the difference between the two orientations. This is a shared linear value writer/readout, not a symbol-potential model. The frozen **encoder weights** remain unchanged, but its state-dependent code is not presumed time-invariant. No target-driven tuning after science-world scores is permitted.

Arms: native `REF_W` and `REF_Z` differ only in old native value writes; head-only `H_W` and `H_N` use the `REF_Z` sensory/native state with native value writes off in both, differing only in the head's old writes. All are scored at the same clocks. At the old-day state, each native branch forks into rest `R`, new sensory/no native write `S`, and new sensory/native write `L`. The head weights fork into `R`, `S`, and `L` for both old-head conditions; `H_*_L` updates on the same later 72-record disjoint three-symbol cyclic cohort, while `H_*_S` sees its bytes and feedback without head updates. All head queries use the no-native-write `REF_Z_S` sensory state for the matching stage. The inherited native REF arms serve as contemporaneous references, not as a source of the head's predictions.

An exact raw/canonical ordered-pair table can learn the 20 taught pairs but only tie (50%) on the eight withheld pairs. Position/frequency shortcuts have no fixed answer because positions, labels, and taught symbol degree are balanced. A rule derived from taught labels can solve the rank task; it is a positive solvability control, not an input to the head. The original three-symbol new cohort is cyclic and all its pairs are taught, so its score is an E1 **new-learning guard**, not a second E3 family. A scalar per-symbol potential cannot learn that cycle completely; the present head operates on full ordered-pair KC codes and may or may not learn it. Any durability interpretation after new learning requires observed new-cohort acquisition by the head relative to its no-new-write branch. Otherwise persistence remains unresolved; no new task will be substituted posthoc.

## Gates and interpretation

Engineering world 9905 first checks: clone identity; exact match of the custom one-record feed to inherited feed semantics; pending-KC code versus same-prestate read-only cue code at the correct time; finite nondegenerate code and updates; predictor digest identity across native W/Z; no-write label inertness; zero-write head remains exactly zero; query purity; held-out cue absence; clocks and write ledgers. Run eight disjoint pilot worlds 1851–1858 for technical/scale diagnostics without changing the rule. Then run the locked 64 confirmation worlds 1901–1964 without outcome-based stopping. The confirmed primary contrast is world-paired `H_W−H_N` old-end held-out choice, two-sided 95% Student-*t* interval. Report also `H_W−REF_W`, absolute choice, trained choice, and native `REF_W−REF_Z`; those are secondary. A practically interesting immediate candidate requires positive primary lower bound, at least +10 percentage points mean `H_W−REF_W`, and absolute `H_W` lower bound above 65%; these are gates for *further testing*, not a mechanism verdict. Report all failures, including if the engineered head underperforms.

At old day, after new-cohort end, and final day, report held-out choices and old-teaching causal contrasts, separately from exact taught-pair choice. The later `H_W_L−H_W_S` on new taught pairs is the new-learning guard; if it is not positive, do not claim resistance to new learning. The paired `H_W_L−H_W_S` on old held-out pairs diagnoses write-associated interference, while `H_W_S−H_W_R` diagnoses exposure/time under this schedule. These later contrasts are descriptive in this first comparator test. No head score is counted as native REF behavior. The full result cannot earn E4; a future prospectively withheld cyclic or other non-scalar relation family is required to test breadth.

## Freeze, audit, and cost

Before the pilot, hash design, runner, separate scorer, independent auditor, parent code, checkpoint, and objective contract. The runner writes only **canonical byte-order margins** and freezes their hashes; the scorer then reconstructs hidden rank/valence and scores them. The runner's head update API accepts only `(pending_x, label, write)` and never receives fixture structure or held-out truth. The independent audit checks source locks, world/arm/target roster, exposure, causal branch flags, raw-to-oriented arithmetic, all summaries, and bundle size. World is the statistical unit. The compact bundle contains only this design, scripts, final metrics, report, checks, and a manifest of unchanged parent assets (<10 MB); no checkpoints, source datasets, per-record trajectories, caches, or parent archives are copied.

The previous V9.9C 64-world run took 920 seconds; this run reuses much of its schedule but has different probes and a new head, so engineering preflight supplies the actual runtime estimate. Pilot and confirmation may be resumed world by world. A technical failure stops the run rather than silently repairing rows.
