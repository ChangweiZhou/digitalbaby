# MiniFly V9.10B — single-write causal transfer map

**Prospective bounded diagnostic, 26 September 2026.** V9.10A found that an external task-specific graph fit can aggregate REF's taught-edge outputs, but it cannot tell whether a native write transfers useful value to other cues. V9.10B measures that transfer directly by comparing two clones of the **same pre-event fly state**. It does not introduce a new learner, tune a mechanism, or claim a new persistent core. The native write switch can change multiple original state components, including gamma and alpha; the assay measures their *combined* single-event effect.

## Fixed intervention

Use the unchanged V9.7 `REF`, V9.2 checkpoint, and V9.9B ranked-byte fixture. Engineering world 9904 and four independent diagnostic worlds 1801–1804 are disjoint from earlier science worlds. For every world, define two prestates: `early`, the untouched parent at the first old record; and `late`, the same fly after the first four V9.9B old-teaching bouts (160 records) with native writes enabled. The late state is built once per world. At each prestate, examine **all 40 taught ordered cues** (20 undirected edges, both orientations), in ascending raw-byte order. Each candidate is separately applied to fresh clones, so candidate tests do not accumulate or affect one another.

For a candidate event, clone the identical prestate to `ON` and `OFF`; feed the same 12-byte context, outcome byte, newline, label, and clock, changing only the native write flag. Probe both clones at the same post-record time, on read-only scratch states. The causal impulse for an unordered target `(u,v)`, `u<v`, is

`K(u,v; event, prestate) = [V_ON(v,u)−V_ON(u,v)] − [V_OFF(v,u)−V_OFF(u,v)]`.

Calculate this in **canonical byte order**, without looking at the never-taught target's true rank or outcome. Also record the event's own taught-edge impulse, write-induced fast/slow/adaptation state norms, and frozen-KC cosine overlap between the event code and both target orientations. The response is not assumed additive across events. A separate scorer, run only after the canonical impulse table is hashed, can orient effects by the hidden rank for interpretation.

Each phase has 40 cloned interventions × eight never-taught target edges = 320 directed event-to-held-edge measurements per world. Both phases and four worlds give 2,560 target rows plus 320 event rows. All 40 candidate records have prior feedback in the `late` phase; no never-taught edge receives feedback at any point. The `early` phase probes one-event generalization from the parent. `ON−OFF` shares the entire sensory stream and prestate, so it isolates the event's native write flag, not time or exposure. It does not isolate a molecular or anatomical site.

## Interpretation and controls

The first output is a descriptive impulse map, not a full-life connectivity matrix. Report per-world averages before pooling, separately for `early`/`late`, aversive/neutral candidate labels, targets sharing one byte with the taught event versus sharing none, and absolute as well as truth-aligned effects. The within-event shared-minus-disjoint comparison controls the event's write magnitude and state; KC-code overlap is reported so shared-symbol effects are not automatically labeled relational. Record the taught-edge self effect as a positive-control diagnostic. With only four worlds there is no promotion or general null test; any interval is exploratory. A useful sign on some impulses does not imply a stable additive `I + A_rel + E_nuisance` decomposition or lifetime protection.

Technical gates: exact clone-state identity before every intervention; identical predictor digests after `ON/OFF`; one-flag ledger difference; no-write label inertness on early and late prestates; query purity; finite KC codes and impulse values; identical post-record clock; and a numerical zero check using two `OFF` clones in engineering world. The engineering world profiles the full 80-intervention schedule; a technical failure stops the diagnostic. No outcome-based stopping or event subset selection is allowed. The separate scorer checks the analytic task controls: raw/canonical exact-pair lookup 0.5 on never-taught edges; a rule based on taught labels can solve them, but is never installed.

The compact result bundle contains design, scripts, event and target final metric tables, score summaries, acceptance/audit checks, report, and manifest referencing unchanged parent sources and checkpoint. It copies no brain datasets, prior archives, caches, or full state snapshots. Target <10 MB.
