# Step 10: single-store E3 value drives an emitted two-option choice

**Prospective protocol, 27 September 2026. No Step 10 outcomes have been inspected.** This is a narrow output-interface bridge from V9.9A, not a repair of Step 9 and not a realistic free-response task. Its E3 claim, if any, is confined to V9.8's synthetic symbol-class relation with two externally supplied alternatives and a fixed response point.

## Question and attribution

Can the **unchanged V9.9A REF/FE0 single native Full151 value store** causally use prior teaching to emit `L` or `R` on never-reinforced pairs, after 24 h, disjoint new teaching, and another 24 h? V9.9A's evaluator compared the two native values and found a +17.19-point final held-out W−N advantage. Here a fixed, label-blind choice organ receives option 1 and option 2 in sequence, retains the first option's value in a one-scalar working trace, and emits the side with the greater value. The scorer sees only the emitted byte. This deliberately tests the *connection from a known value signal to an output action*. Because the comparator uses the same relative value operation as V9.9A, a positive result is mainly an **interface demonstration and fresh-world replication**, not a new memory mechanism. Step 9's two-store, opponent-taught single-cue architecture is not used.

The environment provides two alternatives and their boundary; the learner does not decide when a question is due, generate a candidate answer, or infer the correct side from natural text. This is a T-maze-like bounded choice, not `1+2=3`, natural dialogue, self-derived feedback, or broad E4 competence. The working trace and comparator are fixed engineered structures and do not learn. Their biological plausibility is a hypothesis, not an outcome.

## Exposure and countermodels

Use `make_e3(world)` unchanged: six old uppercase symbols in randomly assigned hidden P/N classes; six of nine P–N edges taught in both orientations over 144 records; three edges withheld in both orientations; a 24-hour gap; 72 records on three disjoint new symbols; another 24-hour gap. Every old symbol is taught in both positions, and both answer orientations are balanced. No held-out ordered pair, wrapper, or answer is reinforced. An exact-byte or canonicalized-pair recitation table has no held-out pair answer. A constant `L` or `R`, option-position bias, and exposure-independent symbol frequency have 50% accuracy because every probed pair is presented in **both** orders. A one-bit class rule inferred from old teaching can solve the family and is a legitimate but narrow E3 explanation.

W and N start from the same frozen V9.2 checkpoint. They receive identical old/new bytes, outcome `!`, labels, teaching calls, and clocks. Only W permits old native writes; both permit new writes. The engineered predictor runs in both as before and cannot supply the scored action. At each probe, the choice organ reads a read-only snapshot of that branch's native value state. Option 1 arrives as 12 bytes; the organ records its value, consumes a literal `|` separator, then receives option 2 as 12 bytes and a `?` response marker. Option 2 is read at its **later** presentation time, from the same starting learner snapshot. The organ emits `L` when value 1 is at least value 2, otherwise `R`. Resetting the cue reader at `|` matches V9.9A's separate cue probes but is an explicit artificial interface assumption. The organ receives no label, pair ID, hidden class, or correct-side flag. The scorer checks the emitted byte against the neutral option's side only **after** emission. Both orders of each pair are probed on independent read-only copies; no probe output or label updates the continuing learner.

## Roster and gates

New technical world **12200** is excluded; trained-only pilot worlds **12201–12216** are excluded; confirmation worlds are exactly **12301–12364**. These IDs are disjoint from V9.8, V9.9A, Steps 7–9 and their receipts. Lock this design, runner, output organ, independent auditor, inherited sources/checkpoint, and exact rosters before the technical world. No completed world is rerun or replaced. A scientific exception writes `FAILURE.json` and stops. Use `caffeinate` during each active runner.

The technical world checks fixture balance and held-out nonexposure; identical W/N birth states, predictor digests and clocks; output-before-feedback; two ordered option presentations per pair; organ state reset and read-only nonmutation; and exact agreement of each internal value with an independent **matched-time** separate-cue reference. The 13-byte presentation offset may change results slightly from V9.9A's simultaneous probes; any difference is reported rather than hidden. An independent audit and tamper checks must pass before the pilot.

The **pilot never presents, computes, or inspects held-out option outputs**. It probes six old trained pairs at old-end and old-day and, additionally, three new trained pairs at new-end/final. Pilot gates over 16 worlds are conjunctive: W old-end trained choice ≥80%; W final old-trained ≥70%; W−N final old-trained ≥10 percentage points; W and N new-end new-trained ≥65%; all probe and exposure integrity checks pass. If any fails, stop before confirmation and make no E3 inference.

Confirmation recomputes those trained guards on the 64 fresh worlds. It also probes the three held-out pairs, in both option orders, at old-end, old-day, new-end and final, with no feedback. For each world, the primary score is mean correct emitted choice across the three held-out pairs (equivalently six order-balanced outputs). The **sole inferential primary** is final W−N world-paired accuracy: a two-sided 95% Student-*t* interval must have lower bound >0 with nonzero variance. Final absolute W held-out accuracy must be ≥60%, and the trained guards must still pass. If any fails, verdict `E3_OUTPUT_NOT_DEMONSTRATED`; if all pass, `LIMITED_E3_EMITTED_CHOICE_SUPPORTED`. Earlier stages, value margins and option-order effects are descriptive only. The scientific unit is world, not emitted byte; no optional stopping, arm search, or post-hoc threshold tuning is allowed.

## Independent audit and downstream boundary

Write one atomic receipt per world: frozen source/fixture hashes, chronological teaching ledger, predictor and clock attestations, emitted byte and scorer result for every ordered option pair, organ value telemetry, and read-only state attestations. The independent reducer regenerates fixture rosters and labels, checks that the organ was given no answer, recomputes every emitted side from values, verifies both option orders and all reported metrics, and rejects altered/omitted rows, wrong labels, source hashes, or output bytes. It does not rerun learner trajectories. Pilot and confirmation remain separate and no held-out pilot result is generated.

If this succeeds, it shows that V9.9A's previously observed narrow transfer signal can drive an **internally selected byte** in a two-option setting. It does **not** explain Step 9's failure or establish that a fly can respond to an unbounded single expression. Subsequent attribution may separately compare FE0 with fading-pair input inside one fixed output geometry, but that is not part of this run. Arithmetic fact capacity and multi-byte generation remain separate questions.
