# BYTE-LEARNER-1 v4：连续字节输入与 NLP 就绪路线

**日期：**2026-09-24  
**状态：**修订实验设计；尚未实现或运行。本文取代同目录的 `BYTE_LEARNER_OUTCOME_FIRST_DESIGN_v3_20260924.md` 作为下一轮方案；旧稿留作追溯。  
**唯一项目目标：**让人工苍蝇从按时间到来的字符字节中学习，最终能在 NLP 任务上利用这些字节。输入器官、脑连接、塑性和读出都可修改；生物相似性不是通过条件，但每次应说明保留了多少果蝇来源结构。

## 1. 不再把接线问题当成语言能力问题

让模型**接收**字符字节只需有限状态的字节协议、最多 256 种输入符号、短程/多尺度状态和一个可学习的接口，不应因“全脑容量不足”而卡住。真正不确定的是：这些字节经过 KC/教学/读出后，能否形成可复用的关联、跨字符组合和较长上下文预测。不能从一个 6 字符键关联成绩直接宣布“会 NLP”，也不能因为这个关联任务失败就说 5,177 KC 容量太小。

本轮同时建立两条**共享同一原始字节 API**的证据链：

1. **关联链：**连续字节 → 果蝇来源学习核心 → 重复字符线索的结果前行为。它确认连接真正接通，保留和迁移可测。
2. **NLP 链：**未经词切分的 UTF-8 文本字节 → 多尺度字节状态/KC → 逐字节预测，继而做需上下文的文本选择。它检验输入是否能支持组合与预训练；不能只靠整词哈希通过。

两条链都必须推进；关联链未通过时不能取消 NLP 链。上一版的 `HASH_TAIL4/HASH_CANON` 可以是**快速接通候选**，但整词或键哈希给陌生词任意新码，不能充当 NLP 编码器的唯一方案。上次 LAG-vs-BAG 排序实验和解剖 motif 解释不占主预算。[先前审计](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_NEXT_STAGES_20260922/BYTE_CORE_2_v2_SELF_HOSTILE_AUDIT_20260923.md)只作为设计约束。

## 2. 一个真正共享的连续字节接口

候选只能逐次收到 `(byte,t)`；不得收到预切好的 `record`、`cue_id`、键起点、真实标签、未来长度或文本 token ID。模型可从流里**可见**的分隔符和长度字符解析边界。输出必须在要预测的字节或结果到来**之前**取值。驱动不得先扫描完整记录再告诉候选事件位置。标准 F3 上，新的逐字节驱动须与旧 `present(record)` 的 FE0/FE-LAG 结果前码、事件顺序和最终状态核对；不等价先修驱动，不把桥接错误当学习失败。[原驱动](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_1_20260922/bytecore.py:949)。

关联任务可把结果编码成流里可见的特殊控制字节；**在 NLP 文本任务中所有 0–255 字节都属于普通文本数据**，不把 UTF-8 内部的 `0xF0/0xF1` 误识为奖励。关联任务若测试任意 UTF-8 载荷，应使用可见长度封包或转义，使教学标记只在载荷结束后生效。奖励是教学事件，语言预训练的目标则是**下一个实际到来的字节**，两者共享感觉路径而不必共享同一个输出头。

字节传入的基础预算可以很小：一个 256×88 的 float32 字节嵌入约 90 KB；128 个原始字节的滚动缓存仅 128 B；若增加 256 个 KC 读出，5,177×256 个 float32 权重约 5.3 MB，还可先试 32–64 维低秩头。这些只是结构量级，**不预言广泛语言知识所需容量**。若需超过原 88 PN 或改 KC/MBON 数量，允许用新世界检验；不设“原图必须原样保留”的人为门槛。

## 3. 关联链：最快证明飞脑能够学到字节线索

沿用 R2/F3 世界和 FULL_151 作为起点，候选仅见逐个字节。既有量级供排序优先级：旧确认 F3 中 FE0 AUC 约 `0.613`，评价器告知键偏移的 FE-TAIL4 约 `0.772`，身份 oracle FE-ID 约 `0.845`，不同学习器 V50-REF 约 `0.802`；FE-LAG 旧开发流约 `0.674`，尚无独立确认。[来源](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_1_ERRATUM_20260923/ERRATUM.md)、[FEAS-1](/Users/pencilbard/Downloads/second_try_copy/BYTE_CORE_FEAS_1_20260923/results/REPORT.md)。不同世界的数值不可直接做新效应差。

按功能先试四种可部署输入器官，FE0 为共同基线：

| 候选 | 只从可见字节得到的状态 | 原因 |
|---|---|---|
| `LAG12` | 旧 12 字节位置码 | 已知部署型参照 |
| `VISIBLE_TAIL4` | 流式识别 F3 前缀/头/分隔符；缓存载荷字节与时戳，在可见分隔符到来时用末四字节及原时戳计算 FE0 输入 | 用可见解析替代旧 FE-TAIL4 的隐藏键偏移；教学不倒流 |
| `HASH_TAIL4` | 对最后四个载荷原始字节以锁定 SHA-256 种子确定 8-of-88 PN 码；无键身份表/结果表 | 简单稳定、对 F3 首两字节 XOR 不敏感 |
| `HASH_CANON` | 根据可见头解除已公开的 F3 XOR，再把完整载荷及长度确定性哈希为 8-of-88；无身份/结果表 | 接近完整字符身份，测试输入码上限 |

哈希只生成固定感觉码，**不能写入正确答案**。所有随机种子、碰撞规则和解析状态在数据世界前锁定。若 `VISIBLE_TAIL4` 不能在标准 F3 再现旧 oracle 的结果前输入，先定位时间/解析差异；其成功不能自动外推到一般文本。

**小规模顺序筛选：**Q 先验证字节因果、源码/环境哈希、原 FE0/LAG 的逐事件等价、UTF-8 内部控制字节不会触发奖励。CAL 4 世界×5 组=20 条生命，只拟合各组冻结概率读出；DEV 8 世界×5=40 条，以结果前 `side 0`、已至少出现一次的正常线索 AUC 选择**一个**最高候选，旧记忆和新包装读数作并列报告但不事后改主指标。同分按锁定名称顺序。CON 24 个独立世界×（冠军、同码 `plastic=False`、FE0）=72 条生命；预定 8 个世界追加结果拆配的 UNP 负对照。总计不超过 **140 条**完整科学生命轨迹，加少量 Q。若冠军只是 FE0，照样报告没有改进，不把未运行的候选称为阴性。

**关联链结果分层：**冠军在 CON 的重复正常 `side 0` AUC `≥0.75`，且相对同码 no-write 的世界配对 ΔAUC 的 95% 下界 `>0.08`，称 `BYTE_ASSOCIATION_LEARNED`。同时强制报告首次出现的 side-0 AUC、完整流 AUC/η、异常/修订表现；不能用 side 1 的成对捷径撑起通过。≥24 h 旧记忆只在该 pair **首次 side-0 反馈之前**评分，要求旧返回相对 no-write 有正向配对证据，才另标 `DELAYED_ASSOCIATION_EVIDENCE`。同一已学键在未训练的 F3 包装 2/3 下作只读转移探针；这和从新状态重学不同。若关联与旧返回/包装转移分化，分别报告，不合并成一个“没有候选”。阈值是工程目标，非生理常数。

## 4. NLP 链：不用整词查表，直接在文本字节上预训练

这一链**无论关联链成败都执行小型试验**，因为它要回答另一件事。模型收到原始 UTF-8 文件按顺序给出的每个字节，包含换行、空格和多字节字符；只在可见文档分隔符处重置或标注状态，不由评价器传词边界。每到字节 `b_t` 之前先给出 `p(b_t|b_<t)`，看到它之后才做教学更新。训练、开发、确认按**整篇文档/来源**分割，不把同一段文字的相邻切片分别放进两区；文本来源、SHA-256、字节数、去重和许可在运行前写入 manifest。先用少量本地文本打通 Q，正式确认语料在模型代码锁定前独立固定。

不用完整词哈希作唯一输入。最小 NLP 输入器官是：当前原始字节的 88 维嵌入/固定投射，加长度 1、2、4、8、16、32、64、128 的因果滚动/衰减痕迹，映到 PN/KC；所有特征只来自已经到达的字节。先试**固定字节与 n-gram sketch + 果蝇 KC + 256 路可塑读出**。若固定 sketch 不足，可学习 256×88 嵌入、时间投射或小循环状态；若 KC 使信息坍缩，允许增加 PN/KC 或真正改 PN→KC 连接。256 路输出可用 MBON 样稀疏/低秩读出，按下一个字节的预测误差在线更新；保留 FULL_151 二结果头供关联任务。任何标准梯度/局部误差更新均可作为工程方案，但要明确哪部分还是果蝇连接约束、哪部分是新增的学习器。

**先证实接口，再问语言：**Q 测 10,000 字节的准确预测时序、峰值内存与吞吐；按实测选择不超过 8 小时、可断点续跑的固定字节预算。首轮目标是约 0.2–1 MB 训练文本和独立整篇测试文本，若 Mac 吞吐不足先优化/稀疏化，而不删较难的测试字节。比较三个基线：按训练集频率的 unigram、只看末两字节的 Markov2、以及同一 KC 码的普通在线读出。它们帮助分清“字节编码可用”与“果蝇学习规则限制”；不因普通读出赢过飞脑而拒绝改脑。

**预定主指标：**测试集 bits per byte（BPB，越低越好）、下字节准确率；单列 ASCII 字母/数字、UTF-8 字符首字节、UTF-8 continuation bytes、词界附近及专门构造的跨 32 字节依赖测试。只赢在 UTF-8 continuation-byte 规则或空格/标点不算 NLP 进展。`BYTE_SEQUENCE_LEARNING` 要求锁定确认文本上的内容位置 BPB 低于 Markov2，并在独立来源上重复；同时报告较强的平滑 8-gram 基线。只有后述下游测试在未见组合上也超过 8-gram 与未预训练对照，才考虑 NLP 就绪。

**最小下游任务：**在同一冻结预训练核心上给两个等长候选文本片段评分，挑真实后续；假后续从相同来源和字符/长度层抽取，并匹配紧邻的最后 8 字节统计，避免只靠标点或 UTF-8 合法性。再做一组需要 32 字节以上依赖的合成最小对（例如前文约束某个后续字节/词形，中间插入干扰文本），训练/测试在词项和模板组合上分开。报告相对未预训练核心、Markov2、平滑 8-gram、冻结 KC 仅训练输出头，以及打乱文本训练的差。若只会整词记忆、不能在未见组合上迁移，不能称语言就绪。后续标准 NLP 分类/生成任务需要单独数据、输出接口与确认，不从二结果任务推断。

**同一只苍蝇的整合门槛。** 两链早期可以比较不同感觉器，这是为了找可行部件；**不能把一条链的哈希键结果与另一条链的 n-gram 结果拼成一个成功模型**。拿到两链试验结果后，必须冻结一个共享的逐字节感觉器、同一套 PN/KC/可塑记忆状态；关联和文本预测可各有任务输出头，但不能换掉核心输入表示。这个**单一模型**须在全新的关联世界和整篇文本上重新确认：既达到 `BYTE_ASSOCIATION_LEARNED`，又达到 `BYTE_SEQUENCE_LEARNING`，并在未见组合的下游任务上优于未预训练及 8-gram 对照，才标 `NLP_READY_FOUNDATION`。这项整合确认不从前述 140 条关联试验或第一批文本中偷用测试数据；规模由两链 Q 的实测耗时另锁。若共享模型失败，报告“两项部件可行、整合未成”，继续改结构而非宣称 NLP 已解决。

## 5. 同一个失败树，允许改脑，但不浪费容量

| 观察 | 下一动作 |
|---|---|
| F3 可见解析与旧 FE-TAIL4 不等价 | 修输入/时间桥接；不调生物塑性掩盖驱动错误 |
| 稳定字节码已有区分，同码普通读出学会而 FULL_151 不会 | 直接修改教学剂量、eligibility、读出或连接，按新世界确认；无需再造无序对照 |
| 同码普通读出也不会，或文本在 KC 前后丢了局部/长程区别 | 调整多尺度字节器、PN→KC 图和必要容量；允许学得时间变换 |
| 关联能学、NLP 的内容位置 BPB 不胜 Markov2 | 增强跨字符组合与可塑读出；不把“能识别键”误称语言就绪 |
| NLP 预训练有效、下游长依赖无效 | 增加时间记忆/循环及持续写入，而不是扩大输入字节字典 |
| 两条链都有效但隔天旧关联丢失 | 专门测写入保持、复习与读出漂移；保留已经工作的字节器官 |

所有升级候选只用开发数据搜索；确认世界和整篇测试文本保持独立。可以使用小种群进化或梯度学习，但它们是**求解工具**，不是另设的科学目标。比较时列出状态字节、固定参数、可塑参数、训练字节与 wall/RSS；不让某模型通过隐藏的词典、标签映射或预切 token 输入作弊。

## 6. 资源与交付

关联链首轮最多约 140 条完整生命；NLP 链先用 10k 字节 Q 测速，再以实测吞吐锁训练字节数和机器上限；共享模型的最终整合确认单独锁预算。一个 256×88 输入嵌入和 5,177×256 float32 输出头合计约 5.4 MB **权重**，说明接入字节的基础结构不必巨大；训练时的优化器/瞬时状态可能另占内存，由 Q 测量。真正任务是否需要更大可塑记忆，交给 held-out BPB、长依赖与旧记忆结果决定。禁止逐字节保存 5,177-KC 稠密状态；在线累计指标，必要时保存预定少量压缩片段。运行记录留项目目录，最终只交付 <10 MB 的报告、指标、关键图、模型/配置、资格检查和指向未变父资产的 manifest。

此版是设计，尚未下载语料、实现驱动或启动实验。开跑前还须锁定文本 manifest、测试划分、候选哈希、逐字节事件桥接、Q 负测试和性能预算。此后评价顺序始终是：**能否从原始字符字节学到东西、能否跨格式与时间保留、能否形成可迁移的文本上下文能力**。
