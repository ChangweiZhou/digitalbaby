# V32: persistent byte memory under aliasing and long interference

Protocol fixed before scientific results, 2026-09-08. This operationalizes the user's V32 proposal. Numerical thresholds below are new implementation choices, not previously agreed numbers. No parameter search or post-result task adjustment is permitted in this round.

## Fixed architecture

Eight fixed routing banks, 96 features, 256 outputs, float64. Predictions use softmax(scores / 0.1). Every observed byte supplies its own teaching target after prediction. No task, identity, alias, noise or revision metadata enters the learner. No reset at records or waves, replay, encoder training, gate, or MESU.

New sensory interface: seeded independent normalized Gaussian receptor vectors, 32 per byte, with the past 12 bytes processed using normalized exponential weights (fast time constant 2 bytes; slow 6). Features are exactly `[last, F, F-S]`, normalized together, with no further sparsification. This choice preserves all 96 proposed coordinates. The V31 reference is copied mathematically and uses 24 receptor coordinates, `[last,F,S,2F-S]`, its original top-24 activity selection, and identical seeded routing centres. The observable-lag diagnostic is 12 lag positions × 8 signed binary byte bits, normalized; it is an information-preserving control on full windows, not a proved accuracy upper bound.

Ordinary writes use q0=z/(z'z). Full writes use q=Pz/(z'Pz), with the orthogonal component capped so ||q|| <= ||q0||/0.6 while preserving z'q=1. Both update W by 0.6 q (onehot(byte)-scores)'. Full starts P=I and updates P <- P-Pzz'P/(1+z'Pz) after the write. This is the V31 byte rule. Ordinary holds no protection matrix.

## Stream and probes

Four waves A/B/C/D, 16 independent six-character keys per wave, 32 presentations per key, no boundary cue. Keys use 0–9/A–Z; arbitrary targets are independent draws from 24 lowercase bytes. Training renderings alternate `~|~|@KEY123:x\n` and `~|~|#KEY123=x\n`. The four-byte prefix makes each target's 12-byte past context exactly reproducible; the live stream remains continuous. The never-trained alias is `~|~|?KEY123>x\n`. The fixed prefix is scaffolding, and the target is only one of 14 bytes: therefore whole-stream AND target-only prequential losses are mandatory.

There is no explicit equivalence information. Each key's same content occurs in the two trained syntaxes; the third syntax is entirely withheld from learning. This intentionally tests both a known alternate rendering and a new syntax. Failure on the latter alone does not demonstrate lack of semantic identity: unseen separators and routing are confounded, with code cosine and bank-agreement diagnostics reporting this limitation.

After B's strict retention checkpoint, four A keys each receive one incorrect target, once only. Probes before and after each full corrupt record measure damage to that key and unrelated unchanged A keys; a later clean return never repairs those keys in this stream. After C's strict checkpoint, four different A keys are revised, eight presentations each, only in rendering 0. Probe at 1/2/4/8 changed labels, and score before every changed label. Rendering 1 is a previously learned but unrevised alternative; rendering 2 is never trained. D then supplies further unrelated interference. Eight A keys never return after A and are the primary strict-retention cohort. B and C cohorts also receive strict post-wave probes; revisions and corruptions are always separately scored.

Read-only probes reconstruct independent past-byte windows and never change live state. Acquisition probes occur after 1/2/4/8/16/32 presentations in each wave. Exact-view presentation counts and logical-key presentation counts are both recorded, so the second key occurrence is not mislabeled a repeated exact context. Source bytes and evaluator annotations are saved separately for reproduction.

## Accounting

Uniform frozen predictions provide H_baseline=8 bits/byte and chance accuracy 1/256. Report absolute losses and accuracy alongside G_learned=8-H_afterA, G_retained=8-H_later. A per-seed retained fraction G_retained/G_learned is reported only if G_learned>0.5 bits and acquired accuracy>=0.5 on that same unchanged cohort. No clipping of ratios, and missing denominators are explicit. Also report retained excess accuracy above 1/256, with its acquisition gate. This baseline alone cannot establish recall: the absolute acquisition gate is essential because targets occupy a restricted alphabet.

Primary contrast is paired whole-stream prequential bits/byte (ordinary minus full; positive favors full). Mandatory accompanying diagnostics: target-only loss, exact and alternate-view first/second acquisition, absolute untouched-A recall after each wave, revision at 1/2/4/8 exposures, obsolete-target probability, unchanged/noise damage, all old cohorts, and held-out alias transfer.

Covariance diagnostics at wave boundaries: eigenvalues, effective rank of C and of accumulated data geometry (subtract the remaining ridge), tr(P), per-bank selected-write counts, current-code z'Pz, actual and uncapped ||q||/||q0||, and cap frequency (all bytes and target bytes separately). Ridge makes the initial C full rank; its initial effective rank must not be mistaken for capacity use. Correlation with degradation is diagnostic, not proof of causality.

Dictionary diagnostic: exact last-12-byte context, sparse categorical counts with a total-one uniform Dirichlet prior, no suffix backoff or parsing. It has growing capacity and is not a proposed fixed-budget core. Its cumulative counts can lag true revisions; that fact must not be attributed to a fundamental limitation of all dictionaries. The unseen-alias contexts are asserted absent from its training keys.

## Stages, seeds and gates

Inference units are independent seeds, not bytes. Report paired two-sided 95% t intervals, sample size and per-seed values. Secondary intervals are descriptive without multiplicity adjustment. Missing jobs never pass. All components are jointly required for qualification; report adverse versus inconclusive evidence separately.

1. **A, scientific encoder preflight: 18 trajectories.** Seeds 33001–33006; only wave A; ordinary writer with new code, exact V31 reference, and observable-lag diagnostic. The new code must have mean acquired accuracy >=0.50 in EACH trained rendering and a 95% lower bound >0.25; same-rendering mean information gain >=0.50 bits and lower bound >0.25. Otherwise stop, even when a reference passes. Held-out syntax is measured but not an encoder gate: it is the main invariance stress test. No automatic fallback to a winning reference.
2. **B, screen: 24 trajectories.** Seeds 33101–33108; new encoder, ordinary/full/dictionary; complete four-wave stream. Full qualifies for confirmation only when all following hold: whole-stream advantage CI lower >0; target-only loss noninferiority CI lower >=-0.05 bits; untouched-A retention gain CI lower >0 and mean >=0.05 accuracy; full final absolute untouched-A mean >=0.75 and its initial accuracy >=0.50; mean across new-wave second-key-occurrence accuracy noninferior (full minus ordinary CI lower >=-0.05); full exact and known-alternate revision accuracy at four exposures each >=0.75, held-out >=0.60; full mean noise damage <=0.10. The absolute criteria use means, not a claim of population threshold certification.
3. **C, confirmation: 24 trajectories if B qualifies.** Seeds 33201–33208; same three arms, same specification and gates. A broad synthetic qualification requires C to pass independently, plus held-out alias accuracy after revision exceeding dictionary with paired lower bound >0. No retuning between stages.
4. **D, one conditional finite-horizon repair: 24 trajectories.** Seeds 33301–33308, ordinary/full/full_h2048; run once only if B (or executed C) shows full initial exact acquisition >=0.50 and either (i) any four-exposure revision rendering below its B threshold, or (ii) data effective rank >=76.8 and target mean z'Pz<=0.05 after D, together with D second-occurrence accuracy >=0.10 below A. High rank alone does not trigger this stage. If the encoder stops or the only failure is uncertain retention/transfer evidence, D does not run. No mechanism is added when full passes all tests.

The finite horizon is one fixed half-life of 2048 writes **to a selected bank**, lambda=2^(-1/2048). It operates from byte one and updates P <- [P-Pzz'P/(lambda+z'Pz)]/lambda. Algebraically this inverts C <- lambda*C+zz'; the ridge also decays. No unselected-bank decay or boundary resets. Same write correction/cap and output state. Repair is judged against ordinary with the same endpoints, and against infinite full for improved deficient endpoints without >0.05 accuracy retention loss (paired noninferiority). A successful repair is a screen requiring future confirmation, not automatic qualification.

Maximum 90 trajectories; Stage A failure means exactly 18 scientific trajectories. Full trajectory: 2,084 records =29,176 bytes, 64 unique keys, 128 distinct acquired key/rendering pairs plus 4 revised pairs, 2,084 target presentations; each byte is presented once, all learned repetition is explicitly in the stream. A preflight has 512 records =7,168 bytes. Engineering smoke uses separate seeds and smaller budgets; it cannot qualify a code or mechanism.

## Reproducibility

One Python file, NumPy/SciPy dependencies, optional one-command installation, macOS caffeinate, single-process BLAS, deterministic stage/job descriptors, atomic per-job checksummed records, source/plan/environment hashes and a process lock. Default rerun resumes only the identical source and scientific plan; corruption or foreign jobs raise errors. No silent replacement. Compact ZIP includes source, protocol, stream recipes, per-seed endpoints and gates; no per-byte prediction dump or large model snapshots.
