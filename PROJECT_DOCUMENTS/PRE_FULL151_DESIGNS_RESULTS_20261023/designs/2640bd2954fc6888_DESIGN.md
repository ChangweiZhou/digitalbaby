# MiniFly V9.4 — causal interference after ordered-byte learning

**Design date:** 2026-09-25. **Status:** pre-science protocol; run the
independent design/code audits and out-of-bank technical smoke before the
fresh scientific worlds. This is a diagnostic of the existing V9.2 checkpoint,
not a new architecture, an A11 certification, or a claim that its engineered
predictor teaches the native value pathway.

## Question and parent

When the inherited FE0→PN→KC fast/slow pathway learns a *new* rewarded
ordered-byte set, does that plastic writing cause loss of an *older* rewarded
ordered-byte set? V9.3 established short order-value acquisition and passive
+24 h persistence. It did not supply a same-clock, same-byte challenge with
intervening new learning.

Every world starts from the **unchanged**
`../BYTE_CORE_V9_2/model_v92_text.npz` checkpoint (SHA-256
`ac79d7f4dcc28a131049b93d6b8390a2423bbe4208e43df1cb2d4052857b11c9`).
Load it through the V9.2 class, verify its saved confirmation digest, and
continue its pending history/clock. Do not call `reset_stream()` or `rest()`
on a main learner. A 14-byte record has a 12-byte cue, constant outcome byte
`!`, and newline. Bytes are 30/14 s apart, records start 165 s apart, and
external `Teach(r)` follows the outcome byte. The reward bit is never encoded
in the raw outcome byte. All frozen probes use copies and leave the source
checkpoint unchanged.

Let `old_t0` be the first old record start. Then
`old_end = old_t0 + 72×165 s`,
`challenge_base = old_end + 86,400 s`,
`new_t0 = challenge_base + 30/14 s`, and
`new_end = new_t0 + 72×165 s`.
The pre-challenge probes are at `new_t0`; bout-6 and bout-12 challenge
probes are at `new_t0 + 36×165 s` and `new_end`, respectively; passive
post-challenge probes are at `new_end + 86,400 s`. The real main-clock
24 h advance uses `native.flush(challenge_base)`. A technical fixture must
show that this produces the same old-value probe as V9.3-style passive
extrapolation from an unflushed copy and leaves predictive weights/history
unchanged.

## Fresh world and chronology

Use one fixed parent fly/model seed and **32 fresh generated worlds** in the
new `BYTE-CORE-V9-4` namespace (indices 301–332). The independent
inferential unit is the complete generated world; the three reversed pairs
inside it, bouts, bytes and probes are not independent samples. Index 900 is
an initial superseded technical smoke; index **901** is the current technical
smoke and is excluded from science. Do not reuse V9.3's
worlds or tune the schedule after smoke.

For each world, draw five different uppercase ASCII symbols. Three form the
old ordered set `(a,b,c)`. One of those three is deterministically selected
as the shared symbol `s`; the remaining two fresh symbols make the new set
`(s,d,e)`. No ordered pair belongs to both sets. Within each set train all
six orientations; cyclic orientations `(x,y),(y,z),(z,x)` are aversive,
their reverses neutral. Thus each symbol occurs equally often in first and
second position under each outcome. No old pair is contradicted, but the sets
share one byte and the same FE0/KC pathway. This is a specific overlap
condition, not a capacity curve or a no-overlap conclusion.

Each cue is 9 spaces, its two ordered bytes, then one space. All cues end
with the same context byte. A fresh, deterministic permutation presents each
set's six cues once per bout for 12 bouts. Every arm of a given phase receives
identical cue order, raw bytes, timestamps and reward labels. The learner
receives only those bytes and the external reward bit, never the evaluator's
old/new/pair labels.

1. **Old acquisition:** fork the parent into `OLD_WRITE` and
   `OLD_NO_WRITE`. Feed the same 72 records with predictor learning on in
   both; call `Teach` with `write=True` or `False`. Probe old pairs on
   copies before and immediately after acquisition. Advance both main
   states by a 24 h `native.flush(absolute_t)`, preserving predictor
   history. Probe old pairs again. The trained, 24 h state is the common
   pre-challenge checkpoint; the no-write state is an acquisition control,
   not a challenge arm.
2. **New-learning challenge:** clone that one trained pre-challenge state
   into `NEW_WRITE`, `NEW_NO_WRITE` and `CLOCK_ONLY`. The first two
   receive exactly the same 72 new-set records, including reward bits and
   predictor updates, differing only in the native `Teach(write)` flag.
   `CLOCK_ONLY` advances to the same final absolute time using
   `native.flush`, with no new bytes or teaching. It is a secondary
   time-only diagnostic, not the primary causal control.
3. Probe old and new pairs from copies of the common pre-challenge state and
   both exposed arms after bouts 6 and 12. At the bout-12 endpoint, also
   probe `CLOCK_ONLY` on old pairs. Probe old and new pairs at +24 h by
   passive extrapolation on copies of each arm; this is not additional
   learning. Do not carry any frozen probe state into later training.

## Primary contrast and controls

For an ordered pair, `margin = value(neutral orientation) -
value(aversive orientation)`. Choice is 1 when margin > 0, 0.5 at a tie,
and 0 when margin < 0. A world score is the mean of its three pair choices.
The single primary estimand is the **paired world mean**
`old_choice(NEW_WRITE, bout12) - old_choice(NEW_NO_WRITE, bout12)`.
Report its two-sided 95% t interval over all 32 worlds, including worlds
where initial old learning fails. This isolates the total effect of new
plastic writes under the fixed shared-byte schedule; it does not isolate a
specific synaptic mechanism.

The assay is interpretable only if the old acquisition and new acquisition
positive controls both pass: (i) at pre-challenge +24 h, absolute
`OLD_WRITE` old choice has 95% lower bound >0.5 **and** paired
`OLD_WRITE-OLD_NO_WRITE` lower bound >0; (ii) at new bout 12,
absolute `NEW_WRITE` new choice has lower bound >0.5 **and** paired
`NEW_WRITE-NEW_NO_WRITE` lower bound >0. If either fails, label
`ASSAY_INSENSITIVE`; report measurements without claiming memory
protection or interference.

Conditional on assay validity and these positive controls:

- `WRITE_SPECIFIC_OLD_HARM` if the primary interval's **upper** bound is
  below zero.
- `WRITE_SPECIFIC_OLD_BENEFIT` if its **lower** bound is above zero.
- Otherwise `UNRESOLVED`. An interval crossing zero is **not** evidence
  of protection or equivalence; no post hoc margin is introduced.

Mandatory secondary measurements: absolute old/new choice and analog
margin before and after challenge and at +24 h; paired old analog margin
effect; number of initially correct old pairs that turn incorrect/tied in
each arm (same at-risk pair identities); per-world minimum old-pair
`NEW_WRITE-NEW_NO_WRITE` margin; old `NEW_NO_WRITE-CLOCK_ONLY` difference
to describe exposure/time effects; KC-code separation at pre-challenge
and challenge endpoint; and the new learning curve at bouts 6/12. The
old-correct transition and minimum are tail diagnostics, not separate
unadjusted formal discoveries.
As an exploratory localization, report the teaching effect on the two old
pairs containing the shared byte separately from the one old pair without
it, averaging within each world before forming intervals. This is not a
second primary hypothesis and does not prove that the shared byte caused
any effect; KC overlap is measured rather than assumed.

An old pair is *at risk* when its shared pre-challenge margin is strictly
positive. Count it as lost if its later margin is ≤0. Record raw at-risk
and lost counts for each world and branch. The reported per-world
`lost_of_all` is lost count divided by all three old pairs, even if zero
were initially correct; this keeps every world in the analysis. Also report
the aggregate raw at-risk count. Do not use pair counts as independent
statistical replicates.

Readout noise remains an unresolved V9.3 limitation. Report the analog
margin distribution and a **fixed, evaluator-side** Gaussian choice-noise
sensitivity at prespecified SDs 0.02 and 0.05 Hz, using analytic
`Phi(margin/(sqrt(2)*SD))`. This assumes independent zero-mean Gaussian
noise with the stated SD added to each of the two option values; these are
sensitivity calculations, not a
validated biological noise model or a claim of robustness.

## Exact validity and byte-prediction checks

Before science, the technical fixture must establish that from identical
state and bytes, `Teach(write=False,r=0)` and
`Teach(write=False,r=1)` produce identical complete states on the parent
and on a trained pre-challenge state: the label
must be inert when plasticity is disabled. The no-write path *does* advance
adaptation, FE0 and memory decay; it is not an unchanged-brain control.
Require every record to pass clock error <1e-6 s and all same-stream exposed
arms to retain bit-identical predictor weights/history. Source/checkpoint
hashes, reward balance, pair disjointness, 14-byte accounting, exact
pre-challenge clone digest, probe purity, and one save/load roundtrip are
fatal checks. A failure yields `INVALID_ASSAY`, regardless of scores.
The source lock includes Full_151 native source hashes, B/Q object digests,
the V9.2 checkpoint and runtime environment. The roundtrip is of a
post-challenge `NEW_WRITE` checkpoint and requires its complete state
digest to match.

For indices 301–304 only, frozen continuation probes of Doyle and Stevenson
read 20,000 raw bytes each from the **common pre-challenge** and
post-challenge `NEW_WRITE` checkpoints. They continue from each checkpoint's
live history and clock, without reset. Compare both full-stream and
content-byte BPB before and after the new-learning challenge, and compare
post-challenge scores with the locked V9.2 train-only Markov-2 values.
This localizes predictor drift to old acquisition versus new exposure.
Exact predictor
state identity makes the `NEW_NO_WRITE` text scores identical, so they
need not be recomputed. These four prespecified sentinels are an operational
regression, not population inference. If any loses the Markov-2 advantage,
report `BYTE_PREDICTION_REGRESSION`; it does not invalidate the native
interference contrast, but it prevents a claim of maintained joint utility.

## Run order, resources and interpretation

1. Lock this design and source versions; independent hostile design audit.
2. Implement and test deterministic world construction, state forks,
   no-write label inertness, clocks, probes, source locks and receipt
   rejection. Obtain an independent hostile code audit.
3. Run one out-of-bank technical smoke (index 901). Inspect **validity and
   runtime only**; do not tune the byte schedule or learning dose on its
   outcomes. Correct any instrument defect before science, rerun smoke on a
   new technical index, and document the revision.
4. Only if all locks pass, run all 32 scientific worlds with at most four
   workers and atomic, source-locked per-world receipts. Resuming reuses an
   identical input; it never changes a failed world or seed. Summarize only
   after every complete world exists.

Keep the final bundle under 10 MB: design, audits, runner/tests, compact
receipts, tables, figure, acceptance checks, report and a manifest of hashes
and unchanged parent assets. Do not copy source datasets, the V9.2 checkpoint,
or raw per-byte trajectories. No topology, learning rate, teaching dose or
readout is modified in V9.4. A positive or negative result defines the
next *byte-specific A11* question; it does not itself certify the persistent
core or the old PN-cue A11 grid.

## Pre-science instrument amendment

The initial index-900 technical smoke passed behavioral-independent validity
checks, but the first full launch stopped **before any scientific world**
because the saved JSON lock contained lists where the in-memory configuration
contained tuples. The source digest itself was unchanged. The runner now
compares a canonical JSON form. This implementation correction changes the
runner hash, so index 900 and its original source lock are retained only in
`results/` as superseded technical evidence. The corrected source version
must pass an independent audit and a new out-of-bank smoke at index 901 in
`results_v2/` before any of the unchanged 301–332 science worlds run.
No index-900 outcome score was inspected or used for tuning. The scientific
question, schedule, arms, endpoints, n, and decision gates remain unchanged.
