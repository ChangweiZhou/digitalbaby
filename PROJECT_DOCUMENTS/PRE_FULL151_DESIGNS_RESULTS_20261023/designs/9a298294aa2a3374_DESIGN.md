# Byte interface, iteration 2: an input organ that keeps recent order — design (fixed before any run)

**Date:** 25 September 2026. Its SHA-256 is recorded in `RESULTS.json`.

**Scope:** only the byte interface. Long memory and language ability are not expected or tested.

**Iteration 1** (`../BYTE_READ_ORDER_FLYROUTE_20260925/REPORT.md`) found two limits:
- **The input organ.** It keeps the most recent byte well: 0.87 decodable with FE0 and 0.997 with TRACE88 at the 88 PN inputs. The byte before it is mostly lost: 0.21 and 0.35.
- **The online rule.** It reached only 11–18% on the target, where an ideal readout of the same KCs reached 47–48%.

This iteration changes the input organ. It also selects the output learning rate on a development world, because the fixed V9 learning rate is not part of the byte interface.

## New input organ: LAT4, four latency classes of projection neurons

The 88 PN are split into 4 classes of 22. Class k (k = 0…3) responds to a byte at an elapsed time τ after its arrival, with a Gaussian latency kernel:
- g_k(τ) = exp(−(τ − μ_k)² / 2σ²);
- μ_k = (k + 1)·Δ, where Δ = 30/14 s, the byte spacing fixed before the stream;
- σ = 0.3·Δ.

**Receptor codes.** Each class has its own receptor code: each byte drives 4 of the class's 22 PN, with weights drawn uniformly from [0.4, 1.0], fixed by seed `BYTE-READ-ITER2|LAT4|v1`. Each byte uses 4 of 22 cells, not one cell per byte.

**Reading.** The PN vector is the sum, over recently arrived bytes, of g_k(t − t_byte) × that byte's code in class k, divided by its maximum as in FE0.

**Inputs and state.** The organ sees only (byte, time). Its state is the bytes that arrived within the last μ₃ + 4σ = 5.2Δ, so at most 6 of them.

**Biological framing.** PN classes with different response latencies act as a delay line; latency diversity is a known feature of sensory neurons. The kernels, classes and receptor codes here are engineered choices, not fly data.

**Limitation, stated in advance.** Order depth is bounded by the PN budget: 88 PN give 4 latency classes.

**Output rule:** V9's local rule unchanged, with bias learning rate 0.001. The weight learning rate is selected per front end, as below.

## Worlds and learning-rate selection

- **Development world 210:** each fly front end is trained and tested with learning rate ∈ {0.03, 0.1, 0.3, 1.0}. The rate with the lowest target bits on world 210's test stream is used for that front end.
- **Gate worlds 211, 212, 213:** fresh, and not used in iteration 1. Stream seeds are 1,000,000 + 100·world + 1 for training and + 2 for test.
- **Task, scorer, baselines and gate:** V9's ORDER, unchanged, exactly as in iteration 1.

## Criteria, per fly front end

1. **Interface: order is kept.** On world 211, an offline linear decoder reads the target y from the KC code with accuracy ≥ **0.90**.
   - Method as in iteration 1: L-BFGS softmax, λ = 1e-4, trained on the last 16,384 training slots and tested on the 4,096 test slots.
   - y depends on both bytes in order, so reading it requires order.
2. **Plasticity can use it.** V9's ORDER gate passes in all three gate worlds with the rate selected on world 210.

**Verdict.**
- *Byte interface resolved for two-byte order* if **FLY_LAT4** meets both criteria.
- FELAG is reported the same way, as an engineering reference.
- V9_POSITIVE must pass the gate.

**Also reported on world 211:** decodability from PN and KC of:
- b (1 byte back);
- a (2 bytes back);
- the previous record's b′ and a′ (5 and 6 bytes back), as a measure of depth.

Controls: shuffled labels (NC) and V9's engineered cells (PC).

## Checks

- **V9 scorer:** targets are scored before they are seen, parameters are frozen during test, and coverage is exact.
- **Fly inputs:** exactly the 5,177 native KCs.
- **LAT4 unit checks:**
  - **Reads are pure:** the state is unchanged by reading.
  - **State stays bounded:** at most 6 bytes.
  - **The code is order-sensitive:** the PN vector differs for a then b versus b then a.
  - **The sensitivity check can fail (NC):** with σ = 50Δ, the latency classes blur and the two orders give nearly identical PN vectors (relative difference < 1%).
