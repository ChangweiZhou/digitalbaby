# MiniFly V9.5 — four-cohort byte-learning lifetime stress

**Design date:** 2026-09-25  
**Status:** design only; `NO_SCIENCE_AUTHORIZATION`. No V9.5 runner or scientific worlds have been launched. This protocol requires an independent design/code audit and a full-length, out-of-bank technical qualification before science.

## Decision this experiment is meant to support

V9.4 showed a write-specific old-choice deficit immediately after one new ordered-byte cohort: −11.46 percentage points (pp), 95% t interval [−21.86, −1.06] over 32 generated worlds. At +24 h, deterministic old choice had recovered to the no-write level, although its analog value margin remained lower. The immediate result was fragile to the interval method and individual worlds. We therefore do **not** infer lasting forgetting, a memory-capacity limit, or a need for new anatomy from V9.4.

V9.5 asks a narrower next question: **after four successive, genuinely learned new byte cohorts, does the inherited value pathway leave an old byte association measurably weaker 24 h later than an otherwise identical no-write pathway?** It also asks whether any terminal effect reflects the first three writes, the last write, or their interaction. This is a causal stress test of the current fixed MiniFly checkpoint, not an optimization run and not the original PN-cue A11 B/HASH8 certification.

The experiment leaves the FE0→PN→KC→fast/slow circuit, its topology, teaching rule, dose, readout and separate byte predictor unchanged. A harmful or null result may motivate a later structure or consolidation test; this protocol does not choose one in advance.

## Parent, worlds, and fixed event format

Every world loads the unchanged [`model_v92_text.npz`](../BYTE_CORE_V9_2/model_v92_text.npz) checkpoint (SHA-256 `ac79d7f4dcc28a131049b93d6b8390a2423bbe4208e43df1cb2d4052857b11c9`). The V9.5 source lock hashes **this `DESIGN.md` itself** alongside the runner/tests, parent confirmation, native Full_151 B/Q objects, imported V9.2/V9.3/V9.4 helpers and Python/runtime dependencies. The earlier V9.4 lock digest `a0d5f02458fd51993d1552538d1a0bc8f2112f7259a89d43af0737e32d7db732` is a provenance reference, **not** a substitute for a new V9.5 lock.

Predeclare 256 fresh generated worlds, indices **401–656**, under namespace `BYTE-CORE-V9-5`. Out-of-bank technical indices **9901–9904** never enter inference. One full generated world, containing every branch and all its pairs, is the statistical unit. The fixed model/fly seed is inherited from the same checkpoint in every world: intervals describe variation across generated byte worlds, **not across independently born flies**. No V9.3/V9.4 scientific world is reused, and a failed world is retried only with its identical sealed inputs.

For world `i`, draw 11 distinct uppercase ASCII symbols from a deterministic namespace/index seed. Three form the old set `(a,b,c)`; the other eight form two fresh symbols for each of four new sets. Each new set also contains exactly one of `(a,b,c)`. Choose the four shared-old-symbol assignments by an independent sealed world draw such that each old symbol is used at least once and one is used twice; randomize which cohort receives the repeat. Consequently all 15 unordered tested pairs (three old plus three per new cohort) and all 30 ordered cues are unique. Each set has three aversive cyclic orientations and their three neutral reverses, as in V9.4. Verify reward/first-position/second-position balance **within each set**, no repeated ordered pair across sets, no contradictory label, and an exact one-symbol old/new overlap per cohort. Save the generated master-world symbol, role, label, schedule, and hash record before executing a branch. Do not select worlds based on prechallenge learning or KC overlap.

Each ordered cue is the V9.4 12-byte delayed-order context: nine spaces, the two ordered symbols, and a final space. Append constant `!` and newline to make a 14-byte record. The outcome byte never discloses reward. Supply the aversive/neutral external reward bit to the inherited `Teach(r)` at the `!` timestamp; all exposed branches receive identical raw bytes, timestamps, reward labels and predictor updates. Bytes are separated by `DT = 30/14 s`; record starts are separated by 165 s. Each set has 12 bouts of its six ordered cues, once each per bout, with a deterministic new permutation per `(world, set, bout)`. Thus old acquisition has 72 records and the four new cohorts have 288 further records. The learner does not receive set IDs, pair IDs, old/new labels, or probe answers.

## Clock and branch graph

Let `t0` be `V9.3.first_time(parent)`, `E0 = t0 + 72×165 s`, and `P = E0 + 86,400 s`. The real old-trained state advances to `P` with `native.flush(P)`; this preserves the byte predictor's learned weights and pending history. Set `T1 = V9.3.first_time(old_trained_after_flush) = P + DT`. The four new blocks start at `Tj = T1 + (j−1)×72×165 s` and end at `Ej = T1 + j×72×165 s`. Probe immediately after each `Ej`; the final persistence probe is at `D4 = E4 + 86,400 s`. The model's simulated span from `t0` to `D4` is approximately **64.5 hours**. Those 24 h waits are virtual clock advances, not real-time sleeps. The four new cohorts are **contiguous** on the record grid: there is no 24 h rest *between* them. A daily-spaced variant would test a different question and needs a separately locked experiment.

1. **Old acquisition and baseline.** Clone the parent into `OLD_WRITE` and `OLD_NO_WRITE`; give both the identical 72 old records, with native plastic writes on or off. Probe old pairs before and immediately after acquisition. Flush **both** main states to `P` with `native.flush(P)` and probe them again at the matched +24 h time. Keep the old-trained `OLD_WRITE` state as the exact shared challenge prestate. `OLD_NO_WRITE` is only the old-acquisition control.
2. **Two continuing histories.** Clone the challenge prestate into `W` (native writes on for cohorts 1–4) and `N` (native writes off for cohorts 1–4). Both ingest every new byte and reward label at the same time. From the same challenge prestate, clone `CLOCK_ONLY`, which receives no new bytes. Flush it to `T1` and then to **every one of the 288 new-record boundaries** (`record_start + 165 s`) in the same order as the exposed arms. Probe `W`, `N` and `CLOCK_ONLY` at each `Ej`, from copies. This matched boundary cadence prevents a sparse-versus-dense rest-call difference from contaminating the exposure/time diagnostic. It is not the causal control.
3. **Same-prestate cohort shadows.** Before each new block `j`, clone the exact `W` prestate into a disposable `S_j` that ingests that block with native writes off. At cohort 1, `N` is already the identical `S_1`, so no duplicate run is needed. At cohorts 2 and 3, `S_j` runs only that block and is then discarded. Probe current new pairs and old pairs in `W` and `S_j` at its end, using frozen probe copies. `W−S_j` measures the incremental write effect of cohort `j` **conditional on the same prior W history**. Do not carry a shadow into later cohorts.
4. **Final 2×2 split.** Immediately before cohort 4, fork both continuing histories: from `W3`, run `W3→W4` (the main `WWWW` arm) and `W3→N4` (the final shadow, `WWWN`); from `N3`, run `N3→N4` (the main `NNNN` arm) and `N3→W4` (`NNNW`, last-only). All four see exactly the same cohort-4 stream. The two comparisons within their respective prestates isolate the last cohort's incremental write effect; cross-prestate comparisons describe prior-write history and interaction, **not a synaptic-damage amount**. Retain all four arms for the immediate and final +24 h probes.

Use `native.flush`, not `model.rest`, for chronological advancement of continuing byte learners: `rest` clears byte-context history. Probes always operate on snapshots/copies; no probe changes a main state, predictor history, teaching count or clock. Each branch's expected actual byte count, `Teach` call count, **actual `write=True` count and write-flag sequence hash** is derived from this graph and checked, including discarded shadows. The writer records the flag at the actual native `Teach` invocation; an independently regenerated schedule must match it. `teach_seen` alone is insufficient because `Teach(write=False)` increments it. `CLOCK_ONLY` must remain at the old-trained byte and teach counts.

## Outcomes and estimands, frozen before science

For each reversed pair, define `margin = value(neutral) − value(aversive)`, and choice as 1 for positive margin, 0.5 for a tie, 0 for negative margin. Average the **three fixed old pairs within each world** before inference. Do the same separately for each new cohort. Do not remove worlds or pairs with poor initial learning. The paired terminal estimand is `WWWW − NNNN` for old memory at `D4` under the sealed four-cohort schedule.

There are **two primary readouts of that one terminal causal contrast**: (a) old deterministic choice in pp and (b) old analog mean margin in Hz. Use paired-world two-sided **97.5% t intervals for each** (Bonferroni familywise coverage at least 95% for the two readouts). Report effect means, sample SDs, exact `n`, intervals and counts of negative/zero/positive world effects. A structural audit failure takes precedence over every scientific label. Conditional on all validity and learning gates below:

- If a primary interval's upper bound is <0, label the corresponding readout `PERSISTENT_WRITE_HARM_CHOICE` or `PERSISTENT_WRITE_WEAKENING_MARGIN`; either is evidence of a negative terminal write effect on that readout at this workload.
- If its lower bound is >0, label `PERSISTENT_WRITE_BENEFIT_CHOICE` or `PERSISTENT_WRITE_STRENGTHENING_MARGIN` for that readout.
- Otherwise label that readout `UNRESOLVED`. Crossing zero is never called protection or equivalence. A choice-null/margin-harm result is a biologically and engineering-relevant weakening, **not** a stable-core success.

An optional bounded statement about deterministic choice is allowed only if the **choice interval's lower bound exceeds −5 pp**, all acquisition/floor gates below pass, and the `WWWW` old and four new sets each have a final +24 h absolute choice interval with lower bound >0.5: “The mean old-choice write cost is less than 5 pp at this exact schedule and fixed checkpoint.” The 5-pp bound is an operational decision scale, not a biological threshold; it does not certify noisy behavior, other workloads, or the persistent learning core. Do not make an analogous margin noninferiority claim without a separately justified Hz bound.

Learning and floor **interpretation gates** are checked from all complete worlds with ordinary whole-world two-sided 95% t intervals (conjunction of required gates; no subset selection):

1. At the old prechallenge +24 h point, `OLD_WRITE` absolute old choice lower bound >0.5 and paired `OLD_WRITE−OLD_NO_WRITE` lower bound >0.
2. At each cohort's own bout-12 endpoint, `W` absolute current-new choice lower bound >0.5 **and** paired `W−S_j` current-new choice lower bound >0. This verifies acquisition by *each* cohort's actual native writes from its own exact prestate.
3. At `D4`, `NNNN` absolute old choice lower bound >0.5. If this time-/exposure-matched old baseline has reached a floor, a zero write contrast cannot be interpreted as preservation.

If a gate fails, report all outcomes and intervals but use `ASSAY_INSENSITIVE_FOR_PERSISTENT_TRADEOFF` (with the failed gate). Do not convert a null old-memory contrast into “protection.” The final `WWWW` old plus cohort-1–4 new choices and margins are a **joint competence panel**, reported at every cohort end and at `D4`. Earlier-new retention after later writing is not hidden by a good fourth-cohort score. Only describe sustained five-set competence if **the old and all four new sets** each have a final +24 h absolute choice interval with lower bound >0.5; this is a narrow operational label for the tested sets, not full A11 certification. Keep the raw 15 pair decisions available in reduced tables, but infer over worlds, never over 15 pairs as independent observations.

Predeclared secondary paired time course: `W−N` old choice/margin after each new cohort and at `D4`; each `W−S_j` immediate incremental old-choice/margin effect; `WWWN−NNNN` (first-three write-history effect under a fourth no-write block), `WWWW−WWWN` (fourth-write effect after three writes), `NNNW−NNNN` (fourth-write effect without prior writes), and their difference as a prior-history×fourth-write interaction. Report these at `E4` and `D4` as descriptive intervals; do not issue additional unadjusted discovery labels. At `E4`, also report `NNNW` absolute current-new choice and its same-`N3`-prestate increment over `NNNN`; if last-only cohort-4 acquisition fails, mark the interaction `LAST_ONLY_ACQUISITION_UNVERIFIED` and do not interpret it as an interaction among two successfully learned policies. The cohort-1 immediate `W−N` result is a fresh-world prospective replication of V9.4, not a replacement primary. Because the first-three histories differ, `WWWW−NNNW` is **not** a same-prestate estimate of accumulated synaptic injury. Report `NNNN−CLOCK_ONLY` and `WWWW−CLOCK_ONLY` to distinguish the V9.4-style benefit of new-byte exposure from active write effects, while recognizing that exposure also changes internal state. The sampling unit remains the generated world; no treatment assignment to independently born flies occurred.

For old pairs, count which were strictly correct in the common prechallenge state and later became tied/incorrect in each arm, always against the same at-risk identities. Report both raw at-risk/lost counts and the per-world lost fraction with denominator **all three old pairs**. Also report each world's minimum old-pair margin and the old-pair margin distribution. The shared-symbol-containing versus unshared old-pair split and KC-code overlap are exploratory localization diagnostics; neither identifies an anatomical teaching address or explains causation by itself. Keep V9.4's fixed evaluator-side independent Gaussian value-noise sensitivities at SD 0.02 and 0.05 Hz (`Phi(margin/(sqrt(2)×SD))`), explicitly as assumed readout sensitivities, not measured biological noise.

## Statistical scope and sample size

The `n=256` world bank is fixed before any scientific endpoint is inspected; there is no outcome-dependent extension, early stop or replacement. V9.4's immediate old-choice paired SD was approximately 0.2885. If that SD carried to a V9.5 endpoint, `n=256` would give a two-sided 95% choice half-width around 3.5 pp and a 97.5% family interval half-width around **4.1 pp**. The four-cohort +24 h variance may be different; these are sizing illustrations, not promised precision or power. The unusually small V9.4 +24 h choice SD is **not** used for planning. Small (<~5 pp) terminal effects may remain unresolved even at `n=256`. No claim of cross-fly anatomical replication follows from many byte worlds on one fly seed.

The main analysis uses the predeclared t intervals over whole-world paired differences. As a robustness diagnostic, also compute deterministic whole-world bootstrap percentile intervals (10,000 resamples, a fixed separately recorded seed) and leave-one-world-out directions. If a t-based harm label changes under bootstrap, prominently mark it `METHOD_SENSITIVE`; do not silently replace the primary method. If either primary endpoint has zero empirical variance across complete worlds, report its point estimate and `INFERENCE_UNRESOLVED_ZERO_VARIANCE`, **not** a zero-width interval proving certainty. World-generation and treatment paths are deterministic; an exploratory sign-flip calculation, if shown, is not a design-based randomization test.

## Integrity, technical qualification, and failure handling

Before any scientific world, independently review the completed design and runner. Unit/fixture checks must reject: repeated/contradictory pairs, unbalanced labels, schedule or reward drift, nonidentical same-prestate forks, a `Teach(write=False)` reward-label leak on parent, old-trained prechallenge **and W3** states, wrong clock, probe mutation, predictor divergence, wrong actual byte/teaching/**write-true** counts or write-flag hash, stale or swapped receipt, source/checkpoint mismatch, missing shadow, and a save/load roundtrip mismatch. On a technical full-length world, show that `native.flush` and passive-copy +24 h probes agree and that flush preserves predictor history/weights. Verify exact predictors across every same-stream write/no-write branch, including final factorial and shadows. Check `max_clock_error <1e−6 s` and a streaming schedule/hash ledger rather than storing raw per-byte rows.

Run four **out-of-bank full-chronology technical worlds**, including one with the final 20,000-byte text-continuation checks and three ordinary worlds, in the final receipt mode with up to four parallel processes. Inspect integrity and resource fields only; do not use their behavioral scores to change the learning schedule, sample size, thresholds or endpoints. If an implementation error is found, record it, revise source hashes, and repeat all applicable technical gates on new excluded indices before science. The science command must refuse to run unless a source-matched technical gate has passed. Every scientific receipt is atomic, schema-checked and revalidated on resume; a failed receipt is retried for the **same** sealed world, never replaced. Do not summarize a partial world bank as confirmatory.

Four prespecified science sentinel worlds (401–404) receive frozen no-reset 20,000-byte Doyle and Stevenson continuations at the common prechallenge state and after cohort 4. Compare full-stream/content-byte BPB with the locked V9.2 train-only Markov-2 baselines and require exact predictor-state equality across same-stream native-write policies. Do not repeatedly score text after each cohort; that would multiply runtime without resolving the value-memory question. A text-regression failure is reported separately and blocks any maintained-joint-utility claim, but does not retroactively change the native write-effect contrast. The predictor remains a separate route; no predictor→value teaching is inferred.

## Resource and execution plan

V9.4 measured **2.53 s per ordinary world** (28 worlds) and **33.86 s per text-sentinel world** (four worlds), totaling about **206 worker-seconds** and roughly 68 s wall for its four-worker execution. That assay had old acquisition plus one new cohort. V9.5 has old acquisition, four new cohorts, disposable same-prestate shadows and a final factorial split: about **1,008 processed arm-records per world versus V9.4's 288**, before extra probes. The ratio 3.5 is a workload count, **not** a calibrated speed ratio. No V9.5 peak-RSS or wall-time measurement exists yet.

Planning estimate, conditional on the full-length qualification: an ordinary world might take **9–18 s**; `256` worlds at four workers would then occupy roughly **10–20 min** of parallel world processing. Allow another **5–20 min** for the four technical qualification worlds, four longer text sentinels, process startup, receipt checks, aggregation and a normal contingency. Thus **approximately 15–40 min wall time** is a planning range, not a promise. With two workers, plan roughly **30–80 min**. Simulated 24 h rest does not add real-time waiting. The technical gate must report each pilot runtime (including its maximum), sentinel time, four-worker aggregate peak RSS, swap activity, and peak/persistent disk. Three ordinary technical timings cannot estimate a reliable P95; monitor actual science runtimes operationally without changing the sample or analysis. If four workers cause swapping or unsafe memory pressure, lock two workers before science; confirm per-world deterministic equality across worker counts. A timing miss changes the forecast or execution concurrency, **never scientific `n` after outcome inspection**.

Keep each receipt to hashes, phase counters, pair-level endpoint summaries, state/route checks and resource fields; persist no per-byte trajectory CSV. V9.4's entire local receipt folder was under 1 MB for 32 worlds; four-cohort receipts could be several times larger, so reserve **tens of MB** locally plus bounded temporary checkpoints and measure it in qualification. The shareable V9.5 result bundle remains **<10 MB**: `REPORT.md`, final metrics tables, one or two key figures, model/config references, acceptance checks, source/manifest hashes and audits. It points to unchanged parent assets; it never duplicates the checkpoint, source datasets, third-party code, caches or raw per-world outputs.

## What the result can and cannot decide

If old choice or margin remains lower after four cohorts and 24 h, and all learning/floor gates pass, continued writing has a persistent adverse effect under this overlapping-byte workload. The shadow and final 2×2 comparisons can localize *when* a write effect appears and whether prior history changes the fourth-cohort effect; they cannot uniquely identify a synapse, a DAN compartment or a neuron-count bottleneck. If no persistent loss is resolved, this design supports only the tested four-cohort, one-checkpoint result; it does not certify lifelong memory or general NLP. If the four cohorts are not learned or the old no-write baseline reaches chance, the assay has not tested a meaningful preservation tradeoff. Only after this result should a separate experiment vary byte overlap, KC coding, inter-cohort spacing, topology or a B/HASH8-style anchor.

This is **byte-specific one-old-plus-four-new-cohort stress**, with three reversed-pair decisions per cohort. It does not inherit the old PN-cue A11 `K8/L1`, `K16/L1`, or `K8/L4` meanings, its 192-life count, or its 16–19 CPU-hour estimate.
