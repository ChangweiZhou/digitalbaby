# Full151 bridge, step 2: fresh-world preservation gate

The step-1 engineering pilot (worlds 9101–9108) suggested that reducing the
additive predictor-to-PN gain from 0.5 to 0.05 restores immediate native
teaching while the predictor remains online. Those eight worlds only selected
the **single** candidate; none enters this confirmation. This test determines
whether gain 0.05 preserves the FE0 value route in the same synthetic V9.8
P/N task. It does not show that the added temporal signal is useful on a task
where FE0 cannot see order, and it does not test arithmetic or autonomous
output. The inherited Full151 structure and plasticity remain unchanged.

## Frozen exposure and branches

Technical world: 9199. New confirmation worlds: 9201–9328 inclusive (128).
These indices are separate from all previous bridge worlds. Every world has
six taught P/N pairings, both byte orientations, repeated in 144 old records;
three other pairings are withheld in both orientations. The first immediate
`old_end` read-only choice on withheld pairings precedes any feedback on them.
Exact raw/canonical taught-pair lookup cannot solve withheld combinations; a
learned one-bit symbol class can. The result, if positive, is limited E3 reuse
within this synthetic relation family, without delay or intervening learning.

The four full-life branches are FE0_W, FE0_N, B005_W and B005_N. W/N receive
the same bytes, teaching labels, online predictor updates and clocks; only
native value writing differs. FE0 gain is 0 and B005 gain is 0.05; the V9.2
predictor continues updating in both. The score comes from the same native
Full151 value comparator over two externally supplied orientations. Predictor
weights and trial time must agree across all four branches. Neither a held-out
label nor a response is fed back during probing.

## Predeclared conjunctive gate

The world is the analysis unit. All 128 worlds run once, regardless of interim
results. Let `D_T` be B005_W minus FE0_W on **taught** choice, and `D_H` be
`(B005_W−B005_N)−(FE0_W−FE0_N)` on **held-out** choice. Let `G_H` be the B005
held-out W−N effect. Use one-sided 95% Student-t lower bounds across worlds.
The gain-0.05 candidate passes this narrow gate only if all hold:

* lower(`D_T`) > −0.05: no more than a five-point taught-choice penalty;
* lower(`D_H`) > −0.10: no more than a ten-point loss in causal held-out gain;
* lower(`G_H`) > 0: native prior teaching improves held-out choice.

The 5/10-point margins are engineering tolerances, chosen before these worlds;
they are not claims of strict equivalence. Also report two-sided 95% intervals,
absolute W/N accuracy and all per-world effects. Failure is informative and
does not trigger a new gain search on these worlds. Passing licenses a *new*
order-dependent task gate, not a general learning-core claim.

Technical qualification must reproduce the frozen route-factorial FE0 pair
margins exactly on world 9199, and reproduce step-1's B005-online path on
that same unused technical world. Probes must leave live state unchanged;
source/checkpoint hashes, predictor digests, write counts, fixture exclusions
and clock parity are checked. If qualification fails, no confirmation world
starts. A scientific failure writes a failure receipt and stops without
automatic restart. Completed receipts are never rerun. Caffeinate stays
attached to the active runner. Receipts store margins and scores, not full
event ledgers or model checkpoints. A separate reducer checks receipt-level
arithmetic and the frozen gate; it cannot independently recompute native
synapse dynamics from source events.
