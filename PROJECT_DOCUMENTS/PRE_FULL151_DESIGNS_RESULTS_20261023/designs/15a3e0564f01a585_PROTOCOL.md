# V38 — Predictive Evidence Arbitration
## From corroboration count to causal confidence

**Status:** design / preregistration only. No V38 scientific outcomes have been observed.

**Proposed scientific seeds:** `38101`–`38108`  
**Stateful trajectories:** 16 total = 8 × `PRED-V` + 8 × `EXACT-V`  
**Primary mechanism:** slot-local predictive Bayes-factor authority (`PBF`)  
**No automatic follow-up. No parameter sweep. No new encoder. No new write rule.**

---

## 0. Decision in one sentence

V37 established that **memory authority must be selective**, but it also exposed that raw corroboration count is too coarse: a support-2 candidate can be either the exact situation where held-out alias transfer should be trusted or a generic nontarget cluster where hard retrieval is harmful.

V38 therefore asks:

\[
\boxed{\text{Can a slot earn generalization authority from how much better it predicts new contexts than the shared base?}}
\]

The primary policy accumulates a causal, label-free, slot-local log predictive evidence score. A second rendering counts as strong corroboration only when the memory predicted an outcome that the base did **not** already predict equally well.

---

# 1. Why the first V38 proposal is rejected

The earlier proposal was to introduce a stable value plus a provisional revision branch and require two distinct contexts before a contradiction could rewrite the whole slot. That is a plausible future mechanism, but it is not the best next experiment for three reasons.

### 1.1 It attacks a downstream problem before finishing the V37 mechanism

V37 qualified `CORR2`, but `CORR2` is not yet a satisfactory endpoint. It grants full authority to every unbound candidate whose slot has support ≥2. V37's own conditional results show that this is still badly overconfident on ordinary text.

Weighted across the eight V37 seeds:

| tentative context class | base bpb | HARD / CORR2 hard-read bpb | fixed α=.50 bpb |
|---|---:|---:|---:|
| nontarget, support 1 | **1.164** | 5.300 | 1.458 |
| nontarget, support 2 | **0.623** | **2.356** | **0.543** |
| nontarget, support 3+ | 0.601 | 0.752 | **0.301** |

The support-2 row is decisive. `CORR2` treats all support-2 neighborhoods as trustworthy, yet hard retrieval there is almost four times the base log loss.

At the same time, support 2 is exactly the point at which the real held-out target alias becomes useful:

| E2 held-out probe after the second trained rendering joins | accuracy | target probability |
|---|---:|---:|
| SHADOW | 3.9% | 0.015 |
| α=.50 | 91.0% | 0.481 |
| CORR2 / HARD | **100%** | **0.946** |

Thus the unresolved question is **not** whether two observations matter. It is why some two-member neighborhoods deserve almost full authority and others deserve little or none.

### 1.2 Provisional revision would be confounded with slower updating

A two-hit or two-context revision rule could improve one-off-noise resistance simply by delaying writes. Without a validated confidence variable, a positive result would be difficult to distinguish from a generic learning-rate / confirmation-delay effect—the same class of confound that killed several earlier gating mechanisms.

### 1.3 It would throw away V37's clean causal experimental structure

V37's strongest methodological feature is that many read policies share **one identical PRED-V state trajectory**. A revision-policy experiment would branch the learner state and immediately reintroduce write-path confounding. V38 should exploit the clean read-only counterfactual structure one more time while the remaining question is still about authority.

**Therefore V38 does not change revision semantics.** One-off-noise behavior remains a diagnostic only.

# 2. What V37 established and what remains open

## 2.1 Established

V37 completed 16/16 fresh stateful trajectories and passed state-path invariance.

- `HARD`: 100% held-out revision, but whole bpb ≈ **2.306**.
- `SHADOW`: whole bpb ≈ **1.290**, but 0% held-out revision.
- `CORR2`: **100% held-out revision**, whole bpb ≈ **1.388**, and qualified under all V37 gates.
- fixed `α=.50`: **87.5% held-out revision**, whole bpb ≈ **1.328**, also qualified.
- `RAND-MATCH`, with the same number of hard tentative reads as CORR2, was materially worse. Thus support count contains real information.

The architectural decomposition is now:

\[
\boxed{\text{proposal} \neq \text{binding} \neq \text{authority}}
\]

and this decomposition is retained.

## 2.2 Still open

V37 does **not** establish that support count is the right confidence variable.

Two facts coexist:

1. `CORR2` achieves the strongest held-out transfer because support 2 can justify high authority on real aliases.
2. fixed `α=.50` achieves better whole-stream utility because full authority on many support-2 nontarget candidates is excessive.

This is the V38 target:

\[
\boxed{\text{distinguish informative corroboration from redundant or accidental corroboration.}}
\]

# 3. Core idea: predictive evidence, not event count

Suppose an unbound context \(c_t\) tentatively retrieves slot \(j\) before the next byte \(y_t\) is known.

Let

- \(p_B(y\mid c_t)\): frozen pre-update shared-base distribution;
- \(p_j(y)\): frozen pre-update slot distribution;
- \(m_j\): number of exact members already in slot \(j\);
- \(E_j\): evidence accumulated from **previous tentative uses of this slot**.

After the true byte is observed, compute the prequential log predictive advantage

\[
\Delta E_t
=
\log p_j(y_t)-\log p_B(y_t).
\]

Then update only the auxiliary evidence ledger:

\[
E_j \leftarrow E_j + \Delta E_t.
\]

No learner weight, slot value, prototype, member set, eligibility state, or binding decision depends on \(E_j\).

Interpretation:

- \(\Delta E_t \gg 0\): the slot predicted something that the base found surprising; this is strong evidence that the similarity match carries reusable memory.
- \(\Delta E_t \approx 0\): both systems already knew the outcome; the match adds little evidence of a special object-level relation.
- \(\Delta E_t < 0\): the base explained the outcome better; this is evidence **against** granting that slot broad authority over similar contexts.

This is the key refinement over CORR2:

> A second context is not automatically one unit of corroboration. Its evidential value depends on what it predicted beyond the base.

---

# 4. Why this is particularly well matched to V37

The PRED-V permanent-binding rule already requires a candidate slot's **pre-update top-1** to equal the subsequently observed byte before a new context may join the slot.

But top-1 equality is a very weak test of evidence strength.

Example:

- slot assigns 0.55 to byte `A`;
- base assigns 0.95 to byte `A`.

PRED-V calls this a successful confirmation because both top-1 predictions are `A`. Yet the observation is evidence **for the base, not for the slot**:

\[
\Delta E=\log(0.55)-\log(0.95)<0.
\]

By contrast, suppose a second rendering of an arbitrary stored association yields:

- slot assigns 0.98 to byte `Q`;
- base assigns 0.01 to byte `Q`.

Then

\[
\Delta E \approx \log 98 \gg 0.
\]

Both events increment support from 1 to 2 under CORR2. V38 treats them radically differently.

This is exactly the distinction needed to reconcile the V37 support-2 target and nontarget results.

# 6. Common underlying learner trajectory

For each V38 seed, run one physical `PRED-V` learner trajectory.

All V38 authority policies see identical, frozen pre-observation quantities at each byte event:

- base distribution;
- candidate slot distribution;
- candidate identity;
- candidate similarity;
- candidate support;
- exact-bound / tentative status.

After the true byte arrives:

1. score every policy;
2. update each policy's auxiliary evidence state according to its own predefined rule;
3. execute the **single unchanged PRED-V observe/bind/write operation**;
4. verify the underlying PRED-V state hash is policy-independent.

Thus policy differences cannot alter:

- future base learning;
- slot values;
- prototype geometry;
- membership;
- eligibility;
- allocation count.

This keeps V38 a read-authority experiment, not a hidden write-rule experiment.

# 7. Authority policies

For every exact bound context, all deployable policies retain **full absolute ownership** exactly as V37.

For no-hit contexts, all policies use the base.

Policies differ only on **tentative unbound candidates**.

## 7.1 CORR2 — locked V37 primary reference

\[
q_{\mathrm{CORR2}}=
\begin{cases}
1,&m_j\ge2,\\
0,&m_j<2.
\end{cases}
\]

Prediction:

\[
p=(1-q)p_B+q p_j.
\]

No changes from V37.

## 7.2 ALPHA-0.50 — locked simple reference

For every tentative candidate:

\[
q_{0.5}=0.5.
\]

This arm was diagnostic in V37 but unexpectedly qualified. V38 treats `0.50` as a **locked candidate**, not as a tuned value. No alpha grid is rerun.

## 7.3 PBF — primary V38 policy

Initialize on slot allocation:

\[
E_j=0.
\]

Before the current outcome is known:

\[
q_j=
\begin{cases}
0,&m_j<2,\\[2mm]
\sigma(E_j)=\dfrac{1}{1+e^{-E_j}},&m_j\ge2.
\end{cases}
\]

Then

\[
p_{\mathrm{PBF}}=(1-q_j)p_B+q_jp_j.
\]

After the outcome is observed, if the context was tentative for slot \(j\), update

\[
E_j\leftarrow E_j+
\left[\log p_j(y_t)-\log p_B(y_t)\right],
\]

using the **pre-update** distributions frozen before observation.

Important details:

- evidence is updated whether or not PRED-V ultimately binds the context;
- failed tentative matches therefore contribute negative evidence when appropriate;
- exact bound repetitions do **not** update \(E_j\), because they test memorization, not generalization of the slot neighborhood;
- no decay, cap, temperature, learning rate, or threshold is introduced;
- `log_softmax` is used directly, so no arbitrary epsilon is required;
- the current event never benefits from its own outcome; \(E_j\) affects predictions only from the next event onward.

The `m_j<2` shadow gate is retained for one reason only: V37 already causally established that singleton speculative authority is catastrophic, and a singleton has not yet generated an out-of-member successful binding event from which reusable identity can be inferred.

## 7.4 SLOT-EVID — base-blind evidence control

This control asks whether the important variable is genuinely **advantage over the base**, rather than simply the slot being confident/correct.

Maintain

\[
A_j\leftarrow A_j+
\left[\log p_j(y_t)-\log(1/256)\right]
\]

on the same tentative events, and use

\[
q_j=0\quad(m_j<2),\qquad q_j=\sigma(A_j)\quad(m_j\ge2).
\]

The uniform reference is fixed by the 256-byte alphabet; no fitted quantity is introduced.

If SLOT-EVID matches PBF, the shared-base comparison is unnecessary and the mechanism should be simplified.

## 7.5 SHUFFLED-PBF — decisive specificity control, nondeployable

This control preserves the **entire marginal distribution and timing of PBF evidence**, but destroys which slot earned which evidence.

After each tentative event:

1. compute the same \(\Delta E_t\) as PBF;
2. update the PBF ledger normally for the primary arm;
3. for the control, deterministically shuffle the current evidence values among slots **within the same current support bin** (`1`, `2`, `3+`) using a seed-fixed RNG before the next event.

Thus SHUFFLED-PBF preserves, at each step and support class:

- number of slots;
- multiset of evidence values;
- total evidence;
- evidence update timing;
- support distribution;
- underlying learner state.

It destroys only the mapping

\[
\text{this slot} \leftrightarrow \text{this slot's predictive history}.
\]

SHUFFLED-PBF is evaluator-side and nondeployable. It exists solely to answer:

\[
\boxed{\text{Does slot-specific predictive history matter, or only the global authority distribution?}}
\]

If SHUFFLED-PBF matches PBF, the mechanism is rejected regardless of headline performance.

# 10. Primary hypotheses

## H1 — V37 residual failure is localized to coarse support confidence

On **tentative nontarget support-2 events**, CORR2 hard retrieval must remain materially worse than the base on the fresh seeds.

This is a replication gate for the problem V38 claims to solve.

If support-2 hard retrieval is no longer harmful on fresh seeds, V38's mechanistic premise is not replicated and PBF interpretation is downgraded.

## H2 — predictive evidence improves the CORR2 utility/transfer conjunction

Relative to CORR2, PBF should reduce nontarget and whole-stream log loss while preserving held-out alias revision.

Primary paired contrasts:

\[
\Delta_{\text{PBF-CORR2}}\text{ nontarget bpb}<0,
\]

\[
\Delta_{\text{PBF-CORR2}}\text{ whole bpb}<0,
\]

with held-out revision noninferior.

## H3 — PBF improves on the simple α=.50 compromise

Relative to fixed α=.50, PBF should recover the missing held-out transfer while remaining whole-stream noninferior.

This is what distinguishes a learned local confidence variable from a globally reduced memory gain.

## H4 — slot-specific evidence is causal

PBF must beat SHUFFLED-PBF on the primary utility/transfer conjunction.

Failure of H4 retires PBF as a mechanism even if PBF's raw metrics are attractive.

## H5 — evidence over the shared base matters

PBF should outperform SLOT-EVID. If SLOT-EVID matches it, the architecture is simplified to base-blind slot confidence and no claim is made for comparative predictive evidence.

# 11. Qualification gates for PBF

All gates are evaluated on fresh seeds only.

## Q0 — invariance / causality

Mandatory engineering gate.

At every checkpoint, the physical PRED-V learner must have identical hashes regardless of read/evidence policy for:

- base;
- slot values;
- prototypes and sums;
- member sets/vectors;
- eligibility;
- full learner state.

Every prediction and evidence increment must use distributions frozen **before** the current byte is revealed.

Any violation voids the run.

## Q1 — acquisition and persistence retained

Using the PBF read policy:

- A acquisition ≥ 90% mean;
- A-after-D ≥ 90% mean;
- D-current ≥ 90% mean;
- no science seed below 75% on A-after-D.

## Q2 — exact and known-alias revision retained

After four true revision presentations:

- exact revised alias ≥ 90%;
- known trained alias ≥ 90%.

## Q3 — held-out generalization remains strong

After four true revision presentations:

\[
\boxed{\text{held-out alias accuracy}\ge 90\%}
\]

with no seed below 75%.

The threshold is intentionally stricter than V37's original 50% gate because V37 CORR2 already established 100% on this workload. V38 is a refinement, not a regression to the old minimum.

## Q4 — obsolete value suppressed

After eight true revision presentations:

\[
P(\text{obsolete byte})\le 0.10.
\]

## Q5 — whole-stream utility

PBF whole-stream bpb must be no more than **0.05 bpb worse** than its base-only counterfactual:

\[
\Delta_{\rm base}^{\rm whole}\le0.05.
\]

This tightens V37's +0.10 qualification margin because V37 has now shown that positive whole-stream utility is achievable.

## Q6 — nontarget utility

PBF nontarget bpb must be no more than **0.05 bpb worse** than base:

\[
\Delta_{\rm base}^{\rm nontarget}\le0.05.
\]

## Q7 — binding purity unchanged

Because PBF is not allowed to alter binding, PRED-V must again show:

- evaluator-known different-key target binding rate <5%;
- final impure target-context fraction <5%.

Any deviation from the underlying PRED-V reference indicates an implementation bug.

## Q8 — comparative improvement over CORR2

PBF must improve nontarget bpb over CORR2 by at least **0.10 bpb in mean paired difference**, with the paired 95% interval excluding zero, while held-out accuracy is noninferior within **5 percentage points**.

This is the main V38 mechanism gate.

## Q9 — comparative improvement over α=.50

PBF must be whole-stream noninferior to α=.50 within **0.05 bpb**, while improving mean held-out accuracy by at least **5 percentage points**.

The interval for the held-out contrast is reported; failure to exclude zero is not by itself fatal because eight-seed Bernoulli endpoints are coarse, but the direction and materiality threshold are fixed in advance.

## Q10 — shuffled-evidence veto

PBF must beat SHUFFLED-PBF on at least one of:

- whole-stream bpb by ≥0.10;
- nontarget bpb by ≥0.10;
- held-out accuracy by ≥10 pp;

with the paired 95% interval excluding zero on that endpoint, and must not be materially worse on the other two primary endpoints.

If SHUFFLED-PBF matches PBF, **PBF is rejected as slot-specific confidence**.

# 12. Evidence diagnostics — mechanistic, not just endpoint scoring

V38 must explain *why* PBF succeeds or fails.

## 12.1 Evidence calibration by support

For tentative events, report separately for support 1, support 2, and support 3+:

- count;
- mean / quantiles of \(E_j\) before prediction;
- mean authority \(q_j\);
- base bpb;
- slot-only bpb;
- PBF bpb;
- fraction where slot beats base in log loss.

## 12.2 Evidence deciles

Within tentative support-2 nontarget events, bin by **pre-event** PBF authority decile.

For each decile report:

\[
R=\log p_j(y)-\log p_B(y)
\]

and PBF/base log loss.

A useful confidence variable should order future reliability: high-authority bins should have higher subsequent slot advantage than low-authority bins.

No evaluator label enters the authority calculation; labels are used only to summarize calibration after the event.

## 12.3 E1 → E2 held-out emergence

Repeat the V37 emergence probe.

At E1 and E2 report for the held-out alias:

- source slot support;
- source slot accumulated evidence;
- PBF authority;
- base probability of target;
- slot probability of target;
- PBF probability of target;
- top-1 accuracy.

The desired signature is:

- E1: support 1, authority 0;
- E2: support 2, strongly positive evidence, authority near 1 for genuine logical aliases.

This is the direct test of the proposed mechanism.

## 12.4 Generic support-2 counterexample audit

For nontarget support-2 candidates, record the same quantities.

The central expected contrast is:

\[
E_j(\text{true alias support 2})
>
E_j(\text{generic support 2})
\]

in a distributional, not evaluator-hardcoded, sense.

# 13. One-off noise remains diagnostic only

V38 does **not** change slot values or revision writes, so the known V37 one-off-noise failure is expected to remain.

Nevertheless record, without qualification consequences:

- evidence state before a one-off wrong observation;
- exact/known/held-out probabilities immediately before and after;
- hypothetical contradictory log evidence
  \[
  \log p_B(y_{\rm wrong})-\log p_j(y_{\rm wrong});
  \]
- how many independent contradictory contexts would be required to offset the slot's accumulated generalization evidence if the same log-evidence principle were later used for revision.

This is **not** a V38 mechanism. It is the preregistered diagnostic that decides whether V39 should reuse predictive evidence for write/revision arbitration.

# 15. Hard implementation invariants

V38 is invalid if any invariant fails.

### I1 — one physical PRED-V learner

No authority/evidence policy has a private copy of base weights, slot values, prototypes, membership, eligibility, or bindings.

### I2 — evidence cannot influence binding

PRED-V candidate confirmation and allocation use the exact V37 rule and never read \(E_j\), \(A_j\), PBF authority, or policy output.

### I3 — evidence is prequential

The prediction uses \(E_j^{(t-1)}\). The current outcome updates \(E_j\) only after all policies have been scored.

### I4 — exact ownership unchanged

For a bound exact context, all deployable policies return the absolute slot value with authority 1. Evidence affects only unbound tentative reads.

### I5 — probes are read-only

Held-out alias probes, revision probes, calibration probes, and noise probes cannot update evidence or learner state.

### I6 — SHUFFLED-PBF has identical evidence marginals

At each audited checkpoint and support bin, the sorted multiset of SHUFFLED-PBF evidence values must equal the sorted multiset of PBF evidence values to numerical tolerance.

Only slot assignment differs.

### I7 — no evaluator metadata

The learner/policy cannot access logical key ID, alias number, target/nontarget flag, wave name, revision status, noise status, or probe type.

# 17. Engineering tests before science seeds

`--self-test` must verify at least:

1. PBF starts with zero authority on a singleton tentative candidate.
2. A positive tentative predictive advantage increases that slot's future authority.
3. A negative predictive advantage decreases that slot's future authority.
4. The current outcome cannot change the current prediction retroactively.
5. Exact bound contexts remain full absolute ownership regardless of evidence.
6. Evidence does not alter PRED-V binding/allocation.
7. Repeated probes do not update evidence.
8. PBF and SHUFFLED-PBF have identical evidence multisets at checkpoints.
9. SHUFFLED-PBF assigns evidence to different slots.
10. Underlying learner hashes match an uninstrumented V37-style PRED-V replay.
11. `CORR2` and `ALPHA-0.50` reproduce their frozen definitions exactly.
12. A synthetic high-Bayes-factor second rendering drives PBF authority close to 1 without any fitted gain.
13. A synthetic redundant confirmation where base is more confident than slot does not increase trust.
14. Resume rejects mismatched source/protocol/plan hashes.

`--verify-full` should independently replay at least one full engineering seed without the observer panel and match learner hashes and HARD losses exactly.

# 18. Decision tree after V38

## Outcome A — PBF passes Q1–Q10

Interpretation:

\[
\boxed{\text{slot-local prequential evidence is a validated confidence primitive.}}
\]

Freeze proposal, binding, absolute ownership, and PBF authority.

**Next round:** use the same evidence principle for **write/revision arbitration**, not a hand-coded two-hit rule. A contradiction should first accumulate evidence against the stable value; only sufficient independent predictive evidence should rewrite the object globally. Capacity can then use the same confidence ledger for admission/consolidation.

## Outcome B — PBF beats CORR2 but not α=.50

Interpretation: the extra evidence state is not justified; a globally bounded memory contribution is sufficient on this workload.

Freeze `α=.50` only after its fresh-seed V38 replication. Move to revision/capacity with the simpler read rule.

## Outcome C — PBF matches CORR2 but does not improve utility

Interpretation: support count captures most useful confidence available from this representation. Do not tune evidence. Move on to bounded capacity / revision.

## Outcome D — SHUFFLED-PBF matches PBF

Interpretation: the apparent benefit comes from the marginal authority distribution or generic regularization, not slot-specific predictive history.

**Reject PBF.** Do not carry the evidence ledger forward.

## Outcome E — PBF loses held-out transfer because evidence is systematically too weak

Do **not** add a temperature or tune a gain. The likely missing variable is identity geometry / evidence quality, not calibration scale.

The next experiment should test a separate identity-address representation (the surviving lesson from the independent V36 separation branch), while keeping the predictive base unchanged.

# 19. What V38 is allowed to claim if successful

A successful V38 would establish, on the current controlled workload, that:

1. persistent absolute memories can remain distinct from a shared predictive learner;
2. similarity can propose candidate object identity;
3. binding can be confirmed causally from subsequent sensory outcome;
4. retrieval authority can be calibrated from **slot-specific prequential evidence relative to the base** rather than a fixed support count;
5. the resulting evidence state improves the transfer/utility conjunction under a decisive shuffled-evidence control.

It would **not** establish:

- bounded lifelong capacity;
- robustness to one-off false revisions;
- natural-language semantics;
- biological equivalence to the fly mushroom body;
- a general replacement for Transformers;
- scaling laws.

The exact intended claim is narrower and more valuable:

\[
\boxed{\text{A memory should earn trust by explaining new experience better than the system that would otherwise predict it.}}
\]

# 20. Why this round is worth doing before capacity or revision

The project has repeatedly suffered when a downstream mechanism was built before the variable it should respond to had been identified.

V37 has now given a rare opportunity to avoid that mistake. We know:

- support count is informative;
- support count is not sufficient;
- a global 0.5 authority level is surprisingly competitive;
- the remaining error is concentrated in exactly the support-2 ambiguity where “corroboration” can mean either real cross-rendering identity or generic redundant structure.

Predictive evidence provides a single causal quantity that could later serve three roles:

1. **read authority** — V38;
2. **revision confidence** — future round;
3. **admission/consolidation priority under fixed capacity** — future round.

If V38 falsifies it, we learn this before entangling it with writes or eviction. If it survives, subsequent rounds can be built around one validated confidence primitive rather than a collection of unrelated heuristics.

That is the reason V38 should be this experiment.
