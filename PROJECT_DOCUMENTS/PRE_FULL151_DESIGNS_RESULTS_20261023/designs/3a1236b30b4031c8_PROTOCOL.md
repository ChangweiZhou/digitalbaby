# OMNIBUS10 implementation protocol

Version `omnibus10.1.1`. Parent design SHA256 `dbddedaec283beb5676ac2bceb6d93a78288507451caf57b8d0d58deeabd4676`.

The runner uses the proven V50 functional cue->consequence interface as the reference organism.
The five train-time mechanisms are fully crossed (2^5); silent reinstatement and read authority are read-only counterfactuals; COV96 is a bounded nonlocal oracle.

Important implementation refinements are listed in the script module docstring. Normal probes reset transient cell state between trials, so delayed retention is synaptic by construction and is additionally checked by a synapse-reset lesion.
