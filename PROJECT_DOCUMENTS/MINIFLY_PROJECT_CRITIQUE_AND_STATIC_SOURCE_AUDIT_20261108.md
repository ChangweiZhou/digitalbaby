# MiniFly project critique and static source audit

November 8, 2026. This note consolidates the project review and follow-up static code audit. Sources include both local working directories and the consolidated and parallel GitHub branches. The static audit used source and existing receipts. It ran no project code, tests, or replays. Historical results are preserved.

## What the project has demonstrated

MiniFly has demonstrated associative memory, bounded consequence learning, and continual learning on synthetic rules. The outstanding integration test is whether one learner can discover a useful representation, revise it after an environmental change, and use it to improve a decision.

- **Associative memory and shared computation.** R_center reached 97.14% on taught associations in one assay, while its held Latin completion teaching effect was −8.20 percentage points. This does not erase separate bounded positive reuse or revision results. In a later finite modular test, the shared path alone reached 86–92% exact while the associative residual reached 0.9–1.6%. E16-A's exact-key Store ablation barely moved aggregate scores. The recent arithmetic evidence belongs to the shared learner, its teaching signal, and replay. A matched episodic retrieval task would test the historical fly-derived memory mechanism on its own merits. The connectome line showed a displacement-direction advantage, with 0/3 fits qualifying for path integration. Distinct operation codes and still-valid old answers leave open how the same cue is revised after a change. Observed replay can retain obsolete answers in that setting. The accelerated reverse scan implements the trace update for the cell gates. Every-byte E16-L dropped delayed add/sub acquisition to 3–5%. The window and cell differ in distractors, curriculum, and replay. E16-S's backprop ceiling uses separately seeded joint sampling of admitted families, while the local arm sees drift plus replay. Those arms cannot isolate the update rule. E16-WL's all-byte arm also broadens Store writes for single operations. Composition scoring in its blocked schedule omits the Store. ## Static audit findings

1. **Deterministic operand overlap in held composition.** The seed formula is `31 * seed + 7 * ord(first) + ord(second)`. Held `+-` uses `seed + 1`, giving `31 * seed + 377`, exactly the taught `->` seed. The first 600 unique triples are therefore identical. The operator pairing and full prompt remain held out. The operand-level holdout fails, and the qualification checks pair membership while missing the collision. This pattern recurs in E7, E8, WR2/WL and E17. The effect on accuracy is unmeasured. Use independent seeds keyed by split and operation pair and assert the intended operand disjointness across all pools. [E17 source snapshot](https://github.com/ChangweiZhou/digitalbaby/blob/4bb3c0832007d254541bf7673f77b0e38ca3e03b/MOD97_LOCAL_RULE_20261106/exp16_integrated.py#L98-L111) · [E7](../MOD97_LOCAL_RULE_20261106/exp7_decon.py#L76)
2. **A post-update score labeled as the birth score.** E16 qualification performs ten D updates and ten T updates on the same model and optimizer before writing `birth_compose_final_before_life`. The archived qualification gives 122/600 on `><`; the scientific stage zero gives 364/600 on the same seed. The scientific scorer evaluates stage zero before updating. Qualification also calls the answer-only updater directly when the all-byte setting is requested. Measure birth first and qualify each update path from an independent copy. [Source](https://github.com/ChangweiZhou/digitalbaby/blob/4880698c080b0c51bfbcd2999fd9b398056d18c9/MOD97_LOCAL_RULE_20261106/exp16_integrated.py#L357-L370) · [Qualification](https://github.com/ChangweiZhou/digitalbaby/blob/4880698c080b0c51bfbcd2999fd9b398056d18c9/MOD97_LOCAL_RULE_20261106/exp45/QUALIFY_E16.json) · [Stage zero](https://github.com/ChangweiZhou/digitalbaby/blob/4880698c080b0c51bfbcd2999fd9b398056d18c9/MOD97_LOCAL_RULE_20261106/exp45/e16_life_T_raw65536_73129.json#L238-L262)
3. **V219's search distribution and feedback dose differ from their intended labels.** Index parity chooses both prefix and final opcode, so Stage T meta-training yields XXX and XYY and omits XXY and XYX. Its probes cross both endings with each prefix. The changed-64 checkpoint counts 61 informative and three invariant records. The T-end write-effect test also follows teaching on its three-opcode strings, unlike the earlier changed-law probes. These bugs change the scope of the search and dose claims. Recorded zero exact scores still describe the executed campaign. [Generator](../minifly_v219_evolved_local_plasticity_design_20261105/lifetime.py#L103) · [Checkpoint](../minifly_v219_evolved_local_plasticity_design_20261105/evaluate.py#L144)
4. **E17 can admit stale births.** The launcher gates on an existing filename and its last score. It does not check individual worker exit codes, expected dose, or a hash linking the receipt to the checkpoint the life will load. A failed child can leave a passing stale receipt available. The launcher also overwrites and unconditionally removes a host-wide lock, while E16-WL uses a checkout-local lock. Two controllers can both proceed. Require one atomic host-wide lock with ownership checks and bind gate admission to a verified completion receipt. Actual stale admission or overlapping execution was not established by this audit. [E17 launcher](https://github.com/ChangweiZhou/digitalbaby/blob/4bb3c0832007d254541bf7673f77b0e38ca3e03b/MOD97_LOCAL_RULE_20261106/e17_overnight.sh#L3-L41) · [Lock amendment](https://github.com/ChangweiZhou/digitalbaby/commit/cb31d431c4c5c754da5613ffc361a078fc17ab6d)
5. **E16-WL can mix score and loss artifacts.** Both loss modes write the same score name. A later answer-only invocation can replace the score while retaining an all-byte sidecar. Validation checks mode only in the sidecar, and the final digest binds the scores while excluding the loss and replay sidecars. No replacement was established for the reported campaign. Use distinct run identities and bind every output to the same completion receipt. WR2's capacity arms have a related pre-digest risk because the scores share a schema and are validated separately from capacity-bearing metadata. Local references under `Documents/second_try/MOD97_LOCAL_RULE_20261106`: `e16wl.py:13,120,130`, `e16wl_campaign.py:81,126`, `e16wr2_common.py:54`.
6. **E16 can mislabel the training stream and comparator.** Drift with default uniform replay switches back to blocked fresh inputs after the first block fills the buffer. The published raw-replay drift arm uses the correct branch. The summary omits `D_lossall` and maps the all-byte local arm to the answer-only D, even when the same-loss receipt exists. Reject unsupported configurations and explicitly join on objective and data policy. [Batch selection](../MOD97_LOCAL_RULE_20261106/exp16_integrated.py#L233-L265) · [Comparator selection](../MOD97_LOCAL_RULE_20261106/summarize_exp16.py#L16-L38)
7. **Ordered-front-end sham is vacuous and excluded from reduction.** One frozen deterministic learner is scored on identical inputs under two laws with conflicting targets, forcing a zero quartet score regardless of its learning. The reducer does not read sham receipts. The negative screen did not enter this conditional path. A future positive screen requires paired matched sham histories and a reducer that evaluates them. Local references under `Documents/second_try/output/minifly-ordered-front-end`: `campaign.py:109,178`, `revised_panel.py:174`, `summarize_campaign.py:53`.
8. **Other restart, scoring and configuration risks.** V218's audit can accept empty or truncated live trajectories with intact counters and panels, and resume does not bind previous rows to the learner source. Ordered-front-end resume accepts same-clock checkpoints without arm, birth, law or parent identity. V216 reruns completed worlds on restart and overwrites the prior accounting. R_center imports bare vendor module names before its lock verification, which cannot validate a different same-name module already cached by a host. Navigation's heading clamp substitutes the entire EPG state and verifies only its angle, while the downstream circuit sees the entire vector. The angle scorer can also count zero displacement as a hit near 0°. These paths establish risks, with no evidence that a stale checkpoint, truncated archived trajectory, or zero-vector hit occurred. WR2 also accepts a blocked `share` schedule that samples an empty composition buffer, and accepts an interleaved batch of four that produces zero examples per task. Store FIFO eviction uses `list.pop(0)`, shifting the list at capacity. ## Priorities

Fix the split and add an independent overlap audit. Bind score, sidecars and checkpoint to one run identity and require the same objective in the matched comparator. Keep the archived receipts and distinguish their original verdicts from corrected evidence.

Freeze the E16 reference and compare answer-only and every-byte loss under local updates and backprop on identical delivered and replayed bytes, with birth, optimizer, and exposure held fixed. Vary distractor predictability and length separately. For composition, vary earlier single-operation teaching while keeping later paired examples identical, and intervene on the generated intermediate to test its causal role.

For architecture promotion, require one learner to infer a change in a familiar cue's meaning from experience and make a first correct choice on a held combination while preserving unrelated knowledge. Use paired cases whose correct actions diverge only when the intervening observation is used. Match memory, feedback and compute against a recency table and an ordinary recurrent learner. Ablate any fly-derived component whose contribution is claimed.
