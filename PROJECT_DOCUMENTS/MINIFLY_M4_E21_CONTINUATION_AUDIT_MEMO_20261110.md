# Audit memo on E21, the interrupted M4 run, and current progress

10 November 2026

Fable has provided a concrete restart-safety brief. The file located in the checked repository is `OPUS_TASK_E21_RESUMABLE_LIVES_20261110.md`. It proposes resumable lives and births for the existing harness. Its engineering direction is sound, with specification defects to resolve before the worker implements it. The available brief does not provide the missing state from the interrupted M4 run. A separate, later instruction explicitly reopening M4 was not located in the checked snapshot or matching file and commit searches.

The distinction matters because the coordinator’s recorded decision closes M4 incomplete, while the interrupted worker’s earlier commit proposed starting the same commands again. A new authorized completion plan can supersede that closure, but the evidence must say whether it recovers saved state or repeats training from the birth. This memo audits the located brief and states the conditions for either path. It also incorporates the latest progress findings requested alongside it. **M4’s scored checkpoints are insufficient to resume its learner.** The original M4 run pinned the `ab0ae7ac` harness. That code writes stage metrics during the life and saves model weights only after the complete six-stage loop. It saves no optimizer checkpoint at each scored stage. The retained twelve lives end at stage five and lack final completion records. Matching a handful of scores cannot identify the parameter state, AdamW moments, or data-generator positions that produced them. E21 replays data with learning switched off to rebuild a pipeline, then loads the saved model and optimizer. That method requires a checkpoint that already contains those learned states. It cannot create them from the M4 metrics. If an external complete checkpoint survives, verify its run configuration, stage, birth, source, optimizer and pipeline state before continuation. If only the birth and partial metrics survive, reproducing the first five stages requires performing their updates again. That is a new full execution of the same seeded experiment. Record its cost and provenance, retain the interrupted attempt, and count one completed life per original seed/share cell. Reusing seeds does not create additional independent worlds. Loading weights with a fresh optimizer would introduce a third, changed trajectory.

For any M4 completion plan, freeze the twelve cells, original shares, dose and predictions. The six share-0.75 cells and the three cells each at 0.875 and 0.9375 must be accounted for. Maintain the original scientific source snapshot or establish the claimed behavioral equivalence of a repaired runner. Verify comparator panels, actual shares and terminal stages. A final-checkpoint prediction must use checkpoint six in every required cell. The existing stage-five trends remain descriptive. They cannot judge the registered late-loss prediction or the final curve-turn prediction. **E21 needs six explicit acceptance provisions.**

1. **A scientific digest that can survive a restart.** The brief says to hash every effective `E16_*` and `E11_*` setting, but enabling `E16_RESUME=1` changes that set. Exclude operational resume controls and normalize effective defaults. Include seed, arm, dose, birth digest, panels, imported scientific source and software settings relevant to determinism. Reject changes with a field-level explanation.
2. **One authoritative checkpoint generation.** Bind model, optimizer, pipeline and receipt to the same stage and run ID. After a crash, an independently written JSON receipt may be newer, older or truncated. Recover from the chosen checkpoint generation and regenerate its receipt view. Test interrupted checkpoint writes, rotation to `.prev`, and final weight/receipt publication, alongside the requested update/evaluation interruptions.
3. **Explicit reconstruction of all pipeline effects.** Replaying batches while skipping the update also skips the Store writes inside that update. Reproduce those writes under the effective loss mask. Verify ordered buffers, reservoir counters, every generator’s position, and random state. Save or explicitly justify excluding Python, NumPy and torch global RNG state. A digest must be formed from a canonical representation, especially for sets and mappings.
4. **Replay independence proved for each supported mode.** The present raw-observation pipeline can be rebuilt without the learned model under the inspected paths. Qualification must demonstrate this for the seven declared command shapes. A later policy, generated replay target or model-dependent admission rule would change that premise. Reject unsupported modes explicitly.
5. **Scientific parity and cost accounting tested separately.** Compare stage scores, losses, tensor values and pipeline state. Record timing and resumption metadata separately because they change. Carry compute spent before every crash, reconstruction compute and checkpoint overhead. When discarded work cannot be recovered exactly, report the missing interval rather than assigning it zero cost. Use matching serialization paths for file-hash parity, with tensor comparisons to diagnose serialization-only differences.
6. **Failing admission must prevent the actual run.** Bind passed qualification to the exact implementation and configuration used by the launch path. Include wrong-source, wrong-birth, wrong-dose, mixed-generation and corrupt-state fixtures. Exhausted or damaged recovery generations must stop with an explicit reason. The coordinator’s independent verification should precede merge. This memo identifies requirements for implementation and does not certify a working resume feature.

The brief already asks for same-machine exact interrupted-versus-uninterrupted comparisons, multiple kill points, corruption checks, a larger technical dose and separate-branch development. Those requirements should stay. A machine-specific parity result should state its hardware, library and thread assumptions. E20 dry runs already showed that cross-machine weight hashes can differ even when nearly all scores agree.
