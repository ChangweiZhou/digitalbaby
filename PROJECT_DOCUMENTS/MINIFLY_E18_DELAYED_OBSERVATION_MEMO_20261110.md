# MiniFly after E18 — learning from delayed observations

10 November 2026

Mr. Zhou proposed that local rules may have a better opportunity in a time series. The environment can later supply information that the learner lacked earlier. That might be the next byte or a wider view of the same scene. A learner can compare a committed prediction with the later observation and learn from the error, even in a passive stream with no reward or policy optimization.

## What E18 earns

The full-time sign-feedback arm reached **84.7–90.7%** on held add/sub at 12 distractors. The two detached-head arms reached **77.2–82.2%** with within-bank backprop and **66.3–74.8%** with sign feedback. The write-trace-only arm stayed near 1%. E18 therefore shows that separate bank objectives can support useful behavior and gives a reason to investigate how much temporal credit each bank needs. The arms also differ in feedback form, head and loss, and decay, so the score gaps belong to the tested packages. E18 used an answer mask and correct answer-byte targets. Its strongest sign-feedback path still swept backward through the record using sign-modified feedback. Ordinary observations as teaching targets and bounded forward-only credit remain separate hypotheses. ## Relevant precedents

- **Local objectives from temporal structure.** Löwe, O’Connor and Veeling’s Greedy InfoMax trains gradient-isolated modules using the natural order of unlabeled data. Its speech results also show that restricting temporal credit hurts when the downstream task needs longer context. Illing et al.’s CLAPP uses later views and a gaze-change signal for layer-local contrastive prediction. The visual setup is especially close to Mr. Zhou’s idea. Its main speech context module used BPTT, so the paper should not be read as a fully local result across all setups. [Greedy InfoMax](https://arxiv.org/abs/1905.11786) · [CLAPP](https://proceedings.neurips.cc/paper_files/paper/2021/file/feade1d2047977cd0cefdafc40175a99-Paper.pdf)
- **Prediction without temporal unrolling.** Ororbia et al.’s P-TNCN tests local representation alignment on sequence modeling. Its Penn Treebank character result was 1.70 test bits per character, versus 1.38 for the cited full-BPTT LSTM. The architectures and budgets differ. This is evidence that non-unrolled prediction is viable on natural text, with a meaningful performance gap to the stronger reference in that comparison. [P-TNCN, Table I](https://arxiv.org/abs/1810.07411)
- **Late feedback and eligibility.** Bellec et al.’s e-prop uses eligibility traces and approximate learning signals, including a supervised cue-integration assay where the teacher arrives late. Murray’s RFLO uses projected output error with local traces and finds a larger gap to BPTT at longer delays. The useful mechanism to borrow is a bounded record of earlier contributions that a later error can act on. The source of that error is an independent experimental factor. [E-prop](https://pmc.ncbi.nlm.nih.gov/articles/PMC7367848/) · [RFLO](https://elifesciences.org/articles/43299)
- **A richer view and later reuse.** Sermanet et al. learn useful representations by pairing views of the same moment. MiniFly can test a delayed version by committing its prediction before the wider view appears. In a different setting, Martinez-Cervantes et al. showed that fruit flies can first associate neutral odors and later respond to an odor that was never directly conditioned. That gives MiniFly a biological analogue for testing whether passive experience can inform a later decision. [Time-Contrastive Networks](https://arxiv.org/abs/1704.06888) · [Fly sensory preconditioning](https://elifesciences.org/articles/79107)

## A bounded test on the existing two-bank model

1. **Test the observation before changing the rule.** Start with gradual warmup on bytes from a small, partially observed world. A narrow view is followed by a wider view after intervening events. Commit the early prediction before the wider view arrives. Compare aligned reveals against targets shuffled within delay and frequency strata, with the same sensory stream, heads and target counts. Include a next-byte comparator with the same target budget. An oracle and a visible-suffix lookup should establish that the assay can distinguish useful history from shortcuts.
2. **Test the credit path once the observation proves useful.** With the same informative targets and architecture, compare a bounded local trace, the same trace reset before the target arrives, and backprop given the same observations and heads. Keep prediction horizon distinct from added target-delivery lag. Log external bytes, loss applications, trace memory and actual compute. Compare paired learning curves under both matched exposure and matched compute.
3. **Measure transfer before the reveal.** On held combinations, pair cases with identical recent bytes, different earlier histories and different correct answers. Require both first autonomous outputs to be correct through EOS. Use a matched branch without the relevant predictive association to test whether earlier learning caused the gain. A later revision test can change the use of a previously observed feature and measure whether the same learner transfers that revision without direct feedback on the held combination.

E16-L is a reason to keep the next-byte arm as a comparator. The every-byte local learner partly acquired add/sub and then lost much of it. Its prompt contained unpredictable distractors, and their causal role remains unresolved. A later view earns its place only if it improves **pre-reveal held behavior**, beyond both shuffled targets and the matched next-byte objective. If local and backprop benefit similarly, the result supports better data. If the local rule gains more and narrows the gap at comparable cost, it also supports Mr. Zhou’s stronger claim about learning in a temporal environment.
