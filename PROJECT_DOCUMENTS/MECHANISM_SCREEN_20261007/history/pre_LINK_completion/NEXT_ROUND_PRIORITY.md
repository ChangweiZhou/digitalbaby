# MiniFly下一轮机制投入筛选

2026年10月7日。71项是去重后的保留研究条目，不是71个同等成熟、同等值得运行的机制。本次按现有短板、合法信息、与失败配方的操作差异及单位成本筛选：**4项值得下一轮投入，其中3项是新候选方向，1项是已有配方的延续裁决/参照；8项留作条件备选，59项不安排本轮。** 这是研究预算判断，不是59项被科学否定，也不代表全部搜索空间已经耗尽。

目标仍是相同新经验与算力下提高现有核心的获取、保持、修订和有限经验复用。旧键/新键/修订E1与未强化关系E3分别报告；不新增智能、NLP、开放输出验收。CONTENT的桥接成功不再被重新开成前端轮换任务。

## 八项条件备选

- **U012 — / `ELIG_TRACE_PORT`：**ELIG_TRACE_PORT只有在提供当前cue缓存没有的实际延迟recipient信息时启动；目前没有这项已证实缺口。
- **U021 — / Stable/flexible compartment split：**稳定/灵活compartment不同于KC-side结构，但现有ERROR已显著改善修订；先要明确其独立收益与固定增益控制。
- **U043 局部边权学习与真实换边协同 P×S：**P×S是未测的联合局部学习/换边结构；需先冻结兼容旧记忆的更新操作。旧P/S负结果不能复活为换名字的配方。
- **U044 稳定地址与可塑内容分离或输入坐标兼容：**输入坐标兼容是采用可塑表示的必要条件。当前CONTENT地址已稳定，不单独开一次无对应变化的运输实验。
- **U045 有界Hebbian key/value或predictive residual fast matrix：**bounded Hebbian key/value是不同结构，但旧精确实现已有混合/负前例；需要限定方程、容量、成本和相对ERROR的新增用途。
- **U055 有界KC↔KC递归与广义调制反馈：**有界KC recurrence具有结构上的新意；缺具体局部动态和独立收益预测，不凭静态连边数量发起实验。
- **U062 冻结或慢残差参考与reference transport或constraint-only slow memory：**残差参考漂移有历史证据；当前center/ERROR没有证明存在这项剩余短板。冻结参考本身也不能重复算作新收益。
- **U070 结构化PN输入采样与输入密度：**结构化PN采样值得条件保留；可成为U069的实施构件，但不能把同一个分区实验再算为第二个独立候选。

备选中保留了联合边权/拓扑变化、坐标运输和递归结构；此前静态PN→KC图的负结果不能把它们整族删除。但“没被试过”不等于应抢占下一轮预算。
