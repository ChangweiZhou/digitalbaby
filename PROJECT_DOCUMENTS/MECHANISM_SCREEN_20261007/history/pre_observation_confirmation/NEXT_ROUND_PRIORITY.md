# MiniFly 自主学习机制筛选

2026年10月7日，按用户的新优先条件重新筛选。目标是核心能从实际字节经验自行获取、保持、修订和有限复用信息。实验器不给正确答案元数据、奖惩bit或哪些时刻应学的任务指令；可以预先声明热身，正式学习阶段必须独立计分。现有监督桥接与机制实验继续保留其原有效范围。

原71项研究条目的预算分类为 **2条优先设计路线、8项可用构件、6项条件备选、6项教学源未合格暂缓、1项关闭当前实例、48项本轮不安排**。构件不是完整自主学习器；两个路线均未资格化。没有任何当前Full151整合配置据此被认证为自主持续学习核心。
