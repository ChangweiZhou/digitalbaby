# MiniFly 下一轮机制投入筛选

2026年10月7日，纳入已完成的 LINK 筛选。原71项去重研究条目及编号保留；它们不是71个可运行机制。当前预算分为 **1个优先候选方向、1个固定参照、9个条件备选、1个关闭当前实例的条目、59个本轮不安排条目**。这些数字不表示科学上剩余多少生物机制。

阶段目标仍是相同新经验和算力下提高核心的获取、保持、修订与有限复用。CONTENT桥接不重开；不增加NLP、开放输出、未教算术或规模扩展验收。正式V1采用状态不变；ERROR只作已有任务内强参照。
