# MiniFly：五类机制的下一步变体分析清单

**日期：**2026-09-28  
**性质：**有限的分析名册；不是已冻结的运行协议，也不授权一次运行全部候选。

## 口径与总数

本名册只覆盖已选出的五种**操作位置**：共享／私有记忆的读写分工（R），现有 KC→输出可写坐标的局部资格（Z），**固定 PN→KC 邻接**上的权重适应（P），出生时确定的 PN→KC 静态图（T），以及生命期间真正改变 PN→KC 邻接的结构适应（S）。把原始清单中的历史实现、诊断对照和搜索方法算成机制变体会夸大总数。

按下面逐项写明的纳入规则，下一步需要分析 **16 个候选变体：R 3 + Z 2 + P 4 + T 3 + S 4**。这是对[50+ 机制清单](MiniFly_50plus_Mechanisms_Pruned_Codex_Summary_2026-09-26.md)作出的**本轮有界选择**；原文并没有给出“天然恰好 16 种”的结论。连续增益／阈值／时间常数、共同基线、因果对照以及不同机制之间的组合均不计入 16。即便形式上每类选择“关闭或一种变体”，也会产生 `(1+3)(1+2)(1+4)(1+3)(1+4)=1200` 个标签组合；其中有些不兼容，**不是实验名册**。

| ID | 待分析变体 | 与本类其他变体真正不同的操作 |
|---|---|---|
| **R1** | 新颖性门控的共享＋私有记忆 | 仅凭当前输入与既有状态计算的新颖度，决定是否向有界私有库写入完整教学目标；共享库继续可读。 |
| **R2** | 整体预测误差门控的共享＋私有记忆 | 根据共享＋私有系统在反馈前的输出误差决定是否向私有库写入完整目标。与 R1 不同，它需要结果反馈。 |
| **R3** | 共享预测残差的私有记忆 | 私有库学习共享库未解释的目标残差，而不再次学习完整目标。现有 Full151 的二元教学接口不能直接表示任意带符号残差；这是一项**需改写入规则的架构包**，不能伪装成只加一份存储。 |
| **Z1** | 坐标局部的活动／教学资格迹 | 每个既有 KC→输出可写坐标持有一个有界迹，只用本坐标活动与到来的教学信号决定耐久写入是否可达；不添加按事实寻址的槽。 |
| **Z2** | 坐标局部的冲突／资源资格门 | 每个坐标根据其本地快／慢状态冲突及可用资源决定耐久写入是否可达；与 Z1 的时间资格迹是不同的受写者选择规则。不得使用任务 ID、旧事实身份或未来相关性。 |
| **P1** | 有界 Hebb 权重适应 | 当前 PN 与 KC 的局部共同活动改变**已有边的权重**，并固定权重／行预算；不更换连接伙伴。 |
| **P2** | Oja 式权重适应 | 在同一固定邻接和预算上，局部共同活动更新同时包含与输出活动有关的稳定项；不是把 P1 换一个增益。 |
| **P3** | 新颖性门控 Oja | 更新方程以 P2 为底，额外由当前局部新颖度控制何时改权重；若新颖度来自答案或未来事实，候选无效。 |
| **P4** | ITDP 式时差权重适应 | 用局部 PN／KC 活动的先后时差更新已有边；它改变输入边权，**不是** Z 类的 KC→输出写入资格。 |
| **T1** | 层级模块静态图 | 出生时固定多级模块和有限跨级连接；随后不换边。模块分配不能使用测试标签。 |
| **T2** | 有界度扩展静态图 | 出生时固定、度数有界且输入邻域扩张性较高的 PN→KC 图；与 T1 对比的是邻接混合几何，不是边数。 |
| **T3** | 稀疏桥接静态图 | 出生时固定局部簇和少量明确受预算约束的跨簇桥；与 T1 的多级模块规则分开。 |
| **S1** | SET 式真实换边 | 依局部边强度剪除现有伙伴，按预定随机候选池补入**新的伙伴**，总边数固定。区别于全随机剪枝＋再生对照。 |
| **S2** | 共活动指导的真实换边 | 剪枝／补边由局部 PN–KC 共活动证据指导，候选池有界；实际改变邻接表。 |
| **S3** | 稳态指导的真实换边 | 根据局部活动目标或利用率不足选择剪除／补入伙伴，固定边数及候选池。 |
| **S4** | 采样后稳定化的真实换边 | 从有界候选池暂试新伙伴，仅在持续局部证据出现后保留；计入临时边与结构状态。 |

### 纳入和排除依据

- R1–R3 是[原文 §P1-B](MiniFly_50plus_Mechanisms_Pruned_Codex_Summary_2026-09-26.md)的“共享＋情节残差”架构及其“novelty/error/residual-gated”三种私有写入条件的操作化；三者的具体阈值、读出和资源预算**尚未冻结**。REF、四／八 bank、HASH8 等是历史架构参照；BROADCAST8 与强制读 canonical bank 是诊断，不另计。
- Z1–Z2 是[原文 §P1-A](MiniFly_50plus_Mechanisms_Pruned_Codex_Summary_2026-09-26.md)允许的逐坐标局部信号中，本轮提出的两种不同资格计算。历史 `A_ELIG`／`ELIG_TRACE_PORT` 是跨底物参照，不算两种已经在 Full151 验证的 Z；STC 的额外有限捕获资源和结构性资格分别属于更宽的组合问题，不偷并为 Z 的参数档。`evolved Z_i` 是**搜索规则的方法**，未产生具体规则前不算第 17 个机制。
- P1–P4 分别拆开[原文 §P1-C](MiniFly_50plus_Mechanisms_Pruned_Codex_Summary_2026-09-26.md)合写的 Hebb／Oja、novelty-gated 和 ITDP 方向；这项拆分是本名册的选择。`norm gate` 应作为所有 P 的输入尺度／权重预算控制，不能只给某一个候选；打乱／速率匹配是因果对照。此前旧模型的局部输入发育并非当前 byte→Full151 底物上已经完成的在线 P 验证。
- T1–T3 正是原文三种建设性静态图方向。A11 的 native、weight-shuffle、10%／50% rewire 是拓扑**敏感性面板／对照**，不是这三种图的已完成构造实验。静态图须匹配 PN/KC 数、每行度、边数和权重预算。
- S1–S4 取自原文 SET-like、HEBB、HOMEOSTATIC、SAMPLE+STABILIZE 四类动态规则，必须证明 `indices`／邻接确实在生命中改变。`FIXED` 与等换边次数的全随机 `RANDOM` 是对照。仅改变伙伴权重归 P；`g_support` 的可写支撑扩张和旧 `g_pnkc_rewire` 的 `B.data` 重排都**不是真正 S**。

## 已有实验对这 16 项的约束

近十几轮桥接实验主要排除了某些**原样实现**：exact HASH 作为整个核心、单路固定 pair 对有限 E3 的削弱、固定 ROLE 单路在 16 题的不足、原样 target-only 政策及学得 `h` v2 的桥接失败。它们没有运行 R1–R3、当前底物的 Z1–Z2／P1–P4、建设性 T1–T3 或真实换边 S1–S4，因此不能把这些家族预先判死。[阶段出口审查](BYTE_FULL151_BRIDGE_STAGE_EXIT_DECISION_20260928.md)确认有限 E1/E2 工程桥接已经完成；不得再以新的“整合资格实验”拖延机制分析。

同时，CONTENT 桥接的 16 题已教回忆为 100%，32 键延后保持为 99.22%，仅拿这两个接近天花板的指标筛选机制会误报“无益”。CONTENT 的精确四可见字节地址缺乏未教输入相似性；P、T 或 S 仅接在该地址之后时，不得声称它理应凭空产生 E3。现有 FE0 的有限 E3 来自另一套单存储二选一输出任务，不能同 CONTENT 四输出字节回忆相加，冒称一个系统已同时通过。[目标契约](MINIFLY_OBJECTIVE_CONTRACT.md)区分 E1/E2 与 E3。

下一份**运行协议**若要从这 16 项选出代表，必须逐项封闭更新方程、调用时钟、状态／连接预算、参数来源、完全相同的外部信息与公平基线，并注明该候选的证据等级。这个分析名册本身不改变任何冻结科学代码或实验结果。

## 补充审查：感觉通道习惯化 FE1

Claude 后续指出原五个位置**上游**还存在一项已实现的候选 **F1 = FE1 通道习惯化**：每个 PN/受体通道的输入按有界习惯化状态 `h` 缩放，重复输入增加 `h`，静息按 1,800 s 时间常数恢复。其冻结源码参数为 `κ=0.3`、`τp=10 s`、`τh=1,800 s`，见 [BYTE-CORE-1 bytecore.py](BYTE_CORE_1_20260922/bytecore.py)。它不修改 PN→KC 边权或邻接，所以不应偷算入 P/T/S。原五类的 **16 项计数不变**；若把这项新发现的上游候选纳入下一阶段分析，范围为 **16+1=17 项、六个操作位置**。

不能称 FE1“从未经过学习器测试”：旧 [BYTE-CORE-1 报告](BYTE_CORE_1_20260922/results/REPORT.md)有 16-world 开发结果，且 [FEAS-1 报告](BYTE_CORE_FEAS_1_20260923/results/REPORT.md)的 32-world 开发实验中，FE1 相对 FE0 的流内 ΔAUC 为 +0.0506，而 ≥24 h 不变线索返回差为 −0.0120、区间跨零；依其预定保留规则为 `NOT_SELECTED`，未运行独立确认。这些旧任务不同于当前自行输出字节及包装关系 E3，既不能预判 FE1 在这里成功，也不能说已有证据完全排除它。

原机制清单的“快减慢时间对比”更接近 FE2/FE3 的那部分操作，**不等于 FE1 的习惯化**。FE3 是习惯化与时间对比的组合，在 BYTE-CORE-1 开发 learner η 仅 0.0002，暂不作为第二项感官适应候选。F1 的下一步是一次有终点的行为机制检验；它不是进入原 16 项研究的资格门槛，任何结果都不撤销 T/S 真拓扑候选。
