# U042 development adoption and next decisions

The owner selected COV-SUPPORT as the current development core on 11 October 2026. Its default entrypoint is documented in [the release](../../addition_core_v2_support_v1_20261011/README.md); COV-R remains an explicit comparison anchor. The adoption does not amend the frozen DEV verdict or substitute for confirmation.

BLURRY low-sample NEW J changed by −0.83 percentage points in six paired worlds; the exploratory paired Student p value is 0.50 and its 95% interval is [−3.79,+2.12]. Stratifying by the two task geometries gives [−5.33,+3.66], p=0.55. The result does not establish harm, equivalence, or benefit. BLURRY OLD held-out final improved by 25.83 points; STANDARD NEW J improved by 12.08 points. These signals support retaining the mechanism for development, with their unconfirmed scope explicit.

The current goal remains exact own-output generalization to never-taught bounded addition combinations per external record and production compute, with retention protected. Changing precision, adding NLP, or counting taught-cue recall as the main gain would change that goal.

The next design should test a concrete way for distinct observations to constrain learning together, using the adopted core as a fixed baseline and COV-R as an anchor. U055 is a conditional direction for bounded multi-observation coordination, not an already qualified recipe. COV-R already maintains correlations, so repeating its existing update or renaming replay as recurrence is insufficient. Any new operation must specify which observations interact, what changes in the estimation or evidence weighting, and its full cost. U043 remains a conditional structural alternative; neither direction is authorized to run here.

Do not infer a universal noise-rate threshold from the two DEV conditions: they change both corruption and missingness and have only six worlds each. A future independent comparison must freeze baselines, task geometry, information budgets and adoption criteria before seeing its outcomes. No extra worlds are appended to the completed U042 experiment.
