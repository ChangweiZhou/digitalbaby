# MiniFly保留条目去重结果

2026年10月7日。去重后的完整保留集合为 **71条**：原主账保留项 **62条**，另外 **6条**不重复的封顶参数备选，以及 **3条**文献启发方向。

主账是上一轮108账中的32条条件记录与136目录中的38条条件记录的对应结果；两者不能直接相加。原目录合写的bayes_stable/reopening、4/8-bank fixed/inferred、CORR2/fixed mixture按明确名称展开，再删除重复。P4-TAU165已在主账，不重复加算。

这个数字的单位是“保留条目”：其中有具体变体、参数配置和待定义变体组，不是71个已经可运行的机制，也不是71个互不相关家族。未有不同更新方程的组不凭名称虚构atomic变体数；有明确不同底物/状态位置的配方不按家族名称合并。当前科学世界数不增加。

原文§P1-A明确要求A_ELIG与ELIG_TRACE_PORT保持区分，故两者都保留；结构资格在目录§3和§5重复出现，只计一次。bayes_reopening在资源和遗忘章节重复出现，只计一次。历史M038是pair_importance/neuron_availability的上位合写记录，不再多计第三个保护机制；M078保留的PAIR部分已在M077计数。DPM名称相同不能证明一般巩固与跨流绑定是同一操作，因此对应具体功能假说保守分开。

## 边界

本表是来源对应与去重后的研究预算清单。保留不表示有效，名称可识别不表示已有最终方程；“待定义组”后续若真正实例化多个不同更新规则，须保留父项、替换为明确子变体并公开计数变化，不能偷偷充数。技术未合格P3、证据不足的其他封存项和V1/ERROR参照不计入当前新候选集合。
