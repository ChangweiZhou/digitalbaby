# MiniFly mechanism shortlist after the V66 version audit

11 October 2026. This is a decision record, not a new experimental result or permission to launch science runs. The target is better **own-output accuracy on never-taught bounded-addition combinations per noisy/missing external example and charged computation**, with old knowledge protected. Exact taught-cue recall is a separate E1 guard; the addition endpoint is limited E3. The digit/role representation and ordinal output prior are engineered, so none of these results show unmodified Full151 discovering arithmetic.

## Filtered shortlist

**Closed: ~~Candidate A: U034 / SUPPORT-DIR~~.** The completed qualified DEV ran 12 paired worlds / 60 jobs / 153,600 external records. In its six BLURRY worlds, SUPPORT-DIR had the same mean held-out NEW sample-curve score as COV-SUPPORT (47.7083%); gain over COV-R was 4.375 points, while training CPU was about 1.18 times SUPPORT. It did not advance. The final OLD held-out score rose descriptively from 85.0% to 93.33%; this is not evidence for the primary low-sample NEW gain, and neither a fresh confirmation nor a family-wide equivalence test was run. Fixed diagnostic RAND/ISO were not eligible and remain unpromoted. Stop this recipe, remove U034 from current scheduling, and do not rescue it by dose/window/threshold changes. See [formal report](../../addition_uncertainty_restoration_dev_v1_20261011/results/REPORT.md) and [review data](POST_U034_REVIEW_20261011.json).

**Candidate B: U047, information-complementary bounded replay on the full COV substrate.** Retain a fixed-size cache of permitted observed input/answer bytes. Select records whose constraint directions add coverage absent from the present evidence, using only state available before each selection; do not synthesize a clean answer from noisy observations. This differs from the already tested residual-priority REPLAY-P and uniform REPLAY-U. Before running, specify whether a reused observation contracts P again, and use the same specified P rule across matched selectors: replaying the same noisy observation can otherwise create spurious certainty. On the *same full-COV/SUPPORT substrate*, compare information coverage, residual priority, uniform selection, and no replay with identical external examples, cache capacity and charged update **and selection** cost. Replaying one observation is computation, not another independent sample. If the selector merely chases the largest residual, it is a renamed REPLAY-P and should be stopped before a large run.

**Conditional reserve: stable/flexible parameter allocation within one role coordinate system.** V25's `split_stable_slow_local`, release and gated variants had different historical association means (about 66.9%, 67.5%, 68.9%), while V24's `bank4_fixed_neuron` release variant fell from about 66.9% to 55.1% on its own old task. These are descriptive cross-program findings, not a current addition ranking. Specify the local write/read operation and a retention-versus-acquisition deficit first; do not copy whole banks or conflate router and release effects. This is not in the immediate science run.

**Park now:** the current EXTRA, uniform COV-REPLAY, residual-only REPLAY-P and TOPO-G recipes. Keep user-adopted U042 SUPPORT, but do not relaunch its current recipe with post hoc threshold adjustments. Further banks or time constants need a newly demonstrated deficit; the tested recipes do not rule out every version. U055's historical source concerns KC↔KC/DPM recurrence; an unspecified batch “joint re-estimation” is not that circuit. U059 causal update-budget allocation remains a secondary design idea only after a concrete selector and same-budget control exist. The full [71-item rescreen](POST_U055_RESCREEN_20261011.md) records the narrower per-direction statuses; parking a tested recipe is not declaring its whole family impossible.

## Gate for the next actual experiment

Freeze one operational recipe and one mechanism claim before new worlds. Use the same byte stream, external feedback provenance, prior information, output organ and held-out combinations for candidate and controls. Score first responses before feedback, with matched no-prior-teaching and shuffled controls that rule out exact-key recitation and exposure-independent shortcuts. Keep the existing BLURRY NEW20/40/80 weighted score as primary, plus OLD retention, STANDARD/ordinary protections and full CPU, state and memory-movement costs. A development signal alone does not promote a candidate; use untouched confirmation worlds and the predeclared gain threshold. No new science run was authorized by this review.

## Current next-step decision after U034

The 71-entry historical set now has one priority design direction (U047), six conditional directions (U021/U043/U055/U057/U058/U059), and eight enabling components. Seven directions remain on the consideration list; that is not seven runnable variants or seven scientific survivors. U034 is crossed out of current scheduling. Old source/crosswalk snapshots remain intact.

**Next recommendation: one precisely defined U047 coverage-selection recipe, with no baseline or benchmark change.** Store a bounded cache of genuinely permitted byte contexts and their actual arriving targets; compare selection on the same full-COV/SUPPORT substrate. Select by under-covered constraint directions using the learner's existing P as an algorithmic coverage score, not as a calibrated posterior. The same cache and fixed replay occasions must feed uniform and residual-priority controls with identical numbers of extra corrections. Recompute residuals from current weights; do not create a clean target from hidden truth or majority votes. No additional P contraction for a reused observation, and no counting it as a new independent sample. The earlier COV-REPLAY already used this no-second-contraction convention, so that convention itself is not the novelty: selection and substrate matching are.

Before locking, define the cache admission/eviction, prior-only selection timing, support factor on reused records, deterministic ties, RNG, forbidden/missing/query state freeze and independent accounting. Selection scans, memory accesses and corrections are all charged. Compare with both COV-SUPPORT and COV-R; keep opaque BLURRY delayed NEW20/40/80 J, OLD retention and STANDARD/ordinary protections. At most one fixed selectable recipe, with a fresh confirmation only if its predeclared gates pass. A no-gain result stops that recipe; do not vary replay dose repeatedly after seeing scores.

**Backup: U059 causal update-budget allocation**, which changes which actual observations consume a fixed update budget without adding replay. It must demonstrate the same held-out ability from fewer external examples or less computation at matched ability; skipping updates alone is not success. Do not combine U047 and U059 in the first attribution test. U021/U043/U055/U057/U058 remain conditional reserves, not a ready queue. This review authorizes no new run.
