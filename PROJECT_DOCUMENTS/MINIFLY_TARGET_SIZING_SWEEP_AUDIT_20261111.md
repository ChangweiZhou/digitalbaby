## Answers to the brief's four questions

1. **Keep Arm A** as a reset-per-episode diagnostic of what the weights learned. Held success supports reuse beyond the tested shortcuts. Ordinary outcomes identify the hidden values only up to a shift within a family, so scores do not establish literal recovery of the latent values or a particular algorithm.
2. **Keep Arm B one-pass.** A separate repeat-dose comparison can distinguish extra updates from additional fresh exposure. Record first-encounter scores before a repeated pass can teach those pairs.
3. **Treat 256 bytes as a credit limit.** Carrying hidden state allows information to survive a detach, while even short dependencies can cross a cut. Log disclosure-to-use distances and boundary crossings. Qualify a controlled cross-boundary dependency before interpreting a null on disclosures.
4. **Keep warm-start training out of the scratch grid.** Use the separate matched contrast above if the scratch table leaves the curriculum decision open.

After the brief is corrected, release implementation and bounded qualification first. The full roster follows only after the evaluator, chronological scorer and resource profile qualify.
