# NATIVE-NEXT V1: preserve storage, repair the arithmetic input state

23 October 2026. **Design delivery only.** No implementation, three-cycle exercise, new teaching, head fitting, confirmation, adoption or GitHub publication is authorized by this document. The completed experiments remain frozen.

The goal remains **retained exact own-output generalization to unseen addition per all training samples and actual compute**. Warmup is gradual. The learner receives raw bytes and permitted feedback, not operand roles, digit magnitudes, carries, arithmetic relations or worked solutions. Attention, Transformers, ELM, backpropagation and a separate learned payload answer network are excluded from these candidates.

There are three separately locked protocols, not one combined learner. A is a native-storage confirmation; B is the main arithmetic development experiment, also called **V6-R1-R2**; C is a subsequent, separate EOS-development experiment. A's success does not gate B, and B does not wait for memory perfection. C requires a separately accepted EXPAND confirmation package. Integration of EXPAND with B is not included.

## 4. Protocol B — V6-R1-R2 input-scale experiment

### Exactly one core intervention

The native substrate remains **CANON 5,177**, not EXPAND. Retain H88, 259 exchangeable symbol columns, the same stochastic gating/content equations, proposal sigma0.1, gate bias `log(0.1/0.9)`, manual score eligibility, record-end update, previous-record baseline, native signed byte/EOS output and both gradual schedules.

For both Wv and Wg, initialize symbol columns at Gaussian SD0.05 and the 88-coordinate recurrent block at SD`0.05/sqrt(88)`. Biases are unchanged. Original R1 uses SD`0.05/sqrt(348)` for all nonbias columns. Couple each arm's underlying standard-normal draws before applying these scales. This changes two presynaptic block scales together as **one declared initialization correction**; it is not a factorial attribution to just the symbol block or a claim that variance has been solved.

Five arms: ORIGINAL, RESCALED, RESCALED_FROZEN, RESCALED_NO_OLD and RESCALED_SH_OLD. RESCALED_FROZEN fixes only controller learning, not native memory. NO_OLD disables both learning routes and baseline updates during OLD, while time/experience counts advance, and permits NEW updates. SH uses the pinned within-answer-length derangement and correct NEW labels. Restoring record counters or query RNG must not accidentally change control semantics.

Do not fix the tape per prompt, use a key-derived seed, turn off proposal noise during generation, replace stochastic state by its mean, or average internal addresses across tapes. Training and inference retain the same stochastic process. Three evaluator tapes are correlated repeated readouts, never a hidden ensemble, voting rule or best-of-three answer.

### Birth preflight: no held labels and no full training by default

Generate the two fresh engineering-world manifests first, but withhold all HELD labels from the preflight. Select the eight OLD orbits in each of two already declared operand-length strata, `(1,1)` and `(4,4)`, by manifest order. Use one prospectively counterbalanced orientation per orbit. Thus there are two equal-length groups of eight prompts, not a new task or a score-selected set. OLD answers are not used here.

At birth, with independently reset private state, obtain each prompt's end-of-prompt controller state and actual side-specific native KC supports on all three tapes for ORIGINAL and RESCALED. Do not infer address quality from hidden Euclidean distance alone.

Within each equal-length group define:

* `J_same`: mean support Jaccard for the same prompt across distinct tapes.
* `J_other`: mean support Jaccard for distinct prompts across distinct tapes.
* `DeltaJ = J_same - J_other`, separately for each side and pooled.
* Leave-one-tape-out prompt identification: for a query support, choose the maximum-Jaccard template among the eight prompts on the other two tapes, averaging their similarities; split ties fractionally. Chance is 1/8. This evaluator-only computation is not an inference memory or a fitted decoder.

Also report different-prompt/same-tape distances and Jaccard, hidden-state norms, actual support sizes/shortfalls, identities of empty codes, and Q/T-weighted support similarity. Tape coupling is an analysis control, not a production address.

On private newborn fixtures, use the first four prompts from each group, two coefficient signs and payload compartment0/EOS compartment8. For each initialization/world, compare a single synthetic write with an identical passive clone; query all selected prompts on independent tapes. This is at most **128 partial native write events** across both initializations and worlds, with every clone discarded. No answer or held label is used, no state enters a continuing history, and all queries/copies are charged. Publish signed self-minus-other margin responses, not just support geometry.

**Operational admission for RESCALED:** in both engineering worlds, each length group must have pooled `DeltaJ > 0` and prompt-ID accuracy strictly above 1/8; neither side may have zero effective recruitment. Across the fixed fixture cells in each world, mean signed self-minus-other native margin response must be positive for payload0 and EOS8. ORIGINAL is measured, not required to pass. Zero contrast and chance follow the null question; there is no arbitrary required SNR ratio or demand for noiseless states. Publish every constituent, including regressions. This is a necessary bounded engineering screen, not confirmation that arbitrary inputs are distinguishable or arithmetic will work.

If it fails, return **INPUT_STATE_NOT_ADMITTED**, preserve all measurements, and do not consume the full roster. Do not tune a threshold, resample birth, shrink sigma or move to EXPAND. Such changes would require another design. Arithmetic held outcomes are not opened to reverse this decision.

## 5. Protocol C — EOS-only attenuation on EXPAND

This is a separate eight-pair E1 development comparison **after A has an accepted storage confirmation**, not an extra arm in A or B. Reuse the exact confirmed EXPAND birth, target-independent addresses, native dynamics and frozen STOP heads. Use fresh pair keys/values, two lives, the same eighteen OLD/eighteen NEW keys, lengths0–8 and fourteen passes. No controller, graph, decoder, warmup or payload teaching changes.

Three EOS-teaching arms, all with identical eight payload-compartment coefficients:

| Arm | EOS compartment coefficient |
|---|---|
| BASE | Unchanged native `c` |
| EOS_BAL | `c` on an observed terminal EOS; `rho*c` on observed payload-byte events |
| EOS_UNIFORM | `beta*c` on every observed event, independent of its current terminal/nonterminal target |

One rule, no weight grid. Let P and M count previously observed terminal and nonterminal targets **in completed records**, initialized to zero. At BOS compute and freeze

`rho = min(1, (P+0.5)/(M+0.5))`,

`p = (P+0.5)/(P+M+1)`,

`beta = p + (1-p)*rho`.

Update P/M only after the full record's observed feedback. The same counters are maintained in all arms and continue OLD to NEW; no-write branches advance observed counts too. These are two bounded-width aggregate counters, not a fact archive. Half counts give a symmetric uninformative start; no assessment label or future record length determines the weight. P/M and the frozen per-record weights are checkpointed.

This balances aggregate past EOS/non-EOS opportunity by **attenuating nonterminal EOS teaching**, never amplifying a terminal event beyond the original gradual coefficient. Eight payload channels and their masks remain untouched. The actual observed current byte/EOS target is allowed teacher feedback, not an inference hint. No final 0/1-learning claim follows.

EOS_UNIFORM matches the **past-frequency predicted mean attenuation**, not exact realized applied L1/L2 or per-record dose. State-dependent residuals and clipping make those different. Measure actual nominal/proposed/applied signed increments and L1/L2 by target type. If BAL improves, comparison against UNIFORM tests whether class-selective attenuation helps beyond this scalar-dose reference; it does not prove perfect dose isolation. Do not use future lengths or labels to manufacture an exactly yoked reference.

Run W/N/within-length SH and S_NEW for each arm, with parent chronology. Independently verify eight payload states and payload sign readouts remain identical across EOS arms on the same histories when the native compartments are independent. If an inherited shared-state route breaks this expectation, stop qualification and revise the causal account; do not silently suppress that route.

Primary development outcomes are final nonempty complete output under **direct native EOS**, OLD and NEW jointly, plus raw native EOS margins and early/late/truncation rates. A favorable screen requires BAL to improve both OLD and NEW complete exactness over BASE and UNIFORM in each pair, with positive BAL W-minus-N effects. Undefined denominators fail conditional-stopping claims; primary unconditional exactness remains defined. These eight pairs do not establish formal efficacy.

All frozen STOP heads, position-only, foreign-EOS and fixed endpoints0–8 remain visible as secondary readouts. Never select a fixed endpoint or refit a head on assessment responses. Report length0 separately and every nonempty length; success on empty/one-byte defaults cannot conceal longer-value failure. Publish payload ceilings unchanged. A frozen STOP regression under shifted EOS responses does not by itself falsify improved direct native stopping. No training-only recalibration is included; any future fit needs a distinct data split and protocol.
