三轮已于 11 月 24 日按要求全部停止。所有数字都是 log-perplexity，单位 nats/字节，负的变化表示变好。

## 测试流程

- **连续训练**：shak → emma → code → moby → shak，每段 64k 字节。每段学完后，在四个数据流的留出集上测一次（各取中间的 10k 字节，测试时关闭学习）。
- **cl**：最后一次测试的四个均值。
- **规模测试**：在 Moby 上用 1×、2×、4× 的网络，各读开头的 32k、64k、128k 字节，每个点都是新网络。slope 是对 log₂ 规模的最小二乘斜率。

## 主要结果

### 1. 网络变大没有用，规模律全部来自数据

**方法**：所有候选的三个规模点放进同一个回归，log-perplexity = a + b·log₂(细胞数) + c·log₂(数据量) + 架构维度，标准误按候选聚类。各候选的细胞数是随机抽取的，所以在同一数据量下，可以横向比较不同大小的网络，从而把 b 和 c 分开。

| 网络 | 细胞数翻倍 b | 数据翻倍 c | 大小 × 数据交叉项 |
|---|---|---|---|
| 第 1 轮 lt（200 个） | +0.002（p 0.55） | −0.046 | +0.003（p 0.002） |
| 第 2+3 轮 lt2/lt3 | +0.013（p 0.02） | −0.064 | +0.009（p 1e-10） |

- **对新点的预测**：用较早的 293 个候选拟合，预测之后完成的约 33 个候选（99 个点），R² 0.30，排序相关 +0.62。
- **对照**：net13 上的拟合（`NEWNET/SCALING_FIT.md`）是 b = −0.023，c = −0.133。

### 2. 能改变细胞项 b 的维度

只有第 1 轮有维度通过 FDR 校正：

| 取值 | b 的变化 | q |
|---|---|---|
| w_new = 0.55（相对 0.3） | −0.021 | 0.02 |
| outr = 1 | −0.018 | 0.05 |
| S = 16（相对 10） | +0.026 | 0.05 |
| eta_o = 0.1（相对 0.05） | +0.030 | 0.05 |

第 2+3 轮没有任何维度通过 q < 0.05。

### 3. 原来那种规模测试筛不出斜率

原来的测试让网络大小和数据量一起翻倍。用全部维度对这样测出的 slope 回归，10 折交叉验证 R² 为 0.00–0.04，对新点的 R² 为负。原因是数据项占主导，而且每个候选只有一个种子。

### 4. 持续学习

最后学的数据流主导一切：学完 code 后，三个英文数据流都退化约 0.5；回到 shak 后，code 又退回学之前的水平。

### 5. 第 3 轮的机制维度

在 cl、Moby 4× 和 slope 上都没有可靠的效果。

## 已知问题（未修）

- **第 2 轮全部用未修正的 `lt2.c` 运行，带有扇出溢出错误。**
  - 错误：一个字节的传感器编码可能重复同一条线，同一次生长里同一个源会被加两次，越过它的扇出上限，写进下一个源的列表。
  - 错误在 11 月 24 日第 3 轮开始前才发现，只在 `lt3.c` 里修正。第 3 轮全部用修正后的代码。
  - 第 2 轮 97–100% 的设置满足触发条件。对结果的影响没有测量。
  - 上面所有"第 2+3 轮"的合并分析都包含这些受影响的运行。
- 长突触时逐个扫描活跃的源细胞，代价是活跃数的平方，使大网络慢到数小时。
- 结果只在候选全部跑完后才写入文件，中途停止会丢失全部中间结果。
- 规模测试的网络大小和数据量一起翻倍，而且只有一个种子。
- 还没满足的结构要求：
  - 输出读取范围达 0.5，等于全局读出；
  - 没有经反馈细胞传回组织内部的反馈；
  - 更替时全局搜索最少使用的连接；
  - 连接数和放电比例都由人工设定。
