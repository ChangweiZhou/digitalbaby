The user authorized running the fixed eight-family V216 development roster. Every training event is one short reset-bounded episode with multiple raw observations, focal and distractor actions, a move and one revealed consequence. Weights and optimizer state carry across episodes and worlds. Held short and long probes move the distractor behind the focal action, with an additional distractor in the long stratum and disjoint entity namespaces. The OLD panel reuses observed invariant records whose outcomes survive the mapping change.

It is not the original V213 learner. The byte reference uses order-three backoff, and the reducer includes exact/normalized lookup, recent location and frequency. A separate word-bag model is not in this runner. The compressed records use the same alphabet and endpoint across arms. Preflight and parity use a compatible PyTorch environment and separate engineering seeds. Formal measurements remain bounded development.
