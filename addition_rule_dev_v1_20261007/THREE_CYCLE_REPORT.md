## Interpretation and next decision

The candidate learned from 80% correct, 10% wrong and 10% missing answer observations. Both orientations of the eight scored expressions were absent from training. Its own learned content produced each emitted byte at `=` before any answer arrived. N_OLD received identical raw observations but disabled actual old writes; later teaching was enabled. SHUFFLED preserved old answer frequencies and missing positions. Frequency/exact-key/commutative-key fallback scored25%; single-operand shortcuts scored0%; the evaluator-only learned linear rule witness scored100%. Countermodels for the short first cycle were recomputed using only its delivered old feedback, excluding planned new records.

This is exploratory E3 evidence within a small engineered numeric domain, not confirmation of biological arithmetic or an already qualified persistent V2. Both numeric input roles and an ordinal output prior are explicit engineering choices. No addition coefficients or answer-dependent features were preset. The new content rule replaces native writing/reading in the candidate; it is not evidence that unmodified native Full151 acquired addition. Differences include output coupling, scalar content and update rule, so the result is not an isolated proof for generic Hebbian learning.

The final old errors were the same in both worlds: `3+4`, `4+2`, `4+3`, `4+4`, each underpredicted by one. This precision/retention pattern identifies a relevant next design question, but does not alone prove a universal forgetting mechanism. Fast/slow decay acts on an absolute numeric value; losing amplitude can change a rounded answer even when some relative information remains. Do not fix it by reading true labels at query, rescaling using held-out outcomes or lowering the guard.

The current instance remains on hold. The three requested cycles are finished; no additional encoding rounds, mechanisms, dose increases or confirmation are added automatically. A future design would need to protect learned numeric values within the already declared task. The byte-to-memory interface is not reopened as a separate milestone.
