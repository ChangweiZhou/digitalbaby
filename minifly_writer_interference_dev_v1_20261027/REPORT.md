# WRITER-INTERFERENCE V1 — three-cycle report

The bounded two-world run completed without replacement worlds, training retries or gain retuning. The saved-artifact audit passed. This is E0 native write-mechanics and E1/E1-R taught association evidence. It does not test unseen arithmetic or justify adoption of a general learning core.

The clearest finding is a stability/plasticity tradeoff: higher-strength writers acquire 14–16 NEW answers but reduce OLD recall from 50/64 to25–35/64. OBS and exact-time IDLE have identical final outputs in both worlds. At matched pulse strength, N and D differ modestly in continuous target metrics without a consistent domination across log-probability and margin; the longitudinal results do not establish DELTA as an intrinsically superior update form.

## Exposure and cost

Main: **3,328 full record applications / 6,656 observed targets** = 2,048 common OLD + 1,024 four-arm NEW + 256 OBS. Qualification:10 records/20 targets. Calibration:128/256. Total:**3,466 full records / 6,932 observed targets**, plus **1497 discarded partial shadow target events**. There were **5288 own/TF probe pairs** and zero held-relation decisions. A branch inherits one common OLD history; that history is not counted four times as independent acquisition.

Qualification/calibration/main CPU: 514.64s; peak RSS 392.8MiB; native-vector reads 31,037; distributions 29,640. The separate saved-artifact reducer took 0.091s. The 1.5x charged preflight estimate was within the original caps. Caffeinate was attached only to each active worker and ended when it exited.

Instrumentation records 12,305 whole-memory clones and 33,635,176,080 bytes for the counted mutable wrapper state. Native reader calls also clone compartments, and signed teaching internally evaluates native write branches; these are additional inherited costs (up to two compartment clones per enabled signed call), not a demonstrated scalable production implementation. The recorded mutable-byte count excludes temporary immutable-array copying inside inherited clone implementations. API coefficients were bounded by assertion with no added coefficient clipping; internal kernel saturation was not separately instrumented. Delivered d and native fast/slow displacement measure the actual net write.
