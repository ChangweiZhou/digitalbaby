# WRITER-INTERFERENCE V1 — revised design after three cycles

This is a prospective revision and interpretation of the completed WCFI-V1 study. The original design, gains, data and history are preserved. No follow-up execution is authorized or launched by this document.

## What the completed test establishes

The native substrate can acquire substantial opaque taught associations with gradual warmup. All four NEW writers start from the identical OLD checkpoint within a world. Lower and higher delivered-strength operating points reveal a stability/plasticity response; matched observations and measured-time IDLE separate write effects from exposure/time effects. The complete behavior is native own-byte plus EOS, not an external answer decoder.

- World 202610277311: common OLD 50/64. Final (OLD,NEW): N-low=(49,0); N-high=(35,14); D-low=(53,0); D-high=(33,16); OBS=(51,0); IDLE=(51,0).
- World 202610277312: common OLD 50/64. Final (OLD,NEW): N-low=(48,3); N-high=(25,16); D-low=(49,3); D-high=(25,16); OBS=(50,2); IDLE=(50,2).

The final OBS and IDLE panels are identical in each world. High-strength OLD loss is therefore attributable to the enabled-write intervention under this schedule, rather than unmatched rest duration. The high operating point is not a net taught-item win: final totals are49/80 in the first world and41/80 in the second for both high writer forms, versus51/80 and52/80 in OBS. This is a meaningful localization of a stability/plasticity limitation, not a new core success.

## Keep update geometry separate from delivered strength

The four fixed gains matched the independent calibration median within 1%. They did not enforce equal output displacement in every later state. The 32 same-state pulse contexts provide the clean direction comparison; their counterfactual magnitude solver is evaluator instrumentation and cannot be installed as an online local learner.

Direction effects must be interpreted beside the remaining ≤1% per-pulse match residual and the distinction between payload and EOS. Pooling both sites can obscure a very confident EOS response. A finite same-state effect is not proof of a superior lifetime learning rule. Longitudinal checkpoint doses, including their tails, are published rather than retroactively normalized.

## Revised next decision

Do not promote a stronger writer simply because it learns NEW. Compare complete NEW acquisition with both all-OLD and initially-correct OLD survival, and with total correct taught associations at the same information and compute budget. A gain that trades approximately one forgotten OLD answer for each NEW answer is an operating-point change, not yet a net kernel improvement.

The next bounded kernel candidate should test **generic local protection/consolidation** against the calibrated historical DELTA reference, keeping delivered write strength as a separate factor. Use the existing native fast/slow state and a bounded activity/feedback-derived local reliability signal; the learner must never receive OLD/NEW labels, item IDs, the experiment phase, arithmetic relations or an evaluator’s future-error gradient. Preserve support/sign of the native update and measure any change in actual delivered d rather than assuming total synaptic alpha proves equal functional strength.

Before a new run, specify one protection formula, its per-active-circuit state/work, and its switch-off control. Match expected-byte arrivals, warmup schedule, complete event clocks, total samples and actual compute. Retain write-inhibited OBS and exact-second IDLE. The same teacher/observation stream must update any permitted local reliability trace consistently; distinguish writing that trace from using it to gate values. Do not add a hyperparameter grid after seeing results. A later correction phase must allow changed feedback to revise previously taught facts, so the protection is not merely permanent freezing. This phase is a future prespecified E1 diagnostic, not an extra result of the present run.

Replay is optional separate work, not a free rescue. If proposed later, use only genuinely observed records and identical replay-observation slots with writes enabled versus inhibited; match NEW exposure, total feedback, clock and compute. It must be evaluated as a budgeted alternative to local protection, not silently added to a winning arm.

## Constraints and evidence retained

Gradual warmup remains 1/16→1 over 1,024 observed target arrivals. Native C16 own-byte/EOS output, local candidate rules, no attention/Transformers/ELM and no task-specific structure remain fixed. Homeostasis was OFF and is not retrospectively credited with these results. The arithmetic track and current adopted core are unchanged.

This task is E0/E1/E1-R. Exact-key recitation solves every scored mapping, so this run cannot establish E2/E3, unseen-addition improvement or a general reusable representation. A future transfer test must be prospectively specified with its own no-prior-teaching control; increasing OLD/NEW scores does not earn that claim.

## Instrumentation revisions for any follow-up

1. Retain identical-code/time zero/write controls and log per-target-site dose, not just one pooled calibration median.
2. Save interrupted mutable state before a failing assertion, and instrument internal native clone traffic and kernel saturation explicitly; the present run completed, but its clone-byte ledger covers only the wrapper mutable arrays and gives bounds for inherited internal clone costs.
3. Keep one common OLD acquisition per world, disclosed correlated forks and all originally selected cases. No outcome-dependent world or sentinel replacement.
4. Publish full own/EOS panels, calibration residuals, fixed-gain dose drift, branch clocks and write/observation/time decompositions.
5. Replication on only two randomized worlds sharing canonical wiring remains development evidence. No architecture adoption or automatic confirmation follows.
