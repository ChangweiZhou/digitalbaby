## Fixed identifiable composition environment
Outcomes remain ASCII 0123, cues exactly eight spaces then `a+b=`. The plus byte is an arbitrary relation delimiter; it does not promise integer arithmetic. Old operands are four visible bytes 0123. Evaluator samples independent permutations L,R,O of the four elements of V4 (two-bit XOR group). Outcome = O[L[a] XOR R[b]]. This is a relabeled quasigroup composition table, with no relation labels or permutations given to the learner.

Hold out a balanced transversal: in latent coordinates x=L[a], y=R[b], set y=GF4_multiply_by_2(x), where multiplication map is [0,2,3,1]. Its four outcomes x XOR y are each distinct. The remaining twelve cells contain three examples of every operand and outcome, identify the missing cell uniquely by Latin-square row/column completion, and therefore identify held-out answers within the declared Latin-square class without relying on XOR-only prior knowledge. We test all 576 order-four Latin squares: all completions consistent with the twelve taught entries must give exactly the locked heldout answers. This evaluator certificate is never sent to the learner. A simple row-wise missing-symbol solver also completes these tables: the estimand is taught-dependent held-out composition-table completion, not proof of an abstract reusable symbolic operator or out-of-alphabet transfer.

Old block has exactly 192 events: sixteen independently shuffled passes over the twelve taught cells. This changes distinct old cue count from the historical exact-fact assay (16→12) while preserving event/timing/write opportunities; it is NOT a same-task replication of the historical accuracy. New block uses original 16 cues over visible 4567 and independent balanced arbitrary outcomes, twelve shuffled passes=192 events. Heldout old cues never appear in either training stream, including outcomes (their full twelve-byte cue is never reinforced). No replacement worlds, adaptive heldout choices, difficulty search or performance tuning.
