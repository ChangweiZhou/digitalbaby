# ERROR versus R_center completion study

This fixed 64-world experiment asks whether a private pre-outcome error coefficient repairs held-out Latin-table completion while preserving taught old/new accuracy. The learner, fixture, protocol and sixteen-contrast analysis are frozen. This initial publication provides the scientific source and three accepted qualification cycles. It contains no official efficacy result or conclusion.

The underlying scientific registration was frozen before official execution. This public projection was prepared after launch; it is not a contemporaneously public preregistration and contains no official efficacy outcomes.

Start with protocol/PROTOCOL.md and protocol/SCIENTIFIC_LOCK.json. audits/QUALIFICATION_SUMMARY.json describes the exact technical quotas and evidence limits. receipts/cycle1, receipts/cycle2 and receipts/cycle3 hold public technical evidence. The pilot and fresh-process replay have equal public scientific payloads after excluding measured resources. They are not official sample members.

provenance/SOURCE_PROVENANCE.json and provenance/MIGRATION_DIFF.txt explain the narrow source-backed change. source/baseline/vendor includes the required canonical NPZ assets, calibration and inherited reference sources. Original source and attribution are preserved; new scientific files in this study directory are GPL-3.0-or-later. See NOTICE.md and COPYING.

## Public projection and reproducibility boundary

The scientific code files are byte-identical to their accepted versions. Public protocol, qualification summaries, receipt headers and integrity manifests are explicitly labeled projections. They omit execution administration and use new public-only identities. Numeric receipt parts are unchanged, except that the published headers are documented projections. Historical Cycle 1/2 versions are included where the admitted scientific sources changed later. PUBLICATION_MANIFEST.json records exact bytes, SHA256 and Git blob SHA-1 for every accompanying public file.

The original sealed launchers depend on execution admission and persistence state that is not in this public scientific package. Their source-level guard references are retained for inspection; this projection does not claim that the private launch guards can run from the public tree. Do not replace the original execution lock with SCIENTIFIC_LOCK.json or pass these public projections to a validator expecting original sealed receipts. Reproduction needs a separately reviewed execution adapter. Scientific equations, fixture generation, schedules, output policy, statistical definitions and numeric receipt parts are fully inspectable here.

The accepted numerical runtime is Python 3.11.15, numpy 2.2.6, scipy 1.14.1 and numba 0.61.2, with one numerical thread. Publication preparation only parsed and hashed files; it did not import study modules, run native learners, rerun tests or create additional experimental outcomes.

Any later official release must include all 64 complete worlds and the terminal analysis, preserving this registration. Technical qualification, partial progress and prior baseline-study results must not be presented as the official efficacy answer.
