# R2：反馈后按反馈前整体误差门控私有库写入

**状态：实现规格；未运行科学世界。** 本文件只实例化原 16 项名册中的 **R2**。共享库固定为 **FE0**，私有库固定为既有四可见字节 **CONTENT**，两库都使用原生 Full151 值存储。**FE1 不在候选、对照、输入路径、参数搜索或本轮成绩中。** R2 与 R1、R3 是同一 R 机制家族的不同变体；本轮从不同机制家族各选一项时，只让 R2 占 R 家族一席。

依据：[16 项名册](../MINIFLY_FIRST_ROUND_VARIANT_INVENTORY_20260928.md)、[v2 共同任务与 R 读出规则](../MINIFLY_FIRST_ROUND_17_MECHANISM_PROGRAM_V2_20260928.md)、[目标与证据边界](../MINIFLY_OBJECTIVE_CONTRACT.md)。旧[四字节 E3 资格收据](../BYTE_FULL151_E3_ASSAY_QUALIFICATION_20260928/results/REPORT.md)只证明单库、二选一线路的既有能力；它不能代替这里的双库四通道实验。

## 1. 主张和一条生命史

R2 测的是：同一双库资源和相同输入下，把私有库写入机会分配给**当前整体系统预测较差**的教学事件，能否相对无选择性 R0 改善最终旧事实 E1 保持，或经 24 小时、新学习、再 24 小时之后的旧未教类别关系 E3 选择。旧事实每题答案曾直接到达；无论成绩多好仍只属 E1。规定的未教学呈现单列 E2。关系未教边的两种方向始终没有反馈；同一生命史的旧关系教学写入因果分支必须支持任何 E3 声称。符号类别一位规则能解这项合成关系，因而阳性也仅是限定 E3。

继承 v2 的 600 条逐字节记录，事实与关系在旧段按 `a=192,b=144`、新段按 `a=192,b=72` 用该文件第 4 节的 floor 交错式合并。每条 12 字节题面后，先记录输出，真实答案字节才到达；步长 `DT=30/14 s`，一条记录占 `165 s`。旧段后休息 86,400 s，新段后再休息 86,400 s。四个检查点均从持续状态的只读副本探测。有效模式只能由已到达的题面字节解析：事实 `8 spaces || a+b=`；关系 `## || 7 spaces || XY || space`。不得传入隐藏任务 ID、事实索引、真实类别或未来答案。若字节解析与预期教学路由不一致，保存技术失败收据，停止该世界。

每个 R 臂有八个原生输出存储：共享 `S[0..3]` 和私有 `P[0..3]`。全部原生快、慢、适应、FE0 感官瞬态按共同新生规则从同一出生状态初始化，四个通道及两库起点逐位相同。`P[j]` 只替换为已锁的 `VisibleContextFE`，其最近四个非空格字节窗口也是出生空状态。两库每通道接收相同题面、答案字节、换行和时钟。本轮不实例化没有接到值存储的 V9.2 预测器；它是历史来源，不是此轮的有效机制。所有实际状态和代码必须计入 R0/R2/Rrand 共同资源账本；相对单库 FE0 的新增四份原生存储另列。

## 2. 固定读出和 R0 标定

对某个答案前题面 `q`，用不改变持续模型状态的同钟读取，得到每库、每通道的原生值 `v_S,j(q)`、`v_P,j(q)`，`j=0..3`。R0 在技术世界 `170000..170007` 的**旧 336 条结束、第一日休息前**，只对该世界 16 个已教旧事实和 12 个已教旧关系方向读值。对 `b∈{S,P}`，锁定

`s_b = sqrt(mean_{world,q,j} [(v_b,j(q) - mean_{k=0..3} v_b,k(q))^2])`。

两个 `s_b` 都必须有限且 `>=1e-8` 原生值单位；独立复算的绝对差 `<=1e-10`。否则 R 读出技术失败，不能临时挑另一组比例。把技术世界字节流、源哈希及 `s_S,s_P` 在科学世界前冻结。校准不看正确率、不看未教关系或未来科学世界。R0、R2 和 Rrand 在所有科学世界统一用

`u_j(q) = v_S,j(q)/s_S + v_P,j(q)/s_P`。

事实发出 `argmax_{0..3} u_j`（同值取最小通道）；关系单个选项的值为 `u_1-u_0`，固定 `L/R` 器官比较两选项、两个顺序都测，同值按既定 `L`，双顺序合计给 0.5。`u` 不按候选或世界重标定。单库 FE0 新平台结果每世界同表发布；R0 若弱，也不凭行为成绩改变比例。校准中的四个通道即使关系只教 0/1，也全部采样，严格遵守 v2 规则。

## 3. R2 的唯一机制改动

把每条教学记录的题面完成时刻记为 `t_q`。在真实答案字节尚未到达且任何本条教学尚未发生时，读取并缓存四个有限数 `u_j(q)`；输出也从这些缓存值产生。事实令活跃集合 `J={0,1,2,3}`，关系令 `J={0,1}`。随后真实答案字节到达，解析为 `y∈J`。此时只对**已缓存**的反馈前值计算

`p_j = exp(u_j - max_{k∈J}u_k) / sum_{k∈J}exp(u_k-max_{k∈J}u_k)`, `e = 1-p_y`。

这给出 `[0,1]` 内的整体预测误差概率：真实答案在整体四/二通道读出上越不可能，私有写入机会越大。它需要已到达的反馈，但不允许反馈改变 `u` 后再算误差。概率标度由第 2 节无标签读出标定和固定 softmax 温度 `1` 决定，不从技术或科学正确率调温度、阈值或目标写入率。用 `SHA256("R2-GATE-v1|<world>|<domain>|<branch>|<record-index>")` 的前 64 位无符号大端整数除以 `2^64` 得到 `U∈[0,1)`；`U` 与字节、标签、当前状态无关。**唯一 R2 门为 `G = (U < e)`。** 按活跃通道组成一个记录级门，绝不逐通道独立掷签。世界、域、分支、全局记录号必须写入摘要以防随机数复用；克隆和恢复不另耗随机数。

共有的教学许可 `A` 由五个因果分支规定：`W` 全部；`N_old_fact` 只停旧事实；`N_old_rel` 只停旧关系；`N_new_fact` 只停新事实；`N_new_rel` 只停新关系。禁写只停对应原生值写入，继续相同字节、答案、时钟和感官调用。对每个活跃通道 `j∈J`，教师二元值为 `r_j = int(j != y)`，即完整目标而非共享预测残差。共享库调用原生 `teach(r_j, t_answer, write=A)`；私有库调用 `teach(r_j, t_answer, write=A and G)`。`A=false` 或 `G=false` 时仍调用 `teach(...,write=False)`，以维持原生教学事件、时钟和适应语义。关系记录的通道 2/3 接收答案字节并调用 `teach(...,write=False)`，保持四通道感官／非写入事件一致。所有通道随后接收同一换行并 flush 到下一条记录时刻。旧事实与新事实应各有 `192×4` 个共享通道写入，旧关系 `144×2`、新关系 `72×2` 个；R2 私有通道写入数必须等于各段 `sum(A and G)×|J|`，逐段逐通道复算。

R0 使用同样两库、相同 `u`、相同缓存/计算、相同 `A` 和教师二元值，只把私库 `write` 设为 `A`，即允许事件全部写入；R2 的 `U/e` 计算可在 R0 作为不影响状态的审计值执行。**R2 对 R0 是主比较**。共享库在匹配分支中的每次写入必须逐位相同；两个臂的私库容量与初态逐位相同，实际写入次数不同并记录，这正是待检验的门控操作。

另设 `Rrand` 诊断“选中哪些事件”是否比仅减少写入更有用。每个世界、压力域及因果分支先只保存 R2 的批准数，不看其正确率；按 `(旧/新, 事实/关系, 到达的答案 y)` 分层。在同一层所有许可 `A=true` 的事件中，独立哈希随机排列，取与 R2 **完全相同**的 `G=true` 数目作 Rrand 私库写入，其他语义与 R0 相同。Rrand 从出生完整重放同一 600 记录，不复制 R2 的学得状态；只将批准数用于定额，绝不将 R2 的具体批准位置、预测值或成绩传给它。Rrand 只能在当前答案实际到达后读取当前记录的预定门位，首答不能读到门位或未来层信息。先锁随机排列算法和命名空间，再运行任何科学世界。Rrand 因使用候选事后总次数，是**写入剂量与放置位置的诊断对照**，不能代替独立的 R0 主对照；其定额按目标类别分层可避免标签频数差成为解释。报告 R2−Rrand 及每层实际门率，若 R2 不优于 Rrand，只能将 R2−R0 归为门控/写入剂量包的结果，不能声称误差定向本身有效。

## 4. 必过技术审计

在科学世界前，先锁共同 600 记录生成器、五分支、四通道读出和完整成本，再作 R 批次校准及 R2 技术全生命史。只看技术正确性和资源，不依技术世界行为分数选参数。至少执行以下断言并保存故障注入失败收据：

1. **时序和无泄漏：**交换尚未到达的答案字节不改变题面完成时的 `u`、首答和门用缓存；交换到达的答案只通过 `p_y` 与 `r_j` 改变门/教学。故意提前给答案、用教学后的值算 `e`、给未教关系边一个答案均被审计拒绝。
2. **库与状态：**R0/R2/Rrand 同一出生原生数组、FE0 受体表和 CONTENT 路由；没有 V9.2 运行态，也没有 FE1 `h`。共享库同分支、同事件逐位相等。CONTENT 最近四非空格字节、换行重置、`pending_x`、快慢迹、适应、时钟、教师计数、哈希门的世界/域/分支/记录号全部进入完整**克隆与状态摘要**。本轮重启原子单位为完整世界臂，绝不从半生命史检查点恢复；父类 `snapshot()` 不含 CONTENT 的 `visible` 窗口，因此本轮不声称或使用其无损恢复。以后若要中途恢复，须另写并资格化完整序列化契约。
3. **教学账与随机对照：**R2 对同一记录或写入全部活跃私库通道、或一个都不写；共享计数等于 R0；每个禁写分支目标段两库写入为零，其他段规则不变；`Rrand` 每层批准数、总通道写入与 R2 逐位相等，但采用独立事件位置。修改收据中的一个门位、答案、标签、可写标志或层计数，独立审计必须失败。
4. **读出：**从完整模型独立克隆、逐字节重放查询，与轻量原生值读取在 `1e-10` 内一致；探针前后持续状态哈希、两库 FE 状态、时钟均不变。事实四通道及关系两顺序的发出字节可由保存的 `v/s/u` 独立复算，包含平局。标定只含 8 个技术世界的 28 个已教提示；伪造未教提示或科学世界读值应被拒绝。
5. **暴露与反模型：**按实际到达的字节重建教学清单，旧未教关系三条边及两个方向在任何阶段无答案/反馈；旧已教方向 12 项；新符号与旧符号不交叉。原始/规范化精确键表在旧未教边只能猜机会水平；按位置、类别频数和单侧偏好分别核算；一位从旧教学推断的类别规则作为任务可解上界，不能放进模型。所有评分在对应反馈前、只读副本上进行。

本轮 R0 读出标定专用技术世界为 `170000..170007`；各臂完整生命史技术世界为 `170000`；共同科学世界预留为 `171001..171032`，具体数量只在技术耗时、内存和收据体积核算通过后由共同源锁确定。这些数字取代旧 v2 草案的较大预留范围；三种**不同家族**的候选须用同一配对世界。R2 单独规格不授权从旧 FE1 世界借数据或拿旧单存储成绩作新平台成绩。每臂全生命史耗时、峰值内存、收据体积及源/输入哈希须先实测并封闭运行上限；技术失败记 `NOT_INSTANTIATED`，不能当科学阴性。
