## 文献与外推边界

目录引用的[输入密度实验](https://pubmed.ncbi.nlm.nih.gov/37348501/)、[结构化 PN→KC 采样](https://pubmed.ncbi.nlm.nih.gov/35797998/)和[跨 KC 通路 DPM 预印本](https://arxiv.org/abs/2604.28007)确实存在，关于重叠／辨别与候选连接通路的概述大体有源。目录把 L5／L7／L9 列为与 MiniFly **高度相关**，是研究判断，不是这些论文验证了当前字节任务。特别是 L9 的 DPM 桥接来自连接组与干预结果支持的**模型推断**，论文摘要也使用“suggests/could”；目录第 635 行“is a biological mechanism”应改作“提出一个可能的生物线路”。L1 的二阶条件化只意味着在**先前有强化学习之后**，已学线索可成为下一次学习的教师；不能简写成完全无需外部教学信号。
