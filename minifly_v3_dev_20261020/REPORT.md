## What passed and what it means

Cycle 1 verified the original archived native assets, scalar/batched native state and readout parity, local direct derivatives, payload coverage, frame timing, read-only generation and explicit EOS/truncation. An initial readout projection error was corrected before comparisons; its failed fixture records are retained.

Cycle 2 selected the first qualifying finite local-rate candidate using generic taught fixtures, without HELD feedback. It verified bounded local updates, frozen/plastic forward equivalence at birth and exact whole-record checkpoint/resume. Gradual teaching had lower early taught recall; that cost is retained in the curves.

Cycle 3 exercised the entire OLD/rest/NEW/rest chronology, all four arms and W/N_OLD/SH_OLD histories on two registered engineering worlds. The separate reducer checks immutable trace/receipt hashes, exact generated outputs, native residuals, gradual/steady multipliers, clocks, shuffled-label multisets and checkpoint hashes.

Technical qualification is not evidence that the new representation learns arithmetic. All E3 comparisons and costs are reported in SUMMARY.json; taught acquisition or a stable checkpoint does not replace retained unseen-addition performance. No extra training, altered task or approximate-answer success criterion was introduced to rescue the outcome.

## Final audit additions and limits

Active-receptor W/G derivative checks and explicit local trace recurrence passed in the supplementary audit. Erasing native fast/slow state on read-only final P-G checkpoints reduced taught recall to zero in both worlds, confirming that the native stores supplied the scored memory. These are E1 attribution checks, not E3 success.

The resource report preserves exact recorded production costs, measured dispatcher wall time and a conservative read-only memory profile. It does not invent missing full-worker process CPU or retrospective peak RSS. Future operations need explicit telemetry/admission qualification; no pilot is currently justified.

The design was revised with the measured parameter lock and the negative outcome. No arithmetic-specific component, extra sleep replay, longer budget, changed held-out set or approximate-answer gate was introduced.
