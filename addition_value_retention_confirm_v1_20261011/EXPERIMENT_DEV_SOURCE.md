# 有限加法数值保持实验设计

2026年10月11日。状态：三轮DEV已完成并通过审查，选择STABLE进入待授权确认；正式确认尚未启动。原始设计留存于DESIGN_RECEIVED.md。阶段目标仍是一个能从带噪、缺失答案示例学习有限加法，并在延迟和后续学习后保留能力的 V2 核心。

## 研究问题与已有证据

[上一轮三轮报告](../addition_rule_dev_v1_20261007/THREE_CYCLE_REPORT.md)中，最终 U045 scalar ordinal 实例在两个 DEV 世界的未教组合正确率为87.5%，旧题最终保持为69.23%，未达到75%门槛。旧题错误均为较大答案少报一。原生九输出配方在该共同表示下失败，不等于整个 Full151 家族不能学习。

当前候选在答案到来时，向快、慢内容写入有界数值残差；读出把两份内容相加，按固定数字顺序选择答案。快状态的时间常数为1小时，慢状态为30天。这个数值读出依赖绝对幅值：状态缩小可能改变答案。这是本轮的可检验解释，不是由旧报告已经证明的因果结论。

主要问题：把无新证据时的被动数值损失去掉，能否在同一学习预算下同时保住已教答案和未教组合能力？只改变内容的时间推进规则，不改题目、编码器、输出字母表、反馈、学习剂量或原始信息。正式结果最多支持该有限加法任务中的 E1 保持和 E3 复用；不支持自然语言、任意精度或通用智能。

## 固定的三种规则

所有规则使用上一轮最终的共同角色特征 KC 连接、scalar ordinal 读出、同一局部 Huber 更新、同一初始零权重与相同边界。原生 Full151 九输出配方不再次运行；本轮直接比较已获得加法开发信号的 U045 具体实例，不声称改良了所有原生 Full151 机制。

| 规则 | 无反馈时的时间推进 | 作用 |
|---|---|---|
| DECAY | F'=F exp(-dt/3600)，S'=S exp(-dt/(30天)) | 上一轮候选的匹配基线 |
| STABLE | F'=F，S'=S；时钟继续推进 | 最简单的数值保留参照，也允许成为下一版本 |
| TRANSFER | 消退的快状态转入慢状态；总数值不损失 | 检验有界快慢转移是否比简单保留有实际价值 |

TRANSFER 对每个被访问的坐标，以推进前的 F、S 计算：

```text
d = exp(-dt / 3600)
u = (1-d) * F
accepted = clip(S+u, -2, 2) - S
S_new = S + accepted
F_new = F - accepted
```

这不是先衰减 F 再额外加 accepted；那样会重复扣减。边界限制的是转移量而不是丢弃内容。因 accepted 与 F 同号、且绝对值不超过 F，F、S 各自仍处于[-2,2]，并且 F_new+S_new=F+S。慢空间已满时，未转移内容保留在快状态，不偷偷消失。负的已学修正同样转移。

反馈时三规则均保留：

```text
value = sum(z_i * (F_i+S_i))
error = clip(actual_arriving_digit - pre_arrival_value, -1, 1)
delta_i = z_i * error / sqrt(1+visits_i)
F_i = clip(F_i + 0.2*delta_i, -2, 2)
S_i = clip(S_i + 0.8*delta_i, -2, 2)
```

时间推进只对被访问的内容坐标惰性计算，常规事件不扫全网；STABLE只维护时钟。只读预测不能把惰性视图写回原状态，物化的搬运以每坐标最后时间记录，重复读取不得重复转移。技术快照/完整状态审计的额外成本独立计入。

ordinal 基础步长仍为1；快慢份额、每坐标±2边界、访问计数上限65535、单位化 z 均不调整。实际答案字节之前不更新；缺失答案不给教学更新；错误答案教的是实际错误字节。TRANSFER 的时间搬运与教学写入分开记录，禁止把搬运计为新增反馈或新增学习内容。

STABLE 与 TRANSFER 在不触及写入边界时可能给出完全相同的总值和答案。这是预期的结构等价，不是两份独立成功机制。若它们表现相同，优先最简单的 STABLE；不能把内部快慢分布不同单独宣布为能力提升。永久保留本身也不证明无限容量、应对规则变化或生物真实性。

## 输入与经验保持不变

- 操作数0–4，答案0–8；模型按字节读取 `a+b=`，在 `=` 到来时自行发出一个数字，之后才收到实际答案或缺失答案的换行。
- 工程数字/角色表示及 ordinal 数值输出先验保持公开。模型中没有加法器、预设加法系数、真值通道或按真答案选坐标。
- 留出完整交换轨道 `(1,1),(1,2),(0,4),(2,3),(3,3)`，计8个有序题面；两种方向从所有训练中排除。这些题面是既有协议的固定目标，不伪称为对研究者从未见过的任务。
- 13个旧题、4个后续题，每题40次；每题固定32次正确答案、4次错误非真值数字、4次答案缺失。世界随机化次序和实际错误字节，不增补正确示例。
- 后续题保持 `(1,3),(3,1),(2,4),(3,0)`；其中部分交换形式已在旧经验出现，不把新题全部描述成新语义。
- 顺序：旧学习→模型时钟24小时→后续学习→模型时钟24小时。各检查点只在只读克隆上测全部25题，无任何探针反馈、重教或测试时参数校准。
- 每个规则运行 W、N_OLD、SHUFFLED。N_OLD 与 W 的全部原始字节和时钟相同，只禁旧教学写入，后续教学开启；SHUFFLED 只打乱旧答案，保留答案频次和缺失位置，后续字节与 W 一致，不能称其旧字节流相同。
- 状态、语法和实际到来字节是模型全部信息。禁止提供 phase、taught 身份、noise_kind、真值、未来正确性或是否属于留出题。

## 规模与预先固定的选择

DEV 固定6个新世界，三规则、三历史：18个 world-arm 完整作业，54条历史。6个世界使用同一任务，结果标为探索性，只用于预先声明的晋级决定，绝不并入正式确认。

每个候选都必须在 DEV 的世界均值上同时达到：

1. 最终未教组合、旧训练题、新训练题正确率各≥75%。
2. 最终未教题 W−N_OLD 和 W−SHUFFLED 各≥20个百分点。
3. 最终旧题相比 DECAY 提升≥10个百分点。
4. 最终未教题相比 DECAY 不低超过5个百分点。
5. 所有技术及独立暴露/禁写审计通过。

选择规则不是挑最高分：STABLE 合格则选 STABLE；仅当 STABLE 不合格而 TRANSFER 合格时才选 TRANSFER；二者都不合格则停止并交付负面结果，不改门槛、不再补训练、不扩展参数搜索。正式选择锁在查看任何确认世界结果之前保存，最多一个候选晋级。

确认固定64个全新世界，只运行 DECAY 与已锁定候选，三历史：128个 world-arm 完整作业、384条历史。合计上限146作业、438条历史、297840个训练记录、1757256个训练字节。全部未晋级时只执行DEV的54条历史。合成技术 fixtures、只读探针克隆和反事实擦除不算新的学习历史；提交数只按完整作业计算。

世界 namespace 在实现前查重并写入锁；不得占用旧831xxx世界、其他实验世界或重跑旧轨迹。统一使用上轮依赖与固定表示的来源身份，候选新规则位于新目录；旧实验目录只读。

## 确认终点和判定

主要行为仍是精确答案，不把相近数字、AUC、代码距离或概率改善当成替代成功。正式确认的三个配对世界均值对比是：

- 最终旧题：候选 W − DECAY W。
- 最终未教题：候选 W −候选 N_OLD。
- 最终未教题：候选 W −候选 SHUFFLED。

三个对比各自的一侧95%下界必须严格大于0，且保持上述DEV同一组绝对与点差门槛。正式成功要求全部条件共同成立，属于一个锁定候选的交集判定；没有在确认中从两个候选挑一个，无需把每个探针都纳入候选选择家庭。各对比和全部失败门槛都报告，不把交集成功拆成多个独立机制发现。

非零世界间样本方差时使用预先锁定的配对 Student t 一侧区间，明确其有限样本近似性质。方差为零时不得伪造零宽区间：因差值位于[-1,1]，使用 Hoeffding 下界 `mean - sqrt(2*ln(1/0.05)/n)`。此回退规则在运行前固定，可能给出 UNRESOLVED；不因此补世界或换方法。全部原始世界值、点差和区间算法一起交付。

64是固定的独立确认世界数；规划上，若世界差值标准差为0.20，一侧区间半宽约4.2个百分点。这是预算/精度假设，不是对未知方差或成功的保证。旧门槛保持75%，不因结果接近改成69%。每个旧题、留出题逐题报告，均值合格也不得称每题可靠。

同时报告获取/保持变化、所有检查点、数字 MAE、概率损失、更新与搬运次数、达到同一成绩消耗的训练字节/反馈、每字节和完整作业 CPU、峰值内存、可变/固定状态字节、时间推进成本。复杂候选若无可用行为或成本优势，不能凭内部状态更丰富而优先。

若候选通过，采用的只是本有限任务中的持久加法工程实例；如 STABLE 与 TRANSFER 等价，报告无需复杂巩固而不是巩固机制获胜。若未通过，保留当前正式自主观察基线，V2加法继续未采用。新实验不影响旧自主观察基线的既有结论。

## 反事实与反背诵审计

所有评分先于反馈；留出及其交换形式不存在于任何教学字节。审计器从原始字节独立重建符号、实际答案、缺失、时钟和输出，不依赖 runner 的汇总表。核对旧13题覆盖所有操作数与答案，记录后续题的已有交换形式。

按实际到达的训练答案分别拟合频次、精确键、交换归一键、只看左项、只看右项的反模型。必须公开它们在该世界留出题上的实际成绩。学习到的线性规则可作为数据可解性证据，但只存在于评估器；不能把它当候选、给模型初始化或在测试时调用。前轮的25%并不是无需重算的新世界保证。

content erase 克隆必须恢复固定的零数值先验；改变已学内容必须改变输出。N_OLD 在旧学习和day1时的实际内容、访问计数均为零。把学习标志改成False但仍更新矩阵属于失败，不能靠台账掩盖。

技术资格至少覆盖：任意符号 F/S 下的守恒、慢边界饱和、反向/重复/拆分时钟、懒推进与逐步推进等价、反馈前值与到来字节更新顺序、缺失不写、三历史实际禁写、只读探针不污染状态、跨模型数组独立、时钟与未来信息拒绝、完整作业拒绝重复提交。所有规则共享完全相同的输入和代码。新增时间搬运不可改变反馈计数。

独立审计的tamper须拒绝：删字节、错答案、隐藏真值、偷偷教留出、禁写仍更新、漏搬运记账、凭真标签修正数值、修改输出、丢作业、错世界/来源、重复提交。检查点若使用，必须先通过不中断与恢复状态/输出一致；未资格化的中途续跑不进入科学运行。

## 运行预算和停止

建议2个后台进程，caffeinate只绑定科学 supervisor。上一轮完整世界（两规则、六历史，含原生九输出）约20.9秒壁钟；本轮不重跑原生配方。以旧耗时按三规则放大估算，最大串行科学时间约26分钟，再为资格、审计、启动和打包留余量，规划约1–2小时。这是保守预算参考，不能保证；以最终日志政策的完整世界资格计时为准。

资格时测一次完整作业的CPU、壁钟、峰值内存和收据大小，再按固定最大规模投影。预计超过单次10小时或最终磁盘预算1GB时，不启动确认、不缩小n假装确认，先交付成本阻塞。每个会话最多9小时开始排空，10小时上限在完整作业边界安全暂停；若一个完整作业无法在剩余窗口安全完成，则不派发。中途恢复必须明确授权，不自动重启。

执行错误立即停止，保留已提交与在途文件，不自动重跑科学轨迹。科学不合格是正常完成，仍分析、审计、打包。发布GitHub需另有授权。日志引用当前supervisor文件，旧root快照不能当实时状态；统计区分完整作业、完整历史、在途记录、尝试次数和重试。

## 不变的目标边界

本轮不加编码器、不扩到多位数或其他运算、不引入规则变化任务、不做NLP或进化搜索。STABLE不意味着遗忘永远无用，TRANSFER不意味着生物巩固被证明。长期容量、错误知识修订和规则变化不因本轮通过而自动认证；这不另加本轮任务，而是限制采用声明。

不以技术定位为终点。时间守恒测试只是准入，最终必须交付同一加法任务上保持和未教组合的完整结果，或明确的负面/未决结果。
