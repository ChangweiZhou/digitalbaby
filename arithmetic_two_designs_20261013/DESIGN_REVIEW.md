# Paired-design review

13 October 2026. Scope: review of existing saved evidence, primary sources and these design documents. The static validator checks count algebra, manifests, local references and complete-inventory coverage. It is not scientific validation or a three-cycle implementation exercise.

## Decisions resolved

1. A remains the existing RAW-RULE V2 proposal. Its canonical experiment/manifest were not rewritten, its eight-arm roster and original task budget remain intact, and no past technical result was relabelled as science.
2. B is an alternative, generic-stream hypothesis. Its recurrent architecture is not presented as a new discovery: RAW-RULE already has a GRU. B's concrete changes are learning targets, paid data curriculum/repetition and fixed decay recipe.
3. Neither design supplies arithmetic identities to new learners. A's exact numeric-feature legacy model is a disclosed nonselectable reference. B's evaluator generates counting examples, not a counting module in the learner.
4. Backprop is labelled engineering. A local-rule target is neither prohibited nor implemented by name without equations. No clarification question inside the pasted advice was treated as a requirement to stop this delivery.
5. B's all-byte loss exempts only generic input-only transport controls. Actual feedback and generated guesses have different permissions. Suppressed phases block encoder/head/optimizer/decay learning throughout the record.
6. Conditional multiplication transfer and total paid efficiency are separate. A matched post-counting scratch state and shuffled prior episode are required; no free counting, arithmetic warmup, exposure repetition or replay is credited.
7. An unchanged core across B's tasks does not establish NLP competence, biological locality, scalable sparsity or four-operation completion. Its subsequent four-operation split must be prospectively complete; no retrospective inverse-family withholding.
8. Repetition is a declared axis with 256 fixed passes, not an unbounded instruction to continue until generalization. B could require more compute than A. There is no minutes-long runtime claim.
9. B's 12 confirmation contrasts are prospective, world-paired and adjusted together. DEV's two-world selection is explicitly exploratory; a negative/no-advance outcome is valid. Taught accuracy is not an E3 gate substitute.
10. B's numerical cost checkpoints distinguish executed shared-prefix experiment work from each represented learner's experience. Five histories and forty forks are correlated, not independent lives. Unique information and repeated observations have separate ledgers.
11. All complete inventory views remain accessible and row-count checked: historical108, catalogue136, versions254, subset71 and first16. These overlap; no new total survivor number or whole-family exclusion is asserted.
12. No prototype, learner implementation, formal source lock, technical cycles, background process, adoption, Git commit or upload is included. Measured full-job cost and future qualification determine whether either design can be run within the user's session budget.
