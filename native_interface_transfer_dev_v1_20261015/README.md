The task remains **better exact answers on never-taught additions per training presentation and actual compute, while retaining relevant old ability**. The user's scope reply on 15 October is: “保持加法主任务，语言方案暂存”. Language/construction proposals remain in the immutable feedback intake. No language data, new architecture, arithmetic representation, attention, Transformer or ELM is added here.

There is no automatic adoption, formal population test, hyperparameter search, retry, or GitHub publication.

## Track A: one finite native-interface qualification

A1 executes the released eight-store R_center code unchanged: twelve cue bytes, a scheduled output from ASCII `0`–`3`, the actual outcome at that slot, newline, and 165 simulated seconds per record. Eight arbitrary clean cues preserve the historical eight-space/four-visible-byte shape. Four additional twelve-visible-byte cues deliberately acquire identical private four-byte suffixes after a shared first answer byte. Labels are arbitrary; arithmetic is absent. This reproduces the *protocol and source events*, not an archived numerical accuracy on identical historical worlds.

A2 holds cues, order, target's first byte, cadence and bank scales fixed, but uses sixteen shared and sixteen private stores with the prior C16 code/readout/teaching coefficients. All 257 classes compete even though the fixtures teach only ASCII `0`–`3`. A1→A2 therefore tests that **declared combined coding/teaching/channel intervention**, not an abstract codebook alone. A2 remains an externally scheduled single output, not autonomous generation.

A3 uses the retained RC151-C16 BEGIN/prompt/REPLY controller, forecasts before every arriving target, and trains whole one- or two-byte responses plus EOS. The controller resets prompt front ends per record, unlike the historical newline protocol; A2→A3 changes controller and sequence demand together and cannot attribute a failure solely to continuation. No learned prompt encoder or hybrid is introduced. The inherited shared FE0 route and private four-visible-byte route are unchanged. Their limitations are recorded rather than treated as a whole-model impossibility proof.

Each stage has the same 768-record cue schedule per W/NO_WRITE history; probes occur at 0, 12, 48, 192, 768 records and after a simulated 24-hour rest. The two first stages teach the first response byte only. A3 teaches the complete response. Forecasts and full score vectors precede observations. W permits all target writes; NO_WRITE observes the same bytes and timing but is checked against pure native plastic-state decay. Each store is born independently through the canonical birth call.

The finite-fixture qualification contract requires all eight clean targets correct at the final immediate probe, a positive actual-target margin for scheduled conditions, and strictly more correct clean targets under W than NO_WRITE. A3 also requires the four suffix challenges correct with its own EOS. **All-correct is a functional contract on these twelve fixtures**, not a statistical threshold for arithmetic or a claim about arbitrary future inputs. Every margin and count is reported even on failure. A failed stage ends escalation; later stages are NOT RUN, never marked failed by inference. The after-rest result is descriptive and does not change the acquisition decision. No dose extension or tuning follows the result.

The native track is E1 diagnostic work; an exact-key table can pass its clean association test. A negative diagnostic neither erases previous native E1 memory results nor the limited earlier V9.9A/B synthetic-relation E3 results. It does not block Track B.

## Track B: addition acquisition transfer and missing zero-shot transfer

Two fresh DEVELOPMENT worlds, each with the unchanged KEEP-C16-CE and G62-C16-CE references. These are independent gradient-trained recurrent models, **not Full151 descendants**. They have 28,440 and 28,800 actor parameters respectively. All 256 payload bytes and a distinct EOS remain possible. Output is the model's own digit sequence and its own EOS; no numeric readout or external arithmetic decoder supplies an answer.

Each world splits all ordered 0–9 additions into OLD60 / NEW20 / HELD20. Whole commutative orbits stay together. OLD covers every possible answer and all digits. The evaluator alone generates arithmetic labels; models receive raw prompts and observed answer bytes. Three histories share identical births, prompt schedules and NEW teaching:

- W: correct OLD expected outputs and permitted learning.
- SH_OLD: the same OLD prompts, with whole response strings shuffled within predetermined dose blocks. This preserves output-length/byte/EOS distributions within each block, but breaks the correct association. It is a matched generic-practice control, not guaranteed uniformly wrong feedback.
- N_OLD: the same correct OLD byte stream is consumed, with all actor and optimizer updates disabled. NEW learning is enabled. The parent resets within-example recurrent state each example; at NEW onset this branch still has birth parameters and optimizer.

OLD checkpoints: 0, 32, 128, 512, 2048, 8192, 16384 and after rest. NEW checkpoints: 0, 1, 4, 16, 64, 256, 1024 and after rest. Every probe scores OLD, NEW and always-untaught HELD. Probes use clones or no-update queries and never feed their labels back. Rest does not change these recurrent weights; it is a timing control, not consolidation evidence.

Report the full NEW curve and its normalized trapezoidal area over log2(dose+1), paired W−SH_OLD and W−N_OLD descriptive contrasts, NEW at dose0, HELD at every checkpoint, and OLD loss during NEW learning. NEW items become taught after dose0, so their later acquisition **is not** zero-shot addition generalization. A result deserves an E3 interpretation only insofar as matched prior learning improves never-taught NEW-at-zero or HELD own-output accuracy. There is no promotion gate from two worlds and no inferential significance claim.

An exact raw/canonical cue lookup has no taught key for HELD or NEW at zero. After NEW teaching it can pass NEW E1 acquisition. Frequency/answer-only shortcuts are calculated from OLD feedback, with ties settled by first occurrence; these descriptive shortcut scores are kept separate from learned behavior. Every HELD operand appeared in OLD, so a putative learned rule is possible; arbitrary-label associations alone cannot solve those held combinations systematically.

## Budget and execution

Fixed maximum: A = three stages × two histories × 768 = **4,608 record applications**, conditional on preceding finite-fixture qualification. B = two worlds × two references × three histories × (16,384+1,024) = **208,896 applications**, twelve correlated histories. OLD practice is charged in every history; it is never called free pretraining. Technical test applications have a separate explicit ledger. There are no independent lives for each checkpoint.

At most two child workers. One A job and four B jobs; a scientific/technical execution error halts dispatch and preserves existing artifacts. A negative *behavior* result is normal completion, and B still runs. No completed job is overwritten. Eight-hour admission and ten-hour hard session boundaries apply. At a boundary the run pauses; it does not silently retry or resume. `caffeinate -i -w <supervisor PID>` remains attached while executing. Local JSON status and a read-only terminal status command expose committed counts separately from partial records.

Measure API training CPU, actual prefeedback readout, idle advancement, query/guard, no-write audits, independent reduction, total child wall/CPU and source/birth startup separately. The inherited scheduled API still contains expensive state guards inside its API cost; this implementation does not quietly remove them. The old native cost omission is corrected in this new variant only. No cross-family compute efficiency claim is supported when native acquisition qualification fails.

Run tests with the pinned interpreter and then `run_dev.py`. The latter accepts only this fixed development roster, requires passing technical qualification and the source lock, and has no formal-world admission flag.
