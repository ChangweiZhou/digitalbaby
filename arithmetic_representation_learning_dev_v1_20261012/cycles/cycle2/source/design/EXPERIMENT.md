# ADAPT-2：让回答误差塑造内部表示

2026-10-12，设计 V1。**仅交付设计；尚未实现、资格验证或启动科学运行。**

目标保持不变：同一个有限状态核心，用更少的训练示例和计算，获得回答未见四则题的能力，并在学习其他运算后保留它。输入和回答仍是通用字节流，回答必须由模型逐字节生成并自行选择 EOS。本轮是四种基本运算；四则混合表达式是之后的能力步骤，不临时加入本轮验收，也不转向噪声处理、NLP、Q&A或扩容。

## 1. 这次实质改变什么

前轮已完成 48 世界、432 完整任务，审核接受，结果为 `NO_CONFIRMED_REPLACEMENT`。已教题回忆很高，未教题能力很弱。竞争编码、局部银行路由及相关写入的那些具体移植，没有确认改善四则样本效率。这不是字节接口失效，也不是所有同类机制都被排除。

前轮的字节嵌入和内容投影始终固定；回答误差只改变读出权重，局部路由最多移动问题原型。**本轮让回答误差直接改变产生共享特征的内部连接。** 精确上下文分支是否掩盖这种学习，是另一个待检验问题，不当作已经查明的原因。

只测试一个新机制：保留式、反馈驱动的非线性适配器 ADAPT-2。用“内部表示可学/冻结”及“精确上下文分支有/无”组成完整 2×2，对照都在相同新底物上。再保留前轮基线，避免只战胜一个新造的弱对照。

结果分三层报告：内部可塑性是否改善未见题样本效率；哪些运算获得了可归因的保留能力；是否足以推荐替换现有工程基线。最后一项失败不抹去前两项，但前两项也不能冒充完整新核心。

预先写下的预测是：若共享表示没有被误差塑造是当前限制，LEARN 应在未教题曲线上优于自己的 FROZEN；精确分支可能帮助已教题，同时改变内部学习收益，方向由交互检验决定。没有可靠依据预测具体准确率，也不保证两层网络在 512 条记录内学出乘除。只提高已教题、只让目标损失下降或内部连接确实移动，都不能支持主要预测。

## 2. 来源和归因边界

机制出自完整版账本中的 `V23/adapter_retained`，直接代码是 `RecyclingAdapterMemory`，`replace=False`。其思想是用回答误差移动下游地址向量，同时学习读出，保留适配器而不周期性重置。历史证据是六种子关联/修订，不是当前四则泛化，不能继承其成绩。

ADAPT-2 是**新工程变体**：两个平滑非线性层、单个共享银行、257 类字节交叉熵。不称为原样移植，也不称为已经验证的苍蝇生物机制。采用反向传播符合用户允许调整内部结构的范围。历史宽度 96、读出步长 0.6、适配器步长 0.025、单次适配器移动上限 0.1保留；两层 tanh、初始化和交叉熵是本设计的新选择，不能伪装成历史参数已有算术依据。

冻结/可学四个配置都用相同两层、损失、共享银行和出生数组，只改变声明的开关。单银行取消随机硬分工，使有限示例可更新共同表示；它是四配置共同底物，不单独获得机制功劳。与前轮基线比较的是整个新核心，不把所有差异归因于反向传播。

| 配置 | 内部 A1/A2/b1/b2 | 共享读出 V/c | 精确上下文 W | 角色 |
| --- | --- | --- | --- | --- |
| FROZEN-HASH | 冻结 | 学习 | 学习 | 匹配对照 |
| LEARN-HASH | 学习 | 学习 | 学习 | 候选一 |
| FROZEN-SHARED | 冻结 | 学习 | 不分配、不访问 | 匹配对照 |
| LEARN-SHARED | 学习 | 学习 | 不分配、不访问 | 候选二 |

候选仅有上述两种 LEARN。不能事后把得分较高的冻结对照升格为新候选。LEGACY-B 在新世界重新运行，不将前轮另一批世界的均值混入配对统计。其源码按原样封存复用，不编辑已完成实验。

## 3. 保持任务和信息预算

复用前轮的事实家族划分、数值范围、训练生成顺序和评分方式；新世界只改变划分、出生和顺序种子。保留整个家族，防止记住已教逆式后冒充泛化。

| 家族 | 合法实例 | 留出规则 |
| --- | --- | --- |
| SUM(a,b)，a≤b | a+b=s、b+a=s；s−a=b、s−b=a；a−s=−b、b−s=−a | 所有交换式和逆式一起留出 |
| PRODUCT(a,b)，a≤b | a*b=p、b*a=p；p/a=b（a>0）、p/b=a（b>0） | 所有交换式和逆式一起留出 |

a、b 为 0..7。SUM、PRODUCT 各有 36 个种子家族，12 个留出、24 个训练。留出从 2≤a≤b≤7 的 21 个家族中抽取，避免 0/1 捷径。不同家族的重复题面须审计，训练/留出题面交集必须为空。完整训练池覆盖被测字符；每个实际低样本前缀的覆盖单独报告。

答案是标准十进制整数字节串：加法到 14、乘法到 49、减法包含负数、除法是精确整数逆运算且分母非零。不是实数除法或长整数算术。训练提供正确完整的观察答案，不增加噪声压力；清洁数据下获得泛化仍是尚需解决的目标。

每个世界、每个配置有 W、N_ALL、SHUFFLE 三条历史；各历史每种运算最多 128 条记录，共 512 条。预算点为每运算 4/8/16/32/64/128，总记录数 16/32/64/128/256/512。每个预算点按世界间平衡轮换的运算块顺序补足预算；同一世界全部配置与历史同序。训练题池按固定随机流打乱整轮循环，不按模型表现选例。

每块结束及四块全部结束都只读评估。最后推进模拟 86400 秒再评估；无衰减的本设计中这是明确的无操作，不称为巩固或真实长期遗忘检验。能力须经其他运算的实际写入检验。

## 4. 通用字节接口和共同感知输入

沿用独立的序列开始、回复开始及结束控制；全部 0..255 是载荷，EOS=256。没有算术解析器、答案渲染器、数字掩码、候选答案列表、预期长度或运算 ID。`=` 只是训练题面的载荷，回复开始来自公开框架，不由隐藏解析器触发。

保持 4096 事件上下文窗口；任意长度输入按原窗口策略接入，退出窗口的字节不能继续作为开头特征。科学题面均落在前八字节内；这不声称学会了长表达式。所有配置最多生成 16 个载荷字节，未主动选择 EOS 时标为 `TRUNCATED`，不能把超限当正确结束。

四个适配器配置使用与 LEGACY-B 相同定义的 96 维 h，归一化后包括：前八原始字节位置的固定 8 维随机嵌入（64维）；这些位置的 ASCII 数字值/9（8维）；回复偏移 0..6 及 ≥7 的 one-hot（8维）；前一个实际/生成回复字节的嵌入（8维）；其余窗口内容的顺序哈希摘要（8维）。

数字数值是所有配置都有的感知先验，不隐藏；没有运算结果、正确答案符号、左右算术系数、家族 ID或反馈标记。固定嵌入和摘要不学习。本轮不重新开启编码器筛选。

推理仅给问题、公开回复边界和模型自己的已生成字节；不提供正确回复前缀。真实答案到来时才产生学习目标。输入题面接入、只读探针及生成均不更新持久学习状态。

## 5. 内部结构、出生和精确更新

共同前向计算（h、s1、s2、u 为列向量）：

```text
s1 = tanh(A1 h + b1)                    A1:96×96，b1:96
s2 = tanh(A2 s1 + b2)                   A2:96×96，b2:96
r  = sqrt(s2·s2 + ε²)                   ε=1e-8，数值稳定常数
u  = s2/r
z  = Vᵀu + c + H·Σ_i x_i W_i           V:96×257，c:257
p  = softmax(z)                        H=1（HASH）或0（SHARED）
```

A1、A2 分别由独立出生子流产生，Xavier uniform 区间 ±sqrt(6/192)；b1/b2、V/c、W 初始均为零。固定字节嵌入使用与 LEGACY-B 相同的种子子流。四配置的对应出生数值相同，独立可变对象不能别名共享。V/c 在四配置都可学；冻结的是内部连接，不是全部学习。

HASH 时 W 为 4096×257 float32；16 个不同的上下文哈希接触各有 x_i=1/4，地址和盐值规则复用已验收接口，读取整个当前窗口。SHARED 不分配 W，也不暗中读取哈希预测。A1/A2、b1/b2、V/c 用 float64。

每个真实回复载荷字节或真实 EOS 到来后，计算全 257 类交叉熵误差 `e=onehot(t)−p`。**所有方向从同一个更新前状态计算**：

```text
v  = V e
g  = [v − u(u·v)]/r                   经过平滑归一化的精确方向
d2 = g ⊙ (1−s2²)
d1 = (A2ᵀ d2) ⊙ (1−s1²)

ΔV  = 0.6 u eᵀ
Δc  = 0.6 e
ΔW_i= 0.6 x_i e                       仅 HASH

ΔA2 = 0.025 d2 s1ᵀ，Δb2 = 0.025 d2    仅 LEARN
ΔA1 = 0.025 d1 hᵀ， Δb1 = 0.025 d1     仅 LEARN
```

每层内部参数与偏置的联合步长范数单独限为 0.1：先形成该层完整增量，再乘 `min(1,0.1/||增量||)`；零增量保持零。没有额外梯度循环、Adam、回放、周期重置、噪声门或任务路由。所有开关使用相同每分支步长；有哈希时总更新容量和梯度分配确实不同，不能称为纯等容量消融。

V 从零开始，第一次事件的内部梯度为零是预期行为；V 非零后才可能出现内部更新。不能改用“读出更新后 V”回传，以人为制造首步信号。冻结配置计算同样前向和读出更新，但不执行内部反向更新及无用的计算填充；额外计算是 LEARN 的真实代价。

## 6. 因果历史、暴露与反模型

| 历史 | 实际收到的观察 | 持久更新 |
| --- | --- | --- |
| W | 正确问题、正确回复、真实 EOS | 开启声明的学习参数及计数 |
| N_ALL | 与 W 相同的全部载荷与控制事件 | A1/A2/b1/b2、V/c、W及学习辅助统计全部禁写 |
| SHUFFLE | 相同问题；在每运算、每预算增量内排列整个答案串 | 开启声明的学习参数及计数 |

SHUFFLE 保留每块的答案频率、长度和字符分布，允许并记录排列固定点，不反复抽到一个更不利的排列。N_ALL 可以推进工作上下文和时钟，但不得通过缓存、优化器、归一化统计或隐含计数学到答案。三历史均在首次未教题响应前不给该题反馈。

暴露审核须证明：留出题及同家族交换/逆式未带答案进入任何训练历史；科学探针不学习；生成的猜测不作为真实观察再次写入。实际训练记录、独特题数、答案字节和 EOS 计数分别记录。

反模型读取相同实际训练前缀：精确题面表、交换/逆式事实表、最常见答案、仅左/仅右操作数表。精确表和事实表对未知项弃答，不能从计分器取答案；其他快捷模型的真实成绩必须报告，不能笼统假定为机会水平。评估器的真算术函数仅作格式/可解性见证，与学习器进程的数据访问隔离。

能支持的最高结论是**本有限任务内的 E3**，包含其他运算写入后的保持。已教题为 E1。没有换呈现 E2、混合表达式或 E4 结论；反向传播及外部正确答案也不构成无教学信号的自主学习证据。

## 7. 测量：能力、样本、计算和干扰

每个预算点，逐运算测留出题完整字节串和 EOS 正确率 A_o(n)，四运算等权宏平均 A(n)。所有主要曲线取该预算点四块训练结束后的状态，包含干扰后的实际能力。

```text
J_samples = [A(4)/2 + A(8) + A(16) + A(32) + A(64) + A(128)/2] / 5
```

这是固定 log₂ 样本区间的曲线面积；不能换成挑出的最终点、教师强制 token 正确率或已教题成绩。逐运算 J 同式。另报告起始、各块后、各预算后和最终探针；每题结果、长度/首字节/EOS错误用于解释，不替换主评分。

J_cpu 沿用前轮共有实际 CPU 区间的 log 插值积分：每对配置在各自 4 样本点 CPU 的较大值到各自 128 样本点 CPU 的较小值上比较；端点不看准确率。无交集则 `UNAVAILABLE`，不能改区间。两候选分别对匹配冻结配置和 LEGACY-B 比较，不按不同积分区间的得分给候选跨比较排名。

核心 CPU 包含特征、哈希、前向、全部实际梯度及写入，不能把内部表示学习排除。探针推理、状态复制、审核、日志另计，并报告完整墙钟、总 CPU、固定/可变数组、峰值内存和每记录/回复字节成本。按样本有益、按计算无益是明确不同的结果。

四配置共同的内部连接、偏置及读出共 43553 个 float64 数值，即 348424 数组字节；冻结配置将内部部分列为固定状态，不能伪装成同样数量的可变参数。HASH 另有 4210688 字节的 W。固定嵌入、工作上下文、临时梯度及运行时开销另计。主要事件工作量为 O(L+2·96²+96·257+H·16·257)，L 是有界上下文哈希/摘要长度；反向更新增加同阶计算，实际 CPU 必须测量。这是小型工程实验，不证明可直接扩到巨型核心。

**干扰直接对同一运算测量**：每预算点，该运算自己的块刚结束的留出准确率 A_just，与随后其他运算写入之后的 A_end 相减，D_o=A_end−A_just。该运算排在最后、没有后续写入的点单列，不混入干扰均值；每运算对其他点取均值。已教题也同样记录。

不再用“后来的四运算宏平均−早先的四运算宏平均”代替旧知识损失，也不把旧基线未学会因而没东西可忘当成优越保持。D 用于呈现实际损失与跨运算收益；推荐条件采用干扰后实际能力的比较，不能仅凭较小 D 宣称更好的持久核心。

## 8. 冻结推断及三层结论

统计单位为 48 个配对世界；题、字节、六个检查点及三个历史不是独立重复。固定 **41 项**两侧 Bonferroni 家族 95% 配对世界 t 区间，均值、区间和世界分布全部报告，不因负面结果缩小校正家族：

| 推断项目 | 数量 |
| --- | ---: |
| 两候选各对匹配冻结配置的宏 J_samples、J_cpu | 4 |
| 两候选各对 LEGACY-B 的宏 J_samples、J_cpu | 4 |
| 表示学习的 J_samples 交互：(LEARN-HASH−FROZEN-HASH)−(LEARN-SHARED−FROZEN-SHARED) | 1 |
| 两候选，四运算，最终 W−N_ALL 与 W−SHUFFLE 完整回答正确率 | 16 |
| 两候选各对 LEGACY-B 的四个逐运算 J_samples | 8 |
| 两候选各对 LEGACY-B 的四个最终干扰后留出准确率 | 8 |
| 合计 | **41** |

最终因果项取 512 条记录、全部其他运算写入及模拟休息之后的第一次只读探针。起始和各中间时间点的因果曲线必须报告，但不事后取代最终项。SHUFFLE 控制的平均分可能高于或低于 N_ALL，不能预设两者都在一个固定“机会水平”。

数值非有限、CPU区间缺失或零方差无法估计时标为不可判，不以零宽 t 区间证明总体等价。保留 41 的家族规模；不能仅用有效子集重算校正。准备阶段给出 48 世界、41 项校正下标准差 0.05/0.10/0.20/0.50 的敏感性表，不从技术世界的好成绩选择功效假设。

报告必须分别给出：

1. **机制结果。** 某候选相对其冻结对照的 J_samples 区间下界>0，支持内部可塑性改善本区间的未见题样本效率；J_cpu 同样单独判断。不能由“一个显著、一个不显著”推出哈希阻碍学习，后者须看预声明的交互。
2. **能力范围。** 某运算最终 W 对 N_ALL 和 SHUFFLE 两个下界都>0，支持该运算的有限 E3。四运算都满足才说观察到四种运算的保留泛化；统计上的小优势不叫熟练掌握。
3. **替换建议。** 仅当候选的两种宏效率相对冻结对照及 LEGACY-B 都确认增加，四运算最终因果项都确认，逐运算样本面积和最终能力相对 LEGACY-B 的下界均≥0，才推荐此范围内的新工程基线。没有确认无损是未决，不等于证明损害；不事后设置 −5pp 豁免。若两候选均满足，按 128 样本 W 训练 CPU 中位数较小、再实际数组字节较小、再名称排序选择。

差为零是增量判断边界，不另设 80%/90%/“提升十点”等能力门槛。上述保守替换条件不会成为压掉分项发现的总开关。报告同时保留实际绝对准确率：不能用战胜接近零的基线宣称四则算术已经解决。

## 9. 有界规模和运行责任

固定 48 个新世界，科学 ID `202610129201..202610129248`；独立技术 ID `202610129100..202610129199`。不得与前轮世界合并，也不复跑旧世界来挑参数。

```text
48 世界 × 5 配置 = 240 完整世界配置任务
240 × 3 历史 = 720 条相关状态历史
240 × 3 × 512 = 368640 次外部记录应用
```

同配置的三个历史接收信息不同的因果控制，不叫三倍独立样本。每个学习器的最大 W 训练预算仍是 512 记录；输入、回复、EOS、重复记录和工作探针另计。只读保存点不算新生命或新训练。新试验比前轮的 432 任务少，但反向梯度成本未知，不能按任务数直接承诺 ETA。

计划两个后台工作进程，BLAS 各单线程，主管与终端脱离、caffeinate跟随活跃主管。准备阶段测完整任务而非只测两条记录，报告生产和审核总成本；依据实测给出运行时间范围。8小时停止接入，10小时会话硬界；完成任务边界暂停或使用资格验证通过的无损事件检查点。不得为窗口赶工改样本量；续跑需要用户授权，失败不自动重启。

没有科学 DEV 选配方，没有后验扩样，也没有本轮内的步长、层数、宽度或训练时长救活搜索。技术准备只修实现与操作缺陷，不按未见题结果改上述结构。科学失败和无改进都保存、审核、报告；只有完整合格任务计入完成数。

## 10. 实现前的三轮准备责任

本文件没有宣称以下工作已经完成。三轮准备须在科学启动前进行，且不能演变成另一个能力目标。

**第一轮：机制和接口。** 实现五配置与出生配对，有限差分审核交叉熵、两层 tanh及平滑归一化方向。验证全部方向使用更新前 A2/V；首事件内部梯度为零，读出非零后的合成非零梯度确实只改变 LEARN。冻结对照也能学习读出，不能成为假无学习对照。回归任意载荷、负号、多字节、空答案、EOS、超限和分块接入；合成夹具只能验证数值和接口，不拟合科学保留集或证明算术。

**第二轮：禁写、暴露和成本。** 逐事件重建训练许可；覆盖所有持久数组、辅助计数、推理缓存及检查点恢复，篡改收据必须被独立审核拒绝。验证 SHARED 没有隐含精确上下文塑性预测分支（公共 h 的尾部摘要仍保留），HASH 不按是否教过启用；训练/留出家族及逆式没有交集。测完整技术任务，并验证同运算干扰指标、41项列表、CPU积分与240/720/368640计数。

**第三轮：冻结和完整管线。** 冻结源码、依赖、出生数组、数据生成与统计清单；用独立技术命名空间冷启动到分析/审核/打包，并验证重复任务拒绝、后台脱离、caffeinate、安全暂停恢复和未提交工作处理。资格通过只能说明管线可运行，不是科学机制成功。若未通过，提供实际缺陷及修复记录；不能悄悄启动科学运行。

## 11. 一次运行后如何决定，而非继续轮换定位

| 结果 | 本轮允许的判断与后续 |
| --- | --- |
| LEARN 改善样本和计算，四运算最终因果成立，干扰后能力不退步 | 采用通过建议条件的工程基线；下一能力步骤才是有限深度混合表达式 |

| LEARN 与匹配冻结配置没有确认差异，或均没有最终 E3 | 该 ADAPT-2 配方没有达到预期；更新完整版机制账，不排除所有 Hebbian、拓扑或适配器家族，不自动再开参数补丁轮 |
| 样本学习有效但干扰后能力消失 | 如实报告学到而未保留；所测知识仍没达到持久核心目标，不能以高已教回忆替代 |
| 技术或来源审核失败 | 科学不可判，保留记录；错误不算机制负面证据 |

暂不增加新的机制组合。任何下一方案都必须解释本轮留下的具体能力缺口，以及为何所选机制能改变它，而不是再改善已经近乎完美的已教题。
