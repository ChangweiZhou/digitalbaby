# ADAPT-2 三轮设计—审核—试跑—修订结果

**三轮通过，已具备正式运行资格；本次没有启动科学实验。**

目标保持：用更少训练样本和计算获得未见四则题的能力，并在后续其他运算学习后保持。保持前轮事实家族留出、样本曲线及通用字节接口；不转向噪音处理、NLP或扩大规模。

## 设计与归因

本轮测试反馈驱动的内部表示学习：两层96维tanh、257类字节读出。四配置是LEARN/FROZEN × HASH/SHARED，另有原样保存的LEGACY-B完整核心基线。SHARED确实没有精确上下文可塑性哈希矩阵，FROZEN仍会学习输出头。匹配冻结对照用于归因内部学习；LEGACY-B用于完整核心能力比较。

这是新工程机制，灵感来自V23/adapter_retained，不能称为旧机制的原样移植或原生Full151。所有配置使用相同公开输入先验；数字值感知先验已在设计中披露。没有内部算术求解器或正确答案前缀。

## 耗时与统计边界

| 配置 | 全任务墙钟秒 | 工作进程峰值RSS MiB |
| --- | ---: | ---: |
| FROZEN-HASH | 13.04 | 111.5 |
| FROZEN-SHARED | 4.31 | 70.6 |
| LEARN-HASH | 13.22 | 94.2 |
| LEARN-SHARED | 4.51 | 82.2 |
| LEGACY-B | 16.24 | 89.0 |

峰值是工作进程生存期高水位，可能包括之前的任务。训练、探针、状态日志及审核序列化CPU，以及每记录/回复事件成本分别保留于RUNTIME_ESTIMATE.json。五任务的最终审核、分析、打包及拒绝检查约1秒，进程峰值约196MiB。

正式规模固定48新世界×5配置＝240任务、720条相关历史、368640次记录应用。按现机两个单线程工作进程测量，理想执行约20.5分钟；包含世界差异、最终分析打包和负载，暂估**30–60分钟**。不是运行承诺。完整分析保留240份解码收据，估算Python对象约3.73GB，规划峰值4–6GB；该科学规模峰值尚未实测。8小时停止接入，10小时硬界，完整任务边界暂停，需要明确授权续跑；失败不自动重启。

固定41项推断，48个配对世界。假设配对差的世界间标准差为0.05/0.10/0.20/0.50，家族校正95%区间半宽分别约2.48/4.97/9.94/24.85个百分点。这是设计敏感性，不是技术数据导出的功效或最小能力门槛。

机制样本收益、逐运算最终因果能力、整体替换建议分别报告。严格替换条件未满足可以是未决；不因此抹掉某运算或某机制的局部正证据，也不事后降低门槛。
