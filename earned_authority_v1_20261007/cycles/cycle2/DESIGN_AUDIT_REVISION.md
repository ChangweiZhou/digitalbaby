# Cycle 2 — native integration, audit, test, revision

Audit finding: on binary disagreement, shared_gap > private_gap means ERROR already selects shared. Halving private is algebraically inert. Revision: use the mechanically derived close-conflict window .5*private_gap < shared_gap < private_gap, with strict boundaries and no fitted thresholds. A witness now changes emitted choice. Except exact ties, binary outputs equal Q_HALF; the prospective benefit is selective four-way behavior, not stronger binary reuse.

Seven native integration tests passed. They exercised all 12 stage/branch decisions with actual teaching-call instrumentation, independently born/nonaliased stores, same pre-answer output under different arriving teachers, native ERROR state parity, serial two-option parent parity and rejection of formal IDs. Altered flags, disabled-state deltas, output timing and policy evidence were rejected. Labels are only used for scoring after emission.

The independent receipt auditor additionally checks the exact probe roster, cue bytes, target derivation, clocks, actual store calls, no-write reference equality, source fixture identity and all readout arithmetic. Missing probes or rows cannot silently change a denominator.

The revised-rule read-only census is exploratory. It retains the original 48-world ERROR learning and reproduces Q_HALF's binary causal effect (+8.68 pp), rather than claiming fresh evidence. Lifetime W old/new/revised mean accuracy is identical to ERROR in that sample. Available Latin raw data are too sparse for a population efficacy conclusion. No rule was selected by a tournament.

Operations defects corrected before full qualification: invalid limits are validated before lock creation; the source lock is enforced at job start and end; interrupted jobs stop only after a completed record and seal; committed jobs are read, not rerun.
