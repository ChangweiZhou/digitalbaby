# 第一轮设计和运行前审核

目标是原生连续观察获取，使用 DEV 810001，不进入正式样本。每个普通字节必须先预测，再从实际 byte 产生 signed error；写入地址缓存自到来前。四个独立原生出生，既有外置预测矩阵不保留。

审核发现旧 CONTENT 的空格跳过和换行重置不适合普通原始流，故本实例改为最近四个实际字节，没有逐块重置、FE0 fallback 或 cue 长度条件。这是预先声明的工程接口更改，不沿用旧 E2 结论。旧固定答案槽 wrapper 不复用，只复用其原生 signed 更新。

验收覆盖独立出生、时钟和调用顺序拒绝、未来目标不影响先前预测/地址、全部字节写入、禁写与原生内容擦除、DEV/science 隔离。完整 byte 损失和旧键输出必须真实改善；不以地址距离替代。
