# 实际观察驱动的 MiniFly 原生记忆学习

本阶段直接检验：连续字节观察能否更新 Full151 的原生快慢记忆，并让模型在延迟、新经验和内容修订后继续利用它。先完成三次设计、审核、试跑、修订；这些 DEV 试跑不作正式科学结果，不启动正式样本。

## 路线与范围

采用 A_NATIVE_OBSERVATION。模型在每个字节到来前，从过去四个原始字节形成固定地址，以四份独立出生的 Full151 原生存储给出 `0`–`3` 的概率和预测。实际字节到来后，内部计算 `s_j = p_j - 1[byte=j]`，使用既有 `teach_signed(c=0,s=s_j)` 更新原生快慢状态。没有额外可训练预测矩阵，也没有正确性 bit、答案位置、cue ID、阶段 ID 或外部 Teach 调用。

这里的固定地址是工程构件，输出也是工程读出。字节字母表仅为 ASCII `0123`；四个字节的固定最近上下文不代表任意长串。每个字节都预测、都可以学习，没有只在答案位置更新的特权。没有监督热身。未满四字节时使用同样固定规则对短上下文编码，不回退到另一条输入路线。

原生更新、连接和快慢分配保持父版本参数；连续观察封装是新实现。softmax 温度固定使用原有 CONTENT 校准尺度 1.3452365735750882，不根据本次答案或 DEV 结果拟合。初版字节间隔为父接口的 `30/14` 秒，延迟按原生时钟推进。

这是有限上下文的自主预测获取和保持，对应 E0/E1 记忆证据。改变题面后映射到同一地址不升级 E2，重复上下文不升级 E3。有限关系泛化仍是 nice-to-have，不进入本次合格门槛。B_PREDICTIVE_HEBB 是结构备选，本轮不自动追加。

## 连续流和干预

外部生成器选择 24 个不同的四字节键：`3abc`，其中 a、b、c 属于 `012`。16 个旧键、8 个新键；每个集合内四种后继字节平衡，标签任意排列。每个五字节块只是原始流 `key + actual_next_byte`；块间不重置状态，不给模型边界通知。这个格式保证目标键只在相应上下文出现，独立审计还要逐字节复核。

旧流 8 遍（640 字节），休息 24 小时，新流 8 遍（320 字节），再休息 24 小时。修订旧集合中的 8 个键，其真正后继字节循环改变一位，再观察 8 遍（320 字节）。总共 1,280 个学习字节。测试克隆依次读取原始探针流，整段原生写入关闭；记录全部字节的预测，不能只公布块末答案。

主分支 W 在每个学习字节启用原生更新。N_OLD 仅旧流更新关闭，随后新流和修订与 W 一样启用；它是外部因果干预，不是给模型的阶段信息。N_ALL 始终关闭原生更新。所有分支得到同样字节与时间。每个检查点另外切断原生内容读出：在只读克隆中清除快慢学习状态；不能以测试答案填回任何状态。

检查点包括旧流结束、第一天后、新流结束、第二天后、修订结束。保持主端点是第二天后、修订之前的 `day2`。修订后整个旧集合按更新后的真实后继评价 `current_old`，另分开报告 revised 和 unchanged；不把正确修订当作旧答案遗忘。每点测全部字节 bits/byte 和预测准确率，另分开报告旧键、新键、改写键及未改键的后继准确率。预顺序损失、更新量、CPU、持久状态字节数、临时副本成本一起报告。

## 三轮练习

1. 因果接口：先预测后观察、写入地址不含当前字节、每个普通字节的更新、独立出生和原生状态贡献。使用 DEV 810001。
2. 完整生命史：获取、两段 24 小时休息、新流、修订及 W/N_OLD/N_ALL；查同流同钟、探针不污染和实际原生写入。使用 DEV 810101，独立重算行为指标。
3. 冻结候选：使用 DEV 810201–810204 完整流程；加入中途保存恢复与不中断状态一致、输入/记录篡改拒绝、IID 不可预测参照、资源测量。不得将这些 DEV 世界再用作正式样本。

每轮保留运行前的设计、代码快照、实际日志、收据、审核问题和修订。技术修正不抹去失败。DEV 行为已被查看，因此任何后来选择的配置只可在新样本上确认。

## 资格和后续科学门槛

技术资格要求零未来泄漏、零隐藏教师、四次独立出生、禁写原始 alpha 更新为零、实际原生输出依赖、检查点恢复精确一致、独立记录审计通过。行为可行性预先要求：旧键获取至少 90%；第二天后旧键比旧流结束最多下降 5 pp，W−N_OLD 至少 25 pp；新键至少 80%；修订键至少 80%，未改键至少 85%。同时全部字节损失必须优于 N_ALL，不能只有目标槽收益。第三轮四个新 DEV 世界以世界等权均值检验这些可行性门槛，并完整报告每个世界的最低项；第一、二轮不混入这个均值。未达门槛明确 BLOCKED，不用几何指标代替。

N_ALL 的概率必须始终为四个 0.25。平衡旧、新键的固定 tie 输出恰有 25% 准确率；修订子集或全部字节的频率不一定平衡，其固定 tie 准确率等于实际 `0` 频率，不能机械标为 25%。真实随机 IID 流使用独立新流评价，作为不可预测参照；固定 context 计数器只从实际观察累积计数，作为可学习性的反模型。

资格通过后才可提请正式运行：32 个新世界 811001–811032，每世界三条学习生命史，96 lives、122,880 个学习字节；测试克隆和恢复验证另计，不假称新增独立样本。world 是统计单位，不能把字节当独立样本。正式采用为交集门槛：day2 保持的 W−N_OLD 和全部旧探针字节的 `N_ALL bpb − W bpb` 的配对 95% Student t 下限为正，day2 旧键平均至少 90%，day2 相对旧流结束的配对 95% 下限不低于 −5 pp，新学/修订/未改内容分别达上述阈值。所有门槛均须通过，属于交集检验而非挑选多项成功；次要结果全部描述性，不能挑最好的检查点。E3 未测不阻断本自主获取保持合同。

正式 run 的时间上限为 10 小时，使用已测 DEV CPU 上界估计后再锁定工人数；预算不足不缩 n 或改门槛，安全暂停完整检查点，须用户授权才能续跑。此请求只授权三轮练习，不启动该 32 世界实验，不上传 GitHub。

## 可以得到什么

通过仅说明：工程固定字节地址已经接入能由普通观察自己更新的原生记忆，且在本次容量、字母表和时钟下能够获取、保持和修订。精确 context 计数器也能解决本任务，因此不声明发现了智能、关系推理或优于查表的算法。新的核心机制比较须给基线与候选相同信息和资源合同；后续结构更改依据实际保持或写入不足，不重新开展无目标的编码器诊断。
