# 自主观察学习路线与三轮练习结果

三轮设计、审核、试跑、修订已经完成。最终状态为 **DEV_QUALIFIED_SCIENCE_NOT_STARTED**：技术资格和四个新 DEV 世界的预设均值门槛通过，正式确认尚未启动。选择 A_NATIVE_OBSERVATION，B_PREDICTIVE_HEBB 保留为结构备选，不自动扩展实验。

## 保持的阶段目标

只解决连续字节读取与原生记忆的有效衔接：先预测，后观察，以实际观察误差更新 Full151，随后保持、再学习和修订。没有实验器提供的奖励、正确性 bit、答案位置、阶段编号或 Teach 调用；没有监督热身。四个输出仍是固定工程通道，模型没有额外训练的预测矩阵。每个普通字节都预测和更新，并非仅答案槽学习。

输入是 ASCII `0123`，最近四个原始字节驱动固定地址；16 个旧 context，8 个新 context，8 个旧 context 后继被修订。固定 context 计数器也能解决后继记忆任务。本结果支持开发可行性，不能升级为 E3、自然语言、开放生成、通用智能或新核心已采用。没有证明这种构件在 CPU 效率上优于查表，也没有证明长串、更多输出或关系泛化。

## 原生状态归因与资源

四份 Full151 每份各调用 canonical fresh birth，快慢状态无别名。内部 signed error 使用到来前的预测和 KC 活动；真正收到 byte 后才更新。保存中途、处于 prediction 待观察状态时，恢复后的 fast/slow/adapt 数组与不中断运行逐位相同。禁写数组与直接 native no-plastic event 相同，不只相信写入开关或日志标签。独立 IID 新流准确率 24.41%、2.00043 bits/byte，未被当成可学习阳性任务。

每模型原生可变数组加四字节历史 payload 为 662,660 bytes（约 0.63 MiB）；不含连接等固定资产、Python/Numba 运行时、至多 256 个固定 receptor cache、待更新活动和临时副本。当前更新与读出仍有全状态复制和全 KC 运算，**不是可扩展稀疏算法**。

W 的 1,280 字节观察平均消耗 6.45 CPU 秒，约 5.04 ms/byte；含三分支、出生及冻结探针的一整个 DEV 世界平均 25.74 CPU 秒。单位观察与算力指标是同合同的后续比较基线，不能把重复观察的 1,280 bytes 当成 1,280 条不同新知识。

## 下一步与停止边界

直接进入同一合同的新样本确认准备，不再先开编码器诊断、换目标或扩展到 NLP。正式计划 32 新世界、96 条训练生命史、122,880 个训练字节，仍是同一 24-context 容量与四输出任务。按本机测量，加一倍运行余量，单进程约 29.3 分钟；这是估计，不是保证。正式 IDs 当前被 DEV runner 硬拒绝，正式实验没有启动。

确认门槛见 EXPERIMENT.md。通过才可把它作为自主观察学习的基线；失败则保留负面结果并不扩大样本。有限关系泛化仍未测，是 nice-to-have。以后比较新核心机制，基线和候选必须使用同样输入、观察预算与输出，并计 CPU、状态和实际更新；不能把外挂预测器的改进归给原生核心。
