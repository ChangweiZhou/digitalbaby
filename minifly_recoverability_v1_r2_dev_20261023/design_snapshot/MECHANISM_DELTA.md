The old ImportanceMemory source credits feature energy using **post-update reliability** and divides a four-output delta write by `1+strength*usage`. CREDIT instead evaluates pre-update correct native bits and a declared local contribution proxy, bounds and time-decays its trace, and multiplies native fast0/fast1/slow *plastic increments* without changing passive evolution. That is an operational distinction, not proof the new variant will work. The contribution proxy ignores gamma/clipping effects; failure can invalidate the proxy without excluding all protection mechanisms.

STOP-ONLY separately removes the eight learned payload outputs from V1's external head. It is a readout restriction, not another native memory mechanism. No result from either proposal is currently available.
