## What changes in the diagnosis

1. An output-local categorical objective is mathematically implementable and can exploit conditional information when useful context values are supplied. This clears a limited output-circuit feasibility question.
2. A simple learned class bias matched or beat learned code on the conditional fixture. Do not promote learned code as a necessary representation mechanism, or mistake output-only context keys for native abstraction.
3. Under the same modest one-pass native budget, the old rule outperformed both new rules. None beat unigram, and none generated EOS in the 96 continuations. Native coupling and dose remain unresolved; toy success cannot authorize adoption.

## Evidence that should guide a separately specified next pilot

The native response audit found that B/C supplied roughly one quarter of A's mean squared teaching-coefficient magnitude (about 0.0066–0.0067 versus 0.0256–0.0260). Their centered native values and logit spans were also smaller. A common numerical rate therefore did not equalize effective native teaching strength. This is an observed confound for interpreting failure, not evidence that increasing the rate will solve it. Native learned-code drift was about 0.28–0.29, versus about 4.34 on the conditional output-only fixture; those are different input distributions and cannot establish an optimal dose.

A next design should first specify a small paired native response assay: measure local change in correct log probability per paid teaching event, signed coefficient, native output displacement, interference with another context and actual CPU. Separate direct output-state learning from the response of the unchanged native stores. Select any gain-matching rule using training-only, predeclared quantities before development outcomes; preserve an unchanged common-rate arm. Include the shared-bias control if testing learned-code necessity. No automatic normalization, additional pass, rate sweep or continuation is performed by this revision.

Only after a measured coupling hypothesis survives that bounded assay should a new fixed-budget native comparison be proposed. Charge calibration, repeated samples and all arms. Report own-byte/EOS results alongside loss. Advancement requires improvement at matched total sample/compute cost; retain the original arithmetic holdbacks for an explicitly authorized later addition evaluation. Do not infer arithmetic competence from text likelihood or a fixture with perfect context keys.
