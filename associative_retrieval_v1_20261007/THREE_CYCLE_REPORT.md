# 三次设计—审核—试跑—修订报告

2026-10-07。三次循环已经完成；本次没有启动正式筛选或确认实验。

**结论：有界关联检索的技术路径通过。当前一个开发世界保持了已教内容，但没有获得未教关系上的增益，因此尚不能采用为新核心。** 下一步若正式运行，只执行已经锁定的八世界筛选；不能跳过筛选直接进入六十四世界确认，也不再根据这个开发世界调整参数。

## 目标与设计

目标仍是用给定的新经验和算力改进持久记忆核心，保持字节接入、学习、保持和修订，并尝试有限的经验复用。没有增加智能、自然语言、开放输出或新编码器要求。

候选 **LINK** 保存最多 64 对实际观察到的 FE0 共享地址与 CONTENT 私有地址。查询时按共享地址相似度选择最多四条旧关联，通过当前 Full151 私有记忆读出其值，再以固定半权重加入已有 ERROR 输出。表中没有答案、类别、题目字符串或“已教/未教”标记。关联更新只依赖曝光过的题面；W 和禁写对照看到相同字节并形成相同关联，只有原生教学写入不同。

ERROR 是现有基线；PERM 用固定置换打乱检索目标地址，保留查询和资源结构。八份 Full151 各自独立出生，原生写规则不变。三个条件共用经验证相同的原生生命史：这个环境的下一条输入与教学不取决于模型输出，所以没有必要将原生学习重复三遍。这不适用于输出会改变环境的后续实验。

## 最后一次修订的证据边界

完整生命史在修订前版本完成。新增检查造成约 26% 教学 API 开销，最终只移除了两个围绕只读副本的重复全状态哈希扫描；检索和写入的数学路径保持原样。

六个保存的最终状态共 336 行查询，其值、地址、权重与输出在修订前后完全一致；24 个丢弃副本上的未来事件测试、最终单元测试及十四类篡改回归通过。没有重跑已完成的完整生命史。安全边界恢复在修订前完整版本验证；最终版本没有另跑一次完整恢复生命史。原始源码、收据与检查点全部保留，最终源码另有锁定记录。

## 成本与正式实验边界

- 新增可变关联数组 **131,840 字节（128.75 KiB）**；固定置换诊断另用 **20,708 字节**。原生状态、Python 对象和临时缓冲另计。
- 完整开发测试合计 **386.57 CPU 秒、391.43 worker 秒**；双任务并行的练习墙钟约 **6.2 分钟**。峰值 RSS 约 **519 MiB**，技术文件约 **24.6 MiB**。
- 最终版在已保存最终状态的事件 API 样本中，LINK 开销为基线的 **1.082 / 1.074 倍**。这是局部测量，不能当成完整正式运行的保证。
- 用较慢的原始完整运行外推，并加 1.5 倍余量：最大八世界筛选加六十四世界确认约 **11.7 worker 小时**；八进程理想墙钟约 **1.5 小时**，还须计入启动、分析和并发损失。存储保守估算约 **2.54 GiB**。这些是一个世界的外推，不是尾部时间保证。

正式方案先筛选 **8 个新配对世界**；只允许这一固定候选通过后进入 **64 个另外的新世界**。最多 144 个物理任务、432 条原生生命史、279,936 条记录。增益目标至少 5 pp，同时保护旧/新/修订 E1、检查真正 W−N 因果增益及单位运行 CPU 的能力收益。筛选失败就结束这一配方，不增加新候选、种子或补丁实验。

正式调度器、分析/打包流水线与十小时会话控制尚未上线。本次授权的三轮练习已结束；没有后台 science 任务，也没有 GitHub 上传。四可见字节窗口、四答案、提示输出及到来答案教学的原有限制仍明确保留。
