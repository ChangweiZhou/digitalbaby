# Cycle 2 — attribution and causal refinement

The executable rule is unchanged from cycle 1. The review closes these ambiguities:

1. This is coherent bounded address-pair storage, not a dense KC×KC graph and not a biological circuit claim. It stores 64 pairs of activity codes, not labels. It deliberately has a finite capacity and inherited four-visible-byte collisions.
2. Adding retrieved values could double-count support; the fixed half-gain is an unoptimized engineering hypothesis. Channel centering removes common offset but does not calibrate uncertainty. No confidence/taught-status gate is introduced.
3. The extra associations are unsupervised exposure state. W and N must update them identically. The native old-teaching intervention alone supplies the causal difference. Turning association learning off with N would confound two interventions.
4. All reported conditions have exactly the same native trajectory because original private-only probabilities determine every write. ERROR and PERM can be evaluated as exact counterfactual readouts of the integrated LINK trajectory. This saves native runs; it does not make their added readout costs free. Eight actual stores still require eight separate canonical birth calls.
5. PERM preserves side/eligibility/writable strata and capacity, but not individual Q/T amplitudes, value norms or a natural cue's geometry. A diagnostic contrast supports the tested correspondence; it cannot prove all internal feedback mechanisms useful.
6. Basic cue→answer timing is already implemented. This candidate addresses retrieval and does not reopen byte encoding or delayed eligibility.

Tests now require actual native no-write transitions, unchanged ERROR states/outputs, cached pre-answer addresses, actual retrieved activity vectors, independent readout arithmetic, legal API boundaries, snapshot tampering, and clone independence. Test fixtures cannot choose parameters or replace failed development worlds.
