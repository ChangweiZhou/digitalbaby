# Cycle 1 — bounded associative retrieval design

7 October 2026. Technical development only; no science authorization.

The stage goal remains a bounded byte-input memory core that acquires, retains and revises taught information and supports modest structured reuse. We change one operation: shared FE0 activity retrieves previously associated CONTENT addresses. This is an engineered associative-memory mechanism informed by ledger M045/M048/M061–63/M094, not a demonstrated native fly circuit.

Eight independently born canonical Full151 stores, byte interfaces, clocks, actual-answer-byte teachers and ERROR private prediction-error writes remain unchanged. A 64-slot FIFO stores only sparse shared/private KC address pairs. It never stores an answer, cue name, world, stage or taught flag. Repeated private addresses update their shared observation without refreshing insertion age. Sparse addresses may contain at most 256 KCs; overflow fails rather than truncates.

At a query, choose at most four slots by shared cosine similarity, ties oldest insertion then slot. Positive similarities are normalized to sum one. Read the native private memory at each coherent saved address. Average those four-channel values with the similarities, then add half their channel-centered value to the original ERROR output. Private teaching probabilities continue to come only from the original exact-address private values. Retrieval does not write or replay teaching.

The extra associations are cue-only learning: after a completed record they use cached pre-answer addresses, even in a native no-write branch. Their evolution must therefore be identical in W and N_old for matched streams. Feedback supplies no association target. Native old teaching remains the causal W/N intervention. An empty table contributes zero.

Conditions: ERROR reference, LINK candidate, PERM diagnostic. PERM changes the retrieval target through one fixed KC permutation preserving side, encoder eligibility and writable support. It has identical slot capacity, query selection and operation count; realized output magnitudes are not claimed identical. This distinguishes a useful correspondence from merely adding another read.

Only the existing lifetime and wrapped binary relation fixtures are used. E1 and limited E3 are separately reported; no new autonomy, natural text or arithmetic requirement. Exact-key recitation explains E1 but cannot determine never-taught relation answers. A learned simple class rule is sufficient E3; no demand for complex reasoning.

Cycle 1 tests: sparse-address validity, finite capacity, tie/FIFO rules, no answer API, self retrieval, clone isolation, empty-table behavior and malformed snapshots. Native integration and actual no-write audit are scheduled in cycle 2. Complete existing development lives, fresh-process resume and resource measurement are scheduled in cycle 3. Development scores cannot select the gain, capacity or neighbour count.
