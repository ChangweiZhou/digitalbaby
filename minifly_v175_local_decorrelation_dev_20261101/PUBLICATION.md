# V175 development publication

Results, code, cycle audits, preserved technical-failure summaries, calibration scalars, source/checkpoint receipts and revised design are published to the existing consolidated branch. The version index records completed development, not adoption.

Raw opaque mappings, calibration input prompts, individual output/code/shadow panels, event ledgers, native binary states and the local ZIP are excluded. The local result ZIP contains raw response panels and must not be uploaded under the no-raw-data publication policy. Paths to omitted local assets in receipts are intentional.

Frozen design-only and pre-publication fields are historical snapshots. The subsequent three-cycle request authorized this execution; publication does not rewrite those snapshots. Original technical failures and the interrupted dispatch are preserved locally and summarized honestly. No completed main history was repeated, no efficacy gate was changed, and the core is not adopted.
