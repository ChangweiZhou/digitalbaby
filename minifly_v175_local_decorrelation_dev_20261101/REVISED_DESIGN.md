## What to retain

The native writer, gradual warmup and own-byte/EOS endpoint remain the operative baseline. Nonzero inhibition does not have to change every individual input code; technical correctness is established by independent formula parity and population counts. Mechanism activity is measured separately on actual learned main states. The original requirement of some nonzero learned code change remains in P2.

Do not equate learning a local coactivity trace with learning useful pattern separation. Report whether codes actually moved, whether OLD/NEW overlap decreased, whether existing addresses drifted, and whether complete answers improved. These are distinct results. Do not reduce the0.05 overlap screen or8-item capability screen after observing a near miss. They are operational screens, not mathematical impossibility boundaries.

## Next prospective design

Do not adopt or automatically retune LPS-16-D1. This exact sparse one-pass cue-coactivity rule did not pass the complete registered development screen. A failure here is not a family-wide impossibility result for inhibitory circuits.

The next useful contrast should localize value-write protection versus address movement on the existing native substrate. Prefer one generic local fast/slow consolidation/protection candidate with the calibrated writer held fixed, rather than adding replay, a different gamma, more neighbors or more rounds to this opened experiment. Any new coefficient, connectivity or learning-rule change needs a prospective design and fresh worlds. The circuit must learn its protection signal only from local activity and genuine past feedback, never OLD/NEW IDs, expected future outputs or arithmetic structure.

A prospective test should retain writer-enabled versus inhibited observations with exactly matched clocks, and include a correction phase so protection cannot win by permanently freezing all earlier associations. If instead inhibition is pursued, first use an independent unlabeled technical fixture to establish that the proposed circuit meaningfully changes the relevant address overlaps at bounded cost; that is engineering calibration, not a new efficacy claim on V175 worlds. Keep a frozen-inhibition comparator to distinguish the circuit’s static conditioning from its plasticity.

## Limits retained

Only E0/E1/E1-R were tested. Exact-key lookup can solve every scored association. No unseen addition, E3, broad language learning or core adoption was established. Keep gradual warmup, local rules and native byte/EOS output; no attention/Transformers/ELM, arithmetic features, task-specific model circuitry or external answer decoder. No follow-up is launched by this document.

Source/metadata discipline for a future run should capture phase runtime and calibration artifact hashes explicitly before admission, record embedded shadow cost separately from live teaching cost, and preserve failed partial states before assertions. This report does not retrofit a production-efficiency claim onto instrumentation-heavy development code.
