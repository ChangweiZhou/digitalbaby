# MiniFly v4 three-cycle engineering contract

User-authorized implementation, audit, bounded test runs and revision of Claude commit 190a26c. Not a formal campaign or adoption. The received memo is preserved verbatim in CLAUDE_RECEIVED.md; v3 files and results remain unchanged.

## Fixed objective and evidence

Retained exact own-byte-output unseen **addition** generalization per every external/replayed training presentation and measured compute. E0 interface and E1 taught acquisition are diagnostics; E3 requires an advantage on never-reinforced operand pairs over no-prior-learning and shuffled-label controls. Subtraction, decimals, evolution and trimming are deferred. They cannot rescue addition failure.

## Audit corrections before tests (cycle 1)

The memo's statements that single-digit sums are necessarily atomic, that the fitted linear readout is a best possible bound, and that recurring KC writes must be arithmetic columns are hypotheses, not established facts. G0 is an empirical feature-readout diagnostic: failure may reflect boundary policy, representation, sample size or oracle fitting. Teacher-forced byte accuracy never replaces own-output accuracy. We preserve the 95% G0 stop for expensive P3, without calling it an impossibility proof. No enlargement after observing test labels beyond the two predeclared sizes.

A3 is implemented as a bounded generic segment buffer, with explicit left-to-right byte slots reversed upon a learned closure. This is the exact finite closure-snapshot version of the otherwise unspecified multi-rate reconstruction; it supplies no arithmetic role or delimiter. Its storage is counted and overflow is logged. A2 sees all bytes as eight bits; no byte is listed as a boundary. At birth all weights are zero, giving probability 1/2 in exploratory training; deterministic evaluation uses probability >1/2. This distinction is logged, and neutral deterministic boundary failure is a diagnostic, not a learned model result.

A4 samples a generic fixed position window (width 1/2/4/8) over all three closed segments, plus segment age, generic time-cell phase, current byte bits and recent byte traces. All slots, including arbitrary nonnumeric payloads, are equally valid. Random-fan-in lesion uses the same feature space, fan-in and active count. No semantic operand/output-column alignment, hard-coded byte identity, arithmetic codebook, arithmetic target or answer parser exists inside the learner. Native KC sparse projection with local homeostasis and native value equations remain the answer route. Global KC scans/top-k remain a measured development limitation, not a scalable sparse-compute claim.

Native P0 is compared at 5,177 cells against the qualified v3 native kernel. Larger Q/T/readout rows are sampled with replacement from that native population; Q/readout rows are normalized by native-N/new-N, while local teaching T rows retain native magnitude; this is an explicit scale extrapolation, not full-engine parity. Consolidation changes only alpha fast/slow allocation; native gamma state, feedback, saturation, adaptation and readout are preserved. Both candidate and native allocation arms receive identical births/streams.

A6 tracks per-output/per-KC signed confirmation q and last confirming **content identity**, not presentation index. Repeating an identical whole record cannot itself add confirmations; distinct records that recruit a synapse can. q decays with simulated time; q increments at most once per synapse per record, and allocation uses the updated q. Contradictory signs cancel. A signature is provenance only, never an answer key or a retrieval route. Selectivity for reusable information remains unproved. The specified sigmoid is a soft gate: even with f_min=0, q=0 permits about 0.899% slow allocation. It does not literally make every unconfirmed write temporary; this leakage is measured rather than hidden.

Warmup starts at 1/16. Fixed generic probe contexts measure Jaccard drift every 16 external records; two consecutive drift values <=0.1 permit an increment of 1/16. Homeostasis learns only in the first 256 distinct external records. Replay preserves actual observed targets and content identity, counts all applications/bytes/CPU, does not advance external-distinct exposure, and cannot confirm the same record twice in succession. N history disables writes, q, boundary and homeostasis updates but retains sensory exposure and clocks. Rest advances native time, applies the declared slow downscale, and replays up to eight previously observed records from a 32-record ring.

## Finite three-cycle sequence

1. Native parity, q-consistency/time/record-identity fixtures, all-byte IO, generic segment/boundary/overflow fixtures. Revise numerical/chronology defects only; preserve failures.
2. Lock readout/data/exposure definitions, G0 at 65,536 and 262,144 KCs (128 training and 64 held records, ordinary 2–4 digit strings). Compare neutral deterministic and independently seeded exploratory boundary policies and random fan-in. Oracle fits expected bit targets only in the evaluator; it is never an answer module or a learning candidate. Fit/reduction CPU is separate. Record possible feature collisions and teacher-forced/own-output distinctions.
3. G1 bounded sanity at 65,536 KCs: B0/B1/B2/B3 and random-fan-in B3, with 64 fresh addition records per arm, no pass-based repetition; B4 optional single-digit phase is deferred until shared prerequisites work. Preserve a no-write sensory history and shuffled-label control for full B3. Score taught and disjoint unseen probes before/after one day and bounded replay; count replay in all budgets. If G0 fails, these are only G1 diagnostics and no full G2/S1 efficacy run is authorized by this exercise. Revise the delivered design with actual results and next prerequisite.

All seeds, sizes, rates, gates and budgets are in SPEC.json before training. No search on HELD, no automatic bigger model, no added task or relaxed accuracy gate. Repeated presentations, partial fixtures, target bytes, replay applications, correlated histories and read-only evaluations are reported separately. Exact native parent parity checks supply the implementation positive control; generic one-record recall supplies E1 sanity. Frequency/exact-key defaults are evaluator-only shortcuts. No E3 claim without all causal controls and exact scoring.

## Cycle-2 audit revisions before cycle 3

G0 failed in all six registered size/policy/wiring cases. Test byte correctness ranged from 5.39% to 9.13%, versus 100% fitted training byte correctness; every teacher-forced held record was wrong. These are descriptive feature/oracle results, not native scores. The large P3/G2 run is stopped. A G1-only third cycle proceeds at the smaller registered size.

Static chronology review found that the first wrapper decayed native state during input without applying passive KC adaptation on every byte. Cycle 3 repairs this: passive native events occur before each arriving input, and own-output queries use an isolated native-state fork with the same passive chronology. The snapshot of the earlier wrapper remains in cycle 2; the native kernel itself is unchanged. A checkpoint/causal preflight tests the revision before the S1 sanity records. All generic neuron weights are now paired between topographic/random lesions using a separate weight RNG. No held score selected these corrections.

A2 is trained by a stochastic local policy. The primary native query therefore samples from a private copy of that frozen policy/RNG; it does not switch to greedy thresholding while the training probabilities remain near one half. A secondary greedy-policy result is reported, never selected for scoring. Sensory no-write histories still sample boundaries and advance their RNG, while weights, homeostasis, q and value writes remain off. This repairs a potential control mismatch. Both G1 worlds and all seven histories (five arms plus B3_N/B3_SH) are reported regardless of outcome.

The third-cycle replay-zero check exposed a controller/wrapper defect: Python [-0:] replayed the full 32-record ring when zero was requested. The invalid first B0 history (64 external +40 replay) and four generic preflight applications are retained as failed technical work, not accepted results. The earlier empty-set digest failure used four generic applications and zero S1 records. The corrected third cycle uses fresh technical worlds 202610204451/4452, explicitly tests zero replay before training, and preserves provisional receipts before acceptance checks. No efficacy threshold, model size or task was changed.

A subsequent source-to-port audit caught the bit wrapper's reversed teaching sign: the native positive coefficient **lowers** its readout, so native teaching takes positive prediction-minus-target residual, as in the pinned parent. The earlier native-event parity check had not tested the new wrapper's directional learning. Six complete wrong-sign histories and 16 whole records in a seventh were preserved as invalid technical work, plus four preflight applications; they support no model verdict. A new native directional-loss fixture and a 16-record arbitrary-byte positive control precede the corrected G1 worlds 202610204461/4462. The current source uses the native sign; no gate, arithmetic feature or size changed. The future dispatcher also checks an explicit STOP_ADMISSION flag before any new job.
