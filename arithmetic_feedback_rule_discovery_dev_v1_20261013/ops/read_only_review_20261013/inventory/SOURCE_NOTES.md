## Current disposition

The next design should isolate generic chronological access and coherent learning credit while keeping the current held-out arithmetic task, own-byte output and actual feedback boundary fixed. The archive supports concrete source lineage for these choices; it does not establish that they will work.

Read-only RAW fixtures are technical evidence, not fresh world-level scientific rejection. Older topology, protection, release, replay, forgetting and consolidation recipes retain their exact verdicts. Acquisition now fails even before intervening learning, so retention-first mechanisms are lower priority for this next package. This is a scheduling decision under the same goal, not family-wide elimination.

Any E1 rescue remains only acquisition evidence. Promotion still requires retained held-out four-operation accuracy gains against equal-information causal histories and matched architecture controls, plus sample and compute curves. An exact associative fallback may be a memory control but cannot stand in for learned arithmetic laws.
